IdentityGuard Server 12.0 Administration Guide

Disallowed Password Settings

These properties control disallowed passwords within an enterprise. For information about managing passwords, see Set disallowed password properties for more details and to view a snapshot of the properties.

Disallowed Password File Name

identityguard.disallowedpasswordfile.name

When Entrust IdentityGuard starts up, it looks for the file and location given in this property. If you do not specify a location, Entrust IdentityGuard does not check for disallowed passwords.

Maximum Number of Disallowed Passwords

identityguard.disallowedpasswordfile.maxentries

Sets the maximum number of entries allowed in the disallowed password file. If the file contains more than the maximum number of entries, the extra entries are not read.

A setting of or an empty file disables password checking.

Default: 1
