IdentityGuard Server 12.0 Administration Guide

SMTP Server Configuration

To use the Entrust IdentityGuard OTP email feature and to enable user email delivery and audit email delivery, you must configure an SMTP or SMTPS server.

Configuration Instance

Provides a list of SMTP configurations.

To create a new instance. enter a unique service name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

SMTP or SMTPS

identityguard.smtp.{0}.usesmtp

Choose either SMTP or SMTPS for this instance.

There is no default.

SMTP Server Host

identityguard.smtp.{0}.mail.smtp.host

This property specifies the SMTP server to connect to. This can be a host name or an IP address.

Note: This property is not used if this server is an SMTPS server.

SMTP Server Port

mail.smtp.port

Optional. This property specifies the SMTP port.

Default: 25

Note: This property is not used if this server is an SMTPS server.

SMTPS Server Host

identityguard.smtp.{0}.mail.smtps.host

This property specifies the SMTPS server to connect to. This can be a host name or an IP address.

Note: This property is not used if this server is an SMTP server.

SMTPS Server Port

mail.smtps.port

Optional. This property specifies the SMTPS port.

Default: 465

Note: This property is not used if this server is an SMTP server.

Perform SMTP User-based Authentication

identityguard.smtp.{0}.mail.smtp.auth

If this property is true, Entrust IdentityGuard attempts to authenticate the user to the SMTPS server.

This property only applies if an SMTPS server is being used.

Default: False

Note: Perform SMTPS User-based Authentication and Perform SMTP User-based Authentication are mutually exclusive. They cannot both be true at the same time.

Perform SMTPS User-based Authentication

identityguard.smtp.{0}.mail.smtps.auth

If this property is true, Entrust IdentityGuard attempts to authenticate the user to the SMTP server.

This property only applies if an SMTP server is being used.

Default: false

Note: Perform SMTPS User-based Authentication and Perform SMTP User-based Authentication are mutually exclusive. They cannot both be true at the same time.

User Name for SMTP/SMTPS User-based Authentication

identityguard.smtp.{0}.mail.smtp.user

This property specifies the user name for SMTPS or SMTP authentication, and is used if SMTP or SMTPS user-based authentication is enabled.

Example: IGtest12@gmail.com

Password for SMTP/SMTPS User-based Authentication

identityguard.smtp.{0}.mail.smtp.password

The password used to authenticate the SMTP or SMTPS user to the SMTP/SMTPS server, and is used if SMTP or SMTPS user-based authentication is enabled.

Select Encrypt to encrypt the password when storing it.

From Email Address

identityguard.smtp.{0}.mail.smtp.from

This property is mandatory. This is the email address associated with the account from which all Entrust IdentityGuard messages are sent.

Example: igadmin@anybank.com

Enable Debug Logging

identityguard.smtp.{0}.debug

Set this property to True to enable javamail debug logging.

When javamail debug logging is enabled, detailed information about email messages—including the email message content—is output to your application server’s log file, or to the screen (if you are using the Master user shell). For example, if you run the command user otp deliver jsmith “Home Email” in the Master user shell, the content of “Home Email” is displayed on-screen when Enable Debug Logging is True. Since email messages may contain sensitive information, such as OTPs, only enable debug logging temporarily for troubleshooting purposes.

Default: False
