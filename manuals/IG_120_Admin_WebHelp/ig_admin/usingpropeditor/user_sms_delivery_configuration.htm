IdentityGuard Server 12.0 Administration Guide

User SMS Delivery Configuration

Your application can automate the delivery of smart credential information using a text (SMS) message to a cell phone. Using the following properties, you can set up delivery the card PIN and unblock response, for example, through SMS. For more details, see “Configuring smart credential SMS delivery” in the Entrust IdentityGuard Smart Credentials Guide.

Configuration Instances

SMS Delivery Class Name

identityguard.smartcredential.delivery.sms.{0}.impl

Sets the Entrust IdentityGuard Java class used for communicating with SMS. When you select SMS, this sets this class:

com.entrust.identityGuard.common.smartCredentialDelivery.sms.SmartCredentialSMSDelivery

If you choose Custom, you must program your own SMS delivery implementation.

SMS Delivery Configuration Display Name

identityguard.smartcredential.delivery.sms.{0}.displayname

The name you use to identify this delivery mechanism.

This is the name you see in the Administration interface when associating the user contact information to the delivery method.

Default: none

SMS Delivery Configuration Type

identityguard.smartcredential.delivery.sms.{0}.type

The content of the SMS message. Options include:

–  Grid – Used to deliver a grid to a user.

–  Password – Used to deliver a password.

–  PVN – Used to deliver a PVN.

–  Token – Used to deliver soft token information.

–  Token Activate – Used to deliver a mobile soft token QR code and password to a user.

–  User – Used to deliver

–  User Temporary PIN – Used to deliver a temporary PIN.

–  Smart Credential Activate – Used to deliver smart credential information.

–  Smart Credential PIN – Used to deliver the smart card PIN to the user.

–  Smart Credential Unblock – Used to deliver the unblock code to the user.

–  Smart Credential – Used to deliver any details about the smart credential to the end user or administrator. For instance, it can be used to send an email with the building access number to the facility manager.

SMS Delivery SMS Server

identityguard.smartcredential.delivery.sms.{}.sms

Select the SMS Server from the drop-down list.

This list of servers is defined using the SMS Server Configuration properties.

SMS Delivery Template File

identityguard.smartcredential.delivery.sms.{0}.template

Provides the location of the SMS template. Entrust IdentityGuard provides two sample SMS templates:

●        igsample_sms_cardpin_template.txt

●        igsample_sms_unblockresponse_template.txt

You can configure the templates as required in a text editor. This template is used by Entrust IdentityGuard to create each message sent to a user.

For both Windows and UNIX, the value is $identityguard.home/etc/templates/smartCredentials/<template>

where <template> is the name of your template. IdentityGuard automatically replaces $identityguard.home with the correct value.

SMS Delivery To Address Type

identityguard.smartcredential.delivery.sms.{0}.totype

The type of SMS delivery type you want to use. Options include:

–  Variable – This is a variable SMS, which dynamically changes based on the smart credential enrollment value. For example, if your definition includes smsaddress as a variable for SMS, it uses the user’s SMS address collected during enrollment and stored under the smsaddress variable for their smart credential.

–  Constant – This is a hard coded SMS address that is used for all SMS messages of this type. You must define that specific SMS in the SMS Delivery To Address setting below.

SMS Delivery To Address

identityguard.smartcredential.delivery.sms.{0}.to

Provides the destination of the SMS message. This is dependent on your selection of the SMS Delivery To Address Type setting above.

If you selected:

–  Variable – The value of this property is a variable name of one of the smart credential enrollment values. The value of that variable is used as the destination address. For example, if your definition includes smsaddress as a variable for sms, enter that variable here.

–  Constant – The value specified for this property is used as the destination sms.
