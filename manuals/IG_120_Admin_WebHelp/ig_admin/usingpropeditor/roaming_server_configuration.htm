IdentityGuard Server 12.0 Administration Guide

Roaming Server Configuration

These properties configure one or more Entrust Authority Roaming Servers that are used when registering or importing user credentials for smart credential identity assured operations.

These properties are used in the migration of Roaming Server digital IDs to Entrust IdentityGuard smart credentials. For more information, see the Entrust TruePass to Entrust IdentityGuard Migration Guide.

Configuration Instances

You can create multiple Roaming Server configuration instances.

To create a new instance, enter a unique label in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To use multiple Roaming Servers that are mapped to Entrust IdentityGuard groups, give each Roaming Server the name of a group when you create it. This means that you could have configuration instances named, for example, marketing, development, and humanresources,

Note: To use the group mapping feature, user IDs must include the group name at login. For more information, see the Entrust TruePass to Entrust IdentityGuard Migration Guide.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

Host

identityguard.roamingserver.{0}.host

Specifies the host name of the Roaming Server.

Port

identityguard.roamingserver.{0}.port

Specifies the port number used by the Roaming Server.

Roaming Server Attribute

identityguard.roamingserver.{0}.attribute

Specifies the name of the LDAP Directory attribute that Roaming Server is using. It must be the same as the User id attribute name configured in the Entrust Authority Roaming Server Configuration application.

Group

identityguard.roamingserver.{0}.group

Specifies the Entrust IdentityGuard group that will use this Roaming Server configuration instance.
