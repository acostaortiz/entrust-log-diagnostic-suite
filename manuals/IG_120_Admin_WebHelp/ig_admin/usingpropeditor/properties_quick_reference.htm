IdentityGuard Server 12.0 Administration Guide

Properties quick reference

This section lists, by property category, all properties that administrators can set in the Properties Editor.

In Properties Editor screens, properties marked with a red asterisk are required.

Note: If you are required to work with configuration files directly in Microsoft Windows, ensure that file extensions are visible. See Ensure that file extensions are visible in Windows Explorer.
