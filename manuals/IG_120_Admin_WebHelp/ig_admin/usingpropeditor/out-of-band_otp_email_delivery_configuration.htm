IdentityGuard Server 12.0 Administration Guide

Out-of-Band OTP Email Delivery Configuration

Your application can automate the delivery of one-time passwords using email, a text message to a cell phone, or voice message to a standard phone or cell phone. Using the following properties, you can set up delivery of the OTP by email.

Configuration Instances

Provides a list of email configurations.

To create a new instance. enter a unique service name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

Email Delivery Class Name

identityguard.oobdelivery.javamail.{0}.impl

Sets the Entrust IdentityGuard Java class used for email. When you select JavaMail, this sets this class:

com.entrust.identityGuard.common.oobDelivery.otp.javamail.OTPJavaMailDelivery

If you select Custom, enter a valid Java class name in the field that appears. (Used only in highly advanced deployments.)

Email Delivery Configuration Display Name

identityguard.oobdelivery.javamail.{0}.displayname

The name you use to identify this delivery mechanism.

This is the name you see in the Administration interface when associating the user contact information to the delivery method.

Default: the instance name

Email Delivery SMTP Server

identityguard.oobdelivery.javamail.{0}.smtp

Select the SMTP Server from the drop-down list.

This list of servers is defined using the SMTP Server properties. See SMTP Server Configuration (22).

Email Delivery Template File

identityguard.oobdelivery.javamail.{0}.template

Provides the location of the JavaMail template. Entrust IdentityGuard provides a default template. The template files are igsample_email_template.txt.

You can configure the template as required in a text editor. This template is used by Entrust IdentityGuard to create each message sent to a user.

In the default case, this property should contain the following, depending on whether you are running on Windows or UNIX:

●        on Windows: <$IG_HOME>\etc\templates\oob\igsample_email_template.txt

●        on UNIX: $IG_HOME/etc/templates/oob/igsample_email_template.txt

Note: Another template is available for html delivery; it is called igsample_email_template.html. The HTML formatted email is displayed along with the text version, and displayed as determined by the email client.

Email Delivery Subject

identityguard.oobdelivery.javamail.{0}.subject

Provides the text for the subject field of the email.

Email Delivery From Address

identityguard.oobdelivery.javamail.{0}.fromaddress

Provides the sender’s email address. Typically, this is an address within your organization.

Default: the server’s SMTP address

Email Delivery Reply To Address

identityguard.oobdelivery.javamail.{0}.replyto

Provides the reply-to email address. Typically, this is an address within your organization that handles customer problems and questions, and that is different than the From address.

This property is optional.

Email BCC Address

identityguard.oobdelivery.javamail.{0}.bcc

If supplied, all out-of-band emails are copied to this email address. The recipient of the one time password (OTP) does not see this address.

Separate Message Per One-Time Password

identityguard.oobdelivery.javamail.{0}.separatemessageperotp

If True, and if multiple OTPs are allowed by policy, each OTP is delivered in its own email message.

If this property is False, all OTPs are sent in one email message.

Default: False

Include Transaction Details

identityguard.oobdelivery.javamail.{0}.includetransactiondetails

Specifies how transaction details will be sent.

The options are:

–  First – The first message contains the transaction details, along with a one-time password. The following messages each contain only an OTP.

–  Separate – The first message contains the transaction details, and the following messages each contain an OTP.

–  All – The transaction details are included in each message sent, along with an OTP.

Default: First
