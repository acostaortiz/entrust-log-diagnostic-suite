IdentityGuard Server 12.0 Administration Guide

Card Export Settings

These properties control the format and location of the Entrust IdentityGuard card export operations. For information about exporting cards and to view a snapshot of the properties, see Configuring grid card export properties.

CSV Card Export Format

identityguard.export.csv

By default, cards exported through the Administration interface are in XML format. Set this to True to have all files exported in comma-separated-value (CSV) format.

Default: False

CSV Card Export Includes Additional Fields

identityguard.export.csv.includeadditionalfields

By default, CSV export format does not include grid card generated date, expiry date, superseded date, or state.

Set this property to true to include these columns in the exported file.

Attention: If you are using a CSV file in the old format with any other applications, these additional columns will cause them to stop working. Set this property to False.

Default: False

Card Export Directory

identityguard.export.dir

This setting defines the directory on the Entrust IdentityGuard server to which the card export files are written.

Default:

–  on UNIX $IG_HOME/export

–  on Windows <$IG_HOME>\export
