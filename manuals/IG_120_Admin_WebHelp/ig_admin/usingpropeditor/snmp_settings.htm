IdentityGuard Server 12.0 Administration Guide

SNMP Settings

SNMP traps can be configured for some of the audits. Each service has three traps defined: INFO, WARNING, and ERROR. You can change the list of audits that will be trapped. See Configuring audits to be sent as SNMP traps.

Audit Traps Enabled

identityguard.snmp.traps.enabled

Enables SNMP traps for selected audits. Audit traps are sent for each Entrust IdentityGuard service, including Master user shell, Authentication, Administration, Administration interface, Radius proxy, and Properties Editor.

Default: False

Heartbeat Traps Enabled

identityguard.snmp.heartbeat.trap.enabled

Enables heartbeat traps. If set to True, Entrust IdentityGuard sends a trap at every interval set in identityguard.snmp.heartBeat.interval.

All Entrust IdentityGuard services will generate a heartbeat trap if this property is enabled, except for the Master user shell. The heartbeat trap is enabled for all services or no services.

Default: False

Heartbeat Ping Enabled

identityguard.snmp.heartbeat.ping.enabled

Enables heartbeat pings. If set to True, Entrust IdentityGuard attempts a service ping in each of its services at intervals defined by identityguard.snmp.heartBeat.interval. All Entrust IdentityGuard services are checked except for the Radius Proxy service and the Master user shell.

The heartbeat ping is enabled for all services or no services. If heartbeat traps are also enabled, a trap is sent only for successful pings.

A failed heartbeat ping generates an audit called HEARTBEAT_PING_FAILED (AUD120).

Default: False

SNMP Manager Host

identityguard.snmp.manager.server

Server address of the SNMP manager. This field is required if either identityguard.snmp.traps.enabled is True or identityguard.snmp.heartbeat.enabled is True.

Note: If this string is missing or contains an error, traps are disabled.

SNMP Manager Port

identityguard.snmp.manager.port

Port number of the SNMP manager. This field is used if either identityguard.snmp.traps.enabledis true or identityguard.snmp.heartbeat.enabled is true.

Values from 1 to 65535 are accepted.

Note: If this string is missing, the default is used. If this string contains an error, traps are disabled, and an error is generated when the services are restarted.

Default: 162

SNMP Community

identityguard.snmp.community

This is a string to be used as a pseudo-password in SNMP messages. The agent and the manager are set up with the same string so that each can recognize that SNMP messages are authentic.

Select Encrypt to encrypt this value when saving it.

Default: public

SNMP Heartbeat Interval

identityguard.snmp.heartBeat.interval

This positive integer defines the frequency of the heartbeat interval in seconds. If it is an invalid value, the default value is used. is an invalid value.

Default: 900 seconds (15 minutes)

SNMP Audit Filter

identityguard.audit.snmp.filter

A comma-separated list of audit codes to be included in traps. If no value is specified, the default audit filter is used to determine which audits to send as traps.

Audits can be specified in ranges. Valid values include:

-1 (all audit with codes <= 1)

2-3 (all codes between 2 and 3)

1- (all codes greater than or equal to 1)

Note: The AUD audit code prefix is not used in this property.

Default: See default list of audits trapped in Audited event reference.
