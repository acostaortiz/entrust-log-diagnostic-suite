IdentityGuard Server 12.0 Administration Guide

Audit Email Delivery Settings

These properties control what information is audited when a call is made to the Administration Service and a WS-Security header is provided in the SOAP message.

Audit Delivery Email Enabled

identityguard.audit.smtp.enabled

Enables audit email delivery for selected audits. Audit email delivery is set for each Entrust IdentityGuard service, including Master user shell, Authentication, Administration, Administration interface, Radius proxy, and Properties Editor.

Default: False

Audit Email Delivery Server

identityguard.audit.smtp.name

Specifies the SMTP server that is used to send audit email messages. You must configure an SMTP server.

Audit Email Delivery Subject

identityguard.audit.smtp.subject

Specifies the text of the subject line of audit email messages.

Default: Entrust IdentityGuard Audit

Audit Email Delivery Template File

identityguard.audit.smtp.body

Specifies the location of the email template file. The template file provides the body of the audit email messages.

Default: $identityguard.home/etc/templates/smtp/audit.txt

Audit Email Delivery To Address

identityguard.audit.smtp.to

Specifies the address of the email account to which audit email messages should be sent. At least on of the To, CC, or BCC addresses must be specified.

Audit Email Delivery CC Address

identityguard.audit.smtp.cc

Specifies the address of the email account to which audit email messages should be copied. At least on of the To, CC, or BCC addresses must be specified.

Audit Email Delivery BCC Address

identityguard.audit.smtp.bcc

Specifies the address of the email account to which audit email messages should be copied without showing the email address. At least on of the To, CC, or BCC addresses must be specified.

Audit Email Delivery From Address

identityguard.audit.smtp.from

Specifies the email address of the sender. Typically, this is an address of an email account in your organization.

Default: email address of the SMTP server.

Audit Email Delivery ReplyTo Address

identityguard.audit.smtp.replyto

Specifies the email address to which replies to audit emails should be sent. If you do not want users to reply to the email address of the sender, specify a different email address in this property.

SMTP Audit Filter

identityguard.audit.smtp.filter

A comma-separated list of audits to be delivered by SMTP. Each entry is either an audit code or a range of audit codes. If no value is specified, the default audit filter is used to determine which audits to send as traps.

Audits can be specified in ranges. Valid values include:

-1 (all audit with codes <= 1)

2-3 (all codes between 2 and 3)

1- (all codes greater than or equal to 1)

Note: The AUD audit code prefix is not used in this property.

Default: See default list of audits in Audited event reference.
