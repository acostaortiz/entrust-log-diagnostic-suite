IdentityGuard Server 12.0 Administration Guide

Key Store Certificate Import Settings

When a managed or unmanaged CA is added to Entrust IdentityGuard, its CA certificates are imported automatically into the key store, so administrators can perform SSL client authentication to the Administration interface by using their smart credentials. These settings control how frequently the CA certificate import takes place.

Key Store Certificate Import Enabled

identityguard.keystore.certificateImport.enabled

Enables or disables key store certificate import. When set to True, key store certificate import is enabled.

Default: True

Key Store Certificate Import Interval

identityguard.keystore.certificateImport.interval

The length of time (in seconds) between key store certificate import checks.

Default: 30

Key Store Name

identityguard.keystore.name

Specifies the name and location of the key store file containing CA certificates of the CAs in Entrust IdentityGuard. If you do not specify a name and location, the location specified in the server.xml file of the Tomcat Servlet Container is used. This property must be specified if Key Store Certificate Import Enabled is set to True and Entrust IdentityGuard is not running in a Tomcat Servlet Container. Otherwise, do not set this property.

Key Store Password

identityguard.keystore.password

Specifies the password of the key store that contains CA certificates of the CAs in Entrust IdentityGuard. If you do not specify a password, the password specified in the server.xml file of the Tomcat Servlet Container is used. A password must be specified if Key Store Certificate Import Enabled is set to True and Entrust IdentityGuard is not running in a Tomcat Servlet Container. Otherwise, do not set this property

Select Encrypt to encrypt the password.

Key Store Type

identityguard.keystore.type

Specifies the type of the key store that contains CA certificates of the CAs in Entrust IdentityGuard. This property must be specified when any type other than Default is used. If using Tomcat, do not set this property.

Default: Default
