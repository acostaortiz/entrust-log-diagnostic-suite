Unrecognized and Custom Properties

Entrust IdentityGuard allows use of properties outside of the standard properties groups listed in the Properties Editor. If they are not set in the identityguard.properties file, they are not visible in the Properties Editor. After you add them to the identityguard.properties file, or if you enter them in the Properties Editor as shown here, you can edit them in the Properties Editor.

To add a new property, enter:

●       the Custom Property Name. All property names begin with identityguard.

●       the Custom Property Value.

Select the Encrypt check box if you want the property to be encrypted.

Note: The values you enter for properties in this section are not validated by the Properties Editor.

This category can also include properties used to set parameters that define the appearance of the output of Master user shell list commands.

For example, the properties that define the column widths for the audit list command are shown here. For more information, see the Entrust IdentityGuard Master User Shell Command Reference.

The following table shows examples of properties for the audit list output format.

Property

Default

identityguard.supersh.auditlist.width.seqno

6

identityguard.supersh.auditlist.width.date

19

identityguard.supersh.auditlist.width.level

5

identityguard.supersh.auditlist.width.userid

18

identityguard.supersh.auditlist.width.code

2

identityguard.supersh.auditlist.width.text

23

identityguard.supersh.auditlist.width.page

25

Note: Setting the column width to zero (0) does not remove the column from the display. A zero width causes the column width to match the width of the data, and the display columns are no longer be aligned.
