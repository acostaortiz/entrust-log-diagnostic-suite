IdentityGuard Server 12.0 Administration Guide

IP Location Library Settings

These property control features are related to IP/Geolocation and risk-based authentication. For information of IP location data and risk-based authentication, see Risk-based authentication overview.

Also see Configuring the Radius proxy for VPN servers for using risk-based features through the Radius proxy.

 

IP Location Library Implementation Class

identityguard.iplocation.impl

Provides the Java class used by the IP location library.

To use other than the default class, select Custom from the list and enter a valid class name in the empty field that appears. (Used only in highly advanced deployments.)

Default: MaxMind®

Note: You must have a subscription to Entrust Open Fraud Intelligence Network (OFIN) to be able to update the MaxMind data.

IP Location Data Directory

identityguard.iplocation.datadirectory

Specifies the location of the IP location data.

Default:

●        On Windows: <$IG_HOME>\etc\ipdata

●        On UNIX: $IG_HOME/etc/ipdata
