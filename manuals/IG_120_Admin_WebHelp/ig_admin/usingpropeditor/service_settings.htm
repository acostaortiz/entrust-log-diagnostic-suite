IdentityGuard Server 12.0 Administration Guide

Service Settings

These properties reflect the URLs used to access Entrust IdentityGuard services. Their initial values are set during installation and configuration. In addition, the WSDL Query property determines whether an Entrust IdentityGuard service returns WSDL or not. Do not change these settings unless absolutely necessary and use extreme caution so that you do not disable services.

Administration Service URL

identityguard.adminservice.url

Sets the URL used to access the Administration service.

Authentication Service URL

identityguard.authservice.url

Sets the URL used to access the Authentication service.

Authentication Service HTTPS URL

identityguard.authservice.https.url

Sets the URL used to access the SSL protected version of the Authentication service.

Authentication Service Client-Authenticated HTTPS URL

identityguard.authservice.client.https.url

Sets the URL used to access a client-authenticated SSL protected version of the Authentication service.

WSDL Query returns WSDL

identityguard.service.wsdlquery.enable

Determines if a WDSL query to an Entrust IdentityGuard service returns WSDL or not.

By default, the Entrust IdentityGuard WSDL query is disabled. Enable this setting to retrieve the WSDL definition for a service. For example, if the property is set to True and you query the Authentication service URL with

http://igserver:88/IdentityGuardAuthService/services/AuthenticationServicev6?wsdl

the query returns the WSDL definition for the service.

Default: False.
