IdentityGuard Server 12.0 Administration Guide

Risk Engine Configuration

Use these properties to configure risk-based authentication through an external risk engine such as Entrust TransactionGuard or iovation SureScore. Other external risk engines can be added. For more information, see Using external risk engine data for RBA authentication.

Configuration Instances

Provides a list of risk engine configurations.

To create a new instance, enter a unique name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

Risk Engine Class Name

identityguard.riskengine.{0}.impl

Specifies the Java class name of the risk engine. Select Entrust TransactionGuard to use Entrust IdentityGuard’s built-in email integration with Entrust TransactionGuard. Select custom to specify a different Java class name.

Default: none

Risk Engine Display Name

identityguard.riskengine.{0}.displaynamel

Specifies a display name for your risk engine. The display name must be unique among all risk engines. This display name appears in the Administration interface and can appear in your client applications.

Risk Engine URL

identityguard.riskengine.{0}.url

Specifies the URL of the risk engine.

Risk Engine Administrator Id

identityguard.riskengine.{0}.adminid

Required. Specifies the user ID of the administrator authorized to authenticate to the risk engine.

Risk Engine Administrator Password

identityguard.riskengine.{0}.adminpassword

Required. Specifies the password of the administrator authorized to authenticate to the risk engine.

Select the Encrypt option to encrypt the password.

iovation Risk Engine REST Service URL

identityguard.riskengine.iovation.iovation.rest.url

Required. Specifies the URL for the iovation SureScore REST service end-point.

iovation Risk Engine REST Service Administrator Id

identityguard.riskengine.iovation.iovation.rest.adminid

Required. Specifies the administrator Id used to authenticate to the risk engine.

iovation Risk Engine REST Service Administrator Password

identityguard.riskengine.iovation.iovation.rest.adminpassword

Required. Specifies the administrator password used to authenticate to the risk engine.

iovation Risk Engine Ruleset For RBA Normal Security Level

identityguard.riskengine.iovation.iovation.ruleset.normal

Required. Specifies the name of the iovation ruleset to use when determining device risk for the NORMAL security level.

iovation Risk Engine Ruleset For RBA Enhanced Security Level

identityguard.riskengine.iovation.iovation.ruleset.enhanced

Required. Specifies the name of the iovation ruleset to use when determining device risk for the ENHANCED security level.
