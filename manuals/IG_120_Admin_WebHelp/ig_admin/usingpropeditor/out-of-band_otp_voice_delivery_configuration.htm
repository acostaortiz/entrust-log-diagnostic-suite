IdentityGuard Server 12.0 Administration Guide

Out-of-Band OTP Voice Delivery Configuration

Your application can automate the delivery of one-time passwords using email, a text message to a cell phone, or voice message to a standard phone or cell phone. Using the following properties, you can set up delivery of the OTP by voice mail through Authentify®, TeleSign® or a custom voice message delivery service. For more details and to view a snapshot of the properties, see Configuring out-of-band OTP delivery in voice messages.

Configuration Instances

Voice Delivery Class Name

identityguard.oobdelivery.authentify.{0}.impl

Sets the Entrust IdentityGuard Java class used for communicating with Authentify. For the Authentifyoption, the Properties Editor sets the correct class in the background.

To use TeleSign, select Custom, and then enter the following Voice Delivery Class Name:

com.entrust.identityGuard.common.oobDelivery.otp.telesign.OTPTeleSignDeliveryVoice

If you select Custom, enter a valid Java class name in the field that appears. (Used only in highly advanced deployments.)

Voice Delivery Configuration Display Name

identityguard.oobdelivery.authentify.{0}.displayname

The name you use to identify this delivery mechanism.

This is the name you see in the Administration interface when associating the user contact information to the delivery method.

Default: the instance name

Authentify Site Owner ID

identityguard.oobdelivery.authentify.{0}.tsoid

Provides the Authentify account customer ID.

Entrust IdentityGuard requires that this field have content, but If you are using TeleSign or another custom service, it is not used. Enter any value, for example: NOT_USED.

Authentify Application ID

identityguard.oobdelivery.authentify.{0}.application

Names the application that is using the Authentify service.

Entrust IdentityGuard requires that this field have content, but If you are using TeleSign or another custom service, it is not used. Enter any value, for example: NOT_USED.

Authentify Account ID

identityguard.oobdelivery.authentify.{0}.asid

Provides the user name or account ID required to access your Authentify, TeleSign, or custom service account.

Authentify Account Password

identityguard.oobdelivery.authentify.{0}.password

Provides the password required to access your Authentify, TeleSign or custom service account.

Select the Encrypt option to have the password encrypted when saved.

Authentify Service URL

identityguard.oobdelivery.authentify.{0}.url

Provides the application-specific Authentify service URL.

Entrust IdentityGuard requires that this field have content, but If you are using TeleSign or another custom service, it is not used. Enter any value that has the format of a URL, for example: http://notused.not_used.

Authentify Template File

identityguard.oobdelivery.authentify.{0}.template

Provides the location of the Authentify XML request template. Entrust IdentityGuard provides a default template named authentify_template.xml. You can configure it as required. This file is copied and populated by Entrust IdentityGuard for each voice mail sent to a user.

You can find the file:

–  on Windows <$IG_HOME>\etc\templates\oob\

–  on UNIX $IG_HOME/etc/templates/oob/

If you are using TeleSign or another customer service, enter NOT_USED.
