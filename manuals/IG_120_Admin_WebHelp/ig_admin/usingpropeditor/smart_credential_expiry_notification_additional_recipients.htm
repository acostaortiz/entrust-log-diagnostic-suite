Smart Credential Expiry Notification Additional Recipients

These properties control the Smart Credential Expiry Notification configuration for additional recipients. When emails are sent to users to let them known that their smart credential certificates are nearing expiry, you can specify additional recipients for those emails. Each user's group is ascertained, and from the group, the list of additional recipients is applied. There is a configuration instance for each group.

Configuration Instances

You can create multiple configurations.

To create a new configuration instance, enter a unique name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

Each configuration represents a different group of semi-colon separated email addresses, as specified in the Email CC Address property.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

Email CC Address

identityguard.user.delivery.smtp.derivedCredentialCfg.admins.cc

Enter a list of email addresses, separated by semi-colons, to which a copy of each smart credential expiry notification message is sent. Typically, the email addresses are those of users within your organization who need to know about which users have smart credential certificates that are nearing expiry.
