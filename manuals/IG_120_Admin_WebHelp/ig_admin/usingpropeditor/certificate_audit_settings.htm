IdentityGuard Server 12.0 Administration Guide

Certificate Audit Settings

These properties control the Entrust IdentityGuard periodic certificate audit mechanism. Certificate auditing sends notifications when certificates are nearing expiry. For more information, see Audit user certificates.

Certificate Auditing Enabled

identityguard.audit.certificate.enabled

Enables or disables certificate auditing.

Attention: This property must be enabled on only one Entrust IdentityGuard server at any time. The Entrust IdentityGuard server chosen must be able to see all of the data in the system.

Default: True

Certificate Audit Interval

identityguard.audit.certificate.interval

Sets the number of hours between certificate audit checks.

Default: 12

Certificate Audit Expiry Day Limit

identityguard.audit.certificate.limit

When only a set number of days remain before a certificate expires, Entrust IdentityGuard generates an audit message. This property specifies how many days must remain before the message is generated. For example, if set to 10, Entrust IdentityGuard generates the message when only 10 days remain before the certificate expires.

Default: 30

Certificate KeyStore

identityguard.audit.certificate.keystore

Specifies the location of the keystore file containing the Entrust IdentityGuard certificates. If no location is specified, the keystore specified by the system property javax.net.ssl.keyStore is used and if that does not exist, the truststore specified by the system property javax.net.ssl.trustStore is used. Normally this property should be left blank.

Certificate KeyStore Type

identityguard.audit.certificate.keystoretype

Specifies the type of keystore containing Entrust IdentityGuard certificates used when a non-default keystore is specified by the identityguard.audit.certificate.keystore property.

Allowed values: JKS, PKCS12
