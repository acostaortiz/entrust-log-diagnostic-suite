Overview of temporary PIN authentication

The Entrust IdentityGuard temporary PIN provides limited authentication when a user cannot authenticate with a valid card or token. For example, the user may have misplaced a card or token, or not yet received a replacement card or token.

You can limit the temporary PIN to a number of uses or to a period of time. For example, if a user misplaces a card or token, you can limit the use of the temporary PIN to a single use, or to a 24-hour period.

You should use temporary only PINs as an interim second-factor authentication method, not as a primary second-factor authentication method.
