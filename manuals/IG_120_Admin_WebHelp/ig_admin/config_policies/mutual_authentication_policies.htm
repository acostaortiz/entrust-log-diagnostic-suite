IdentityGuard Server 12.0 Administration Guide

Mutual Authentication policies

These policies enable and control authentication secrets.

Total Maximum Size in Kilobytes

Sets the maximum storage space (in KB) that all mutual authentication secrets for the user combined can use. To determine the correct size for your system, consider the type of information displayed; for example, images require more space than text. A setting of 0 disables the storing of authentication secrets and effectively turns off mutual authentication.

Default: 1000

Maximum Mutual Authentication Secrets

Sets the maximum number of mutual authentication secrets a user can have. A setting of 0 disables the storing of authentication secrets and effectively turns off mutual authentication.

Default: 3

Return Mutual Authentication Secrets With Challenge

Determines if Entrust IdentityGuard presents mutual authentication secrets to users before they log in and are authenticated or after authentication.

The following methods in the Authentication API can return the authentication secrets based on the authSecretParms parameter passed to them:

–  getGenericChallenge 

–  authenticateGenericChallenge 

–  checkMachineRegistration 

–  registerMachine 

If set to No, authentication secrets are not returned by the authentication API until after Entrust IdentityGuard authenticates the user or the machine secret.

Default: No
