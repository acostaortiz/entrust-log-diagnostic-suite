IdentityGuard Server 12.0 Administration Guide

IP/Geolocation policies

The IP/Geolocation policies help configure your risk-based authentication setup.

Maximum Location History Size

Sets the number of IP addresses to store in a user’s history list. An administrator can override this policy attribute on a per user basis. A setting of 0 means no location history is stored: in this case, the location history test always fails and the velocity test always passes.

For information about the location history list, see Using location lists.

Default: 5

Location History Lifetime

Sets the number of days an entry in the location history list can exist before it expires and is no longer used in the IP history test. A setting of unlimited means entries do not expire.

For information about the location history list, see Using location lists.

Default: Unlimited

Check IP Address in Location History

When Entrust IdentityGuard compares two locations (such as the user’s current location and a previous location), it compares several values (such as country and region), but not the IP addresses. To include the IP addresses in the comparison, set this property to Yes.

Note: the IP address of a location may vary over time, and may change each time you connect to an ISP.

Default: No

Maximum Possible Velocity

This defines the maximum velocity that a user can travel per hour between locations. The value can be entered in kilometers or miles per hour, but is automatically converted to kilometers per hour. A setting of 0 means any change in location by the user results in failure of the velocity test.

For information about the velocity test, see Using IP location velocity.

Default: 500 km/h

Check Velocity

Determines if the velocity test is always conducted on external addresses. This can be overridden on a per user basis.

Set this to No if location information for some addresses being compared is inaccurate or incomplete. For example, one IP address may have very accurate location information including the latitude and longitude, but another has only country information. In this case, the test often fails.

Also see Calculating the distance between locations for information about calculating velocity using the Master user shell

Default: Yes

Country Blacklist

Sets the country codes on the country blacklist. For details, see Configuring RBA policies.

Default: Anonymous Proxy, Satellite Provider

Maximum Number of Expected Locations

Sets the number of IP addresses to store in the expected location list for any individual user in the group. There is no maximum size for the general expected location list. (See Expected Location List parameter later in this table.)

A setting of 0 means no list is stored, and the expected location test for the user always fails. For information about the expected location list, see Using the expected IP location list.

Default: 10

Expected Locations List

Sets the countries, regions, and cities on the general expected locations list used by all users in the group associated with this policy. User can have their own list. For details, see Using the expected IP location list.
