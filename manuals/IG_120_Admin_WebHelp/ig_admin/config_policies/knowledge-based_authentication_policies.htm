IdentityGuard Server 12.0 Administration Guide

Knowledge-based Q&A policies

These policies set minimum, maximum, and default limits for the number of questions existing and asked, the number of wrong answers allowed, and the question size. For authentication policies related to knowledge-based authentication, see IP/Geolocation policies.

Total Maximum Size in Kilobytes

Sets the maximum storage space (in KB) that all questions and answers related to a user can use. A setting of 0 disables knowledge-based authentication.

To determine the correct size for your system, consider what sorts of questions and answers you need to ask each user in order to properly authenticate them.

Default: 5

Maximum Number of Q&A Pairs

Sets the maximum number of questions and their paired answers Entrust IdentityGuard can store for a user. A setting of 0 disables knowledge-based authentication.

When setting the maximum number of questions consider:

–  your storage space (more questions means more room is required in the repository to store the values)

–  your users (more questions mean your users have to remember more answers)

–  increased security (the less often a question is asked of a user, the more difficult it is for an attacker to impersonate the user)

Default: 25

Default Q&A Challenge Size

Sets the default number of questions your application presents to users during a knowledge-based challenge. This must be greater than or equal to 1. It cannot be greater than the number of questions stored.

For more information, see Setting the number of questions asked.

Default: 3

Minimum Q&A Challenge Size

Sets the minimum number of questions your application must present to users during a knowledge-based challenge. The number must be greater than zero, less than or equal to the number set in the Default Q&A Challenge Size policy.

Note: To work with the Entrust IdentityGuard Radius proxy, the Minimum Q&A Challenge Size must be set to 1. For more information about the Radius proxy and configuring it, see Configuring the Entrust IdentityGuard Radius proxy.

Default: 3

Maximum Q&A Challenge Size

Sets the maximum number of questions your application can present to users during a knowledge-based challenge. The number must be greater than or equal to the number set in the Default Q&A Challenge Size policy.

Default: 3

Disable Challenge Retention

Enable this setting if you want to replace the challenge (namely, the set of questions) each time a challenge is requested. Users who answer a challenge incorrectly will have a new challenge presented to them for the next attempt.

Deselect it if you want to retain the challenge for the duration of the Q&A Challenge Lifetime. Users who answer a challenge incorrectly will have the same challenge presented to them for all subsequent attempts until they are locked out or until the challenge lifetime is exceeded. After the challenge lifetime is exceeded, a new challenge is presented.

Default: No

Q&A Challenge Lifetime

Set it to Unlimited to have the challenge (namely, the set of questions) last an unlimited amount of time.

Set it to a number of seconds to limit the lifetime. If it is not answered in the lifetime, a new challenge is generated.

Default: Unlimited

Update Lockout Count for Replaced Challenge

When set to Yes, the lockout count is increased when a Q&A challenge is replaced because:

–  a user does not answer a challenge in the allotted time (as defined by the Q&A Challenge Lifetime setting) causing a new challenge to be requested by the client application

–  a user restarts the client application without answering the challenge, causing a new challenge to be requested by the client application

When set to No, the lockout count is not increased in the above-mentioned scenarios.

Note: The lockout count is always increased when a user enters an incorrect challenge response, regardless of how you configure this setting.

Default: Yes

Default Number of Wrong Answers Allowed

Sets the default number of wrong answers allowed. The value must be less than the number of questions presented, and less than or equal to Maximum Number of Wrong Answers Allowed. A value of 0 means all questions must be answered correctly. Your application can override this policy.

For more information, see Setting how many correct answers are required.

Default: 0

Maximum Number of Wrong Answers Allowed

Sets an upper limit to how far your application can override the value set by the Default Number of Wrong Answers Allowed policy. The value must be less than the number of questions presented, and greater than or equal to the Default Number of Wrong Answers Allowed policy. A value of zero means all questions must be answered correctly.

For more information, see Setting how many correct answers are required.

Default: 0

Inexact Match Allowed for an Answer

Determines if inexact answers are allowed and the map file used. Selecting the policy means use the map file; deselecting it means answers must be exact. (See Allowing inexact answers.)

For more information, see Setting the accuracy level of answers and Using and editing a word map.

Default: Yes

External Provider

Sets the name of an external Q&A provider integrated with Entrust IdentityGuard to provide and manage question and answer pairs for knowledge-based authentication. For more information about integrating an external QA provider, see the Entrust IdentityGuard Programming Guide, and Using external Q&A data for Entrust IdentityGuard authentication.
