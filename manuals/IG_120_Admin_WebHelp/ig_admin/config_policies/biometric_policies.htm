IdentityGuard Server 12.0 Administration Guide

Biometric policies

These policies are related to fingerprint biometric authentication using the Entrust IdentityGuard Desktop for Microsoft Windows.

You might want to change these properties, for example, if you want to prevent members of a group from enrolling for biometric authentication or authenticating with biometrics. In such a scenario, set Allow All Biometric Vendors to No and leave Allowed Biometric Vendors empty.

Allow All Biometric Vendors

Select this option to allow all biometric vendors to be available for all users whose group is associated with this policy.

Clear this option if you want to use only specific biometric vendors you select in the Allowed Biometric Vendors list.

Note: Currently, only one biometric vendor is supported for each Biometrics license.

Default: Yes

Allowed Biometric Vendors

Specifies all the biometric vendors that can be assigned to a user.

Note: Currently, the only supported biometric vendor is Cogent.

Default: no default

Maximum Biometric Data Size (bytes)

Specifies the maximum size in bytes allotted for a user’s biometric data.

Default: 40,000 bytes

Requires Admin Activation After Enroll

If you select this option, when an end user enrolls or updates biometric data, the biometric is put into the inactive state. This allows the administrator to complete any required process steps before the biometric is changed to the active state, after which it can be used for authentication.

Default. No
