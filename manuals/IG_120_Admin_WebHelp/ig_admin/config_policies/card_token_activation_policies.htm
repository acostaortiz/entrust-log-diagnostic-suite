IdentityGuard Server 12.0 Administration Guide

Card/Token Activation policies

These policies define how cards and tokens are activated within Entrust IdentityGuard. You can set the activation period—how long before a grid or token must be used in second-factor authentication.

Use of card and token methods of authentication require that your users all have access to cards or tokens, respectively. Since access might involve mailing a card or token to the user, a period of time must be allowed for activation to take place.

Activation Period

Sets the grace period in days to wait for token or card activation. When the period expires, the user must authenticate with a second-factor authentication method listed in the Activation Authentication Types policy.

Default: 30 days

Maximum: 3650 days

After the user authenticates with an allowed second-factor authentication method, the value is set to 0 meaning the user’s card or token is active and must always be used for second-factor authentication.

For new or upgraded users, the value is null until an expiry date is set.

Activation Authentication Types

Lists the second-factor authentication methods that indicate successful activation. You can select one or more of:

–  GRID - authenticates with a card.

–  TOKEN (Response-Only) - authenticates using a dynamic password generated by a response-only token.

–  TOKEN (challenge-response) - authenticates using a dynamic password generated by a challenge-and-response token.

Default: all methods
