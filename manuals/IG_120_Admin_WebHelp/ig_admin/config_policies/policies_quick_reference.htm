IdentityGuard Server 12.0 Administration Guide

Policies quick reference

This section lists all policies administrators may need to set to configure Entrust IdentityGuard. Policies are arranged in related categories.

The initial installation of Entrust IdentityGuard sets policies to a default value. This section provides the default settings.

Note: Administrators can view and change only the policies allowed by their roles.
