Configuring Radius server for failover and high availability

Entrust IdentityGuard offers a common failover scheme to ensure there are backup systems in place in the event that a primary system fails.

All data sources and resources that Entrust IdentityGuard uses are listed in specific properties in the Entrust IdentityGuard properties file. This includes Radius servers.

For more information about failover and high availability, see Specifying multiple repositories.

To set up failover and high availability for Radius, complete the following procedure.

To configure the Entrust Identity Guard Radius proxy server for failover

1.      Start the Entrust IdentityGuard Properties Editor.  (See Log in or out of the Properties Editor.)

2.      On the Table of Contents, click Radius Server Configuration.

3.      In the Configuration Instances drop-down list, select the instance you want to set up for failover.

If the Configuration Instances list is empty, enter a Radius server name in the empty field and click Add. The other properties appear.

4.      In the Radius Server Address field, enter two or more Radius server addresses. These are Radius server host names or IP addresses. Use a space to separate servers in the list.

To properly configure the Radius Server Address field, you must enter the server name (or IP address) as well as the port the radius service is listening on. That is, the address must be in the following format:

radius1.entrust.com:1812

An example of a failover value for this field would be:

radius1.entrust.com:1812 radius2.entrust.com:1812

5.      In the Radius Server Secret field, provide a valid shared secret that applies to all Radius servers in the address list.

6.      Configure the Radius Timeout value in the Radius Proxy to be shorter than the timeout value set for the VPN server.

This ensures that the IG radius proxy server is given enough time to fail over to the next third party Radius server prior to the VPN server resending an ACCESS-REQUEST.

7.      Click Validate & Save.

8.      Log out of the Properties Editor and restart Entrust IdentityGuard Server service and the Radius proxy service after making all of the property changes.
