IdentityGuard Server 12.0 Administration Guide

Configure revocation checking for various CAs

Use the guidance in the following table when configuring CA certificates from these common CA providers. Keep in mind that these are the most common configurations for each type of CA, but your implementation may be different.

Some general rules:

●       If the CA is set up with an OCSP server, use OCSP.

●       If the CA is set up with CRLs posted to LDAP and there are no URLs in the CDP, use LDAP URL.

●       If the CA is set up with CRLs posted to LDAP or HTTP, and there are corresponding URLs in the CDP, use URL CDPs.

Certificate providers and revocation checking

CA provider

How to configure the CA certificate in Entrust IdentityGuard

Entrust Managed Services CA

Revocation checking via OCSP using the AIA extension.

·      Select Use AIA Extension to Locate OCSP Responder.

Revocation checking via URL CDPs.

·      Select Follow URL CDPs.

Note: Some managed services include an OCSP server, and all managed services include CRL URLs in their Certificate Distribution Point (CDP).

Entrust Security Manager CA

Revocation checking via LDAP DN CDPs (or combined CRL).

·      Set the LDAP URL and possibly the LDAP User DN and New LDAP Password.

Entrust Certificate Services CA

Revocation checking via URL CDPs.

·      Set Follow URL CDPs.

Microsoft CA

Revocation checking via URL CDPs.

·      Set Follow URL CDPs.

Verisign CA

Revocation checking via URL CDPs.

·      Set Follow URL CDPs.

 

Note: The Microsoft 2008 CA also has built-in support for OCSP responders. See the Microsoft documentation for setup details. After the OCSP responder is configured appropriately, you could choose to select Use AIA Extension to Locate OCSP Responder.
