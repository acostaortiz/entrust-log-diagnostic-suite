IdentityGuard Server 12.0 Administration Guide

User certificates

Each user certificate must be unique across all users; that is, the issuer DN and serial number are unique across all user certificates for all users. If you try to register a user certificate that is not unique, an error will be returned.

When assigning a user certificate, it must have the digitalSignature or nonRepudiation key usage set, and the certificate must be valid.

Depending on policy, user certificates may not be allowed because they are self-signed or because the CA that issued them is not allowed. For more information about certificate policies, see Certificate Authentication policies.

The following list describes the information that Entrust IdentityGuard stores for each CA certificate. Click a list item to read the description for each item.

Issuer DN

Specifies the issuer DN of the certificate. This is mandatory.

The issuerDN is stored as a string.

Can be used for searching, but wild card characters are not supported.

Subject DN

Specifies the subject DN of the certificate.

The subjectDN is stored as a string.

Can be used for searching, but wild card characters are not supported.

Optional in X.509, but mandatory in Entrust IdentityGuard.

Serial number

Specifies the serial number of the certificate.

The serial number is stored as a string.

Can be used for searching.

State

Specifies the state of the certificate, either ACTIVE or INACTIVE.

Can be used for searching.

Assign date

Specifies the date on which the certificate was assigned to the user

Can be used for searching.

Issue date

The date on which the certificate was issued by its CA.

Expiry date

The date on which the certificate expires.

Last used date

The date on which the certificate was last used for authentication

Self-signed

A Boolean flag that indicates whether this certificate is self-signed.

Can be used for searching.

CA

The name of the registered CA that issued this certificate.

This value is not set if the certificate is self-signed or the certificate was not issued by a registered CA.

Can be used for searching.

Comment

This is a comment describing the certificate.

You enter this comment when you load the CA certificate.

Certificate

The full X.509 encoded certificate

 

Example searches you might use when administering user certificates:

●       Search by issuer DN or CA to find all certificates issued by a given CA.

●       Search on the inactive state to find all inactive certificates so you can remove them.

●       Search on the active state to see only certificates that can be used for authentication.

●       Search on the expiry date to find certificates that may be close to expiry and will soon need to be replaced.

●       Search on the last used date to find users that are or are not actively using certificate authentication.
