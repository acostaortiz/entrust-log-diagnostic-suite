IdentityGuard Server 12.0 Administration Guide

Using the Administration interface

Administrators use the Administration interface to perform administration operations. The ability of administrators to configure Entrust IdentityGuard policies, roles, groups, users, authentication methods and system resources is only limited by their assigned roles. For more information about roles, see Entrust IdentityGuard roles overview.

Note: Before using the Administration interface for the first time, read the sections in this section on creating policies, groups, and roles. These three entities work together to determine the scope and privileges of administrators.

The following topics provide the administrator with procedural information about using the Administration interface.

This section includes:

●       Navigating the Administration interface

●       Selecting options

●       Moving items between option lists

●       Setting option precedence

Note: When entering integers in the Administration interface fields, note the following limits:

Integers must fall between -231 and 231.

Non-negative integers can be any value from 0 to 231.

Positive integers can be any value from 1 to 231.
