IdentityGuard Server 12.0 Administration Guide

Locate your Administration interface URL

If you cannot recall the host name or administration port you selected, use one of the following methods to locate the URL of your Administration interface application.

To find your Administration interface address in any environment

1.      Log in to the Properties Editor. (See Log in or out of the Properties Editor.)

2.      In the Table of Contents, click Web Application Settings.

3.      Take note of the address in the Administration Interface URL field.

To find your Administration interface address on UNIX

1.      Log in to the Entrust IdentityGuard server as the user who owns the Entrust IdentityGuard installation.

2.      Change the current directory to $IG_HOME/bin, if it is not already in your path.

3.      Enter:

./identityguard.sh status 

The Administration interface URL appears.

Note: You may notice that client status messages use different wording than messages for other services. This is because the client SSL ports cannot be queried for confirmation that they are available, therefore, they are shown as “configured at” rather than “available at”.

To find your Administration interface address on Windows

1.      On the computer where you installed Entrust IdentityGuard, select Start > All Programs > Entrust > IdentityGuard > Configuration Panel.

2.      Open the Web Service and Application Manager.

3.      The Administration Interface section lists the URL.

(Alternate method) To find your Administration interface address in the properties file

1.      In Windows Explorer on the computer where you installed Entrust IdentityGuard, go to the etc directory in your Entrust IdentityGuard installation, for example, C:\Program Files\Entrust\IdentityGuard\identityguard<release number>\etc.

2.      Open the identityguard.properties file in a text editor.

3.      Find the property called identityguard.webadmin.url and copy the URL for the Administration interface.

4.      Close identityguard.properties without saving it.
