Move items between option lists

Some Groups pages and Policies pages, such as the example shown in the following screen capture, contain lists from which you can select multiple options or values in one list and move them to a second list. This action either turns on or turns off features or options, depending on which direction you move the option.

The preceding screen capture shows part of the policy edit page where you set the Authentication Types.

In the preceding screen capture of the Authentication Types page there are options in two lists:

●       Not Included lists options that are not selected—that is, options not in effect.

●       Included lists selected options—that is, options in effect.

You can move options between the two lists using the arrow keys.

You can move options one at a time:

●       To add an option to the Included list (enable the option), select it in the Not Included list and click the right-arrow or double-click it to move it.

●       To remove an option from the Included list (disable the option), select it in the Included list and click the left-arrow or double-click it to move it.

You can move several options at a time:

●       To add several options to the Included list (enable the options), select them (press and hold the Ctrl key) in the Not Included list and click the right-arrow to move them.

●       To remove several options from the Included list (disable the options), select them (press and hold the Ctrl key) in the Included list and click the left-arrow to move them.

You can also move all of the options at once:

●       To move all options to the Included list, click the double right-arrow between the lists. All options move from the Not Included list to the Included list.

●       To move all options to the Not Included list, click the double left-arrow between the lists. All options move from the Included list to the Not Included list.
