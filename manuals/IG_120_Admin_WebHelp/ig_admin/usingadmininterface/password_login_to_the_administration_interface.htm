IdentityGuard Server 12.0 Administration Guide

Password login to the Administration interface

The default method to log in to the Authentication interface is using a user name and password.

To log in to the Administration interface using a password

1.      Start the Entrust IdentityGuard Administration interface.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      On the Administrator Log In page, enter your administrator name and password.

If you do not remember your password, contact the administrator in charge of the Entrust IdentityGuard system to have it reset.

For information about changing administrator passwords, see Change a password while logged in.

3.      (Optional) Enter a group name in the Group field. The group is required if the administrator name is not unique within your system.

4.      Click Password Log In.

Note: If the disallowed password list changed since your last login, and your password is now disallowed, you are prompted to change your password as you log in.
