IdentityGuard Server 12.0 Administration Guide

Select options

Many pages contain lists from which you can select multiple options or values.

Some pages display options that are turned on or off using check boxes. When the box contains a check mark, it is selected, or enabled. Conversely, when the check box is empty, the option is not selected or disabled. Click the check box to toggle the option on or off.

Some pages allow you to add or remove multiple settings from a list.

●       To select a single setting, click it.

●       To select multiple settings, press and hold the Ctrl key and do one of:

–  drag the mouse pointer to select several adjoining settings

–  click each setting you need individually

●       To deselect a single selected item, click it.

●       To deselect multiple selected items, press and hold the Ctrl key and click each setting you want to deselect.
