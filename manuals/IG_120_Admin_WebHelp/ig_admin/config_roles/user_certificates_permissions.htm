IdentityGuard Server 12.0 Administration Guide

User certificates permissions

These permissions control the management of user certificates for authentication. For more information about certificate authentication, see Certificate authentication overview.

 

Permission

Dependencies

Description

userCertificateAssign

userCertificateSet

userCertificateGet

Assign a certificate to a user, and verify the certificate.

userCertificateAuthenticate

userCertificateGet

Perform a certificate challenge and a certificate authentication.

userCertificateDelete

userCertificateGet

Delete a user certificate.

userCertificateGet

 

Display or export a user certificate. If this permission is missing, userGet and userList do not display the user’s certificates.

userCertificateList

userCertificateGet

Display user certificates.

userCertificateSet

userCertificateGet

Modify a user certificate state or comment.
