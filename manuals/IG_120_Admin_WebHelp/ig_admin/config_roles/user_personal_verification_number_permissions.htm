IdentityGuard Server 12.0 Administration Guide

User personal verification number permissions

These permissions control the creation and management of personal verification numbers (PVN). For information about using a PVN, see Personal verification number overview.

 

Permission

Dependencies

Description

userPVNCreate

userPVNGet

Create a user’s PVN value and unset the Change Required option if the policy is set to make changing a PVN optional.

userPVNDelete

userPVNGet

Delete a user’s PVN value.

userPVNDeliver

userPVNGet

Deliver a user’s PVN.

userPVNGet

 

Retrieve a user’s PVN information.

userPVNSet

userPVNGet

Modify a user’s PVN value and unset the Change Required option if the policy is set to make changing a PVN optional.

userPVNView

userPVNGet

View a user’s PVN value prior to distribution and use. An administrator can view a user’s PVN value only after setting the it. As soon as a user changes or uses their PVN, the administrator can no longer view the PVN value, regardless of this permission. This permission is required for automatically generating a PVN.
