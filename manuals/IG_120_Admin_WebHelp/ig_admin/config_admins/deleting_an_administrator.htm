IdentityGuard Server 12.0 Administration Guide

Delete an administrator account

Deleting an administrator is similar to deleting a user, except that roles must be taken into account. An administrator can delete another administrator as long as they can access that administrator. Access to other administrators is controlled by the roles list. For example, for Admin1 (who is assigned RoleA) to delete Admin2 (with RoleB), Admin1's roles list would have to include RoleB, and Admin1's permission list would have to include userDelete permission. (See Understanding roles for further explanation.)

The role of the administrator being deleted must appear in the roles list of the role assigned to the administrator performing the deletion. Similarly, the group of the administrator being deleted must appear in the group list of the role assigned to the administrator performing the deletion.

When deleting administrators:

●       Ensure that the user groups they are responsible for are assigned to other administrators.

●       Ensure that no client applications are logging in using the administrator accounts.

●       If they are using second-factor authentication (Configuring an administrator to use second-factor authentication), their cards are also automatically deleted, unless you unassign the cards first.
