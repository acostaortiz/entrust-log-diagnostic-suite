IdentityGuard Server 12.0 Administration Guide

Edit an administrator account

Modifying an administrator is similar to modifying a user, except that roles must be taken into account. One administrator can change information about another administrator as long as they can access that administrator and have the appropriate permissions. Access to other administrators is controlled by the role list. For example, for Admin1 (who is assigned RoleA) to manage Admin2 (with RoleB), Admin1's role list would has include RoleB. (See Understanding roles for further explanation.)

As with modifying users, permissions and groups are a factor. The roles of the administrator making the changes must include permissions related to changing user and password values. The administrator being modified must be in one of the role group lists of the administrator performing the changes.

To modify an administrator

1.      Log in to the Administration interface. (See Logging in and out of the Administration interface.)

2.      Click User Accounts on the home page.

3.      Find the administrator to modify. (See Finding an administrator.)

4.      To change basic account details, click Edit Account.

The Edit Account page appears.

a        Change any existing information. (See Modifying user information for details.)

a.      Click Save Changes.

5.      To change an administrator’s roles, click Change Roles.

The Change Roles page appears.

a        Pick one or more roles from the list.

b.      To remove a role, deselect it. (See Selecting options.)

c.      Click Save Changes.

6.      If applicable, change the second-factor authentication methods that apply to the administrator. (See Configuring an administrator to use second-factor authentication.)
