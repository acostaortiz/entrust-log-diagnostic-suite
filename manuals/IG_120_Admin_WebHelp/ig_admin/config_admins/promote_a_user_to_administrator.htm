IdentityGuard Server 12.0 Administration Guide

Promote a user to administrator

Use this procedure to make an existing regular user an administrator or to change a former administrator into an ordinary user.

To promote a user to administrator

1.      Click User Accounts on the home page and find the user to promote.

2.      Under Account Information for that user, click Change Roles.

The Change Roles page appears.

3.      To add a role to the user account, select the role from the list presented. To select more than one item at a time, hold down the Ctrl key as you click the items you want to select.

If you are demoting an administrator, deselect all roles by holding down the Ctrl key while clicking the roles to remove.

Note: If you change the roles your own account is associated with, the changes take effect immediately, and you may find that you have lost permission for actions that you could perform before.

If you make a change that could result in removing all roles from your account, you will see a warning that, if you proceed, you will no longer be an administrator after your current Administration interface session ends.

4.      Click Save Changes.
