IdentityGuard Server 12.0 Administration Guide

Delete a question

You can delete one or more question-and-answer pairs belonging to a user.

1.      Locate the user. (See either View user questions and answers or Search for users who have challenge questions

2.      On the Account Information pane for the user, scroll down to Authentication Types, click Knowledge-Based Q&A and review the details.

3.      Select the questions to delete and click Delete Questions.

4.      Click OK to confirm the deletion

Make sure that, when you delete a question, the number of questions left for the user is not less than the number set by the Default Q&A Challenge Size policy.
