IdentityGuard Server 12.0 Administration Guide

Search for users who have challenge questions

You can search specifically for users who have question-and-answer pairs.

To find users based on their questions

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      Click User Accounts on the main menu.

3.      From the User Accounts page, click the Find Accounts tab. The Search Options page appears.

4.      Click Has the additional account characteristics below. The Additional Account Characteristics pane appears.

There is one user search option that applies to knowledge-based authentication.

5.      To find users with knowledge-based authentication data (question-and-answer pairs), select Has between [ ] and [ ] question and answer pairs, then do one of the following:

●       To find users with a minimum number of questions and any more than that minimum, type the minimum number in the first text field and leave the second field blank.

●       To find users with a maximum number of questions and any fewer than that maximum, type the maximum number in the second text field and leave the first field blank.

●       To find users with any number of questions in a range, type the minimum number in the first text field and the maximum number in the second text field.

6.      Select other search options as applicable (see To search for information about one or more users for details).

7.      Click Find Accounts.

The Search Results page appears.

8.      Click a user name.

The Account Information pane appears.

9.      Scroll down to Authentication Types, click Knowledge-Based Q&A and review the questions.
