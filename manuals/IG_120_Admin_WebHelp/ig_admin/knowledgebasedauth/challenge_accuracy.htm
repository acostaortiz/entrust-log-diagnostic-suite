IdentityGuard Server 12.0 Administration Guide

Challenge accuracy

After you determine how many questions a user must answer to authenticate, you must determine how accurate a user’s answers must be.

Number of correct answers required

Entrust IdentityGuard provides tolerance, or flexibility, in the number of questions a user must answer correctly. You can make it mandatory that all questions be answered correctly, or you can allow room for error. For example, you can decide that three out of four correct answers represents a successful authentication.

If you configure knowledge-based challenges to allow some wrong answers, you must take into account the number of questions presented in different scenarios. The number of allowed wrong answers must be lower than the number of questions presented. For example, you cannot ask only two questions, and allow two wrong answers. In any knowledge-based challenge, at least one question must be answered correctly.

Accuracy of answers

When you use knowledge-based authentication, you can configure your system to allow people to be “close” rather than exact in their responses to questions. It is easy for a challenge response to differ a bit from the answer stored during registration.

In the standard configuration, the answer matching compensates for additional or missing spaces, and for different character case, so that “the q uick bro wnfo x” is considered a match for the correct answer, “The Quick Brown Fox”, for example.

Using the word map file, Entrust IdentityGuard also lets you ignore wrong answers caused by typing errors (for example, “receive” versus “recieve”), common abbreviations (for example, “Dr.” versus “Doctor”), pluralized words (for example, “dollar” versus “dollars”) and alternative spellings of common words (for example, “color” versus “colour”).
