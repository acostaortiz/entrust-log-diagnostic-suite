IdentityGuard Server 12.0 Administration Guide

Edit the word map file

When Entrust IdentityGuard starts, it looks for the file and location named in the Word Map File Name property. By default, the file is named qamap.txt. When Entrust IdentityGuard finds this file, it loads the contents into memory and uses the settings in the file to verify user responses to authentication questions.

Note: If Entrust IdentityGuard cannot read or understand the map file, perhaps because the encoding or format is incorrect, it generates an error and processes responses as if the map file did not exist; that is, it expects exact answers.

Entrust IdentityGuard does not apply the map file if the user policy Inexact Match Allowed for an Answer is disabled.

Use the Properties Editor to change the map file location if needed. See Knowledge-Based Authentication Settings.

Ensure that your word map file is included in your Entrust IdentityGuard backups.

To allow for variations in users’ responses to knowledge-based questions, you can add words to the map file.

In addition to the specific advice in this procedure, review the information in Map file editing rules.

To edit the map file

1.      Open the map file in a text editor.

The sample map file included in the Entrust IdentityGuard installation looks something like this:

[Protection]

Version=1

[Substitutes]

; This entry would make 'St.' be equivalent to 'street' and to ;'saint'. It does not make 'street' equivalent to 'saint'.

;

St. = street saint

;

; This entry makes 'Dr.' be equivalent to 'doctor' and allows

;'Dr.' to be omitted from the answer or response. It does not

; allow 'doctor' to be omitted from the answer or the response.

;

Dr.= doctor <null>

;

; This entry allows 'doctor' to be omitted from the answer or

; response.

doctor = <null>

Attention: Take great care in defining substitutions in the qamap file; you could unintentionally create security holes. Consider the following example:
Dr.= doctor
Drive = Dr.
In this case, “Maple Doctor” may be accepted as an answer, when you really wanted “Maple Drive.”

2.      Add new entries under the Substitutes section header in the form “A = B” where A is a word that might appear in an answer and B is one or more equivalents for it; for example:

St. = street saint

3.      To permit a word to be missing from an answer, add an entry in the form “A = B” where one value for B is <null>; for example:

Dr.= doctor <null>

4.      As you add entries to the file, add comments to explain the intent of each entry. Comments begin with a semicolon and end at the next paragraph return. A semicolon anywhere in a line of text means the rest of the line is treated as a comment.

5.      Save the file using UTF-8 encoding. (You can select the UTF-8 option on the Save As dialog box of most text editors.)
