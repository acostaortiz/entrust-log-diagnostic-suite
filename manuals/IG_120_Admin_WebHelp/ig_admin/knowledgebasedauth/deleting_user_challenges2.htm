IdentityGuard Server 12.0 Administration Guide

Delete unanswered (retained) challenges

For grid, knowledge-based, and challenge-response token authentication, Entrust IdentityGuard stores and reuses the same challenge until it is answered correctly. This prevents users or attackers from cycling through challenges until they find one they can answer.

If there is an unanswered (also called retained) challenge in the system and a user attempts the same operation again, the same challenge is presented. However, if a user attempts another operation that presents a different challenge (for example a challenge with more question) and the user is unable to correctly answer the second challenge, there could be more than one unanswered challenge associated with the user.

If the user has one or more unanswered challenges, or you believe a challenge has been compromised, you can delete the user's stored challenge (or challenges).

When you delete a retained challenge, Entrust IdentityGuard provides a new challenge the next time the user attempts to authenticate.

To delete user challenges

1.      Open the Master user shell and log in. (See Using the Master user shell.)

2.      To see if a user has unanswered challenges, enter the following command:

user challenge get <userid>

3.      To delete all retained challenges for the user, enter the following command:

user challenge delete <userid>

Note: The command deletes all challenges for a user. You cannot select individual challenges to delete.

4.      When prompted to confirm the action, enter y.
