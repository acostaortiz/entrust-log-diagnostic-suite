IdentityGuard Server 12.0 Administration Guide

Ensure exact answers

To disable the use of the map file and enforce exact responses, deselect the Inexact Match Allowed for an Answer policy under the Knowledge-Based Q&A policy category.

When requiring exact answers, your application should employ the following techniques to improve the chances of receiving a match:

●       Standardize responses. Questions that require answers formatted in a standard way, especially dates, should include drop-down lists or other mechanisms that enforce a standardized response.

●       Avoid syntactic representations. What do you expect the answer to look like; for example, having to process “St.” as “Street”? This requires thoughtful creation of the question. Of course, you can eliminate such problems using a word map. (See Allow inexact answers)

●       Validate the answer set. You should include rules-based postprocessing of the answers given during enrollment to ensure answer quality. You do not want the same response to each question, or sequential keyboard sequences, or repeated characters, and so on. Many of the rules that apply to good password quality also apply to good answer quality. Your application can reject answers that do not fit your rules, and prompt for a better answer.
