IdentityGuard Server 12.0 Administration Guide

Delete a group

The built-in roles provided with Entrust IdentityGuard permit an administrator with the superuser role to delete a group (see Initial roles). Any administrator with a role that includes the groupDelete permission and the special “all” option in the group list can accomplish this, too.

Delete a group when it is no longer required by your organization. You cannot delete a group that is still includes users, administrators, tokens, or preproduced cards. You cannot delete a group flagged as the default group.

If the group being deleted is on the group list of any administrator, including the one performing the deletion, the group is removed from all those lists.

You can delete a group in one of two ways:

●       from the View Group page

●       from the Delete Group tab

Attention: This cannot be undone.

If the group you plan to delete is flagged as the default group, first modify another group to make it the default. See Modify a group.

To delete a group from the View Group page

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      Find the group to delete on the List Groups tab.

3.      Click any group name to view its information.

4.      On the View Group page, click Delete Group.

5.      Click OK to confirm the deletion.

Note: If you do not see the Delete Group function on the View Group page, there may still be users assigned to the group. Check that your own userid is not part of the group you are trying to delete.
You cannot delete a group that has users associated with it.

To delete groups from the Delete Group tab

6.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      Click Groups on the home page.

3.      Click the Delete Group tab.

4.      From the list, select the group you want to delete.

5.      Click Delete Group.

6.      Click OK.

Note: If you do not see the Delete Group function, there may still be users assigned to the group. Check that your own userid is not part of the group you are trying to delete.
You cannot delete a group that has users, unassigned cards, or unassigned tokens associated with it.

Note: If a repository is assigned to a group but the repository can no longer be reached (for example, it is offline), you cannot delete the group because Entrust IdentityGuard cannot search to make sure there are no users in the group. In this case, make the repository available again, and then delete the group.
