IdentityGuard Server 12.0 Administration Guide

Updating passwords

Users need to change their password if it expires or is about to expire. No matter how passwords are created initially, all regular updates of the password should be the users’ responsibility. This reduces the workload of administrators.

Using the Administration API, you can change the settings to force the user to update their password at their next login. The API applies the password rules set by policy.

Have administrators update user passwords when a problem arises. For example, administrators should change passwords if a user forgets their password and needs a new one. Also change a password if you think it is compromised.

At any time, you can force users to change their passwords. See Forcing a password update.

If users access your application using the Radius proxy, password changes are supported through the PAP protocol only. If your system uses the CHAP or MSCHAP protocols, you need to create a self-administration page where users can change their passwords and redirect users to that page when it is time to change a password.
