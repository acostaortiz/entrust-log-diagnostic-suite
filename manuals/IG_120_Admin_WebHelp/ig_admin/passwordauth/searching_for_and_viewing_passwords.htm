IdentityGuard Server 12.0 Administration Guide

Searching for and viewing passwords

Administrators with the userPasswordGet permission can search on users under their control based on attributes of their password. You can search for users based on the presence or absence of a password, the expiry date associated with an existing password, the date a password was last changed, as well as its state (that is, whether it requires a forced update or not).

To search for password information in the Administration interface, complete the following:

To find users based on their passwords

1.      Log in to the Administration interface. (See Logging in and out of the Administration interface.)

2.      Click User Accounts on the home page.

3.      Click the Find Accounts tab.

4.      Select Has the additional account characteristics below to view additional options.

The Additional account characteristics pane appears.

5.      To find users who have no password, select Doesn’t have a password.

6.      To find users with passwords, select Has a password.

Other options appear that let you choose the passwords to search for:

●       Password needs to be changed

●       Password doesn’t need to be changed

●       Password last changed

●       Password expiry date

For information about searching for users using password information and other criteria see To find users by password authentication.

7.      Select additional search options if needed.

8.      Click Find Accounts.

A list of existing users meeting your search criteria appears.

9.      Click any name to see details about that user.
