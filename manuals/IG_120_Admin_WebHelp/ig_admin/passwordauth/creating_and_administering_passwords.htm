IdentityGuard Server 12.0 Administration Guide

Creating and administering passwords

Administrators with applicable permission can create or change passwords for users and other administrators:

●       They can create or change passwords and password attributes one by one in the Administration interface.

●       They can create or change passwords and password attributes in bulk.

After you create passwords, you need to distribute them to your users. Alternatively, you can have the user create and update their own password in your application interface. (See Having a user set up a password.)
