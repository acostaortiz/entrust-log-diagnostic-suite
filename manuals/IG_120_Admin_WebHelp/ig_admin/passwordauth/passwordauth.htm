IdentityGuard Server 12.0 Administration Guide

Password authentication

This section explains how to configure Entrust IdentityGuard password authentication, and how to create and manage user passwords.

This section contains the following topics:

●       Password authentication overview

●       Configuring password authentication policies

●       Setting disallowed password properties

●       Creating a disallowed password list

●       Creating and administering passwords

●       Providing passwords to users

For information about administrator passwords, see Creating and changing administrator passwords.

Note: The term “password” appears often in Entrust IdentityGuard documentation. For clarification, one-time password, the Entrust IdentityGuard password, and token password all refer to separate authentication methods.
