IdentityGuard Server 12.0 Administration Guide

Setting password authentication policies

The Authentication Types policy sets the authentication methods available to users and your application. To allow password authentication as an authentication method, the Password option must be in the list of allowed authentication methods. (It is set as part of the initial default policy.)

There are two authentication levels you can set: normal and enhanced. Each has its own policy, so you can set different authentication methods for each level.

To view authentication types policy

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      Select Policies on the menu bar.

A list of all policies appears on the List Policies tab.

3.      Click any policy name to view its policy information.

The View Policy page appears and lists all policy settings.

4.      Under Policy Category, select Authentication Types from the list.

The policies for normal and enhanced security appear along with other authentication-related policies.

To change authentication policy

1.      Find the policy to change.

2.      On the View Policy page, click Edit Policy.

An editable version of the settings appear.

Where authentication methods can be in one of two lists (Included and Not Included), buttons placed between the two lists allow you to move some or all options from one list to the other.

3.      Do one of the following to select authentication methods for the Normal Security Authentication Types and Enhanced Security Authentication Types:

●       To add password authentication if not already selected, select Password in the Not Included list and click the right-arrow to move the option to the Included list.

●       To disable password authentication if in effect, select Password in the Included list and click the down-arrow to move the option to the Not Included list.

See Move items between option lists for detailed instructions on moving options between the Included and Not Included lists.

4.      Set the precedence of the password authentication method for normal security, enhanced security, or both:

●       Select Password in the Included list.

●       Click either the up-arrow to move Password up the list or click the down-arrow to move it lower in the list. Click the button once for each position you want the option moved.

See Set option precedence for more information about precedence.

5.      Change other policies as applicable. For a description of each policy, see Policies quick reference.

For information about setting the authentication types that can view or modify user secrets, see Configure access to user secrets.

6.      Click Save Changes. The View Policy page reappears.
