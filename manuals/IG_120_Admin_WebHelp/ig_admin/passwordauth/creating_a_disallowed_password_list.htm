IdentityGuard Server 12.0 Administration Guide

Creating a disallowed password list

You can set up a list of passwords that your users cannot pick when they create or update a password. When Entrust IdentityGuard starts up, it looks for the file named in the Properties Editor (see Setting disallowed password properties). If it finds this file, it loads the contents into memory. This prevents users from setting password values that are easily guessed, default system passwords, the names of financial institutions, or password examples from the documentation.

Attention: If Entrust IdentityGuard cannot find the file or if it encounters an error while loading the password file, such as corrupt data, this effectively disables the check for disallowed passwords. You can monitor the audit file for a failure code (AUD3207) or a success code (AUD3208) to determine the status of the disallowed password file. If the file is empty, Entrust IdentityGuard ignores the file and does not generate an audit message.

Make sure your disallowed password file is included in your Entrust IdentityGuard backup strategy and is copied to replicas each time it is updated.

Note: A large list may have a performance impact. A file with more than a 1000 words is not recommended.

To create a disallowed password list

1.      Open the disallowedpasswords.txt file in a text editor. The default location for this file is:

●       on Windows, in <$IG_HOME>\etc\ 

●       on UNIX, in $IG_HOME/etc/ 

2.      Modify this file to include the list of password values that your users are not allowed to use. Set only one value per line. The case of the words is ignored.

3.      Save this text file.

4.      If necessary, set the applicable password properties. (See Setting disallowed password properties.)
