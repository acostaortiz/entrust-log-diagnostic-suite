IdentityGuard Server 12.0 Administration Guide

Configure a biometric vendor

Currently, only one biometric vendor is supported (Cogent). For a list of biometric properties, see Biometric Vendor Configuration.

To configure properties for a biometric vendor

1.      Start the Entrust IdentityGuard Properties Editor. (See Logging in and out of the Properties Editor.)

2.      On the Table of Contents, click Biometric Vendor Configuration.

3.      Enter a biometric configuration name in the Configuration Instances field, for example, Fingerprint, and then click Add.

The properties for the biometric vendor appear.

4.      From the Biometric Vendor Class Name drop-down list, select Cogent Fingerprint.

5.      Under Biometric Vendor Display Name, enter a name for the biometric vendor to display in the Administration interface, for example Fingerprint.

6.      Click Validate & Save.

7.      Log out of the Properties Editor and restart the Entrust IdentityGuard server service after you make all property changes.
