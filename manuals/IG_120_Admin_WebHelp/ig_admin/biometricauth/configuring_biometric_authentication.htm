IdentityGuard Server 12.0 Administration Guide

Worksheet for configuring biometric authentication

Tip: Copy and save this worksheet in Microsoft Word or another word-processing application to track your progress and record configuration details. Be sure to keep your worksheet in a secure location.

This worksheet describes the tasks involved in configuring Entrust IdentityGuard to support fingerprint biometric authentication with Entrust IdentityGuard Desktop for Microsoft Windows. Tasks are performed in various Entrust IdentityGuard components, as indicated.

This worksheet uses the following abbreviations:

IG—Server that hosts the Entrust IdentityGuard Server

IG Ad—Entrust IdentityGuard Server Administration interface

PE—Entrust IdentityGuard Properties Editor

SSM—Server that hosts the Entrust IdentityGuard Self-Service Module

SSM Config—Entrust IdentityGuard Self-Service Module Configuration interface

SSA—Self-Service application

 

Task done on...

Task

Details

IG

1.      Install Entrust IdentityGuard 10.2 Feature Pack 1 or later.

For installation instructions, see the patch release notes.

SSM

2.      Install Entrust IdentityGuard Self-Service Module 10.2 Patch 184895 or later. Ensure the Transaction component is enabled. (It is selected by default in the Self-Service Module installer.)

For installation instructions, see the patch release notes.

IG Ad

3.      Ensure that your IdentityGuard implementation has licenses for the biometric authentication feature.

To check, see Display license information. For more information, see Managing licenses.

IG Ad

4.      Ensure that Entrust IdentityGuard administrators have the required permissions to complete biometric-related tasks and manage biometrics. The built-in roles superuser, useradmin, auditor, and transactionadmin have biometric-related permissions.

See Biometric permissions and Built-in roles.

SSM

5.      Ensure that Entrust IdentityGuard Self-Service administrators have the required permissions. If the Self-Service administrator uses the superuser role and the transaction administration service account uses the default transactionadmin role, they will have all the required permissions.

See Biometric permissions and Built-in roles.

PE

6.      Use the Properties Editor to set the configure the biometric vendor.

See Configuring a biometric vendor.

IG Ad

7.      Use the Administration interface to configure policies for biometric authentication.

See Include biometric authentication in a policy and Configure biometric authentication policies.

SSM Config

8.      Use Self-Service Module Configuration to configure biometric self-administration actions that allow end-users to launch the fingerprint enrollment client and enroll their fingerprints in Entrust IdentityGuard.

For more information, see "Configuring biometric self-administration" in the Entrust IdentityGuard Self-Service Module Administration Guide.

User PCs

9.      Deploy fingerprint scanners to users.

  

User PCs

10.  Deploy Entrust IdentityGuard Desktop for Microsoft Windows and the Fingerprint Enrollment Client to end users.

For more information, see the Entrust IdentityGuard Desktop for Microsoft Windows Administration Guide for Windows Login.

SSA

11.  Have users install the Entrust IdentityGuard Desktop for Microsoft Windows and the Fingerprint Enrollment Client. As part of the installation of the Fingerprint Enrollment Client, users are directed to your self-service module where they select I’d like to enroll for biometric authentication.

For end-user instructions, see the Entrust IdentityGuard Self-Service Module User Guide.
