IdentityGuard Server 12.0 Administration Guide

Modifying user information

You may need to modify user account information when:

●       you are adding or modifying contact information

●       your users require new or modified aliases

●       you need to assign a user to a different group

When modifying user information:

●       If you are updating the user name in an LDAP-compliant directory, you can do one of the following

–  First update the user name in the directory and then make the corresponding changes in Entrust IdentityGuard.

–  Create a new user name in the directory and then change the user name in Entrust IdentityGuard. You can then delete the old directory entry.

●       If you move a user to another group, ensure that the user’s user name and aliases are unique within the group (they cannot match another user name or alias in the group).

●       If you move a user to another group, the associated cards and tokens also automatically move and any new challenges are generated using the policies of the new group. Ensure the card is valid for answering the challenges generated using the new policies. If not, cancel it and issue another card for the user.

Entrust IdentityGuard generates the challenge using the grid size policy. The least-used challenge algorithm generates challenges according to the history of previous challenges using the current card. The least-used algorithm does not update automatically with the policy or group change—you must issue your user a new card with the new challenge policies. See When to replace a user grid card.

Note: If an administrator changes the policy governing the maximum number of aliases, shared secrets, or contact information entries allowed for a user to values less than those already assigned to a user, you cannot change and save any fields related to that user's account until the problem is fixed. The Edit Account page displays a message informing you how many aliases, shared secrets, or contact information entries must be deleted.

To modify information about a user

1.      Log in to the Administration interface (Logging in and out of the Administration interface).

2.      In the main menu, click User Accounts.

The User Accounts page appears.

3.      Find a specific user in one of two ways:

●       use the Go To Account tab (see To search for information about one user)

●       use the Find Accounts tab (see To search for information about one or more users)

The View Account pane appears with account and authentication information for the specific user.

4.      Click Edit Account.

The Edit Account page appears.

Note: If you use a directory as your repository and you have changed a user name entry for a user, Entrust IdentityGuard recognizes the discrepancy and forces you to update the user name when you select Edit Account. For more information, see User name consistency between Entrust IdentityGuard and an LDAP directory.

5.      On the Edit Account page, edit the user information as required:

●       (If applicable) Change the user name by entering a new user name in the User Name field.

●       Select the new group for the user in the Group drop-down list. (For LDAP repositories, changing the group may not be possible if the group references a different search base.)

Note: The user ID (group and user name) must be a maximum of 255 characters.

●       Change the user’s full name by entering a new full name in the User’s Full Name field.

●       Add or remove aliases. (For more information about aliases, see Using aliases.)

–  To add a new alias, enter a new alias in the text field and click Add or press Enter while your cursor is still in the text field.

–  To remove aliases, select one or more aliases in the Aliases list and click Remove. See Selecting options.

–  Click Restore to restore the list of aliases to what it was when the page was initially displayed. This restores deleted aliases and also removes newly added aliases.

Alias guidelines:

–  Aliases must contain at least one character and can contain any Unicode characters except for the slash mark (/).

–  Aliases are case-insensitive.

–  Spaces before and after an alias are removed by Entrust IdentityGuard.

–  Aliases must be unique within a group (an alias cannot match another user name or alias within the group).

●       Change the user’s card or token activation time period. (See Creating grid cards.)

●       Add comments to the user account by entering text in the Comments text box.

●       Create, edit, or delete contact information. (See Administering contact information.)

●       Create, edit, or delete shared secrets. (See Administering shared secrets .)

6.      Click Save Changes.

The View Account page reappears.
