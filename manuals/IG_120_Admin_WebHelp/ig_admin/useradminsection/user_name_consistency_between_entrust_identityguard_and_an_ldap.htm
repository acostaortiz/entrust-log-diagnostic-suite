User name consistency between Entrust IdentityGuard and an LDAP directory

The label for the user name field on the Edit account information page can vary depending on your repository.

●       If you use a database, the label is always User Name.

●       If you use Active Directory or an LDAP repository, the label is one of the following:

–  User Name appears if the name used by Entrust IdentityGuard is the same as the user ID used in your directory.

–  Previous User Name appears if someone has changed the user ID used in your directory.

If the label says Previous User Name, you must update the user name in Entrust IdentityGuard by changing the previous name to the new name in the repository. See Modifying user information.
