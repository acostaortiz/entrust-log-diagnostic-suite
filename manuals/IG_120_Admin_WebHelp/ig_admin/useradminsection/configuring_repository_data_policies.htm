IdentityGuard Server 12.0 Administration Guide

Configure repository data policies

The repository data policies define the following:

●       whether users can authenticate if their user entry is disabled or expired in the LDAP user repository (including a synchronized Active Directory repository)

●       whether users can be created in Entrust IdentityGuard if their user entry is disabled or expired in the LDAP user repository (including a synchronized Active Directory repository)

●       whether users can authenticate if their user entry is orphaned after a synchronization with the Active Directory user repository. For more information about synchronization with Active Directory, see Synchronize Active Directory users with an Entrust IdentityGuard database.

For detailed information about setting up repository data feature, see Suspend disabled and expired LDAP users.

To configure repository data policies

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      In the main menu, click Policies.

A list of all policies appears on the List Policies tab.

3.      Click any policy name to view its policy information.

The View Policy page appears and lists all policy settings.

4.      From the Policy Category drop-down list, select Repository Data.

5.      Click Edit Policy.

An editable version of the settings appears.

6.      In the Repository Data Policy Category pane, configure the following settings. The policies apply to either an Entrust IdentityGuard LDAP repository or a synchronized Active Directory repository.

 Click a policy to see its description.

Allow Creation if User Disabled in Repository

Set this policy to Yes if you want to allow creation of a user in Entrust IdentityGuard whose directory entry is disabled (in either an Entrust IdentityGuard LDAP repository or a synchronized Active Directory repository).

This may be useful if you are moving a user from one repository to another. The user may already be disabled in one repository, but you will still be allowed to create the user in another.

Default: No 

Allow Creation if User Expired in Repository

Set this policy to Yes if you want to allow creation of a user in Entrust IdentityGuard whose directory entry is expired (in either an Entrust IdentityGuard LDAP repository or a synchronized Active Directory repository).

Default: No (not selected)

Allow Authentication if User Disabled in Repository

Set this policy to Yes if you want to allow users to continue to be able to authenticate if their user record is disabled in the LDAP user repository (either an Entrust IdentityGuard LDAP repository or a synchronized Active Directory repository). If you set this policy to No, the user is treated as suspended in Entrust IdentityGuard.

Note: This setting does not apply if the LDAP user record is being used for external authentication. When external authentication is enabled, and the user’s record is disabled, their first-factor external authentication attempt will always fail regardless of how this setting is configured, and no second-factor challenge (such as a grid challenge) will be presented. For more on external authentication, see External authentication.

Default: No (not selected)

Allow Authentication if User Expired in Repository

Set this policy to Yes if you want to allow users to continue to be able to authenticate if their user record is expired in the LDAP user repository (either an Entrust IdentityGuard LDAP repository or a synchronized Active Directory repository). If you set this policy to No, the user is treated as suspended in Entrust IdentityGuard.

Note: This setting does not apply if the LDAP user record is being used for external authentication. When external authentication is enabled, and the user’s record is expired, their first-factor external authentication attempt will always fail regardless of how this setting is configured, and no second-factor challenge (such as a grid challenge) will be presented. For more on external authentication, see External authentication.

Default: No (not selected)

Allow authentication if User Orphaned in Repository

Set this policy to Yes if you want to allow users to continue to be able to authenticate even if their user record is orphaned after a synchronization operation with an Active Directory user repository. When this policy is set to No, the user is treated similarly to a suspended user in Entrust IdentityGuard.

Note: This property is used only with the Active Directory synchronization feature.

Default: No (not selected)

7.      Click Save Changes.
