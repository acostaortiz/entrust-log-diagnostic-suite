IdentityGuard Server 12.0 Administration Guide

Manage orphaned user accounts

Entrust IdentityGuard accounts might be orphaned after a synchronization with Active Directory. This might occur for one of the following reasons:

●       a user was deleted in Active Directory

●       a user was moved to an Active Directory container that is not synchronized with an Entrust IdentityGuard database

You can generate an Entrust IdentityGuard report to get information about orphaned accounts. Use this report to review the orphaned accounts and determine whether the accounts should be deleted.

Entrust IdentityGuard does not delete user accounts automatically because to do so would delete all authenticators for the user and that information cannot be recovered if it turns out that the Active Directory user was only moved or perhaps deleted by mistake.

Orphaned users are treated similarly to suspended users in Entrust IdentityGuard, which means that (by default) orphaned users cannot authenticate to resources protected by Entrust IdentityGuard. The default behavior can be changed by enabling the Repository Data policy setting Allow Authentication if User Orphaned in Repository.

To create a report of Entrust IdentityGuard orphaned accounts

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      In the main menu, click Reports.

The Select a report page appears.

3.      Click User CSV Report, and then click Next.

4.      In the Report Description field, briefly describe what the report will contain, for example "Orphaned user accounts".

5.      In the User account search criteria pane, select Has the additional account characteristics below.

The Additional account characteristics pane appears.

6.      Select Sync orphaned.

7.      If desired, select other report options, as described in Configuring reports.

8.      Click Generate Report.

The Report List shows the report title and its status as it is being generated.

9.      When report generation is complete, click the report icon in the Download column.

The report opens in a program that reads CSV files (for example, Microsoft Excel).

10.  Use the information in the report to take appropriate action for the orphaned accounts. For example, if the users are deleted in Active Directory, delete the accounts in Entrust IdentityGuard individually or through a bulk operation..

Note: The Sync orphaned and Not sync orphaned user account characteristics apply only to users in an Entrust IdentityGuard database. Users in an Entrust IdentityGuard LDAP repository are not selected if there characteristics are selected as part of the search criteria. Additionally, any user in an Entrust IdentityGuard database repository that is not configured for Active Directory synchronization is not returned for searches using these characteristics.
