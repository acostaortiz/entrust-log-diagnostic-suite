IdentityGuard Server 12.0 Administration Guide

Modify shared secrets

Modify shared secrets as needed. You cannot modify shared secrets if you exceed the size limit set by policy. To change the shared secret policies, see Configuring shared secret policies.

To modify shared secrets

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      In the main menu, click User Accounts.

The User Accounts page appears.

3.      Find a specific user in one of two ways:

●       use the Go To Account tab (see To search for information about one user)

●       use the Find Accounts tab (see To search for information about one or more users)

The View Account page appears.

4.      Click Edit Account.

The Edit Account page appears.

5.      Click Shared Secrets to expand the Shared Secrets pane.

6.      In the Shared Secrets pane, modify the following settings, as required:

●       Secret Name — Enter a unique name for the shared secret.

●       Secret Value — (Optional) Enter a value for the shared secret.

●       Admin API Access Only — Select this option to restrict access to shared secrets to administrators and applications using the Administration API). By default (not selected), both the Authentication API and Administration API have access to the secrets. This means that users can see the secrets.

7.      Click Save Changes to update the shared secret information.

If required, to undo any changes, click Restore.
