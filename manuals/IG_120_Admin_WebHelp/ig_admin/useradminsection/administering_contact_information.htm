Administering contact information

When you create or modify users, you can configure their contact information. Users can have as many contact information entries as allowed by their group's policy. To specify the maximum number of entries users can have, see Configuring user data policies.

Each contact information entry has the following attributes:

●       a label (such as Phone or Email)

●       a value (such as a phone number or an email address) (This is optional if you have set the Delivery Method to None.)

●       a delivery method (see Configuring delivery mechanisms for one-time passwords )

●       a flag indicating if the delivery method is the default delivery method

You can use a user’s contact information to send information to them. You can also configure your Entrust IdentityGuard to use contact information entries to automatically send users one-time passwords (see Configuring delivery mechanisms for one-time passwords ).

For more information about one-time passwords, see Configuring and using out-of-band one-time password authentication
