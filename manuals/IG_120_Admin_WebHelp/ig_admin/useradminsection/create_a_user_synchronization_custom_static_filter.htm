Create a user synchronization custom static filter

You can create a custom static filter for use when you are enrolling  Entrust IdentityGuard users from your Active Directory user repository or when you are synchronizing data from the Active Directory user accounts..

The base filter used by Entrust IdentityGuard filters out the records of those users who already have Entrust IdentityGuard accounts.

The base filter for Active Directory that is used by Entrust IdentityGuard is:

(&(<useridattribute>=*) (!(entrustIGUserInfoMac=*)) (!(entrustIGGlobalPolicy=*)) (!(objectclass=group)))

 

The base filter tests for users already enrolled in Entrust IdentityGuard. You create additional filtering to skip entries beyond that by creating a filter expression. The following table provides some examples of user enrollment filter expressions.

Filter expression

Result

objectclass=inetOrgPerson

returns only those entries that contain the inetOrgPerson objectClass attribute

|(c=ca)(c=us)

returns entries located in either Canada or the United States.

!(isCriticalSystemObject=TRUE)

skips user entries that are added to the LDAP repository by default, and that are used for Windows internal purposes

&(!(isCriticalSystemObject=TRUE))(objectClass=person)

skips user entries that are added to the LDAP repository default, and that are used for Windows internal purposes. Returns only those entries that contain the person objectClass attribute

Note: If you add this filter to the properties file manually, and it is invalid (that is, it contains errors), the error is logged and user enrollment is disabled.

To create the filter for finding potential new users in the Active Directory repository

1.      Log in to the Entrust IdentityGuard Properties Editor.

Windows

a.      Select Start > All Programs > Entrust > IdentityGuard > Properties Editor.

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

UNIX

a.      Enter the URL of your Properties Editor web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardPropertiesEditor

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

2.      On the Table of Contents, click LDAP Directory Server Settings.

3.      Ensure that User Enrollment is set to True to enable user enrollment.

4.      Compose a valid  filter expression to show the user entries to be added to Entrust IdentityGuard. See the Active Directory repository documentation for details.

5.      Test your filter to ensure that it results in the desired records being selected.

The Properties Editor checks the syntax of your filter, but does not test it for accuracy.

6.      Enter your filter expression in User Enrollment Search Filter property field.

7.      Click Validate & Save.

8.      Restart the IdentityGuard Server service to have the changes take effect.
