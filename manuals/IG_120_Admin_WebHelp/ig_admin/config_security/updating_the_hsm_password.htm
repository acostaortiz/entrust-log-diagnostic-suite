IdentityGuard Server 12.0 Administration Guide

Updating the HSM password

Read this section if you are using a Hardware Security Module (HSM) to store Entrust IdentityGuard’s master keys. For details on HSMs, see the Entrust IdentityGuard Installation Guide.

When you installed and initialized your HSM, you specified a password that would be used to access the HSM. If you want to update this password, you must do so on the HSM and Entrust IdentityGuard.

Attention: Just updating the password on the HSM causes the Entrust IdentityGuard services to fail, and may lock you out of the HSM.

Follow the instructions below to update the HSM password.

To update the HSM password

1.      Stop all Entrust IdentityGuard service on the primary and replica servers.

2.      Exit any Master user shell sessions.

3.      On the HSM, update the HSM password. See your HSM vendor’s documentation for details.

4.      In Entrust IdentityGuard, update the HSM password:

a.      Log in to the Master user shell. See the Master User Shell Reference Guide for details.

The following message appears:

The password required to access the hardware security module has changed. The updated password is required.

b.      Enter the new HSM password.

The new password is encrypted and stored in the master key file.

5.      Start the services on the server that you just updated.

6.      Repeat steps 4 and 5 for all replicas accessing the HSM.
