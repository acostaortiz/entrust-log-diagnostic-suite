IdentityGuard Server 12.0 Administration Guide

Managing certificates in the key store

This section contains procedures for managing the key store for your Entrust IdentityGuard installation.

The Entrust IdentityGuard server's key store contains the public certificate and the associated private key that allows other components, such as Self-Service Module, to communicate with the Entrust IdentityGuard server. To communicate with the server, the other components need to import the Entrust IdentityGuard server's SSL web server certificate, which is typically found at the tomcat entry in the keystore, into their own key stores (or key store equivalent).

If your installation uses the embedded Apache® Tomcat® Java application server, the Administration interface includes a Key Store Management interface that provides a simple way to perform most tasks associated with monitoring and managing the certificates used in your installation. In most cases, it replaces the need to use the command-line keytool utility. Where use of keytool is required, the appropriate procedures are included.

If your installation uses an IBM® WebSphere® or Oracle® WebLogic application server, the Key Store Management interface is not present. You can use the command-line keytool utility or other key store management tools available in your environment.

●       If you choose to use the Key Store Management interface, see the procedures in Manage certificates using the Key Store Management tab

●       If you choose to use they keytool utility, see the procedures in Manage certificates using keytool
