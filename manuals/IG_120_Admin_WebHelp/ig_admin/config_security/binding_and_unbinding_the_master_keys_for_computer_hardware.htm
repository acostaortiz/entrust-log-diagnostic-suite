Binding and unbinding the master keys for computer hardware changes

By default, Entrust IdentityGuard binds the Master Keys to the local computer hardware in such a way that minor changes to the hardware still allows the Entrust IdentityGuard services to start. You can also bind the master keys in strict mode. In strict mode, minor hardware changes will cause the services to fail to start.

If you need to change your computer hardware, complete the following procedure to avoid Entrust IdentityGuard service errors.

To bind and unbind the master keys for computer hardware changes

1.      Stop all Entrust IdentityGuard services.

2.      Start the Master user shell in UNIX or Windows (see Using the Master user shell).

3.      Unbind the master keys by entering the following command:

system unbind

4.      Change your computer hardware as required.

5.      Start the Master user shell again.

6.      Bind the master keys back to the local computer by entering the following command:

system bind [-strict]

Where -strict binds the binds the Master Keys to the local computer hardware in strict mode. In strict mode, minor hardware changes will cause the services to fail to start.

7.      Restart the Entrust IdentityGuard services.
