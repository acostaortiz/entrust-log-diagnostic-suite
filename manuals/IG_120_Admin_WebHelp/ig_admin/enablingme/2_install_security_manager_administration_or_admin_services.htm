IdentityGuard Server 12.0 Administration Guide

2: Install Security Manager Administration or Admin Services

If you installed a Microsoft CA, skip this section.

If you installed Entrust Authority Security Manager, you must install either Entrust Authority Security Manager Administration or Entrust Authority Administration Services. Both these software products are user interfaces for Security Manager. Administration Services is the pared-down Web-based version of Security Manager Administration. Install one or the other.

Installation instructions can be found at https://secure.entrust.com/trustedcare in one of the following guides:

●       Entrust Authority Security Manager Administration User Guide 

●       Entrust Authority Administration Services Installation and Configuration Guide
