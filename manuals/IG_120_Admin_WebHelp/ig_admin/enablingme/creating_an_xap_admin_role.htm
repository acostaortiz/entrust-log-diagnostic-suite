IdentityGuard Server 12.0 Administration Guide

Creating an XAP admin role

You must create an XAP administrator role. This role is needed in preparation for the next step, Creating an XAP credential (EPF file), which is used to access the Security Manager CA.

To create an XAP administrator role

1.      Log in to Security Manager Administration (SMA) as an administrator. For more information about logging in to SMA, see the Entrust Authority Security Manager Administration User Guide.

2.      In the tree view, expand Security Policy > Roles.

3.      Select the User Reg Service (Admin Services) role.

The User Reg Service (Admin Services) role is the default role for the User Registration Service (URS). This role includes the user policy and most of the permissions required for the XAP administrator.

4.      Select Policies > Roles > Selected Role > Copy.

A copy of the role appears at the bottom of the list of roles in the tree view, and the new role’s properties appear in the right pane.

5.      Under the Role tab:

●       In the Unique name field, enter a name for the role. For example, XAP Administrator Role.

●       In the Authorizations field, enter the number of authorizations required for sensitive operations.

The default is 1. When you want to queue operations for administrator approval, you must set this to 2 or greater. For more information on queuing, see the Entrust Authority Security Manager Administration User Guide.

●       In the User Policy drop-down list, select Server Login Policy. This user policy should already be selected.

●       Deselect the End User check box. This check box should already be deselected.

6.      Click the Permissions tab.

7.      In the Categories list, select Groups then click Properties.

The Administrative Permissions: Groups dialog box appears.

8.      Under Administer Groups, click All groups.

9.      Click OK.

10.  In the Categories list, select Users then click Properties.

The Administrative Permissions: Users dialog box appears.

11.  Click the User - General tab. Select the following permissions:

Note: For each permission, ensure that Requires Authorization is not selected. Operations performed by the XAP administrator should not be queued for administrator approval.

●       View 

●       Add 

●       Reactivate 

●       Deactivate/Remove 

●       Modify properties 

●       Revoke certificates 

●       Update key pairs 

●       Set for key recovery 

●       Modify key update options 

Do not select this permission if you want to enable request queuing with Entrust Entelligence Security Provider for Windows clients.

●       View activation codes 

●       Reissue activation codes 

12.  Click the User - Advanced tab. Select the following permissions:

●       Change user’s role 

●       Modify group membership 

●       Perform PKIX requests 

●       Create user profile 

●       Recover user profile 

Note: For each permission, ensure that Requires Authorization is not selected. Operations performed by the XAP administrator should not be queued for administrator approval.

13.  Click OK.

14.  In the Categories list, select Roles then click Properties.

The Administrative Permissions: Roles dialog box appears.

15.  Under Administer Roles, click All roles.

16.  Click OK.

17.  To prevent the XAP Administrator operations on a Managed CA from being queued for administrator approval, set the following permissions:

a.      In the Categories list, select Security Policy, then click Properties.

The Administrative Permissions: Security Policy dialog box appears.

b.      Select the Force CRLs permission, and ensure that the Requires Authorization check box is not selected.

c.      Click OK.

d.      In the Categories list, select Queued Requests, then click Properties.

The Queued Authorizations dialog box appears.

e.      Deselect the View Queued Requests and Create Queued Requests permissions.

f.        Click OK.

18.  On the Security Manager Administration window, click Apply.

19.  If prompted, authorize the operation. The operation may require more than one authorization. See the Security Manager Administration User Guide for details.

Note: If you chose to complete Step 17, you can ignore the recommendation to set the View Queued Requests permission. You can ignore the Bind to Directory prompt; it is not applicable to the XAP administrator.
