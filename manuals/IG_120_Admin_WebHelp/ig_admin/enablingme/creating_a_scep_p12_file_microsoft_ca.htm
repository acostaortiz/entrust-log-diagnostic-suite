IdentityGuard Server 12.0 Administration Guide

Create a SCEP P12 file (Microsoft CA)

Complete the following procedure to create a SCEP P12 file.

To create a SCEP P12 (Microsoft CA)

1.      Log in to the Master user shell. See Using the Master user shell.

2.      To create the P12 file, use the following command syntax:

ca microsoft p12 -dn <dn_of_certificate> -certTemplates “<name_of_template>” -p12 <name_of_cert>.p12 -caCommonName <common_name_of_CA> -host <fully_qualified_name_of_CA_host> -dirHost <fully_qualified_name_of_diectory_host> -dirLdapPort <port_number_of_ldap_directory>

Where:

●       <dn_of_certificate> is the distinguished name that you want to have appear in the certificate. The DN can be anything you like, for example, cn=IGSCEPadministrator. However, as a best practice, it is recommended you use a DN that incorporates your Windows domain. For example, if your domain is mydep.myco.com, then an appropriate CN might be cn=IGSCEPadministrator,dc=mydep,dc=myco,dc=com.

●       <name_of_template> is IG Dual Usage.

●       <name_of_cert>.p12 is the name of the PKCS#12 file that the IG Dual Usage key and certificate will be stored in after it is created. This guide assumes you used IGSCEPadministrator.p12.

●       <common_name_of_CA> is the common name of the CA. You can find it by opening the Windows Server Manager, and looking under Roles > Active Directory Certificate Services. It is the item with the green check mark ()that contains folders for Revoked Certificates, Issued Certificates, and so on.

●       <fully_qualified_name_of_CA_host> is the fully qualified domain name (FQDN) of the machine where the CA is installed. You can find the FQDN by going to the CA computer, opening Windows explorer, and navigating to Computer > Properties. The FQDN is listed next to Full computer name.

●       <fully_qualified_name_of_directory_host> is the fully qualified domain name of the computer hosting the directory.

●       <port_number_of_ldap_directory> is the port used to contact the LDAP directory—389, by default. If you are using the default port, there is no need to specify it.

An example of this command is:

ca microsoft p12 -dn cn=IGSCEPadministrator,dc=mydep,dc=myco,dc=com -certTemplates “IG Dual Usage” -p12 c:/IGSCEPadministrator.p12 -caCommonName msca -host exampleca.mydep.myco.com -dirHost exampledir.mydep.myco.com

Attention: Use / in paths. Do not use quotes or \.

3.      Entrust IdentityGuard prompts you to provide a password for the PKCS#12 file.

Specify a password for the PKCS#12 file.

You will need to enter this password again when you add your CA’s information to Entrust IdentityGuard, in a later step.
