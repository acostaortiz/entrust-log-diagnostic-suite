IdentityGuard Server 12.0 Administration Guide

Step 14: Mirror password rules

You must ensure that your password rules are mirrored in the following systems: Entrust IdentityGuard and your CA (either a Security Manager CA or a Microsoft CA). Mirrored means that no one password rule should be stronger than the equivalent one in a different system. If the rules are not mirrored, conflicts may arise.

To mirror password rules

1.      To view (and configure, if necessary) the password rules in a Security Manager CA:

a.      Log in to Security Manager Administration. See the Entrust Authority Security Manager Administration User Guide.

b.      In the tree view, expand Security Policy > User Policies.

c.      Select a user policy. It must be the one that is configured in the digital ID configuration. See Step 10: Add a digital ID configuration In this guide, the End User policy is used.

d.      Click the General Information tab.

e.      Password rules are listed in the Policy Attributes section. Change them to match the Entrust IdentityGuard password rules, if required.

2.      To view (and configure, if necessary) the password rules in a Microsoft CA:

a.      Go to the computer hosting the Active Directory used by your Microsoft CA. (They might be installed on the same computer.)

b.      Open Active Directory Users and Computers.

c.      Find your password policy. It is listed under your Group Policy, under Computer Configuration > Windows Settings > Account Policies > Password Policy.

d.      Ensure the password policy matches the Entrust IdentityGuard password rules, if required.

Consult your Active Directory documentation for details on setting password rules.

3.      To view (and configure, if necessary) the password rules in Entrust IdentityGuard:

a.      Log in to the Entrust IdentityGuard Administration interface.

b.      Click Policies.

c.      Select a policy that is assigned to your user groups.

d.      From the Policy Category drop-down list, select Password.

e.      Password rules are listed. Click Edit Policy to change them to match the Security Manager password rules, if required.
