IdentityGuard Server 12.0 Administration Guide

Configuring the KDC map file

When you use a domain controller for external authentication, you need to map each realm to its Key Distribution Center (KDC) in the igkrb5.conf file. On Windows, the KDC is the domain controller.

The igkrb5.conf file, if it has been created, is located:

●       on UNIX in $IG_HOME/etc/

●       on Microsoft Windows in <$IG_HOME>\etc\

If the igkrb5.conf file does not yet exist, copy igkrb.sample to igkrb.conf.

igkrb.sample is located:

●       on UNIX in $IG_HOME/etc/

●       on Microsoft Windows in <$IG_HOME>\etc\

To edit the igkrb5.conf file

Note: For more information about syntax, refer to http://web.mit.edu/kerberos/krb5-1.5/krb5-1.5.1/doc/krb5-admin/krb5.conf.

1.      Open igkrb5.conf in a text editor.

2.      Using Kerberos syntax, map each realm to the server hosting the corresponding Kerberos Key Distribution Center (KDC).

Note: For Windows Active Directory domains, the KDC is the domain controller.

For example:

[realms]

ENTRUST.COM = {

      kdc = ig1.entrust.com

   }

Make sure to enter the realm name in uppercase characters.

3.      Add other Kerberos-related settings as required. For example, you may want to change the default encryption key type. For Windows Server 2008, you require the following lines for the encryption key types:

default_tkt_enctypes = des-cbc-md5 des-cbc-crc rc4-hmac

default_tgs_enctypes = des-cbc-md5 des-cbc-crc rc4-hmac

permitted_enctypes = des-cbc-md5 des-cbc-crc rc4-hmac

Attention: If you wish to support non-ASCII passwords when using Microsoft Active Directory Kerberos, you must use RC4 encryption. Ensure that you are running a Java Runtime Environment version that supports this.

If you are using IBM WebSphere or BEA WebLogic application servers, check with your vendor to find out if non-ASCII passwords are supported.

4.      Save your changes.

For an example of how to set up the KDC file for failover, see To set up failover when using Kerberos for external authentication.

For an example of how to set up the igkrb5.conf file, see the igkrb5.sample file stored in the etc directory where you installed Entrust IdentityGuard.
