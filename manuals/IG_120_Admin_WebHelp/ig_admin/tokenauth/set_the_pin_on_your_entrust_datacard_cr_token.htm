Set the PIN on your Entrust Datacard CR token

When you receive your new Entrust Datacard CR token, it has the default personal identification number (PIN) 123456. The token prompts you to set a new 6-digit PIN the first time you use it.

To set your PIN

1.      Press the power button to turn on the token.

2.      When prompted, enter the default PIN, 123456.

3.      Enter a new 6-digit PIN, and enter it again to verify it.

A message indicates that the PIN has been updated.
