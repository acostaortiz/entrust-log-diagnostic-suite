IdentityGuard Server 12.0 Administration Guide

Assign WatchdataQRO tokens to users

Initialized WatchdataQRO tokens must be assigned to specific users before they can be delivered. Specific tokens can be assigned by an administrator using the Administration interface, or they can be assigned by Self-Service (using the auto-assign option described in Configure self-administration for WatchdataQRO tokens).

The following procedure describes how an administrator assigns a token using the Administration interface.

To assign a WatchdataQRO token

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      Click Tokens.

3.      Click the List Unassigned Tokens tab and locate the token you want to assign in one of the following ways:.

●       Enter the serial number of a specific token.

●       Select Watchdata QRO from the Token Vendor drop-down list, and then click Search to see a list. Select a token from the list.

4.      On the Token Details page for the selected token, click Assign Token.

5.      On the Select a user account for this token page, enter the user name of the intended user, and then click Next.

6.      On the Assign a token to a user page, click Assign Token.

Entrust IdentityGuard confirms that the token is assigned.

If you enabled the Move Hardware Tokens To User's Group During Assignment policy, Entrust IdentityGuard displays an informational message that the token group will be updated automatically.

7.      Click OK.
