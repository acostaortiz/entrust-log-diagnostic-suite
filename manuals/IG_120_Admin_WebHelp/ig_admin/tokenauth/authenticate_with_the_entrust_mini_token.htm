IdentityGuard Server 12.0 Administration Guide

Authenticate with the Entrust Mini Token

When logging in to a protected resource, use the Entrust Mini Token to generate a unique and time-limited password.

To authenticate with the Entrust Mini Token

1.      Press and hold down the button on the Mini Token until the status bar fills the display.

The token generates and displays the dynamic password.

2.      Enter the password into the login screen of the software you are using.

3.      To turn off the token, press the button again.

The token turns off automatically after 20 seconds of inactivity.
