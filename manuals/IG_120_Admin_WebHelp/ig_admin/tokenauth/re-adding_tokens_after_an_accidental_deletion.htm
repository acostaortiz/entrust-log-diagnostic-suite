IdentityGuard Server 12.0 Administration Guide

Add tokens again after an accidental deletion

If you accidentally delete a token instead of unassigning it, the token is removed entirely from Entrust IdentityGuard and cannot be re-used. To integrate the deleted token back into Entrust IdentityGuard, you must re-load the token data file. Upon re-load, Entrust IdentityGuard will load any tokens that are not in the system and skip any tokens already present. At the end of the process, a message appears telling you how many were loaded.

For details on re-loading the token data file, see Load the token data file.
