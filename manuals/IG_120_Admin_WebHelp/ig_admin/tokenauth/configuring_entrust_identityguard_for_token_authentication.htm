IdentityGuard Server 12.0 Administration Guide

Worksheet for configuring token authentication

Tip: Copy and save this worksheet in Microsoft Word or another word-processing application to track your progress and record configuration details. Be sure to keep your worksheet in a secure location.

This worksheet describes the tasks involved in configuring Entrust IdentityGuard to support hardware token authentication. Tasks are performed in various Entrust IdentityGuard components, as indicated.

This worksheet uses the following abbreviations:

IG—Entrust IdentityGuard Server Administration interface

PE—Entrust IdentityGuard Properties Editor

SSM—Entrust IdentityGuard Self-Service Module Configuration interface

SSA—Self-Service application
