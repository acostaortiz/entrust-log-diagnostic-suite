IdentityGuard Server 12.0 Administration Guide

View the serial number on a Pocket Token

Complete this procedure if your administrator asks you for the token serial number.

To view the serial number

1.      Generate a dynamic password, as described in Authenticate in response-only mode - Entrust Pocket Token.

2.      When the Pocket Token displays the dynamic password, press the MENU button to access the menu.

3.      Press the MENU button. Repeat until the Pocket Token displays the VIEW SN menu option.

(The number of times you need to press the MENU button depends on the number of menu options with which the Pocket Token is configured.)

4.      Press the ON button.

The Pocket Token displays its serial number.

5.      Press the MENU button to return to the Pocket Token menu.
