Get the reason for token response failure

Note: This section applies to all event-based tokens and OATH time-based tokens.

By default, the error message shown for an invalid token response is the same as the one shown for an out-of-sync token. You can change this behavior so that Entrust IdentityGuard provides different error messages for the two cases. Follow the instructions below.

To generate separate error messages for token response failure reasons

1.      Find the entrusttoken.conf file (or an equivalent file with a different name). If the file does not exist, create it as a text file. The default location is:

●       on UNIX, $IG_HOME/etc/

●       on Microsoft Windows, <$IG_HOME>\etc\

2.      Add the following entry to the file

checkForReset=true

●       When checkForReset is true, Entrust IdentityGuard presents an error message indicating that the token must be synchronized (also know as ‘reset’ or ‘reactivated’) if it has drifted too far out-of-sync with the server. A different error message is presented if the token response is invalid.

●       When checkForReset is false, Entrust IdentityGuard presents the same, generic error message for both an invalid token response and an out-of-sync token.

3.      Save the file.

4.      Follow the procedure at Ensure the token configuration file is assigned.
