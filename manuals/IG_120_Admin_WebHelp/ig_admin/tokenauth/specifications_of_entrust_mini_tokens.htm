Triple DES

Uses the DES algorithm three times. Like DES, it operates on 64 bit data blocks. Some forms of triple DES use two 56 bit keys and some use three. The DES “modes of operation” may also be used with triple DES. Entrust uses EDE mode with two 56 bit keys.

Authentication

The Entrust Mini AT Token supports synchronous authentication using a two variable algorithm: the event counter plus DES or 3DES key. The Mini Token OT supports the OATH TOTP algorithm.

Standards compliance

The Entrust Mini Token complies with the following standards: FCC (IEC-1000-462 Level 4), CE, UL

Customizing the Entrust Mini Token

The Mini Token can be customized with customer names and logos.

If you want to customize Mini Tokens for use in your organization, you must have a completed and approved Entrust Mini Token Customization document.

Customization is subject to minimum quantities and may require a longer delivery time. Contact Entrust for details.
