IdentityGuard Server 12.0 Administration Guide

Using a token

A hardware token generates a dynamic one-time password (OTP) of up to 8 digits that a user enters when challenged by your Web site or application. Entrust IdentityGuard checks whether the OTP is valid and, if it is, authenticates the user.

Note: Each token password can be used just once. The token generates a new dynamic password for every authentication challenge. 

The general token authentication flow is described here. User procedures for specific types of tokens are included in the section of each token.

For response-only tokens, the process is:

1.      Through your Web site or application, Entrust IdentityGuard asks for a generated token response.

2.      For some tokens, the user may have to enter a personal identification number (PIN) using the token's keypad. When the PIN is entered the token is unlocked and can be used.

3.      The user presses the button on the token device.

4.      The token generates a numerical password.

5.      The user enters the password in the response field.

For challenge-response tokens, the process is:

1.      Through your Web site or application, Entrust IdentityGuard issues a challenge number and asks for a generated token response.

2.      The user presses the button on the token.

3.      For some tokens, the user may have to enter a personal identification number (PIN) using the token's keypad. When the PIN is entered the token is unlocked and can be used.

4.      The user enters the challenge number issued by Entrust IdentityGuard into the token.

5.      The token generates a numerical password.

6.      The user enters the password in the response field.

Entrust Datacard CR tokens also allow users to digitally sign transactions with their tokens. For more information, see Sign a transaction with your Entrust Datacard CR token.

Using PVNs with hardware tokens

In Entrust IdentityGuard, when authenticating with a token, a personal verification number (PVN) may also be required as part of the token response. A PVN is a number that the user chooses. (See Personal verification number overview.) A PVN consists of a string of numeric characters that users must enter into the application with their dynamic token password when challenged by Entrust IdentityGuard. A PVN is available for use with several authentication methods, including tokens.
