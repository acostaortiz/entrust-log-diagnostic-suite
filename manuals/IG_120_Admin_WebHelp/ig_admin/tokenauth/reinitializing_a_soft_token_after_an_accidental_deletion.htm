Reinitialize a soft token after an accidental deletion

If a soft token becomes locked because a user repeatedly enters an incorrect PIN, it remains locked for the timeout period. If you accidentally delete the token or token user at that point, you must take the following steps to restore a working token.

Issue a new soft token to the user.

When the user accesses the token, it will be in a locked state. The user must right-click the gray background in the token challenge dialog and select Reinitialize.

A warning dialog box appears to the user. Click Yes. The Add Identity dialog box appears.

The administrator must now click Activate Token on the User Accounts page for the user in the Administration interface.
