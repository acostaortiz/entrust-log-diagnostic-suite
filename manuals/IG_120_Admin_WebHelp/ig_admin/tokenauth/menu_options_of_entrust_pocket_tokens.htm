IdentityGuard Server 12.0 Administration Guide

Menu options of Entrust Pocket Tokens

The menu options described in the following table are accessible after the Entrust Pocket Token has generated a dynamic password. These standard menu options are configured during manufacture.

Message

Description

CHANGE PIN

(Optional) Change the PIN on the Entrust Pocket Token.

Note: If you configure the Entrust Pocket Token to not use a PIN, the CHANGE PIN menu option is not available.

VIEW CLOCK

View the internal clock value on the Entrust Pocket Token. This menu option is available when using the synchronous authentication mode or the dual authentication mode.

VIEW COUNT

View the value of the synchronous authentication event counter on the Entrust Pocket Token.This menu option is available only when using the synchronous authentication mode.

VIEW SN

View the serial number of the Entrust Pocket Token..

INIT KEY

(Optional) Manually initialize the 3DES keys of the Entrust Pocket Token, and optionally, the PIN policy and authentication mode policy.

SEC MODE S

(Optional) Toggles the Entrust Pocket Token to asynchronous mode. This menu option is available only when using the dual authentication mode.

SEC MODE A

(Optional) Toggles the Entrust Pocket Token to synchronous mode. This menu option is available only when using the dual authentication mode.
