IdentityGuard Server 12.0 Administration Guide

Load updated IP location data

When you first install Entrust IdentityGuard, the IP/Geolocation data is preloaded. You need to update this data regularly.

To load updated IP location data

1.      Download the latest IP data ZIP file as described in Get updated IP data files.

2.      Open the Master user shell and log in.

To start the Master user shell on UNIX

1.      Log in to the Entrust IdentityGuard server as the user who owns the Entrust IdentityGuard installation.

2.      Change to $IG_HOME (usually /opt/entrust/identityguard101).

3.      From $IG_HOME, source the environment settings file by typing:

. ./env_settings.sh

(Include a space between the two periods in the command.)

4.      To start the Master user shell, enter:

supersh

Copyright information and the Entrust IdentityGuard version number appear, followed by a command prompt.

To start the Master user shell on Windows

●       Click Start > All Programs > Entrust > IdentityGuard > Master User Shell.

Copyright information and the Entrust IdentityGuard version number appear, followed by a command prompt.

3.      At the prompt, enter

system ip load <file>

where file is the name of the file, typically geoip.zip.

For example:

system ip load c:/geoip.zip

Attention: Use ’/’ or ’\\’ in the file path. Do not use ’\’.

This command unzips the file in the default location.
