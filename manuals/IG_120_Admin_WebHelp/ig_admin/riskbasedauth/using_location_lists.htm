IdentityGuard Server 12.0 Administration Guide

Using location lists

Entrust IdentityGuard can maintain two location lists for a user:

●       Location history — This list tracks all the places from which a specific user has logged in to your network.

●       Expected location — This list specifies the locations from which a specific user usually logs in to your network.

Entrust IdentityGuard recognizes two location address types:

●       Private — Private location addresses are private IP addresses in an internal network. Each network has a set of private addresses They fall within the following ranges

–  10.0.0.0-10.255.255.255,

–  172.16.0.0-172.31.255.255, and

–  192.168.0.0-192.168.255.255

While many external networks have these same IP addresses, these private addresses are unique within the internal network. They work behind a firewall and are not accessible externally.

●       Public — Public location addresses are Internet addresses. They include any address that is not private. Public addresses are accessible to anyone with Internet access. Each address is unique.

Note: Entrust IdentityGuard does not support IPv6 addresses. If an IPv6 address is provided to RBA authentication, it is ignored.
