IdentityGuard Server 12.0 Administration Guide

Using the location history list

When a user logs in, Entrust IdentityGuard can compare the user’s location to past location data in the user’s location history list. The result of this comparison (pass or fail) is part of risk assessment.

For each successful authentication from a public location, Entrust IdentityGuard converts the IP address to location data and stores the following information in the location history list:

●       country

●       region

●       city

●       ISP name

●       latitude and longitude of this location

●       IP address

●       date and time of the authentication

●       number of times the user authenticated from this location

For each successful authentication from a private location, Entrust IdentityGuard stores the following information in the location history list:

●       IP address

●       date and time of the authentication

●       number of times the user has authenticated from this location

Location comparisons that involve public locations look at the country, region, city, and ISP. The IP address is also used in the comparison if the Check IP Address in Location History policy is enabled. (See Configuring IP/Geolocation policies.) If all comparison items exactly match, the two locations are considered the same and the test passes. If there is any difference, even a minor spelling variation for the ISP name, the test fails.

Private location comparisons use just the IP address, and checking is controlled by the “Check IP” flag. You can set the “Check IP” flag in policy or by user. If the flag is set, then two private locations match only if they have the same IP address. If the flag is not set, then all private locations are deemed to match.

When a user logs in for the first time, that user has no location history list; therefore the location history test fails.

The number of entries in the list is set by the Maximum Location History Size policy. To set policy related to the location history, see Configuring RBA policies.
