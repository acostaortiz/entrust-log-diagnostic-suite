IdentityGuard Server 12.0 Administration Guide

Get updated IP data files

Entrust IdentityGuard is configured to use MaxMind as the source for IP/Geolocation data.

You need to update the MaxMind IP location data on a regular basis — at least monthly. To update the MaxMind data, your organization must have a subscription to Entrust's Open Fraud Intelligence Network (OFIN) Standard Data Service. For more information, see http://www.entrust.com/ofin/. Data downloads are available from the Entrust TrustedCare Online Web site

Note: The Entrust IdentityGuard backup mechanism does not back up MaxMind data files.

You can have multiple versions of the IP/Geolocation data on a server. Entrust IdentityGuard always uses the most recent version and automatically checks (every minute) to see if a new version has been installed into Entrust IdentityGuard.

The original installation of Entrust IdentityGuard installs the IP data file. To install later updates of the IP data file or to reload a file after a backup and restore operation, get the latest data file (see To get an updated IP location data file), and then use the Master user shell (see Loading the IP location data).

The latest IP data file is always available on the Entrust Web site.

Note: Before performing this procedure, ensure that you have subscribed to the Open Fraud Intelligence Network (OFIN) Standard Data Service.

To get an updated IP location data file

1.      In your Web browser, go to https://www.entrust.com.

2.      Click OFIN.

3.      Click Get Started.

4.      Login using your Entrust credentials.

5.      If this is the first time you are visiting this site, scroll to the bottom of the license agreement page, and click I accept.

6.      Click Data Downloads.

7.      Choose one of the downloads available for the GeoIP database. The choices are:

●       ZIP

●       MD5

●       SHA-1

●       SHA-256

8.      Save the download.

9.      Copy the file to your Entrust IdentityGuard server.

10.  Continue by following the instructions in Update IP location data using the Master user shell.

11.  Repeat steps 9 and 10 for every Entrust IdentityGuard replica.
