Calculate the distance between locations

In some cases you might need to turn off velocity checking for certain users.

For example, a user may authenticate from two different public IP addresses. The first IP address might contain complete information, including the latitude and the longitude of the IP address. The second IP address might contain only the country and the location defaults to the middle of the country. When authenticating from the two IP addresses, it may appear the user changed locations too quickly.

Use this procedure to calculate the distance in kilometers between two locations (that correspond to two public IP addresses) and determine whether some users might encounter the situation described. If it is likely that the user authentication attempt would fail the velocity test due to insufficient detail in the IP address, you could turn off velocity checking for the affected users.

To calculate the distance between locations

1.      Open the Master user shell and log in. (See Using the Master user shell.)

2.      At the prompt, enter

system ip distance <ipaddess1> <ipaddress2>

where <ipaddress1> and <ipaddress2> are two IP addresses.
