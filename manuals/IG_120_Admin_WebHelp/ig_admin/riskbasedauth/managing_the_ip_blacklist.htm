IdentityGuard Server 12.0 Administration Guide

Add entries to the IP blacklist

You can have a single, system-wide IP blacklist that applies to all users. When Entrust IdentityGuard starts up, it loads the IP blacklist into memory for quick comparisons.

To keep the list compact and easy to maintain, each entry you add to the blacklist can specify a range of IP addresses. For example, the entry “100.1.1.1-100.1.1.10” represents 10 IP addresses. (The blacklist supports only version 4 IP addresses.) By default, the IP blacklist included with Entrust IdentityGuard is empty.

Administrators with applicable permissions (ipListGet, ipListAdd, and ipListDelete) can view and edit the IP blacklist. You can also import a list contained in a file.

To add entries to the IP blacklist

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      Select System on the menu bar.

3.      Click the IP Blacklist tab.

The list of blacklist entries appears. Initially, the list is empty.

4.      Click Add New Range.

The Add to the Blacklist pane appears.

5.      To add addresses, complete the following:

●       To enter a single address, enter the IP address in Start Address and click Add.

●       To enter an address range, enter the first address in the range in Start Address, enter the last address in the range in End Address, and click Add.

6.      To get location information about any address you enter, click Lookup IP Address.

A page of location details similar to the following appears.

Click Done to return to the Add to the Blacklist pane.

7.      Each time you click Add on the Add to the Blacklist pane, you add a new address or range to the blacklist.

8.      After you add all IP addresses to the list, click Done.
