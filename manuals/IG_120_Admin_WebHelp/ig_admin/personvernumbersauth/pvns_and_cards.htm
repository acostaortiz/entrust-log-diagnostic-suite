IdentityGuard Server 12.0 Administration Guide

PVNs and cards

You can require any user to enter a PVN as part of their grid challenge. The PVN is entered first, followed by the grid challenge response.

If grid authentication requires a PVN, and the user does not have a PVN yet, the user is forced to assign themselves a new PVN. The new PVN is accepted when the user successfully authenticates with the grid (assuming the new PVN is numeric and the correct length).
