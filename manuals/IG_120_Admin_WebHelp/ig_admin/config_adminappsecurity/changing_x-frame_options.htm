IdentityGuard Server 12.0 Administration Guide

Changing X-Frame options

To change the default X-FRAME-OPTIONS setting for the Administration interface

1.      Stop the Entrust IdentityGuard services.

2.      Locate the web.xml file for the Entrust IdentityGuard Administration interface and open it for editing. By default, this file is found in the following directory:

$IG_HOME\services\admin\IdentityGuardAdmin\WEB-INF

3.      Search for the following entry.

<!--  Servlet Filter for adding the X-FRAME-OPTIONS directive -->

 <filter>

   <filter-name>X-FRAME-OPTIONS Filter</filter-name>

   <filter-class> com.entrust.identityGuard.webadmin.XFrameOptionsFilter</filter-class>

   <init-param>

       <param-name>X-Frame-Options</param-name>

       <param-value>DENY</param-value>

   </init-param>

 </filter>

4.      Change the <param-value> from DENY to one of the following options:

●       SAMEORIGIN to allow the page to be rendered in a frame if the origin of the top-level browsing context is the same as the origin of the content containing the X-Frame-Options directive.

●       ALLOW-FROM <origin> to allow the page to be rendered in a frame only if the origin of the top-level browsing context is the same as the origin value supplied with the ALLOW-FROM setting.

Note: At the time of publication of this document, the ALLOW-FROM <origin> option is not implemented by Google Chrome or Apple Safari browsers. This setting is not recommended if your user community uses either of these browsers.

5.      If you entered the parameter value ALLOW-FROM <origin> in the previous step, replace <origin> with the URL of the top-level Web page in the browsing context. For example, if https://ig.mycompany.com contains the X-Frame-Options directive with the value ALLOW-FROM https://adminportal.mycompany.com, the pages associated with https://ig.mycompany.com can be framed only by pages that originate from the https://portal.mycompany.com.

6.      Save and close the file.

7.      Restart the Entrust IdentityGuard services.

To change the default X-FRAME-OPTIONS setting for the Properties Editor

1.      Stop the Entrust IdentityGuard services.

2.      Locate the web.xml file for the Entrust IdentityGuard Administration interface and open it for editing. By default, this file is found in the following directory:

On Windows:

$IG_HOME\services\admin\IdentityGuardPropertiesEditor\WEB-INF

On UNIX:

$IG_HOME/services/admin/IdentityGuardPropertiesEditor/WEB-INF

3.      Search for the following entry.

<!-- Main Preditor Servlet: GET to retrieve language-based XML property template and POST to save changes -->

 <servlet>

   <servlet-name>Main Preditor Servlet</servlet-name>

    <servlet-class>com.entrust.identityGuard.preditor.PropertiesEditorServlet</servlet-class>

   <init-param>

       <param-name>supportedProperties</param-name>

       <param-value>/xml/properties.xml</param-value>

   </init-param>

   <init-param>

       <param-name>X-Frame-Options</param-name>

              <param-value>DENY</param-value>

   </init-param>

   <load-on-startup>2</load-on-startup>

 </servlet>

4.      Change the <param-value> from DENY to one of the following options:

●       SAMEORIGIN to allow the page to be rendered in a frame if the origin of the top-level browsing context is the same as the origin of the content containing the X-Frame-Options directive.

●       ALLOW-FROM <origin> to allow the page to be rendered in a frame only if the origin of the top-level browsing context is the same as the origin value supplied with the ALLOW-FROM setting. Replace <origin> with the URL of the top-level Web page in the browsing context.

Note: At the time of publication of this document, the ALLOW-FROM <origin> option is not implemented by Google Chrome or Apple Safari browsers. This setting is not recommended if your user community uses either of these browsers.

5.      If you entered the parameter value ALLOW-FROM <origin> in the previous step, replace <origin> with the URL of the top-level Web page in the browsing context. For example, if https://ig.mycompany.com contains the X-Frame-Options directive with the value ALLOW-FROM https://adminportal.mycompany.com, the pages associated with https://ig.mycompany.com can be framed only by pages that originate from the https://portal.mycompany.com.

6.      Save and close the file.

7.      Restart the Entrust IdentityGuard services.
