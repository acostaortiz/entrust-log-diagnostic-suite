IdentityGuard Server 12.0 Administration Guide

Data items for one-time password bulk operations

Each data item in a one-time password bulk file must use the correct data type.

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique.

otpIndex

integer

all

Used to specify the OTP to delete.

Use the all option to delete all OTPs.

contactInfoLabels

semicolon (;) separated list

Used to specify the contact address for sending the OTP.

useDefaultDelivery

boolean

If True, the contactInfoLabels column is ignored.

Used in the DeliverOTPs operation.

lifetime

duration

A non-negative integer with optional units, where:

·      d = days

·      h = hours

·      m = minutes

·      s = seconds

Example: 10s  = 10 seconds

Example: 2000 = 2000 msec

Note: If you do not specify a time unit, the value will be interpreted as being in msec.

Sets the lifetime of a one-time-password. Lifetime always starts from the current time on the server. A value of 0 indicates no time limit.

expireDate

dateTime

An RFC3339-formatted time string. Example 1:

2007-04-12T23:20:50Z

represents 20 minutes and 50 seconds after the 23rd hour of April 12th, 2007 in UTC.

Example 2:

2007-12-19T16:39:57-08:00

represents 39 minutes and 57 seconds after the 16th hour of December 19th, 2007 with an offset of -08:00 hours from UTC.

Provides an alternative way to set a lifetime. The date must be in the future.

overwrite

Boolean

true  or  false

Used for OTP creation to force overwriting of an existing OTP.
