IdentityGuard Server 12.0 Administration Guide

Edit a bulk file

When you edit a bulk file, keep the following in mind:

●       If a bulk file includes accented characters or other special characters, you must save the bulk file as a UTF-8 encoded file.

●       The user ID implies both the group and user name. You do not need to specify the group if your system includes unique user names.

●       To include a comma character in a string, prefix the comma with a back slash (\).

●       A string cannot contain a newline character.

●       Entrust IdentityGuard validates a dateTime value exactly as entered. For example, Entrust IdentityGuard treats February 31 as an error and does not convert it to March 3.

●       Entrust IdentityGuard ignores the fractional seconds component of a dateTime value. For example, 2013-04-12T23:20:50.52Z is treated as 2013-04-12T23:20:50Z.

●       You can include multiple aliases when you create users. To do so, there are two methods:

–  Include the alias data type multiple times in the first row. Include the user’s group as part of the user ID but do not include the group name with each alias. Find the user with the most aliases and create a column for each of that user’s aliases. For other users, leave the extra columns blank.

–  Separate aliases with a semicolon (;). If the alias includes a semicolon, prefix the alias with a back slash (\).

●       To include more than one role for a user, separate role names with a semicolon. If the role name includes a semicolon, prefix the semicolon with a back slash (\).

●       In the bulk file, Entrust IdentityGuard ignores blank rows, and trims white space at the beginning and end of each row and surrounding each comma.

●       The bulk files used by the Administration interface and the Master user shell are constructed the same way. You can use the bulk files in either interface.

●       If Entrust IdentityGuard finds any errors when processing a bulk file, it displays the errors in the Administration interface.

After editing a bulk file, you can validate it in the Administration interface. See Validating bulk files.
