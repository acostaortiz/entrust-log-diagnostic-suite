IdentityGuard Server 12.0 Administration Guide

Data items for token bulk files

Each data item in a token bulk file must use the correct data type.

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique.

serialNumber

string

Contains one of three types of values:

·      all matches all tokens

·      a state value (for example, current) matches any tokens in that state (only one state can be specified)

·      any other value is treated as a serial number

Provides a token serial number.

Note: The all and state values are not valid for assign operations.

state

One of: pending, hold_pending, current, hold,  or  canceled

Provides the state of a token.

Note: You cannot create a token in the canceled state.

group

string

Specifies the group to move the token to.

targetSets

string

Specifies an existing token set to which an existing token belongs.

set

string

Specifies a new token set for the token.

tokenVendor

string

Specifies the vendor ID of the token.

If you do not include this data item, the default token vendor is assumed.

resetToken

Boolean

true  or  false

When true, it resets a token to fix token drift. Depending on the token, the bulk file must also include at least one of resetTokenResponse1  and resetTokenResponse2.

tokenActivationType

string

Can be one of NONE, ONLINE, or OFFLINE.

Used for activation of third-party soft tokens. Do no use for Entrust tokens or soft tokens.

comment

string

Assigns a comment to a token.
