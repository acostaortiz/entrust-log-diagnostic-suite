Data items for smart credential bulk files

Each data item in a user account bulk file must use the correct data type.

An example bulk file for creating a smart credential with the Enterprise definition might look like the following:

userid,smartCredentialDefinition,smartCredentialVariable:photo:image,smartCredentialVariable:firstname,smartCredentialVariable:lastname,smartCredentialVariable:grid,friendlyName

default/user1,enterprise,<base64 encoded image>,Nathan,Sample,1,AnyBank

default/user2,enterprise,<base64 encoded image>,John,Smith,2,JSmithSC

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

smartCredentialDefinition

string

The value is the name of a smart credential definition.

smartCredentialId

string

The value is a smart credential ID.

smartCredentialFriendlyName

string

The friendly name gives the smart credential a display name that is more meaningful than the smart credential id. This value is displayed to the user, for example, in Self-Service when the user is shown a list of smart credentials on which to perform actions.

smartCredentialApproved

Boolean

Specifies whether you want to approve or unapprove the smart credential. Values include:

·      true: Set to true if you want to approve the smart credential.

·      false: Set to false if you want to unapprove the smart credential.

smartCredentialSealed

Boolean

Specifies if you want to seal the smart credential. Set to true to seal the smart credential.

smartCredentialSerialNumber

string

The value is an unassigned smart credential serial number.

smartCredentialState

  

A smart credential state value:

·      UNASSIGNED

·      ACTIVE

·      HOLD

·      CANCELED

smartCredentialDelivery
Method

string

The name of a configured delivery method.

smartCredentialPrint
Module

string

The name of a print module.

smartCredentialIssue
Operations

  

A list of smart credential issue operation values:

·      PRINT

·      PRINTER_ENCODE

·      EXTERNAL_ENCODE

·      PROXIMITY

smartCredentialVariable

  

The column names are of the form smartCredentialVariable:[<varname>][:<subtype>], where <varname> is a variable name from the smart credential definition and the optional <subtype> depends on the type of the variable. The value for the column in the bulk file depends on the variable type. Variable types:

·      BOOLEAN: No subtype. The value is a boolean.

·      COUNTRY: No subtype. The value is a country code.

·      DATE: No subtype. The value is a string of the form YYYY/MM/DD.

·      DIGITALID: No subtype. The value is a digital id name.

·      ENUM: No subtype. The value is one of the allowed enum values.

·      FINGERPRINT: Subtypes. In the following, <n> is replaced by an integer value 1,2,3,4, depending on how many fingerprints are stored. For the columns below, the imagewsq column is required. All other columns are optional:

–  <n>:imagewsq – Base64 encoded value storing the WSQ.

–  <n>:imagejpg – Base64 encoded value storing the JPG.

–  <n>:type – an integer value

–  <n>:index – an integer value

–  <n>:width – an integer value

–  <n>:height – an integer value

–  <n>:dpix – an integer value

–  <n>:dpiy – an integer value

–  <n>:quality – an integer value

–  <n>:depth – an integer value

·      GRAPHIC: No subtype. The value is a smart credential graphic name.

·      GRID: No subtype. The value is a grid serial number.

·      INTEGER: No subtype. The value is an integer value.

·      KEY: No subtype. The value is a Base-64 encoded binary value.

·      PHOTO: Subtypes.

–  :image – a Base64-encoded image. This value is required

–  :smallimage – a Base64- encoded image. This value is optional

–  :result – an integer value. This value is optional

·      SIGNATURE: No subtype. The value is a Base-64 encoded signature.

·      STRING: No subtype. The value is a string.

UUID. No subtype. The value is a string.
