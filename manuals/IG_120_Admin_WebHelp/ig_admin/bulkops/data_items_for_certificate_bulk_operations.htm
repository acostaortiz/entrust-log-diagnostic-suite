Data items for certificate bulk operations

Each data item in a certificate bulk file must use the correct data type.

An example bulk file for assigning certificates to users might look like the following:

userId,certificateSerialNumber,certificateState,Comment

user1,MyCorp.com,87387578837987,active,Setting state to Active.

For more information about creating, editing and validating bulk files, see Perform bulk operations.

Attention: When using the assign operation, the certificate must be included in the bulk file.

Note: The export operation is included only in the Master user shell.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique within your system.

certificate

base-64 encoded

This is the actual certificate.

certificateIssuerDN

string

Specifies the DN of the certificate issuer.

The issuerDN must be specified only if a user has two certificates with the same serial number.

Note: Commas in the DN must be escaped ( \,) because commas are used as the separator in the bulk file.

certificateSerialNumber

string

Use this field to select the certificates to modify or delete.

This field can contain either the certificate serial number or the certificate state (active or inactive).

certificateState

string

This is the state to assign or set the certificate to.

The state must be either:

·      active

·      inactive

comment

string

Sets a new comment for the assigned or modified certificate.

certificateExportFile

string

This is the name of the file to export the certificate to.

certificateExportType

string

This specifies whether to export in CERT or P7.

If not specified, it defaults to CERT.

certificateExportBinary

boolean

This specifies whether to export the data as binary (true) or base-64 (false),

If not specifies, it defaults to false (base-64).
