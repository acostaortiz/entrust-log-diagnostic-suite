IdentityGuard Server 12.0 Administration Guide

Data items for user account bulk files

Each data item in a user account bulk file must use the correct data type.

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique within your system.

alias

list of strings

Separate aliases by a semicolon (;). For example:

alias1;alias2;alias3

If a semicolon is part of the alias name, prefix it with a backslash (\). For example:

alias1;alias2\;id;alias3  means alias1, alias2;id, and alias3.

Note: Alternatively, you can include the alias data item more than once in a single entry if the alias header is repeated multiple times.

Provides a user with one or more aliases.

fullName

string

Provides the user’s full name. For example, Alice Grey.

group

string

Provides a user’s group.

accessGroup

list of strings

Separate user access groups by a semicolon (;). For example:

ag1;ag2;ag3

If a semicolon is part of the user access groups name, prefix it with a backslash (\). For example:

ag1;ag2\;id;ag3 means user access group 1,and so on.

Note: Alternatively, you can include the user access groups data item more than once in a single entry if the user access groups header is repeated multiple times.

A list of all access groups.

addAccessGroups

Boolean

Indicates whether  the accessGroup list should be added to the current list of access groups.

removeAccessGroups

Boolean

Indicates whether the accessGroup list should be removed from the current list of access groups. If both addAccessGroups and removeAccessGroups are set to true, addAccessGroups is used.

usePolicyForAccessGroups

Boolean

Enables or disables the access group override policy. Note that when creating or modifying users with access groups, this parameter must always be present and set to false. Exception: You can set this parameter to true and leave accessGroup empty. This allows the combination of users being processed with some users having usePolicyForAccessGroups set to true and some having it set to false.

userState

string

active  or  suspended

Provides the state of the user.

suspendReason

string

Provides the reason why the user is suspended. The data item userState must be set to suspended.

userActivationDaysToExpiry

integer

Specifies how long (in days) a user can use just first-factor authentication until forced to use second- factor authentication.

The number of days is calculated from the current date.

Note: The userActivationCode string must contain the number of days (numdays)

userActivationCode

string

Contains one of four values:

·      notset — There is no forced activation date.

·      activated — The user is activated.

·      usepolicy — The user has as many days to activate as defined by policy.

·      numdays — Uses the number of days as specified in the userActivationDaysToExpiry column.

Specifies how long a user can use just first-factor authentication until forced to use second- factor authentication.

role

list of string

Separate role names by a semicolon (;). For example:

role1;role2;role3;

If a semicolon is part of the role name, prefix it with a backslash (\). For example:

role1;role2\;help;role3  means role1, role2;help, and role3

Specifies the name of a role or names of roles to assign to the user. The role or roles must already exist.

repository

string

Specifies the repository the user’s information is stored in. A blank field is ignored.

See Configuring repositories.

questions

semicolon (;) separated list of questions

Used to set and modify question and answer values.

If questions is not specified, then answers, mergeQA, and removeQA are ignored.

If removeQA is false, then the number of questions must match the number of answers.

answers

semicolon (;) separated list of answers

Used to set and modify question and answer values.

If removeQA is false, then the number of questions must match the number of answers.

mergeQA

Boolean

If true, contents of questions and answers are added to existing list of questions and answers.

If false, contents of questions and answers replace existing list.

If mergeQA is true, removeQA is ignored.

Default: false

removeQA

Boolean

If true, specified questions are removed from user’s list of questions.

If removeQA is true, the answer column is ignored.

Default: false

comment

string

Assigns a comment to a user.
