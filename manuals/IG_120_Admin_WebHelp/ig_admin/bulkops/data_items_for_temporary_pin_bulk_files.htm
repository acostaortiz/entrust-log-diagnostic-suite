IdentityGuard Server 12.0 Administration Guide

Data items for temporary PIN bulk files

Each data item in a temporary PIN bulk file must use the correct data type.

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique.

lifetime

duration

A nonnegative integer with optional units, where:

·      d = days

·      h = hours

·      m = minutes

·      s = seconds

Example: 10s  = 10 seconds

Sets the lifetime of a temporary PIN. Lifetime always starts from the current time on the server. A value of 0 indicates the temporary PIN never expires.

expireDate

dateTime

An RFC3339-formatted time string. Example 1:

2007-04-12T23:20:50Z

represents 20 minutes and 50 seconds after the 23rd hour of April 12th, 2007 in UTC.

Example 2:

2007-12-19T16:39:57-08:00

represents 39 minutes and 57 seconds after the 16th hour of December 19th, 2007 with an offset of -08:00 hours from UTC.

Provides an alternative way to set a lifetime. The date must be in the future.

maxUses

positive integer

Sets the maximum number of uses for a temporary PIN.

Note: A value of zero (0) is not allowed.

overwrite

Boolean

true  or  false

Used for temporary PIN creation to force overwriting of an existing temporary PIN.

comment

string

Assigns a comment to a temporary PIN.
