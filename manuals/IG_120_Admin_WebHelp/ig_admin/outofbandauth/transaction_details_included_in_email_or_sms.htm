Transaction details included in email or SMS

As an additional level of security, Entrust IdentityGuard can include transaction details in email or SMS messages containing OTPs, although this is not required. (Transaction details cannot be included in voice messages.) This allows the user to confirm that the transaction information is correct before entering the OTP in the application to complete the transaction.

Note: Transaction details are not included in voice messages.
