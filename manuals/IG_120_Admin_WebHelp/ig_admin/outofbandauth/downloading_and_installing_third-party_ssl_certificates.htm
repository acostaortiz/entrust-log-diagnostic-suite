Downloading and installing third-party SSL certificates

Entrust IdentityGuard uses third-party applications for some of its functions. For example, Clickatell and TeleSign are used for out-of-band delivery of one-time passwords in text messages and Authentify and TeleSign are used for out-of-band delivery of one-time passwords in voice messages. You need to obtain and install SSL certificates from these application providers as part of configuring OOB delivery.

Authentify requires a secure communication link using HTTPS. You must add the Authentify SSL certificate to the Entrust IdentityGuard trusted certificate store before using the service. The Authentify SSL certificate has a lifetime of two years. When the certificate expires, you must import an updated certificate.

To use the Clickatell or TeleSign text message services, you need to set up a secure communication link by using their SSL certificate. You must add this certificate to the Entrust IdentityGuard trusted certificate store before using the service. When the certificate expires, you must import an updated certificate.
