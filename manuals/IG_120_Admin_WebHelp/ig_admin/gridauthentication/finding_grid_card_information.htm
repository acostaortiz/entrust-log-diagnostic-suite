IdentityGuard Server 12.0 Administration Guide

Find grid card information

Use one of the following procedures to search for information about grid cards assigned to an individual user or list of users.

●       To find assigned grid card information

●       To display a user’s grid card information

To find assigned grid card information

1.      Log in to the Administration interface (see Logging in and out of the Administration interface).

2.      On the main menu, click Cards.

The Cards page appears.

3.      Click the List Assigned Cards tab.

4.      Enter any of the following criteria to locate specific assigned grid cards:

a.      To find a grid card with a specific card serial number, type the serial number in the Serial Number field.

b.      To find grid cards in specific states, do one of the following:

–  To only find grid cards in specific states, select the grid card states from the States Include list.

–  To locate tokens belonging to users who have no tokens in a specific state, select the state from the States Don’t Include list. Hold down the Ctrl key to select more than one state.

For more information about grid card states, see Grid card state overview. To select more than one option from a list, hold the Ctrl key (see Selecting options).

c.      To find grid cards that have reached certain usage thresholds, select one or more thresholds from the Usage Threshold Indicator list.

–  None returns all grid cards that have not reached a usage threshold.

–  Warning returns all grid cards that have reached the warning threshold.

–  Replacement returns all grid cards that have reached the replacement threshold.

To select more than one option from a list, hold the Ctrl key (see Selecting options).

Note: The Usage Threshold Indicator appears only when the grid card policy Challenge Generation Algorithm is Least-Used, not when it is set to Random.

d.      To find grid cards created within a certain date range, select a date range from the Creation Date drop-down list.

If you select Custom date range, select the From and To dates from the drop-down lists (day, month, year). You can also use the calendar icons to select dates.

e.      To find grid cards that expire within a certain date range, select a date range from the Expiry Date drop-down lists (day, month, year).

If you select Custom date range, select the From and To dates. You can also click the calendar icons to select dates.

5.      To find grid cards according to specific user account characteristics, select The owner of the card has the characteristics below.

The Card owner account characteristics pane appears. This pane provides additional options so you can search by various user account information. For more information about the options in this pane, see To search for information about one or more users.

6.      Optional. Select how many search results appear on each page, select a number from the Showing results per page drop-down list.

7.      Click Search.

The Search Results page appears.

8.      In the Serial Number column, click the serial number of the grid card you want to view.

The Card Details page displays all the information associated with that grid card.

To display a user’s grid card information

1.      Log in to the Administration interface (see Logging in and out of the Administration interface).

2.      On the main menu, click User Accounts.

3.      Find a specific user in one of two ways:

●       Use the Go To Account tab (see To search for information about one user).

●       Use the Find Accounts tab (see To search for information about one or more users).

4.      Under Authentication Types, click Cards.

5.      Click the serial number of a grid card to view its details.
