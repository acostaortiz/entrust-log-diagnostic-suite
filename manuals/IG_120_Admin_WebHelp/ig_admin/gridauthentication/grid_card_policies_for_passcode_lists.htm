Grid card policies for passcode lists

A passcode list is a grid card with specific policies. The following table lists the grid card policies that govern the construction of a passcode list. The policies you need to use depend on whether you want to prompt users for codes in the list randomly or in a fixed order, such as first to last.

Note: Random order offers more security than a fixed order because it is harder for an attacker to guess the next challenge.

To prompt for the passcodes in a random order, set the grid card policies as listed in the Random column of the following table. To prompt in a fixed order, set the grid card policies as listed in the Fixed Order column. After you set the grid card policies, use the applicable API operations described in API operations for passcode lists.

To configure grid card policies, see Configuring grid card design and behavior policies.
