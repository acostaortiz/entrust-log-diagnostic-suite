IdentityGuard Server 12.0 Administration Guide

Deleting user challenges

For authentication involving grids, knowledge-based questions and answers, and challenge-response tokens, Entrust IdentityGuard retains the challenge until it is answered correctly. This prevents users or attackers from cycling through challenges until they find one they can answer.

If you believe an attacker has compromised the challenge or if a user cannot authenticate with that challenge, you can delete the challenge.

When you delete a retained challenge, Entrust IdentityGuard provides a new challenge when the user attempts to authenticate. Users can have more than one unanswered challenge. To delete one unanswered challenge, you must delete all unanswered challenges. You cannot delete individual challenges.

To delete user challenges

1.      Open the Master user shell and log in. (See Using the Master user shell.)

2.      If you want to see if a user has unanswered challenges, enter

user challenge get <userid>

If there are no unanswered challenges, you see

Challenge Type:

If there is an unanswered grid card challenge, for example, you see

Challenge Type: GRID Size 3

3.      Next, delete the unanswered challenges for that user.

user challenge delete <userid>

4.      Enter y (yes) when prompted to confirm the action.
