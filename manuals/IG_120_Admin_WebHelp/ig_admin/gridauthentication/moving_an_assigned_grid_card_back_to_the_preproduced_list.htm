IdentityGuard Server 12.0 Administration Guide

Move an assigned grid card back to the preproduced list

You can only unassign grid cards that were originally preproduced grid cards, and that are in the pending or hold-pending state. A grid card created individually for a user cannot be unassigned because it was never on the preproduced grid card list.

You cannot unassign grid cards with a bulk operation in the Administration interface. You can only unassign grid cards with a bulk operation in the Master user shell. To unassign grid cards in a bulk operation, see the bulk operations section in the Entrust IdentityGuard Master User Shell Reference.

Note: You can only unassign a grid card from a user's account page, not from the Card Details page.

You can only unassign grid cards that are in the pending or hold-pending state, and they must have been preproduced grid cards.

To unassign a grid card and move it back to the preproduced list

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      On the main menu, click User Accounts.

3.      Find a specific user in one of two ways:

●       Use the Go To Account tab (see To search for information about one user).

●       Use the Find Accounts tab (see To search for information about one or more users).

4.      Under Authentication Types, click Cards.

The grid card options appear.

5.      Select the serial number of the grid card you want to unassign.

6.      Click Unassign Card.

7.      When prompted, click OK to confirm the reassignment of the grid card to the unassigned grid card list.
