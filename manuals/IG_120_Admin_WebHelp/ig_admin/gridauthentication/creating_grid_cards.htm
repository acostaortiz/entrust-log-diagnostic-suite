IdentityGuard Server 12.0 Administration Guide

Creating grid cards

Entrust IdentityGuard offers you multiple approaches to grid card creation:

●       Approach 1: Create the grid cards in Entrust IdentityGuard and then print them (the preproduction model). See Approach 1: Create preproduced grid cards for printing.

With this approach, you create the digital versions of the grid cards in Entrust IdentityGuard, and then you have them printed out using a printer of your choosing. Once printed, you can begin assigning grids to users.

Use this option to preproduce the grids so that you can assign them to users later. You may prefer to create and configure grid cards independently of user management activities, for example, if you want to have the grid cards manufactured before assigning them to users.

●       Approach 2: Obtain grid cards from Entrust and then add them to Entrust IdentityGuard (a variation on the preproduction model). See Approach 2: Load preproduced cards from Entrust.

With this approach, Entrust sends you a box of pre-printed physical grid cards, along with a CSV file containing the equivalent grids in digital format. You must load the CSV into Entrust IdentityGuard, and once this task is complete, you can begin assigning grids to users.

Use this option if you would prefer to have the grid card printing handled by Entrust instead of your organization.

●       Approach 3: Create a single grid card and assign it to an existing user (the produce and assign model). See Approach 3: Create a grid card for a specific user.

Use this option if you want to create grid cards on demand.

You can create grids in multiple partitions. You can create grids from any site or replica repository as long as your replica sites and your “master site” create grids in different partitions.

When creating grid cards, the following occurs:

●       The grid is associated with a group.

●       An entry containing the card information and grid is stored in a repository.

●       Optionally, the grid card is assigned to a user.

●       The grid card’s lifetime is set when assigned to a user.

Note: The preproduced grid card must belong in the same group as the user to whom it will be assigned. If it does not, you cannot assign the grid card to that user.

In order to complete these procedures, administrators must have the correct role permissions. See Configuring grid card policies for a list of all role permissions relating to grids.
