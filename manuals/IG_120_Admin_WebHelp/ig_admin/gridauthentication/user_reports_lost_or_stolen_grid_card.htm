IdentityGuard Server 12.0 Administration Guide

User reports lost or stolen grid card

It is not uncommon for users to lose or misplace their grid cards, and your organizational policies should encourage them to report a loss as soon as they notice. Entrust IdentityGuard allows administrators to deactivate a lost or stolen grid card and assign a new one easily and quickly.

To find user of lost or stolen grid card

1.      Log in to the Administration interface (see Logging in and out of the Administration interface).

2.      On the main menu, click User Accounts on the main menu.

3.      Type in the User Name or Alias, and select the user’s Group, if the user name or Alias is not unique.

4.      Click Go Account.

The View Account page for the user appears.

5.      Continue with the procedure To cancel the lost or stolen grid card.

To cancel the lost or stolen grid card

1.      Under Authentication Types in the User Account view, click Cards.

2.      Select the serial number of the grid card you want to cancel.

3.      Click Edit Card.

The Edit Card page appears.

4.      In the State drop-down list, select Canceled. If the user believes he will be able to locate the grid card by tomorrow (the user forgot the grid card at home, for instance), then see To put the lost grid card on hold.

5.      Click Save Changes. 

6.      When prompted, click OK to confirm the cancellation.

The grid card is now canceled. It is still accessible through the user’s account page as well as through a grid card search until it is deleted.

7.      Take note of the user’s Group before proceeding to the next step.

8.      Continue with the procedure To assign a new grid card.

To assign a new grid card

1.      On the Administration interface menu at the top of the window, click Cards.

2.      Click List Unassigned Cards.

The Search Options page appears.

3.      Select the user’s Group from the pull down list.

4.      Click Search.

A list of all unassigned grid cards created for the user’s group appears.

5.      Select a grid card by clicking the Serial Number of the grid card. Make sure you have the printed grid card showing that serial number in your inventory.

6.      On the Card Details page, click Assign Card.

7.      On the Select an account screen, type the User Name of the user you are assigning the new grid card to.

8.      Click Next.

9.      Select the Initial Card State you want the grid card to be in when you send it to the user. Pending is the default. The grid card state is changed to Current when the user successfully authenticates with it.

10.  Select the Card Lifetime.

11.  Optional. Check the box labeled Use the following comments instead of those assigned to the preproduced card. Type a note about the circumstances of the replacement grid card in the Comments box.

12.  Click Assign Card.

The confirmation screen appears.

13.  Click OK.

14.  Continue with the procedure To send a new grid card to the user.

To send a new grid card to the user

1.      Get the grid card with the serial number you just assigned out of inventory.

2.      Package and send the grid card using security precautions necessary based on

●       the location of the user: If the user is sitting on the same floor in the same building, you could call the user to pick it up. If the user is overseas, you must to package the grid card for shipment.

●       your method of getting the grid card to the user. If you are sending the grid card within your building or within your city, you may choose to put it in an interoffice mailer. If you are sending the grid card overseas, you may need to package it for shipment with a courier.

To put the lost grid card on hold

1.      In the View Account page for your user, under Authentication Types, select Cards.

2.      Click Edit Card.

3.      Select the grid card in the Current state (if the user has not yet used the grid card, it is in the Pending state) and click Edit Card.

4.      In the Edit a user’s card screen, select Hold from the State drop-down list.

5.      Click Save Changes.

If the user finds the grid card within, for example, 24 hours, then repeat this procedure and change the state of the grid card back to Current.

If the user has not found the grid card within the time frame set within your organization, follow the procedure To cancel the lost or stolen grid card.
