When to replace a grid card

Replace a grid card when it is nearing its usage or time replacement threshold. For example, you may need to replace a grid card when:

●       it has reached the end of its lifetime as set by the Card Lifetime policy

●       it has reached the maximum number of uses as set by the Challenge Count Replacement Threshold policy

●       it has reached the maximum threshold for least-used cells as set by the Least-Used Cell Replacement Threshold policy

For more information about configuring these policies, see Configuring grid card design and behavior policies. You can also search for users that need replacement grid cards. For more information, see To find assigned grid card information .

When replacing a grid card:

●       Assign, or create and assign, another grid card to the user. This grid card should be in the pending state. See Assign grid cards to users for details.

●       (Optional) Set the currently active grid card to be unusable after a certain date, for example, the superseded date. See Modify and import grid card information for details.

For more information about superseded grid cards, see Unassigned, deleted, valid, active, expired, and superseded grids.
