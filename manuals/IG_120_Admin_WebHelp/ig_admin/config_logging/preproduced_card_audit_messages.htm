IdentityGuard Server 12.0 Administration Guide

Preproduced card audit messages

These messages provide information about pre-produced grid cards.

 

Audit name

Log level

Default SNMP trap?

Event description

Single Preproduced Card Creation

(AUD2100)

INFO

 

Preproduced card {1} has been created in group {0}. {2}

Where:

·      {0} is the group.

·      {1} is the serial number of the card.

·      {2} is the list of arguments set for the new card.

Multiple Preproduced Card Creation Started

(AUD2101)

INFO

 

Start creating {1} preproduced cards with serial numbers from {2} to {3} in group {0}. {4}

Where:

·      {0} is the group.

·      {1} is the number of cards that are going to be created.

·      {2} is the start range for serial numbers of the new cards.

·      {3} is the end range for serial numbers of the new cards.

·      {4} is the list of arguments set for the new card.

Multiple Preproduced Card Creation Completed

(AUD2102)

INFO

 

Created {1}/{2} preproduced cards with serial numbers ranging from {3} to {4} in group {0}.

Where:

·      {0} is the group.

·      {1} is the number of cards actually created.

·      {2} is the number of cards that were supposed to be created.

·      {3} start range for serial numbers of the new cards.

·      {4} end range for serial numbers of the new cards.

Preproduced Card Deleted

(AUD2103)

INFO

 

Preproduced card with serial number {0} has been deleted.

Where {0} is the serial number of the card.

Preproduced Card Updated

(AUD2104)

INFO

 

Preproduced card {0} has been updated. {1}

Where:

·      {0} is the serial number of the card.

·      {1} is the list of arguments set for the new card.

Preproduced Card Assigned

(AUD2105)

INFO

 

Preproduced card {0} has been assigned to user {1}. {2}

Where:

·      {0} is the serial number of the card.

·      {1} is the user ID.

·      {2} is the list of arguments set for the new card.

Preproduced Card Imported

(AUD2106)

INFO

 

Preproduced card {1} has been imported in to group {0}.

Where:

·      {0} is the group.

·      {1} is the serial number of the card.
