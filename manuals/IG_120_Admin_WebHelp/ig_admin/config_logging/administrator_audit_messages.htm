IdentityGuard Server 12.0 Administration Guide

Administrator audit messages

These messages provide information about Entrust IdentityGuard administrators.

 

Audit name

Log level

Default SNMP trap?

Event description

Administrator Login

(AUD4003)

INFO

 

Administrator logged in.

Administrator Logout

(AUD4004)

INFO

 

Administrator logged out.

Administrator Failed Login And Was Locked Out

(AUD4005)

ERROR

 

Administrator has been locked out until {0}.

Where {0} is the time at which the administrator will unlock.

Administrator Login For Operation

(AUD4006)

INFO

 

Administrator logged in to perform operation {0}.

Where {0} is the operation that the administrator is performing.

Administrator Permission Denied

(AUD4007)

INFO

 

Administrator attempted to perform an operation but their roles did not permit it.

Administrator Permission Denied Not Self

(AUD4008)

INFO

 

Administrator attempted to perform an operation on another user. Operation is only allowed to be performed on self.

Administrator Authentication Attempt With Invalid Password

(AUD4009)

INFO

 

Administrator {0} entered an invalid password.

Where {0} is the administrator name.

Administrator Authentication Attempt While Locked Out

(AUD4010)

INFO

 

Administrator {0} attempted to access the administration service, but their account is locked.

Where {0} is the administrator name.

Administrator Has No Password

(AUD4011)

INFO

 

User {0} attempted to access the administration service, but they do not have a password.

Where {0} is the user name.

Administrator Has No Roles

(AUD4012)

INFO

 

User {0} attempted to access the administration service, but they do not have any roles that grant administrative privileges.

Where {0} is the user name.

Administrator Authentication Attempt While Not Active

(AUD4013)

INFO

 

Administrator {0} attempted to access the administration service, but their account is not active.

Where {0} is the administrator name.

Administrator Authentication Attempt While Disabled in Repository

(AUD4014)

INFO

 

Administrator {0} attempted to access the administration service, but their account in the repository is disabled.

Where {0} is the administrator name.

Administrator Authentication Attempt While Expired in Repository

(AUD4015)

INFO

 

Administrator {0} attempted to access the administration service, but their account in the repository is expired.

Where {0} is the administrator name.

Administrator Failed External Authentication

(AUD4016)

INFO

 

Administrator {0} failed external authentication.

Where {0} is the administrator name.
