IdentityGuard Server 12.0 Administration Guide

Managed CA audit messages

These messages provide information about managed Certification Authorities (CAs).

 

Audit name

Log level

Default SNMP trap?

Event description

Managed CA Created

(AUD5450)

INFO

 

Managed CA {0} created: {1}

Where:

·      {0} is the name of the managed CA.

·      {1} is a list of details about the managed CA.

Managed CA Updated

(AUD5451)

INFO

 

Managed CA {0} updated: {1}

Where:

·      {0} is the name of the managed CA.

·      {1} is a list of details about the managed CA.

Managed CA Deleted

(AUD5452)

INFO

 

Managed CA {0} deleted.

Where {0} is the name of the managed CA.

Managed CA Management Occurred

(AUD5453)

INFO

 

The Managed CA management task updated the {0} digital identity for the {1} managed CA.

Where:

·      {0} is the name of the digital identity that was updated.

·      {1} is the name of the managed CA.

Managed CA Management Failed

(AUD5454)

ERROR

Yes

The Managed CA management task failed.

Managed CA Management Failure

ERROR

Yes

The Managed CA management task failed while attempting to update the {0} digital identity for the {1} managed CA.

Where:

·      {0} is the name of the digital identity for which the update was attempted.

·      {1} is the name of the managed CA.
