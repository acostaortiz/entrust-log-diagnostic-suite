IdentityGuard Server 12.0 Administration Guide

Authentication audit messages

These messages provide information about user authentication failures and problems with authentication methods.

 

Audit name

Log level

Default SNMP trap?

Event description

Authentication Success

(AUD6000)

INFO

 

User {0} successfully authenticated a challenge. {1}

Where:

·      {0} is the user ID.

·      {1} is a list of parameters including the authentication type, and possibly the location and application name.

Note: By default, this audit is disabled. To add this message to logs, set the Audit Successful Authentications property to True.

Authentication Failure

(AUD6001)

INFO

 

User {0} failed authentication. {1}

Where:

·      {0} is the user ID.

·      {1} is a list of parameters including the authentication type, and possibly the location and application name.

Authentication Failure Locks Out User

(AUD6002)

ERROR

 

User {0} failed authentication and is now locked{1,choice,0#|1# out of {2} authentication}.

Where:

·      {0} is the user ID.

Shared Secrets Updated

(AUD6003)

INFO

 

Shared secrets for user {0} updated.

Where {0} is the user ID.

Authentication Causes Card Update

(AUD6004)

INFO

 

User {0} authenticated with pending card. Card {1} updated. {2}

Where:

·      {0} is the user ID.

·      {1} is the serial number of the card.

·      {2} is a list of parameters, including the new state of the card.

Card Replacement Warning

(AUD6005)

INFO

 

User {0} authenticated with a card ({1}) that is in the replacement warning period.

Where:

·      {0} is the user ID.

·      {1} is the serial number of the card.

Card Replacement Required

(AUD6006)

WARN

 

User {0} authenticated with a card ({1}) that is in the replacement required period.  Card has been placed on hold.

Where:

·      {0} is the user ID.

·      {1} is the serial number of the card.

Authentication Causes Machine Registration

(AUD6007)

INFO

 

New machine registered for user {0}.

Where {0} is the user ID.

Authentication Causes Shared Secrets Update

(AUD6008)

INFO

 

Authentication secrets for user {0} updated.

Where {0} is the user ID.

Authentication Causes Token Update

(AUD6009)

INFO

 

User {0} authenticated with pending token. Token {1} updated. {2}

Where:

·      {0} is the user ID.

·      {1} is the vendor/serial number of token.

·      {2} is list of parameters including new state of the token.

Authentication Attempt By Suspended User

(AUD6010)

INFO

 

User {0} attempted an Authentication API {1} operation while suspended.

Where:

·      {0} is the user ID.

·      {1} is the API operation being performed.

Challenge Request Results in Rejection

(AUD6011)

INFO

 

User {0} challenge request was rejected. {1}

Where:

·      {0} is the user ID.

·      {1} is a list of parameters, including the result of IP and machine authentication, security level of the request, and possibly the location of the user.

Challenge Request Results in Challenge

(AUD6012)

INFO

 

User {0} challenge request was challenged. {1}

Where:

·      {0} is the user ID.

·      {1} is a list of parameters, including the result of IP and machine authentication, security level of the request, and possibly the location of the user.

Note: By default, this audit is disabled. To add this message to logs, set the Audit Challenge Requests That Return Challenge property to True.

Challenge Request Results in Authentication

(AUD6013)

INFO

 

User {0} challenge request was authenticated. {1}

Where:

·      {0} is the user ID.

·      {1} is a list of parameters, including the result of IP and machine authentication, security level of the request, and possibly the location of the user.

Note: By default, this audit is disabled. To add this message to logs, set the Audit Challenge Requests That Return Authenticated property to True.

Incorrectly Answered Questions in Challenge Response

(AUD6014)

INFO

 

User {0} answered the following questions incorrectly: {1}

Where:

·      {0} is the user ID.

·      {1} is a list of questions that the user answered incorrectly.

Note: By default, this audit is disabled. To add this message to logs, set the Audit Knowledge-Based Questions That Are Answered Incorrectly property to True.

Machine Registration Check Success

(AUD6015)

INFO

 

Machine registration check for user {0} succeeded.

Where {0} is the user ID.

Note: This audit property applies only to machine authentication performed via the Entrust IdentityGuard 9.0 V1 or V2 API.

Machine Registration Check Failure

(AUD6016)

ERROR

 

Machine registration check for user {0} failed.

Where {0} is the user ID.

Note: This audit property applies only to machine authentication performed via the Entrust IdentityGuard 9.0 V1 or V2 API.

Transaction Receipt Signing Failure

(AUD6017)

ERROR

 

Failed generating transaction receipt signature.

Authentication Attempt With Disabled Directory Account

(AUD6018)

INFO

 

User {0} attempted an Authentication API {1} operation when their directory account was disabled.

Where:

·      {0} is the user ID.

·      {1} is the API operation being performed.

Authentication Attempt With Expired Directory Account

(AUD6019)

INFO

 

User {0} attempted an Authentication API {1} operation when their directory account was expired.

Where:

·      {0} is the user ID.

·      {1} is the API operation being performed.

User Token Requires Reset

(AUD6020)

ERROR

 

Token {1} {2} for user {0} requires a reset.

Where:

·      {0} is the user ID.

·      {1} is the token vendor.

·      {2} is the token serial number.

No Second Factor Authentication Types Available

(AUD6021)

ERROR

 

User {0} was challenged but has no second-factor authenticators available.

Where {0} is the user ID.

Authentication User Not Exist

(AUD6022)

ERROR

 

User {0} does not exist.

Where {0} is the user ID.

Certificate Transaction Failure

(AUD6023)

ERROR

 

Certificate transaction failed with status {1} for user {0}.

Where:

·      {0} is the user ID.

·      {1} is the transaction status.

Token Transaction Failure

(AUD6024)

ERROR

 

Token transaction failed with status {1} for user {0}.

Where:

·      {0} is the user ID.

·      {1} is the transaction status.

The messages for AUD6011, 6012, 6013, 6015 and 6016 also include the user’s IP address if the Include Location Information In Authentication Audits property is set to True.
