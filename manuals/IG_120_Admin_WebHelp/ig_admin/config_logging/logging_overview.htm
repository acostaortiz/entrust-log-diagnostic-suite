Logging overview

Entrust IdentityGuard uses the log4J logging service to generate both audit logs and general system logs. Log4J lets you define:

●       loggers (the type and level of messages to be logged)

●       appenders (where the logs are to be written)

●       layouts (the format used for writing the logs)

Entrust IdentityGuard defines three loggers:

●       the Audit logger, where audit messages are logged

●       the System logger, where general system messages are logged

●       the Base logger, the default logger for all logs not included in the audit logs and the system logs

Entrust IdentityGuard also defines two different types of appenders:

●       a syslog appender

●       a rolling file appender

You can configure a different instance of each of these two appenders for both audit logs and system logs. You can assign each logger a severity level. Of the messages sent to that logger, only those targeted at the specified severity level or above are logged.
