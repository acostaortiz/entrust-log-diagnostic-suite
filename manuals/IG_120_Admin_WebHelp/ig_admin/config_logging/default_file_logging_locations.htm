IdentityGuard Server 12.0 Administration Guide

Default file logging locations

By default, all logging messages are written to files located in the <$IG_HOME>\logs directory.

Log file name

Contains

identityguard_system.log

identityguard_audit.log

logs from the services

igradius_system.log

igradius_audit.log

logs from the Entrust IdentityGuard Radius proxy

supersh_system.log

supersh_audit.log

logs from the Master user shell

igradius_startup.log

Entrust IdentityGuard Radius errors generated during service startup before the logging system is initialized

configpanel.log

configpanel_audit.log

messages generated during configuration of Entrust IdentityGuard in Windows

configpanel.log also contains the results of an upgrade (Windows only)

upgrade.log (UNIX only)

contains the results of an upgrade

The default maximum size of the log files is 1000 KB. You can change the maximum size and location of these files by editing entries in the logging properties (see Audit Logging Appenders and System Logging Appenders).

When the log reaches the maximum, it rolls over. Entrust IdentityGuard closes the old log file, renames it, opens a new log file with the old name and continues logging in the new log file. However, if the log file is locked and it cannot be closed and renamed, Entrust IdentityGuard continues writing log entries to it until the lock is removed. This means some log files may exceed the maximum size specified.
