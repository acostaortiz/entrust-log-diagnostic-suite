IdentityGuard Server 12.0 Administration Guide

Set audit logging properties

An audit logging appender defines where audit messages are written and the format of those messages. For audit messages, Entrust IdentityGuard supports an appender for the Syslog protocol (AUDIT_SYSLOG) and a rolling file appender (AUDIT_FILELOG).

For descriptions of audit log file properties, see:Audit Logging Appenders.

The Audit Logging Appenders section of the Properties Editor provides standard defaults that should work in most environments. Several properties cannot be modified or should not be modified under normal circumstances:

●       The AUDIT_SYSLOG Implementation Class Name property defines the log4j appender to use for audit logs. Changing the default may disable audit logging.

●       The AUDIT_SYSLOG Layout Implementation Class Name and AUDIT_FILELOG Layout Implementation Class Name properties set the log4j class that converts a logging event into a message string to be printed in the logs. Do not change them. If you do, you will not get readable log files.

●       The AUDIT_FILELOG Implementation Class Name property defines the appender used if audit events are logged to files. Changing the default may disable audit logging.
