IdentityGuard Server 12.0 Administration Guide

User smart credential audits

These messages provide information about user smart credentials.

 

Audit name

Log level

Default SNMP trap?

Event description

User Smart Credential Created

(AUD2350)

INFO

 

Smart Credential {1} has been created for user {0}. {2}

Where:

·      {0} is the user ID.

·      {1} is the smart credential ID.

·      {2} is the list of arguments set for the smart credential.

·      {1} is the smart credential ID.
