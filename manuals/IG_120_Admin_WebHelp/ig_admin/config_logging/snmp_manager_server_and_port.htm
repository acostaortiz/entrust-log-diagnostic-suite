IdentityGuard Server 12.0 Administration Guide

SNMP manager server and port

If either the audit traps or the heartbeat traps are enabled, the SNMP manager server must be configured in the Properties Editor.

If the SNMP manager server string is missing or there is an error in the string, the traps are disabled. SNMP traps are also disabled if there is an error in the manager port (that is, there is no SNMP manager listening on the specified port).

SNMP traps are sent using UDP, so there is no way to confirm that the messages were received at the SNMP manager. Entrust IdentityGuard is not aware of problems with the SNMP host or manager—no errors are reported within Entrust IdentityGuard. Use the system test audit Master user shell command to test that audits are reaching the SNMP audit manager. See the Entrust IdentityGuard Master User Shell Command Reference for detailed syntax.

Note: After the Entrust IdentityGuard service has been running for 497 consecutive days, the sysUptime variable rolls back to zero, so a low sysUptime value does not necessarily indicate a recent failure.
