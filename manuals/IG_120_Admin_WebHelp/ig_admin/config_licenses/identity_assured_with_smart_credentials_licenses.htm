IdentityGuard Server 12.0 Administration Guide

Identity Assured with Smart Credentials licenses

Entrust IdentityGuard keeps track of the number of users licensed to use the Identity Assured with Smart Credentials features of mobile smart credentials  (authentication, transaction verification, and digital signing).

The tracking is performed as follows:

●       When a mobile smart credential user initiates a first identity assured operation, the Identity Assured with Smart Credentials license count increases by one. The use of the identity assured features is controlled by policy. If the policy is not enabled, users do not receive notifications for identity assured operations.

●       One Identity Assured with Smart Credentials license supports the feature on all of the user's mobile smart credentials (if the Identity Provider that issued each smart credential has configured this feature).

●       When all of a user's mobile smart credentials are deleted from Entrust IdentityGuard, the counts of both the Mobile Smart Credential and the Identity Assured with Smart Credentials licenses decrease by one.

●       When a user  who has this kind is license is deleted from Entrust IdentityGuard, the counts of the Smart Credentials,  Mobile Smart Credentials, and the Identity Assured with Smart Credentials licenses (if applicable) decrease by one.

●       Canceling all mobile smart credential does not decrease the count of the Smart Credentials, Mobile Smart Credentials, or Identity Assured with Smart Credentials licenses. To decrease the license counts, all of the user's mobile smart credentials must be deleted, or the user who is licensed to use the mobile smart credential must be deleted from the system.
