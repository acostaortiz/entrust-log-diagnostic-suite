IdentityGuard Server 12.0 Administration Guide

Update license information

An administrator must have the licenseGet and licenseSet permissions to change the license information.

Use the Administration interface to administer license information and set the installation key and the activation key. Use the Properties Editor to set license auditing properties.

Use the following procedure to update the license information when you receive updated keys from Entrust.

To update license information

Attention: If your license has already expired, you cannot use this procedure. You must update the license in the Master user shell using the system license set command. For details on using this command, see the Entrust IdentityGuard Master User Shell Command Reference.

1.      Ensure that the file containing your installation key and In the Administration interface, select System and click the License Information tab.

2.      Click Update License.

The Update License pane appears.

3.      Type the installation key and activation key in their respective fields.

Note: The install key and activation key values are supplied by Entrust.

4.      Click Check License.

All changes to the license are highlighted in bold text.

The update operation fails if:

●       the new license cannot be validated

●       the new license has already expired. In this case, see the system license set command in the Entrust IdentityGuard Master User Shell Command Reference.

●       the current license count is greater than the new license limit for any type of license

5.      Click Save Changes..
