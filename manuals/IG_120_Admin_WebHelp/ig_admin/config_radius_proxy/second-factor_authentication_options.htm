Second-factor authentication options

After first-factor authentication is complete, you can have Entrust IdentityGuard present a hardware token (response-only mode or challenge-response mode), mobile soft token (in the Entrust IdentityGuard Mobile ST app), grid, Q&A, or one-time password challenge for second-factor authentication. Your Radius proxy chooses the authentication method to use and, assuming it is supported by policy, the Radius proxy forwards the applicable challenge to the VPN server.
