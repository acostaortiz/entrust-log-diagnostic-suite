IdentityGuard Server 12.0 Administration Guide

Radius proxy configuration overview

Remote Authentication Dial-In User Service (Radius) is an industry standard authentication protocol. The Entrust IdentityGuard Radius proxy provides a way to use the Radius protocol with a VPN server. The Radius proxy allows you to add second-factor authentication to your remote access system.

The Entrust IdentityGuard Radius proxy allows your remote VPN access gateway (IPSec or SSL) to communicate with Entrust IdentityGuard and (optionally) a Radius server. When integrating with an external resource (LDAP directory or Windows domain controller) for first-factor authentication, the Entrust IdentityGuard Server communicates with that external resource.

Some users may not exist in Entrust IdentityGuard, or they may not have a second-factor authentication method. For these users, you can set properties so they are authenticated by the first-factor authentication resource only.

For first-factor authentication, you can use a Radius server, an LDAP directory, a Windows domain controller, or Entrust IdentityGuard’s password feature.

For one-step authentication, you can use tokens in response-only mode.

For second-factor authentication, you can choose to use a grid, token, mobile soft token, temporary PIN, one-time password, knowledge-based questions and answers, and IP/Geolocation (risk-based authentication). Grids, tokens, one-time passwords, and temporary PINs can also include a personal verification number. For grids and tokens, the Radius proxy supports mutual authentication with serial number replay.\
