Customizing error messages

For each VPN server instance, you can specify a different error messages properties file. This allows you to update error messages or localize them, and then integrate the customized error message strings into your Entrust IdentityGuard implementation.

The Entrust IdentityGuard installation includes a sample file that includes the most commonly displayed error messages.

To create a localized error message properties file

1.      Make a copy of the vpn-example.error.messages.properties file. By default, this file is found in the following directory:

$IG_HOME/etc/

2.      Rename the copy with a name that indicates which VPN server instance it is intended for. If you choose to create different error message files for different language, you might consider adding the two-letter ISO language and country code to the file name.

●       For a list of language codes, see .http://www.loc.gov/standards/iso639-2/php/code_list.php

●       For a list of country codes, see http://www.iso.org/iso/home/standards/country_codes/country_names and_code_elements.htm.

3.      Change the text strings by updating them as required.

Note: Properties files are encoded as Latin-1 (ISO-8559-1) If you are using non-Latin characters, you must use Unicode escape characters. You can convert a non-Latin-1 text file to a correct properties file by using the native2ascii tool that is shipped with the JDK. For more information, see https://docs.oracle.com/javase/8/docs/technotes/tools/unix/native2ascii.html.

4.      Save the file.

5.      Specify the file when you create or modify the VPN Server Configuration properties in the Properties Editor. See To configure VPN connections.
