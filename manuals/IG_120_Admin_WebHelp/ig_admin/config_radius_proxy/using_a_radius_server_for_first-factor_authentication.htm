Using a Radius server for first-factor authentication

Assume you want to set up one Radius server and one VPN server to provide first-factor authentication for two VPN instances named SalesVPN and MarketingVPN. These instances are paired with two Entrust IdentityGuard user groups, IGSales and IGMarketing. In this scenario, the relevant settings would look like this:

●       Radius Proxy Configuration pane

–  Radius Proxy Port: 1812 1813

●       first VPN configuration instance on the VPN Server Configuration pane

–  Configuration Instance: salesVPN

–  Radius Proxy Port Used By VPN: 1812

–  VPN Host: 10.12.1.1

–  VPN Shared Secret: xyz76#r

–  Entrust IdentityGuard User Group: IGSales

–  First-Factor Authentication Server: Radius

–  Radius Server: radius1

●       second VPN configuration instance on the VPN Server Configuration pane

–  Configuration Instance: marketingVPN

–  Radius Proxy Port Used By VPN: 1813

–  VPN Host: 10.12.1.1

–  VPN Shared Secret: xyz76#r

–  Entrust IdentityGuard User Group: IGMarketing

–  First-Factor Authentication Server: Radius

–  Radius Server: radius1
