Configuring the Radius proxy for groups

You can use groups with the Radius proxy in the following ways:

●       You can define Entrust IdentityGuard user groups, and then configure a VPN server instance to apply to just that group. This way, the Radius proxy can direct users in specific groups to different methods of first-factor authentication.

●       You can configure Entrust IdentityGuard to check the user’s LDAP or Entrust IdentityGuard group memberships before granting access to an authenticated user. To configure this feature, you must define your VPN server, and, during this process, set the Authorization expression and (optionally) the Skip Second-Factor Authentication for Users That Have Been Authorized properties. For details on these properties and how to define your VPN server, see To configure VPN connections.
