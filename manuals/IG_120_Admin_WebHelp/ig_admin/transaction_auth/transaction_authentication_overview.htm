Transaction authentication overview

When your users are challenged by Entrust IdentityGuard based on a specific transaction, the challenge contains the transaction details. The transaction details can be configured to be a part of the challenge and challenge response for all second-factor authentication methods.

In transaction authentication, the transaction details are compared to those contained in the challenge, and the authentication is successful only if the two sets of transaction details match. When the authentication is successful, a transaction receipt is returned to the application. The transaction receipt may be signed, depending upon the policies set in Entrust IdentityGuard.

With transaction authentication, you get assurance that the transaction requested is the same as the transaction that is authenticated. That is, you can be sure that the transaction has not been modified during transmission.

If the user is using OTP authentication with the email or SMS delivery method, you can make the transaction details visible to the user in the OTP email or text message. See Editing the JavaMail out-of-band OTP template or Customizing the SMS message template.

If users have the Entrust IdentityGuard Mobile Soft Token app, the transaction details can be sent to users’ mobile devices. See Soft token transaction verification overview.

There are several options for delivering transaction details with OTPs. You can set the behavior in the Properties Editor:

●       Send the transaction details in a separate email or text message: The transaction details are sent first, followed by one or more OTPs.

●       Send the transaction details with the first OTP: The transaction details are sent in the first email or text message, along with the first (or only OTP).

●       Send the transaction details in every email: The transaction details are included with each OTP sent.

See Out-of-Band OTP Email Delivery Configuration and Out-of-Band OTP SMS Delivery Configuration for more information about setting these delivery properties.
