IdentityGuard Server 12.0 Administration Guide

Configuring the soft token vendor

During installation of Entrust IdentityGuard, the soft token vendor is automatically set to Entrust, and several other properties are set. For a complete list of token properties, see Token Vendor Configuration.

To change those properties or to add additional soft token vendors, use the Properties Editor.

To modify the soft token vendor properties

●       See To modify token vendor properties. The instructions are for tokens, but work the same for soft tokens. Ensure that the Token Vendor Implementation Class is set to Entrust Soft Token.

To configure a new soft token vendor

●       See To configure a new token vendor. The instructions are for tokens, but work the same for soft tokens. Ensure that the Token Vendor Implementation Class is set to Entrust Soft Token.
