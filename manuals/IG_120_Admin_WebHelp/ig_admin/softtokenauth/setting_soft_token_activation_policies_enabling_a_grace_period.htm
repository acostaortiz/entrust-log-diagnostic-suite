Enable a grace period for soft token activation

Optionally, you can set an interval of time (sometimes called a grace period) within which soft token users can continue to authenticate using only their first-factor credentials. The grace period begins the moment the soft token is created and assigned to the user in Entrust IdentityGuard, and ends a configurable number of days later. After the grace period lapses, users are forced to activate their soft tokens by using them for the first time to authenticate.

Why use a grace period with soft tokens?

The grace period is principally used for other authenticators, namely physical grid cards and hardware tokens, to allow users to continue to log in while they wait for their physical grids or tokens to be delivered. With soft tokens, however, this wait time does not exist because a soft token is a software-only authenticator that users can download and begin using immediately. A soft token grace period is useful if a user is interrupted while activating a soft token, and is left with a soft token that is assigned but not yet activated, so it cannot yet be used to authenticate. The grace period allows users to continue to log in with first-factor authentication until they have time to complete the soft token activation.

Example of how a grace period might be useful for soft tokens

Suppose a user begins the soft token activation but gets interrupted—maybe the phone rings, or they are distracted with something more important. The user decides to quit the activation process before supplying the necessary activation and registration codes. At this point, the user has a token that is created and assigned to them, but it is not activated, so it cannot be used for authentication. If a grace period is enabled, this user can continue to log in using first-factor credentials until the grace period lapses. The user has until the end of this grace period to complete the soft token activation.

Note: The grace period is not the same as the lifetime of the activation code. For more information, see the Token Activation Lifetime policy.

To enable a grace period, configure the activation policy, as described in Configuring grid card or token activation period policies. The instructions refer to grid and token authenticators, but are equally valid for soft tokens.
