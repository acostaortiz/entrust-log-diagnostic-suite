IdentityGuard Server 12.0 Administration Guide

Remove old repository definitions

After all the data has been moved out of a repository, you may no longer need the repository definitions. The following procedure details how to remove them.

To remove unused repository definitions from Entrust IdentityGuard

Attention: After you delete a repository, you cannot retrieve it. Make a backup of the identityguard.properties file before removing it.

1.      Log in to the Properties Editor. See To log in to the Properties Editor).

2.      Delete the repository definition:

a.      If you are deleting a database, select JDBC Database Settings.

b.      If you are deleting an LDAP repository, select LDAP Directory Server Settings.

3.      Under Configuration Instances, select the database or LDAP repository you want to remove.

4.      Click Remove.

5.      Click Table of Contents.

6.      Update the implementation class settings as appropriate.

7.      Click Repository Settings.

8.      Change the following settings as required:

●       Card/User Repository Implementation Classes

●       Policy Repository Implementation Class

●       Preproduced Card Repository Implementation Class

●       Token Repository Implementation Class 

Example: If all unassigned card information was moved from a file-based repository to a database, change the Preproduced Card Repository Implementation Classes setting from File-based (Default, Primary Node Only) and Database to Database (JDBC).

9.      Click Validate & Save.

10.  Restart the Entrust IdentityGuard services. For instructions for restarting the services for your platform, see the Entrust IdentityGuard Installation Guide.
