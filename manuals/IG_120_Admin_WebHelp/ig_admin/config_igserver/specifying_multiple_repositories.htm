Specifying multiple repositories

You can store your Entrust IdentityGuard user data across more than one repository. The repositories can be of different types (LDAP directory/search base, database). This allows you complete flexibility in how you organize data. For example, you could have normal users of a group in an LDAP repository and all administrators of that group in a database repository. Conversely, you could decide to have the administrators in the LDAP repository and the users in a database repository. (For more information, see Using multiple repositories with groups.)

In addition to having your users divided among multiple repositories, you can also store preproduced cards and unassigned tokens across multiple repositories.

Configuring multiple repositories does not provide high availability. To configure high availability and failover, refer to Configuring failover and high availability.

When you set up a second or subsequent repository:

●       All of the configuration properties are inherited from the default repository.

●       Second and subsequent databases inherit the properties of the default database repository.

●       Second and subsequent LDAP repositories inherit the properties of the default LDAP repository.
