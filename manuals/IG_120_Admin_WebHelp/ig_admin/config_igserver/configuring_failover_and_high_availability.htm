Configure failover and high availability

●       For instructions on setting up failover for a directory repository (LDAP), see To configure failover and high availability for a directory repository.

●       For instructions on setting up failover for a database repository, see To configure failover and high availability for a database repository.

●       For instructions on setting up failover for Radius servers, see Configuring Radius server for failover and high availability.

●       For instructions on setting up failover for external authentication, especially when using a domain controller, see Configuring external authentication failover and high availability (Kerberos).

To configure failover and high availability for a directory repository

1.      Start the Entrust IdentityGuard Properties Editor. (See Log in or out of the Properties Editor.)

2.      On the Table of Contents, click LDAP Directory Server Settings.

3.      In the Configuration Instances drop-down list, select the instance you want to set up for failover.

4.      In the LDAP URL field, enter additional directory or search base URLs. Each URL is delimited by a space. If there are spaces in the URL, encode them as %20.

5.      Optional. Enter a number in the Primary Directory Server Maximum Reconnect Interval field. This sets the maximum time in hours between attempts to reconnect to the primary directory (the first directory URL defined) when the current in-use directory is not the primary. The default is 24.

6.      Optional. Enter a number in the Directory Server Connection Test Interval field. In a high-availability setup where directory connections are pooled, this sets the time in seconds to wait between tests to see if a directory connection is still valid. A setting of 0 means the directory is tested each time it is pulled from the pool. The default is 0.

7.      Optional. Change other settings related to credentials, timing, and connection pooling, if required. Any change applies to every directory in the URL list. For an explanation of each property and their defaults, see LDAP Directory Server Settings.

Note: The LDAP credentials and principal specified must work for all directories listed.

8.      Click Validate & Save.

9.      Log out of the Properties Editor and restart the Entrust IdentityGuard server service after making all property changes.

To configure failover and high availability for a database repository

1.      Start the Entrust IdentityGuard Properties Editor. (See Log in or out of the Properties Editor.)

2.      On the Table of Contents, click JDBC Database Settings.

3.      In the Configuration Instances drop-down list, select the instance you want to set up for failover.

4.      In the JDBC Driver URL field, enter additional database URLs. Each URL is delimited by a space. If there are spaces in the URL, encode them as %20.

5.      Optional. Enter a number in the Primary Database Maximum Reconnect Interval field. This sets the maximum time in hours between attempts to reconnect to the primary database (the first database URL defined) when the current in-use database in use is not the primary. The default is 24.

6.      From the Table For Testing Database Connections drop-down list, pick the database type used for the Entrust IdentityGuard repository. This identifies the table to use for testing the connection. All pooled connections are tested prior to being used to ensure they are still valid. Connections are only tested if the number of seconds set in Step 7 have elapsed.

7.      Optional. Enter a number in the Database Connection Test Interval field. In a high-availability setup where database connections are pooled, this sets the time in seconds to wait between tests to see if a database connection is still valid. A setting of 0 means the database is tested each time it is pulled from the pool. The default is 0.

8.      Optional. Change other settings related to credentials, timing, and connection pooling, if required; but note that any change applies to every database in the URL list. For an explanation of each property and their defaults, see JDBC Database Settings.

Note: The credentials specified must work for all databases listed.

9.      Click Validate & Save.

10.  Log out of the Properties Editor and restart the Entrust IdentityGuard server service after making all property changes.
