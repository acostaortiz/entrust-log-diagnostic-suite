IdentityGuard Server 12.0 Administration Guide

Partitions and the global policy (licensing)

In a standard Entrust IdentityGuard configuration, there is one global policy. The global policy keeps track of the following things:

●       license information, including

–  the maximum number of users

–  licensed features (one license per user can allow multiple authenticators, for example, multiple soft tokens for that user)

–  licensed items (like soft tokens that use a TEE Storage for Soft tokens license)

–  license expiry date

●       the current number of users in the system as a whole. This number is incremented each time a user is created, and decremented for each user that is deleted.

●       the current number of licensed features and items created in the system as a whole. As with the user count, this number is incremented each time one of those user licenses is assigned or a licensed item is created, and decremented each time a user stops using a feature or a licensed item is deleted. For more information, see How license counting works.)

●       the user number to assign to the next user created

●       the serial number to assign to the next grid created

●       the serial number to assign to the next licensed item created

When you create a partition and assign it to a group, users, grids, and feature licenses and licensed-items you create in the group are assigned user numbers and serial numbers from the partition. The count of users created in a partition is maintained by the partition, but the license information continues to be maintained solely by the global policy.

For more information about partitions and licenses, see How user and licensed-item counting works when partitions are used.

Note: You cannot assign ranges of users or grids to the global policy. The global policy retains ownership of all user ranges and grid ranges not assigned to a partition.
