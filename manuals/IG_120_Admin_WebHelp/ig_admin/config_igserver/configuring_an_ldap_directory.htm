Configuring an LDAP directory

If you choose an LDAP directory as your user repository during Entrust IdentityGuard installation, it becomes your default directory repository. You can modify that default configuration in the Properties Editor, or add more directory repositories.

In the Properties Editor, there are two sections of properties that apply when configuring LDAP directories, LDAP Directory Server Settings and Repository Settings. The first LDAP directory you configure in the LDAP Directory Server Settings pane becomes the default LDAP directory. Only the default directory applies to the directory server specified on the Repository Settings pane.
