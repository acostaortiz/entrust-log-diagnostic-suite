IdentityGuard Server 12.0 Administration Guide

Machine authentication overview

Machine authentication provides validation of the device from which a user attempts to access a resource protected by Entrust IdentityGuard. It is a very useful authentication method for users who usually access your Web site or client application from the same computer or mobile device. It allows for seamless authentication without any noticeable impact on the user experience.

If a user logs in from a different device than the usual one, your Entrust IdentityGuard policy evaluates whether the user should be challenged or denied access.

Entrust IdentityGuard policy lets you select the components of the machine secret. For the most secure machine authentication solution, use them all:

●       Machine nonce

●       Sequence nonce

●       Application data

●       Device fingerprint

Machine authentication is a form of risk-based authentication. It can be used alone, or with other risk-based authentication capabilities. See Risk-based authentication overview.

To configure machine authentication, do one or more of the following:

●       Determine the level of machine authentication security that suits your application. (See Creating a machine secret.)

●       Make sure administrators have the required permissions to set policy and manage machine secrets (see User machine secrets permissions).

●       Use the Policies pages of the Administration interface to set the machine secret policies (see Configure machine authentication policies.

●       Create an application that does the following:

–  Gets any existing machine secret information from the user's device (potentially using the machine secret library introduced with Entrust IdentityGuard release 11.0), and pass it to the Entrust IdentityGuard Authentication API, which is used to request a challenge.

–  If the request for an authentication challenge does not result in the user automatically being authenticated, present the challenge to the user and collect the user's response.

–  If the user's response is successful, store the machine secret information returned by Entrust IdentityGuard on the user's device. (This might also use the machine secret library in Entrust IdentityGuard.)

For more information about configuring your client application, see the Entrust IdentityGuard Programming Guide.
