IdentityGuard Server 12.0 Administration Guide

Overview

Digital IDs (also known as certificates) can be used for various cryptographic functions such as securing email or logging in to a corporate network over a VPN connection.

The mobile enrollment of digital IDs feature enables Entrust IdentityGuard to issue digital IDs to users’ mobile devices where they are convenient for users to use.

Users enroll their mobile devices and have digital IDs encoded on them by going to the Self-service Web application supplied by Entrust and requesting a digital ID. The request initiates processes between the self-service application, the mobile device, the Entrust IdentityGuard server, and the Certification Authority (CA), that results in a digital ID being created and installed on the user’s mobile device. All these interactions are not apparent to the user: the only action they need to take is to click a download button when the digital ID is ready to be installed.

Digital IDs are tied to a CA, which means that they can be managed in the following ways:

  • An administrator can revoke a digital ID if it is thought to be compromised or it is no longer of use, for example, when an employee leaves the organization.

  • For an Entrust CA, Entrust IdentityGuard maintains a key history that lets users do things like decrypt older emails that were encrypted with a public key that has expired.
