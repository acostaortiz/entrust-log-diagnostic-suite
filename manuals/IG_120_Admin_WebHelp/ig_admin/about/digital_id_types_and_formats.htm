Digital ID types and formats

Entrust IdentityGuard can issue digital IDs in these types:

●       Network access—this type is used to log in to a network over a wireless or VPN connection

●       Secure email—this type is used to encrypt, decrypt, sign and verify email

Entrust IdentityGuard can issue digital IDs that use the following formats or protocols:

●       SCEP — This format is considered more secure because the mobile device itself creates the keys, and only the public ones are passed to the CA, Rhe private keys never leave the device.

●       PKCS#12 (also called P12) — For this format, all keys, both public and private, are generated by the CA and need to travel back to the mobile device.
