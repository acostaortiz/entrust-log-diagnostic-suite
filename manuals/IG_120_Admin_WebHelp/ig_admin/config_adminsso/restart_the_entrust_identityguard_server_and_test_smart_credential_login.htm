Restart the Entrust IdentityGuard Server and test smart credential login

To restart the Entrust IdentityGuard Server and test smart credential login

1.      Restart the Entrust IdentityGuard Server to have your settings take effect. For details on restarting the Entrust IdentityGuard Server, see the Entrust IdentityGuard Server Installation Guide.

2.      In a browser, navigate to the Administration interface. For example:

https://igserver.example.com:8444/IdentityGuardAdmin

3.      Ensure that a Smart Credential Log In button is displayed on the login page.
