IdentityGuard Server 12.0 Administration Guide

Enable SAML through the Properties Editor, and enable auto-redirect

To enable SAML through the Properties Editor, and enable auto-redirect

1.      Log in to the Entrust IdentityGuard Properties Editor.

Windows

a.      Select Start > All Programs > Entrust > IdentityGuard > Properties Editor.

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

UNIX

a.      Enter the URL of your Properties Editor web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardPropertiesEditor

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

2.      From the table of contents, click Web Application Settings (near the top).

3.      Set SAML Single Sign-On Enabled to True.

4.      (Optional.) Set SAML Single Sign-On Login Auto-Redirect to True if you want users to be redirected to the Federation Module’s SAML login page when they attempt to access the Administration interface. Set it to False to have a SAML Single Sign-On link appear at the bottom of the Administration interface’s login page. This link takes users to the Federation Module’s SAML login page. See How the SAML login works with the Administration interface for details.

5.      Click Validate Only.

6.      Leave the Properties Editor open.
