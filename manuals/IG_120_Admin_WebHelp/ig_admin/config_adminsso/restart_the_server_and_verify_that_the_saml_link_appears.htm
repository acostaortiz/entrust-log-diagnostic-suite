Restart the Server and verify that the SAML link appears

To restart the Server and verify that the SAML link appears

1.      Restart the Entrust IdentityGuard Server service to have your settings take effect. For details on restarting the Entrust IdentityGuard Server service, see the Entrust IdentityGuard Server Installation Guide.

2.      To test that the SAML link appears on the login page, in a browser, navigate to the Administration interface. For example:

https://igserver.example.com:8444/IdentityGuardAdmin

3.      Ensure that a new SAML Single Sign-On link is displayed on the login page.

Note: This link does not work until the Federation Module has not been configured to recognize the Entrust IdentityGuard Server, which happens in a later step. Clicking on the link, at this point, takes you to the Federation Module’s site, where you will see a The partner site was not configured message.
