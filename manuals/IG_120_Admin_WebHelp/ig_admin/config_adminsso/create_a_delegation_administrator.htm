IdentityGuard Server 12.0 Administration Guide

Create a delegation administrator

Typically, a user authentication does not require an administrative account because the user-supplied password or other challenge response is used to gain access to the APIs. However, in the case of SAML, the Administration interface does not have the user’s password or challenge. All it has is the assertion containing the user’s user name. Therefore, it needs some other way to access the APIs, namely, a pre-defined administrative account.

To create a delegation administrator

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

or other login scenarios, see

2.      Click Create Account.

Note: If you are using a directory in the Active Directory family of products, you must first create this account in the LDAP directory before creating the account in Entrust IdentityGuard, as described below.

3.      Specify the account information as follows:

a.      For the User Name, enter iginternalSAMLdelegate or another name that describes the account.

b.      For the Group, select a group.

c.      For the User’s Full Name, enter IdentityGuard Internal SAML Delegate.

d.      Enable Entrust IdentityGuard Administrator.

e.      For the Roles, select delegationadmin.

f.        For the Comments, enter: Internal system account used when SAML is used to protect the Administration interface.

g.      Click Create Account.

4.      Click Create Password.

5.      Create the password as follows:

a.      Select Manual Generation and set the password.

b.      Set the Password Lifetime to any of the available options. When the password expires, it will be auto-updated with a new, system generated one.

c.      Deselect Change Is Required on First Usage.

d.      Click Create Password.
