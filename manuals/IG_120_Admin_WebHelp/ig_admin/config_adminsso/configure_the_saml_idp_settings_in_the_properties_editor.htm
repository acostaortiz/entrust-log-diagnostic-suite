IdentityGuard Server 12.0 Administration Guide

Configure the SAML IDP settings in the Properties Editor

To configure the SAML IDP settings in the Properties Editor

1.      Return to the table of contents in the Properties Editor.

2.      Click SAML IDP Configuration (near the bottom).

3.      Under Configuration Instances, enter a name for the configuration.

Example: IDP Configuration.

4.      Under IDP Metadata File Location, specify the name and location of the Federation Module’s metadata file. For example, c:\IDPdata\idp.metadata.xml.

5.      If you have another Federation Module deployment with a metadata file that is different from the one you just specified, create another configuration instance, and specify the name and location of that metadata file.

Example:

You might specify another configuration instances called,

IDP Configuration 2

with a metadata file, here:

c:\IDPdata\idp2.metadata.xml

6.      Click Validate Only.

7.      Leave the Properties Editor open.
