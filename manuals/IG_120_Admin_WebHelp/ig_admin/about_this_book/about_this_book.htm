IdentityGuard Server 12.0 Administration Guide

About this guide

Standard authentication is commonly done through the use of a user name and password combination, which validate the user’s identity. Multifactor authentication provides one or more additional authentication methods. Entrust IdentityGuard is a multifactor authentication product that uses various challenge and response techniques to increase the security of an online identity.

The Entrust IdentityGuard Administration Guide is intended for system administrators who configure Entrust IdentityGuard, and for administrative users who manage users and their authentication data.
