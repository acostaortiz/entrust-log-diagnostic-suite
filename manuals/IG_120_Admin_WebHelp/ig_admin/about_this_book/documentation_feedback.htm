Documentation feedback

You can rate and provide feedback about Entrust product documentation by completing the online feedback form. To open this form in a browser, click the "Report errors or omissions" link on any page in this help system or go to http://go.entrust.com/documentation-feedback

In your feedback, please identify the guide and topic on which you want to comment by copying the topic URL. To do so,

1.      Right-click the topic title in the Table of Contents (TOC).

2.      From the menu, select the option for the browser you are using:

●       Mozilla Firefox: Copy Link Location

●       Microsoft Internet Explorer: Copy shortcut

●       Google Chrome: Copy Link Address

3.      Click the feedback link.

4.      Paste the topic URL into any field in the feedback form.

Alternatively, you can copy the "breadcrumb" navigation link a the top right corner of any topic.

Feedback concerning documentation can also be directed to the Customer Support email address: support@entrust.com
