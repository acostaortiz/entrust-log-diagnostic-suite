1. Código [5202013]: Invalid user ID or password

5202013

Significado del Log: El usuario intentó autenticarse o acceder a través de la API de Contexto de Sistema pero la ID de usuario o la contraseña proporcionada es inválida o no coincide con la base de datos de identidades.

Remediación: Verifique las credenciales en Active Directory / LDAP o desbloquee el usuario en la Consola de Administración.

2. Código [5205139]: Unable to find a user for user name or alias

5205139

Significado del Log: La API de Gestión de Usuarios no pudo localizar la entidad de usuario o alias dentro de la base de datos o almacén LDAP.

3. Código [5203018]: Authentication type is not allowed for user

5203018

Significado del Log: El tipo de autenticador solicitado (TOKENRO, Grid, OTP) no está permitido en la política asignada al grupo del usuario.

4. Código [5202046]: Cryptographic Services Initialization Failed

5202046 Nivel: CRITICAL

Significado del Log: No se pueden inicializar los servicios criptográficos porque no hay contraseña o datos de protección de clave disponibles.

Cannot initialize cryptographic services because no password or key protection data is available. (Ref:31056583)

Remediación: Inicie sesión en supersh y ejecute el comando system bind para asociar el archivo de claves.

10. Guía Operativa: Actualización de Claves Maestras y Repositorios

Rotación de Master Keys (`system keyupdate`)

Procedimiento paso a paso para actualizar las claves maestras de cifrado de Entrust IdentityGuard:

  1. Detener Servicios: Detenga todos los servicios de Entrust en el servidor primario y réplicas.
  2. Respaldo de Seguridad: Realice una copia de respaldo (backup) completa del servidor primario y de la base de datos.
  3. Ejecutar Rotación en Servidor Primario:

    Inicie la consola SuperShell (supersh) sin iniciar sesión y ejecute:

    system keyupdate -reason "Rotacion periodica de claves de seguridad IT Servicios"

    Entrust generará el nuevo archivo de claves maestras cifradas .enc (Registrando el evento AUD116).

  4. Respaldar y Copiar el archivo .enc: Copie el nuevo archivo .enc generado a todos los nodos réplicas.
  5. Re-inicializar Réplicas:

    En cada nodo réplica, inicie sesión en supersh y ejecute:

    init -replica -overwrite
    system bind
  6. Iniciar Servicios: Inicie los servicios en el servidor primario y réplicas.

Re-encriptación Masiva del Repositorio (`system repositoryupdate`)

Para forzar la re-encriptación inmediata de todos los datos en la base de datos SQL, LDAP y repositorios de tarjetas:

system repositoryupdate -start
  • -status : Consulta el reporte de avance del proceso (Eventos AUD118).
  • -stop : Pausa temporalmente el proceso de cifrado masivo.
  • -resume : Reanuda la re-encriptación pausada.
  • -continue : Fuerza el avance omitiendo errores no fatales.
