IdentityGuard Server 13.0 Administration Guide

Grid challenge string

The syntax and default content for the Default Grid Challenge Message property is:

Enter

{3, choice, 0#| 1# your PVN and}

{4, choice, 0# a response to the grid challenge {0}| 1# your temporary PIN}

{5, choice, 0#|1# using cards with serial number {1} or {2} or your temporary PIN|2# using cards with serial number {1} or {2}|3# using a card with serial number {1} or your temporary PIN|4# using a card with serial number {1} }

{6, choice, 0#.|1# and update your PVN  twice in succession}{7,choice, 0#|1# (PVN size: {7})}. 

 

Parameter

Value

Description

{0}

grid challenge

The grid challenge to be answered.

{1}

serial number

The serial number of the user's current card.

{2}

serial number

The serial number of the user's pending card, if there is one.

{3}

0

A PVN is not required for authentication.

1

A PVN is required for authentication.

{4}

0

A card is available for authentication. There may also be a temporary PIN.

1

Only a temporary PIN is available for authentication.

{5}

0

Only a temporary PIN is available for authentication.

1

Authentication can take place with a current or pending card or a temporary PIN.

2

Authentication can take place with either a current or pending card.

3

Authentication can take place with only one card, either current or pending, or a temporary PIN.

4

Authentication can take place with only one card, either current or pending.

{6}

0

If a PVN is required for authentication, it does not need updating.

1

If a PVN is required for authentication, it requires updating.

{7}

0

If a PVN does not require updating, nothing is shown.
 

1

If a PVN is required or it must be changed, show the required PVN size.
