Configuring the Entrust IdentityGuard Radius proxy

This section describes how to use the Properties Editor to configure the Entrust IdentityGuard Radius proxy, your VPN servers, and Radius servers.

Note: With the exception of log settings, you must restart the Entrust IdentityGuard server service and the Radius proxy service for property changes to take effect.
