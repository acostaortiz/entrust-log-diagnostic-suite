Understanding challenge string syntax

Challenge string syntax includes two types of parameters; simple value substitution parameters, and choice format parameters. Choice Format parameters allow you to substitute different text values, based on the value of a parameter. Choice Format parameters may contain references to simple value parameters, and other choice value parameters.

There are eight value parameters in all, numbered 0 through 7, associated with an Entrust IdentityGuard challenge message. You do not have to use all of them within any challenge message. See VPN challenge string reference for a list of parameters and their values.

When a parameter has multiple possible values, the syntax uses a feature known as Choice Format. Choice Format takes the value associated with a given parameter and maps it into different strings based on the value of that parameter. Choice Format appears in the syntax with the parameter number, a comma, the keyword choice and another comma, like this:

{3,choice,

The choices in Choice Format are separated by or-bars (|), as in this parameter example using 0 and 1:

{7, choice, 0#|1# using the token challenge {2}.}

All text and values associated with a parameter are contained within curly brackets: {}. For example, this is a complete parameter:

{4, choice, 0# a response from your Entrust IdentityGuard Token| 1# your temporary PIN}

In this example, if 0 is used, the text in the challenge is, “a response from your Entrust IdentityGuard token,” and when the simple value parameter is 1, the challenge text is, “your temporary PIN”. Place the text you want displayed between the # and the |, or between the # and the end bracket, if this is the last element of the parameter.

A parameter can also have other parameters nested within it. The following example has simple value substitution parameters 0 and 1 nested within it:

{5, choice, 0#|1# with serial number {0} or {1} or your temporary PIN|2# with serial number {0} or {1}|3# with serial number {0} or your temporary PIN|4# with serial number {0}}

What this says that for a value of 0 in parameter 5, display the text between the # and the next | or end bracket. In the preceding example, there is no text, so if the value of parameter 5 is 0, then display no text.

By reading the user’s account details and the policies for the user’s group, Entrust IdentityGuard knows what authentication methods the user has available. Based on this data, Entrust IdentityGuard knows which Choice Format values apply to a given user for each parameter.

This way, the challenge string that appears is tailored to the user based on existing account and policy settings.
