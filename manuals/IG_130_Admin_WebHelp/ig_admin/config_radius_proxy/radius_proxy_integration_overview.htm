IdentityGuard Server 13.0 Administration Guide

Radius proxy integration overview

To configure the Radius proxy for use with Entrust IdentityGuard, you need to do the following:

1.      Determine which first-factor authentication method to use with the Radius proxy (see First-factor authentication options).

2.      Determine which second-factor authentication method to use with the Radius proxy (see Second-factor authentication options).

3.      Configure the Radius proxy properties (see Configuring the Radius proxy configuration).

4.      Configure the Radius proxy for use with your VPN servers (see Configuring the Radius proxy for VPN servers).

If applicable, configure the Radius proxy for use with your wireless network (see Configuring the Radius proxy for EAP (wireless support))

If applicable, configure the Radius proxy to match VPN user groups with Entrust IdentityGuard groups (see Configuring the Radius proxy for groups).

5.      Configure your VPN server to use the Radius proxy (see Configuring your VPN servers for the Radius proxy).

6.      Optionally, configure the VPN challenge strings presented by the Radius proxy to user attempting to authenticate (see Customizing VPN challenge strings).
