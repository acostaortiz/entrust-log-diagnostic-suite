Device fingerprint attributes iOS

The table that follows lists the Apple iOS device attributes that can be used to create the device fingerprint for an iOS mobile device. The table shows the default settings for the attribute characteristics. For descriptions of these characteristics, see Characteristics of device fingerprint attributes.

To collect and use these attributes for machine authentication or as part of risk-based authentication, you must create an application that gathers the attributes and passes them the Entrust IdentityGuard. For more information, see the Entrust IdentityGuard Device Fingerprint SDK Programming Guide.
