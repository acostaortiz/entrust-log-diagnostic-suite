IdentityGuard Server 13.0 Administration Guide

Basic policy settings

Each policy includes the following settings.

Policy

The name of the policy. For the default policy included with Entrust IdentityGuard, the name is default.

Default Policy

Indicates if this policy is the default policy. There can be just one default policy. For the policy named default included with Entrust IdentityGuard, this is initially set to Yes. Making another policy the default, automatically sets the previous default to No.

Default (for all policies except one): No

Comments

Provides a way to add explanatory text about any policy you create.
