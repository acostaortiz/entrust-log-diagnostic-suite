IdentityGuard Server 13.0 Administration Guide

Initial administration workflow

When you first install and use Entrust IdentityGuard, have an administrator with the superuser role create any initial custom policies, groups, and roles you need for your organization. (The administrator created during Entrust IdentityGuard configuration has this role.) Initially, there is just one policy named default, one group named default, and multiple roles (see Built-in roles).

After you create your custom policies, create the user groups you need for your Entrust IdentityGuard applications. You can assign any new policy to your new groups (just one policy per group).

After you have your policies and groups created, create custom roles if the built-in roles are not sufficient. During the creation of a role, you assign specific permissions to the role. You can also grant the new role access to specific policies, groups, and other roles.

After you create all the custom roles you need, create new administrators (if needed) and assign them one or more of these roles.

●       For a complete list of policies, see Policies quick reference.

●       For information about associating a policy with a group, see Assigning policies to groups.

●       For more information about roles, see Roles overview.
