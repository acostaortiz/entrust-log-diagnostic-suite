IdentityGuard Server 13.0 Administration Guide

Risk-Based Authentication policies

These policies determine how risk-based authentication is applied to users at the normal and enhanced security levels.

Machine secrets can also be part of risk-based authentication. For more information, see Machine authentication.

Normal Security Level — Reject User

When an authentication test fails at the normal security level, this policy sets which failures result in a rejection of the user.

For a description of the choices, see Using risk-based authentication tests.

Normal Security Level — Authenticate User

When an authentication test passes at the normal security level, this policy sets what combination of successes result in automatic authentication.

For a description of the choices, see Using risk-based authentication tests.

Enhanced Security Level — Reject User

When an authentication test fails at the enhanced security level, this policy sets which failures result in a rejection of the user.

Enhanced Security Level — Authenticate User

When an authentication test passes at the normal security level, this policy sets which combination of successes result in automatic authentication.
