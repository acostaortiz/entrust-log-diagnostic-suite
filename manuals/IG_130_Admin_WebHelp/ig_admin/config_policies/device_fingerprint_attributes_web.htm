IdentityGuard Server 13.0 Administration Guide

Device fingerprint attributes Web

The table that follows lists the device attributes that can be used to create the device fingerprint for a computer that is used to access a website or Web-based application. The table shows the default settings for the attribute characteristics. For descriptions of these characteristics, see Characteristics of device fingerprint attributes.

To collect and use these attributes for machine authentication or as part of risk-based authentication, you must create an application that gathers the attributes and passes them to the Entrust IdentityGuard server. For more information, see the Entrust IdentityGuard Device Fingerprint SDK Programming Guide.
