IdentityGuard Server 13.0 Administration Guide

Generate and send an EGrid

If your organization does not use Self-Service Module, which allows users to generate and manage their own EGrids, complete the following procedure to create and send an EGrid from the Administration interface.

To generate and send an EGrid

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

2.      Locate the account of the user for whom you want to issue an EGrid.

3.      Under Authentication Types, select Cards.

4.      Click Create Card.

5.      On the Create a card for a user page,

a.      From the Card Lifetime drop-down list, select the period of time the EGrid should be valid for. By default, grid cards never expire.

b.      (Optional) Add a note in the Comments field about the EGrid.

c.      Click Create Card.

On the user's Account Information page, the grid card appears in the list of cards assigned to the user.

6.      Click Deliver Card.

7.      On the Deliver Card page, confirm the card serial number, user name and group, email address and delivery method for the EGrid delivery, and then click Deliver.

A banner confirms the delivery of the EGrid. The user receives an email with the EGrid in PDF, PNG, or embedded image form, as configured.
