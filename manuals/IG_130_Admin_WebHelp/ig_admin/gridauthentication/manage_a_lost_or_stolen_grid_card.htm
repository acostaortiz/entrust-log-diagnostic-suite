IdentityGuard Server 13.0 Administration Guide

Manage a grid card that a user reports lost or stolen

It is not uncommon for users to lose or misplace their grid cards, and your organizational policies should encourage them to report a loss as soon as they notice it. If your organization uses Entrust IdentityGuard Self-Service Module, users can go to your self-service website to perform these actions. If you do not use the Self-Service model, an Entrust IdentityGuard administrator can deactivate a lost or stolen grid card and assign a new one.

To find user of lost or stolen grid card

1.      Log in to the Administration interface.

2.      On the main menu, click User Accounts.

3.      Enter the User Name or Alias, and select the user’s Group, if the user name or Alias is not unique.

4.      Click Go to Account.

The View Account page for the user appears.

5.      Continue with one of the following procedures to hold or cancel the grid card.

To put the lost grid card on hold

If the user believes he will be able to locate the grid card by tomorrow (the user forgot it at home, for instance), complete this procedure.

1.      In the View Account page for the user, under Authentication Types, select Cards.

2.      Click Edit Card.

3.      Select the grid card in the Current state (if the user has not yet used it, it is in the Pending state) and click Edit Card.

4.      In the Edit a user’s card screen, select Hold from the State drop-down list.

5.      Click Save Changes.

If the user finds the grid card within, for example, 24 hours, then repeat this procedure and change the state of the grid card back to Current.

If the user has not found the grid card within the time frame set by your organization, follow the next procedure.

To cancel the lost or stolen grid card

If the user believes the grid card is lost or stolen and cannot be recovered in a short period of time, complete this procedure.

1.      Under Authentication Types on the View Account page, click Cards.

2.      Select the serial number of the grid card you want to cancel.

3.      Click Edit Card.

The Edit Card page appears.

4.      In the State drop-down list, select Canceled.

5.      Click Save Changes. 

6.      When prompted, click OK to confirm the cancellation.

The grid card is now canceled. It is still accessible through the user’s account page as well as through a grid card search until it is deleted.

7.      Take note of the user’s Group before proceeding to the next step.

8.      Continue with the procedure to assign a new grid card.

To assign a new grid card

1.      See Assign grid cards to users.

2.      (Optional) During the procedure, check the box labeled Use the following comments instead of those assigned to the preproduced card and type a note about the circumstances of the replacement grid card in the Comments box.

3.      Continue with the next procedure to send the grid card to the user.

To send a new grid card to the user

1.      Get the grid card with the serial number you just assigned out of inventory.

2.      Package and send the grid card using security precautions necessary based on

●       the location of the user: If the user is sitting on the same floor in the same building, you could call the user to pick it up. If the user is overseas, you must to package the grid card for shipment.

●       your method of getting the grid card to the user. If you are sending the grid card within your building or within your city, you may choose to put it in an interoffice mailer. If you are sending the grid card overseas, you may need to package it for shipment with a courier.
