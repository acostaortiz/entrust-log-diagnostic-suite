IdentityGuard Server 13.0 Administration Guide

Find users based on activation details

You can use the search function in the Administration interface to find all Entrust IdentityGuard users who

●       have activated already

●       who have an activation period set

●       who do not have an activation period

Note: Forced activation does not apply to grid cards used by administrators to log in to the Administration interface or Properties Editor.

To find users based on activation information

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      On the main menu, click User Accounts.

3.      Click the Find Accounts tab.

4.      You have a choice of multiple search criteria. (For details, see Searching for user information.)

5.      Click Has the additional account characteristics below.

6.      Narrow your search to consider the activation status of users:

●       To find activated users, select Card/Token activated.

●       To find users who are not activated, select Card/Token not activated. To narrow the search further, do one of the following:

–  To find users who are not set for forced activation, select Activation period expiry date not set.

–  To find users who are set for forced activation, select Activation period expiry date set and select a date range from the drop-down list.

If you select Custom date range from the drop-down list, choose dates from the From and To drop-down lists (day, month, year), or click the calendar icons to select dates.

7.      Click Find Accounts.
