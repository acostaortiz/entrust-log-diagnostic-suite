IdentityGuard Server 13.0 Administration Guide

Create and send an EGrid using the Administration interface

Users can create and manage virtual grid cards (EGrids) using Self-Service. If your organization does not use the Entrust IdentityGuard Self-Service Module, you can create EGrids for users and send them by email using the Administration interface.

To create EGrids using the Administration interface, the following things are required:

●       An administrator must have the userCardDeliver permission.

●       The user who will receive the eGrid must have a valid email address in their Entrust IdentityGuard account contact information.

●       A valid email delivery method must be configured.

●       If you want the eGrid to be protected with a password, the user must have an Entrust IdentityGuard password configured and the password policy CHAP/MS-CHAP Compatibility must be set to Yes.

To configure EGrid creation and delivery, complete the following procedures:

1.      Configure the properties to enable EGrid generation

2.      Configure delivery of EGrids

3.      Customize the email template for EGrid delivery

4.      Generate and send an EGrid
