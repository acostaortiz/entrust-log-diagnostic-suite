Customize the email template for EGrid delivery

If your organization does not use Self-Service Module, which allows users to generate and manage their own EGrids, complete the following procedure to customize the email message used when delivering an EGrid generated from the Administration interface. This is an optional procedure.

A message template is used in email EGrid delivery. The template uses Velocity syntax. You can find the template file in the following location:

●       on Windows

<$IG_HOME>\etc\templates\grids\

●       on Linux

$IG_HOME/etc/templates/grids/

You can modify the templates to meet your needs.

For information about Apache Velocity syntax, see http://velocity.apache.org/engine/2.2/user-guide.html.

Entrust IdentityGuard uses the values set in the User Email Delivery Configuration properties, such as Email Delivery Subject, to fill in fields in the message.

All email messages use the template named in the Email Delivery Template File property. For EGrid delivery, the email template files are called:

●       igsample_email_grid_template.txt 

●       igsample_email_grid_template.html

Copy the template file before changing it for your application. You can customize the contents to add branding and standard messages or disclaimers. You must use UTF-8 as the character-encoding format for the email template.

You can use the optional HTML template to send both text and HTML messages if required. If you would like to send an HTML message to email clients able to read HTML, create a text template and an HTML template. Both are supplied when Entrust IdentityGuard is installed, as described above.

If you have both text and HTML templates, a MIME multi-part alternative message is sent with both text and HTML body parts. When the email message is received, character-based e-mail clients use the text template, while graphical e-mail clients like Microsoft Outlook can display the HTML formatted email message.

The template, which uses Apache Velocity for formatting, allows you to define placeholders that Entrust IdentityGuard replaces with the appropriate information when the message is sent:

●       $fullname — The user's full name (If the user account does not include a full name, this will be the user name.)

●       $userid — The Entrust IdentityGuard user name (without the group name)

●       $gridSerialNumber — The unique serial number of the generated grid

●       placeholders for the actual grid content from the XSL file

●       $gridExpiryDate — The last date on which the grid can be used, if configured.

As an example, an email to John Smith to deliver an attached EGrid (PDF or image) could look something like this:

Hello John Smith,

Your grid with serial number 1234567 is attached.

Your grid expires on August 11, 2525.

Optionally, the EGrid can be shown directly in the body of the email instead of being delivered as an attachment.s
