IdentityGuard Server 13.0 Administration Guide

Admin-assisted automatic creation and activation of mobile soft tokens

Use the procedures in this section if you do not use Entrust IdentityGuard Self-Service Module through which users can create and activate their own soft tokens, or if users have problems with activating a soft token through self-service. These procedures let you  configure delivery of activation information to users in ways that it can be automatically populated in the soft token, which is easier for users and eliminates the risk of manual entry errors.

Here are the  ways you can get the activation information into the user’s soft token on a mobile device without entering it manually:

●       Scan a QR code in person at a help desk – When users are physically present at a help desk, they open the Entrust IdentityGuard Mobile Soft Token app on their mobile devices and scan the QR code directly from the Administration interface. The users select Activate in the app to complete the activation.

●       Scan a QR code or tap an activation link delivered by email – Sending activation information by email requires configuration of an email delivery method and, optionally, customization of the email message template. See Configure a delivery method for soft token activation information. An administrator sends an email to the user with all or some of the following information:

–  a QR code - If the user’s mobile device has an internet connection, the user opens the email on a mobile device, taps the QR code in the email, and then enters the activation password when prompted by the Mobile Soft Token app.

If the user opens the email on a computer, the user scans the QR code displayed on the computer using the Mobile Soft Token app on the mobile device, and then enters the activation password when prompted by the app.

–  an activation password - By default, this password is delivered in the same email as the QR code. That makes it convenient, but for added security, the password could be sent in a separate email or by other means.

–  a link to a URL where the user can activate the soft token. Inclusion of this link requires that the User Email Delivery Configuration property Include Registration Password be True. It is false by default.

–  activation information for manual entry - As a backup method, the email might also include a token serial number and activation code to enter manually in the Mobile Soft Token app.

●       Tap an activation link delivered in an SMS message – Send the user an SMS message that contains a link to a Web page that completes quick activation. This method requires configuration of an SMS delivery method and, optionally, customization of the SMS message template. See Configure a delivery method for soft token activation information.

Any of these actions enters the serial number and activation code in the app, after which the user can select the Activate button in the app to complete the activation.
