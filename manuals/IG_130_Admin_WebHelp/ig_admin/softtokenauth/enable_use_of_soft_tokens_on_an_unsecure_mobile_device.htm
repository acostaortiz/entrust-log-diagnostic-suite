IdentityGuard Server 13.0 Administration Guide

Enable use of soft tokens on unsecured mobile devices

This procedure applies only to Android or iOS mobile devices.

Prior to Release 11.0, the Entrust IdentityGuard Mobile Soft Token app (previously known as the Entrust IdentityGuard Mobile or Entrust IdentityGuard Mobile OTP) would not run on unsecured mobile devices. With Entrust IdentityGuard Server Release 11.0 or later and app version 3.1 or later,.the app always starts, but a policy determines whether users will be able to activate new soft tokens on unsecured devices.

For more information, see Effects of enabling the Mobile Soft Token Allow Unsecured Device policy.

To enable use of soft tokens on an unsecure mobile device

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

Note: Log in as a user with a role that includes these permissions: policyGet, and one of policyCreate, or policySet. See Policy permissions for details.

2.      Select Policies on the menu bar.

A list of all policies appears on the List Policies tab.

3.      Click the name of the policy for which you want to enable this feature.

The View Policy page for the selected policy appears.

4.      From the Policy Category drop-down list, select Token.

The token policies appear.

5.      Click Edit Policy.

An editable version of the settings appears.

6.      Enable the Mobile Soft Token Allow Unsecured Device policy.

Note: Mobile soft tokens that are activated manually (by entering the Identity provider address and name, along with a serial number and activation code in the app) cannot be activated on unsecured devices. In this scenario, there is no communication with the Entrust IdentityGuard server to check the policy setting, so the default setting (No) is used.

Note:This note applies to QR code activation only. If the Mobile Soft Token Allow Unsecured Device policy is changed after a QR code has been generated and the token has not yet been activated, the QR code must be regenerated.

7.      Click Save Changes.

Mobile soft tokens activated after this configuration use the new policy setting. The policy setting cannot be applied to existing mobile soft tokens. Users must delete their old soft tokens and recreate them to comply with the changed policy.

The View Policy page reappears.
