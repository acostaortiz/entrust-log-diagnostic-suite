IdentityGuard Server 13.0 Administration Guide

Configure delivery methods for soft token activation information

Use one or more of the following procedures to configure delivery of soft token activation information to users through the Administration interface. If you complete all of the procedures, you will have enabled Entrust IdentityGuard for all possible administrator-assisted delivery methods described in Admin-assisted automatic creation and activation of mobile soft tokens and the Activate Token page in the Administration interface would look like this:

To configure delivery of soft token information through a QR code at a help desk

1.      Log in to the IdentityGuard Properties Editor as an administrator. See To log in to the Properties Editor.

2.      From the table of contents, select Web Application Settings.

3.      Set Enable Token Activation using QR Codes to True (the default setting) to have the QR code displayed in the Administration interface (where users who are present can scan it using their mobile devices).

4.      Click Validate & Save.

A confirmation dialog box appears.

5.      Click OK to confirm.

6.      Restart the Entrust IdentityGuard Server service.

User steps for activating a mobile soft token through a QR code at a help desk

1.      When a user is physically present at a help desk, the administrator navigates to the Token Activation page.

2.      The user opens the Entrust IdentityGuard Mobile Soft Token app on their mobile device.

3.      The user scans the QR code displayed in the Administration interface.

4.      The user enters the activation password displayed in the Administration interface.

5.      The user selects Activate in the app to complete the activation.

To configure delivery of soft token activation information by email or SMS from the Admin UI

1.      Decide what information you want to include in the email and, if required, customize copies of the TXT and HTML format email templates appropriately.

The sample templates for this use case are

●       igsample_email_tokenactivate_template.txt

●       igsample_email_tokenactivate_template.html.

They are located in $IG_HOME/etc/templates/tokens.

Note: Entrust IdentityGuard provides templates in both TXT and HTML formats. A best practice is to customize both versions. In the configuration instance, specify the .txt version because all email clients can process and display plain text. When there is a corresponding template of the same name but with an .html extension (in the same folder), Entrust IdentityGuard automatically creates a MIME multi-part alternative message using the txt template and the html template. Most email clients can display the HTML but for email clients that cannot, the text content is displayed.

2.      Log in to the IdentityGuard Properties Editor as an administrator. See To log in to the Properties Editor.

3.      Specify the following settings:

●       Web Application Settings

–  IdentityGuard Self-Service Activation Address – If you have Self-Service Module in your implementation, enter the URL of the Self-Service website. If specified, the value is included in the soft token activation QR Code.

Example address: ssm.example.com:8445/igst

Note: This Administrator-assisted procedure assumes you do not have a Self-Service website, however, configure this setting if you use Self-Service Module and still want to offer administrative activation of soft tokens.

●       SMTP Server Configuration – This is required to send activation information by email.

–  Configuration instances – Create a new configuration instance with a descriptive name such as For Soft Token Activation and configure the settings. For information about the settings, see SMTP Server Configuration).

●       User Email Delivery Configuration

–  Configuration instances – Create a new configuration instance with a descriptive name such as ST Activation Info and configure the following settings for it.

–  Email Delivery Configuration Type – Select Token Activate.

–  Email Delivery Template File – Specify the TXT version of the email template you want to use (from Step 1).

–  Email Delivery Subject: Specify a subject line like "Activation information for your Mobile Soft Token".

–  Include Registration Password – Set to True.

For information about the other settings, see User Email Delivery Configuration

●       SMS Server Configuration – This is required to send activation information in a text message.

–  Configuration instances – Create a new configuration instance and configure the settings. For information about the settings, see SMS Server Configuration.

●       User SMS Delivery Configuration – If you plan to send activation information by SMS message, create a new configuration instance and configure the following settings:

–  SMS Delivery Configuration Type – Select Token Activate.

–  SMS Delivery Template File – Specify igsample_sms_tokenactivate_template.txt or a custom template. The sample SMS template is located in $IG_HOME/etc/templates.

For information about the other settings, see, User SMS delivery configuration property settings.

4.      To enable delivery of activation information in a QR code with a password, in addition to the settings in Step 2, specify the following settings:

●       Web Application Settings

–  Enable Token Activation using QR Codes – Set to True (the default setting) to have the QR code displayed in the Administration interface (where users who are present can scan it using their mobile devices).

●       User Email Delivery Configuration 

–  Email Delivery Enable QR Code Attachment – Set to True.

a.      Click Validate & Save.

b.      Click OK on the confirmation dialog box.

5.      If required, customize the appropriate delivery message: 

●       igsample_email_tokenactivate_template.html or

●       igsample_sms_tokenactivate_template.txt

The message templates are located in $IG_HOME/etc/templates/tokens.

Note: The .txt and .html versions of the templates must be located in the same directory.

The default email template covers sending activation information in all 3 possible ways: through an online activation link, as a QR code, and full details for manual entry. Remove parts of the text for any method you do not want to use. For example, if you send a QR code, for added security, you might want to send the password that is required to use it by another means.

The configuration is complete. Use the activation procedure to create and activate mobile soft tokens through the Administration interface as needed. See Create and activate a soft token in the Admin UI.

6.      Restart Entrust IdentityGuard Server service.
