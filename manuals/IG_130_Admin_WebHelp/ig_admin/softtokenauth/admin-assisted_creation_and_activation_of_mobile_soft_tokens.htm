IdentityGuard Server 13.0 Administration Guide

Create and activate a mobile soft token using the Administration interface

If you have Entrust IdentityGuard Self-Service Module, users can creates and activate their own mobile soft tokens. For Self-Service configuration information, see the Entrust IdentityGuard.Self-Service Module Installation and Configuration Guide. For end-user procedures, see the help in the Entrust IdentityGuard Mobile Soft Token app.

If you do not use Entrust IdentityGuard Self-Service Module, or if users have problems with activating a soft token through self-service, use one of the following procedures to create a mobile soft token and deliver to the user the information they need to activate it.

This section contains two procedures that describe how to activate a mobile soft  token using the Administration interface.

●       Administrative creation and activation of mobile soft tokens - manual entry – describes what information to give the user. The user must enter it manually in the Mobile Soft Token app.

●       Administrative creation and activation of mobile soft tokens - automatic entry of activation information – describes how to get information to the user through a QR code or a URL link. The user does not need to enter the information manually.

Note: For information about having users create and activate their own mobile soft tokens using a Self-Service website, see the Entrust IdentityGuard Self-Service Module Installation and Configuration Guide.
