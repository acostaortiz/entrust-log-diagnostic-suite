IdentityGuard Server 13.0 Administration Guide

Using external Q&A data for Entrust IdentityGuard authentication

If you already use a knowledge-based authentication system, you can continue to use it with Entrust IdentityGuard rather than use Entrust IdentityGuard’s built-in Q&A capabilities.

Entrust IdentityGuard does not provide a plug-and-play integration with any specific third-party Q&A applications. You must design the way that the external Q&A provider interacts with Entrust IdentityGuard in your implementation.

Entrust IdentityGuard does provide an interface that enables you to make Entrust IdentityGuard aware of your external Q&A application so that it can pass users to the external provider for knowledge-based authentication in appropriate scenarios.

For more information about integrating your external Q&A provider with Entrust IdentityGuard, see the Entrust IdentityGuard Programming Guide.

One Q&A provider per user

All users in any given Entrust IdentityGuard group must use either Entrust IdentityGuard’s own Q&A authentication, or a single external Q&A implementation. A user cannot use both internal and external Q&A, nor can that user use multiple external Q&A implementations.

If external Q&A is used, existing Entrust IdentityGuard Q&A data is unavailable

Typically, users whose Entrust IdentityGuard policy specifies an external Q&A provider will not have Entrust IdentityGuard question and answer pairs. However, it is possible that users previously had Entrust IdentityGuard Q&A values defined under a different policy or before the external Q&A provider was integrated with Entrust IdentityGuard. If a policy specifies that external Q&A data is used, the Entrust IdentityGuard administrator cannot view or modify pre-existing Entrust IdentityGuard Q&A data. Similarly, end users cannot view or edit their Q&A data through Self-Service. If the policy is changed to again use Entrust IdentityGuard Q&A, the administrator can once again administer this data through the Entrust IdentityGuard Administration interface, and users can administer this data through Self-Service.
