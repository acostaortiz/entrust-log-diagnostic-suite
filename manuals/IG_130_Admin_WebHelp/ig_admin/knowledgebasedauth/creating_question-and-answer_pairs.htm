Create question-and-answer pairs in the Master user shell

Knowledge-based authentication involves asking users a series of questions to which they must respond with the correct answers. You can create question-and-answer pairs for users in the Master user shell.

To create question-and-answer pairs for one user

1.      Open the Master user shell and log in. (See Using the Master user shell.)

2.      At the prompt, do one of the following:

●       To create new question-and-answer pairs, enter

user set <userid> -qa (<question> <answer>)+

●       To add question-and-answer pairs to existing pairs, enter

user set <userid> -qa -merge (<question> <answer>)+

Example:

user set johnsmith -qa -merge “What was your first car?” Mustang

To create question-and-answer pairs for multiple users, you must use data from an import file. See the Entrust IdentityGuard Master User Shell Reference for more information.

To create question-and-answer pairs for multiple users

3.      Create a bulk import file. (See Create a bulk file

4.      Open the Master user shell and log in. (See Using the Master user shell.)

5.      At the prompt, enter

user set -bulk <file>
