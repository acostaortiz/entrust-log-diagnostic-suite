IdentityGuard Server 13.0 Administration Guide

Set the number of correct answers required

Entrust IdentityGuard provides tolerance, or flexibility, in the number of questions a user must answer correctly. You can make it mandatory that all questions be answered correctly, or you can allow room for error. For example, you can decide that three out of four correct answers represents a successful authentication.

If you configure knowledge-based challenges to allow some wrong answers, you must take into account the number of questions presented in different scenarios. See Set the number of questions asked. The number of allowed wrong answers must be lower than the number of questions presented. For example, you cannot ask only two questions, and allow two wrong answers. In any knowledge-based challenge, at least one question must be answered correctly.
