IdentityGuard Server 13.0 Administration Guide

Approve user biometrics

If your policy is configured to require approval of user biometrics before they can be used to authenticate, use this procedure to approve a biometric. Alternatively, you may use a bulk operation in the Master User Shell to approve numerous enrolled biometrics. For more information, see Performing bulk operations.

To approve a user’s biometric

1.      Log in to the Administration interface (see Log in and out of the Administration interface).

2.      On the main menu, click User Accounts.

3.      Find a specific user in one of two ways:

●       Use the Go To Account tab (see Search for information about a specific user).

●       Use the Find Accounts tab (see Searching for user information).

4.      Under Authentication Types, click Biometrics.

5.      Click the vendor name in the Vendor column of a biometric to view its details.

6.      Click Edit Biometric.

7.      On the Edit Biometric page you can change the state of the biometric from Inactive to Active.

8.      Click Save Changes.
