IdentityGuard Server 13.0 Administration Guide

Find biometric information

Use one of the following procedures to search for information about biometrics belonging to an individual user or list of users.

●       To find biometric information

●       To display a user’s biometric information

To find biometric information

1.      Log in to the Administration interface (see Log in and out of the Administration interface).

2.      On the main menu, click Biometrics.

The List Biometrics Search Options page appears.

3.      Enter any of the following criteria to locate specific biometrics:

●       To find a biometric by whether or not it is active, select the state from the State list. For more information, see Biometric states overview.

●       To find biometrics by their enrollment states, do one of the following:

–  To find biometrics in a specific state, select the states from the Enroll States Include list.

–  To locate biometrics belonging to users who have no biometrics in a specific state, select the state from the States Don’t Include list. Hold down the Ctrl key to select more than one state.

For more information, see Biometric states overview. To select more than one option from a list, hold the Ctrl key (see Select options).

●       To find biometrics that were enrolled within a certain date range, select a date range from the Enroll Date drop-down list.

If you select Custom date range, select the From and To dates from the drop-down lists (day, month, year). You can also use the calendar icons to select dates.

●       To find biometrics by the date they were last used, select a date range from the Last Used drop-down list.

If you select Custom date range, select the From and To dates. You can also click the calendar icons to select dates.

●       To find biometrics according to specific user account characteristics, select The owner of the biometric has the characteristics below.

The Biometric owner account characteristics pane appears. This pane provides additional options so you can search by various user account information. For more information about the options in this pane, see Searching for user information.

4.      (Optional) To specify how many search results should appear on each page, select a number from the Showing results per page drop-down list.

5.      Click Search.

The Search Results page appears.

6.      Click the vendor name in the Vendor column of the biometric you want to view.

The Biometric Details page displays all the information associated with that biometric.

To display a user’s biometric information

1.      Log in to the Administration interface (see Log in and out of the Administration interface).

2.      On the main menu, click User Accounts.

3.      Find a specific user in one of two ways:

●       Use the Go To Account tab (see Search for information about a specific user).

●       Use the Find Accounts tab (see Searching for user information).

4.      Under Authentication Types, click Biometrics.

5.      Click the vendor name in the Vendor column of a biometric to view its details.
