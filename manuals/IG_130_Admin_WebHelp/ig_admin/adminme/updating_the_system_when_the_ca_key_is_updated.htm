Update SCEP digital IDs when the CA key is updated

This section applies only to SCEP digital IDs (see Digital ID types and formats for details).

If you update your CA key pair (for example, because it is approaching expiry), you must update your SCEP digital IDs immediately afterwards to take into account the CA’s new keys. Use of the following methods.

Note: There is no need to update the XAP credentials (which you would have created as part of the mobile enrollment configuration with a Security Manager CA). The XAP credentials are updated automatically by a background process.

To update SCEP credentials (Method 1)

1.      Ensure you have updated your CA key pair. Consult the Security Manager Administration User Guide or the Microsoft CA documentation for details.

2.      Stop the Entrust IdentityGuard server using the Services panel (Windows) or using the identityguard.sh stop command (Linux). See the Entrust IdentityGuard Server Installation Guide for details.

3.      On your Entrust IdentityGuard server, log in to the Master user shell. See Using the Master user shell.

4.      Enter the following command:

ca update <name> scepRa

where

<name> is the friendly name of your CA. You can find this friendly name in the Managed CA Name field in the Entrust IdentityGuard Administration interface. For details, see Step 9: Configure a managed CA.

Your SCEP credentials are updated in the Entrust IdentityGuard repository.

5.      Start Entrust IdentityGuard server using the Services panel (Windows) or using the identityguard.sh start command (Linux). See the Entrust IdentityGuard Server Installation Guide for details.

6.      Restart the Self-Service Module. See the Entrust IdentityGuard Self-Service Module Installation and Configuration Guide for details.

To update SCEP credentials (Method 2)

This method applies only to Entrust CAs.

1.      Create a new SCEP user and EPF (do not recover the existing SCEP user). Use different names for the user and EPF to distinguish them from the old ones. For instructions, see Creating a SCEP EPF file (Security Manager CA).

2.      Remove the old EPF and add the new one to the managed CA in Entrust IdentityGuard. See Step 9: Configure a managed CA.
