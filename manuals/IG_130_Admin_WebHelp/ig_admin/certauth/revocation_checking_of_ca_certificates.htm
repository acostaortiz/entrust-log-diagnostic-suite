IdentityGuard Server 13.0 Administration Guide

Revocation checking of CA certificates

Revocation checking is done only for user certificates issued by registered CAs.

A user certificate may be defined with any combination of the following.

●       AIA extension for OCSP

●       CDP extension specifying CRLs

–  DN CDP

–  HTTP URL CDP

–  LDAP URL CDP

The Entrust IdentityGuard CA certificate can be configured with the possible certificate revocation value values described in the following table.

Combinations of these parameters can be specified, and if so, multiple revocation sources are checked during certificate validation. If none of these values are specified, then certificate revocation is not checked during validation.

Entrust IdentityGuard certificate property

Rule and dependencies

Follow URL CDPs

If set, Entrust IdentityGuard follows the HTTP/LDAP URL CDPs to retrieve the Certificate Revocation Lists.

LDAP URL

If supplied, Entrust IdentityGuard uses this LDAP server to retrieve CRLs if DN CDPs are defined. It also tries to retrieve combined CRLs from the LDAP entry of the CA certificate.

If you enter an LDAP URL, you can also specify the LDAP user DN and LDAP password. If you do not supply the LDAP user DN and password, then authentication to the LDAP directory will be anonymous.

If you specify an LDAP URL, you must also select Follow URL CDPs, and it will be automatically set if it is not specified. If an LDAP URL is not specified, the LDAP Follow URL CDPs will be turned off by default.

Use AIA Extension to Locate OCSP Responder

When this option is enabled, Entrust IdentityGuard uses the OCSP entry in the certificate Authority Information Access (AIA) extension to locate the OCSP server from which to retrieve certificate revocation information.

In Entrust IdentityGuard 10.2 FP1 Patch 197971 and later, this option is disabled by default. Previously, it was enabled by default.

OCSP Responder URL

If supplied, Entrust IdentityGuard uses the URL to access the OCSP revocation checking.
