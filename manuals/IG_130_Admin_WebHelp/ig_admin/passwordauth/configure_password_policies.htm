IdentityGuard Server 13.0 Administration Guide

Configure password policies

One policy category governs how Entrust IdentityGuard stores passwords and apply password creation rules. These cover features such as the number of required characters, the use of numbers and special characters, the case of alphabetic characters, the maximum number of repeated characters, password uniqueness across all of a user’s passwords, and the password storage method.

Entrust IdentityGuard prohibits user passwords that contain the user name, user aliases, and identifiable contact information. See Avoiding embedded user information in passwords.

If you do not want users to use real dictionary words as passwords, configure the password policy to require at least one special character in their password. 

Administrators can create user passwords manually or by autogeneration. See Autogenerated passwords.

To view password policy

1.      Log in to the Administration interface. (See Logging in and out of the Administration interface.)

2.      Select Policies on the menu bar.

A list of all policies appears on the List Policies tab.

3.      Click any policy name to view its policy information.

The View Policy page appears and lists all policy settings.

4.      Under Policy Category, select Password from the list.

The password policy appears as described in Password policies.

To change password policy

5.      Find the policy to change (see To view password policy).

6.      On the View Policy page, click Edit Policy.

An editable version of the settings appear.

Note: Any changes you make to passwords apply to all members of the group, but only to passwords created in the future. For example, if you change the Password Storage policy to be Compatible with CHAP/MSCHAP when it was not before, no current passwords are affected. Users with existing passwords must perform a password change for the new policies to take affect.

7.      Edit the policies as described in Password policies.

8.      Click Save Changes. The View Policy page reappears.

Note: Administrators are prompted to change their passwords at next login so that their passwords comply with the new policies settings right away.

Changing password policies does not affect ordinary users—their current passwords continue to work. When their passwords expire, users will create new passwords that comply with the new policy settings.
