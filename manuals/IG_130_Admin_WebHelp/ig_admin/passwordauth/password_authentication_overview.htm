IdentityGuard Server 13.0 Administration Guide

Password authentication overview

The password authentication feature provided with Entrust IdentityGuard lets you manage first-factor authentication through Entrust IdentityGuard instead of relying on an external resource such as a Radius server or other external authentication manager.

Entrust IdentityGuard built-in passwords support PAP/CHAP/MS-CHAP. If you need CHAP/MS-CHAP, your Password Storage policy must be set to Compatible with CHAP/MSCHAP. See To change password policy.

Typically, you use password authentication as the first layer of a multifactor Entrust IdentityGuard authentication regime.

Note: If first-factor authentication is supplied by a mechanism other than the Entrust IdentityGuard password feature, you can use Entrust IdentityGuard password authentication as one of your second-factor authentication methods. The password authentication feature is always limited to first-factor authentication when authenticating through the Radius proxy.

Entrust IdentityGuard allows users to have multiple passwords for authentication. This facilitates the use of different passwords for different access points. One unnamed password can act as the default password, which uses the default policy. Each additional password policy is given a name to distinguish it, and has matching named password rules and lockout policy.

Administrators can also have named passwords but the Administration interface accepts only the default password.

To configure Entrust IdentityGuard to use password authentication:

●       Make sure administrators have the required permissions to complete the following tasks and to manage passwords (see User password permissions).

●       Use the Policies pages of the Administration interface to:

–  Set Password as an authentication option for each applicable group. This is set by default.

–  Set password rules.

(See Configuring password authentication policies.)

●       Use the Properties Editor to set the Entrust IdentityGuard properties related to the disallowed-password list. (See Setting disallowed password properties.)

●       To use password authentication in a VPN environment, configure the Radius proxy. (See Radius proxy configuration overview.)

Password authentication through Radius supports the PAP, CHAP and MSCHAP (v1 and v2) protocols. Password changes are limited to PAP. (See also Having a user set up a password.)

After you configure Entrust IdentityGuard password policies and properties, configure your application to use password authentication. For more information, see the Entrust IdentityGuard Programming Guide.

Passwords used by the Administration interface and the Properties Editor to authenticate administrators are managed through the Administration API. For information about administrator passwords, see Creating and changing administrator passwords.
