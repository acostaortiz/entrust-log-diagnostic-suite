New property group: Content Security Policy (CSP) Directives (IDG-12031)

The Entrust IdentityGuard Properties Editor now provides an option to enable Content-Security-Policy (CSP) Directives to enhance the security of a web page. CSP is an added layer of security that helps to detect and mitigate certain types of attacks, including cross -site scripting (XSS) and data injection attacks.

 Content Security Policy Directives

New property group: HTTP Strict Transport Security (IDG-12030)

The Entrust IdentityGuard Properties Editor now provides an option to enable HTTP Strict Transport Security (HSTS), which offers protection against TLS downgrade attacks. More...

TLS downgrade attacks (also known as SSL stripping attacks) are a form of man-in-the-middle attack in which the attacker tricks the victim's browser into communicating with Entrust IdentityGuard over HTTP rather than HTTPS. HSTS prevents this by including a header in HTTP responses that tells the browser to require HTTPS on future connections to this server.

 HTTP Strict Transport Security

Enhanced display of locked accounts and authenticators (IDG-13095)

To help determine whether an account or authenticator is still locked when auto-unlock is provisioned, the Entrust IdentityGuard  Administration interface now shows auto-unlock dates in red if they are still in force, or green if they have expired, meaning that the account (or the given authenticator if per-authenticator lockout is being used) is now unlocked.
