IdentityGuard Server 13.0 Administration Guide

Creating and changing administrator passwords

The first administrator needs a password to log in. You set the password when you create the administrator during Entrust IdentityGuard configuration. When this administrator logs in for the first time, the password must be changed.

If you do not want to have to change the password immediately on first login, use the Master user shell to set the -changerequired attribute to false for that administrator. For example:

user password set firstadmin -changerequired false

–  where firstadmin is the name of the new administrator.

When an administrator creates new administrators later in the Administration interface, they can create a password at the same time. They can also change another administrator’s password when needed, if they have the applicable permissions.

Any administrator who is logged in to the Administration interface can change their own password.

Administrators can also change and manage user passwords. The password rules—what a password must consist of—are set by the password policy for the group and apply to administrators and users (see Configuring password authentication policies).

Note: These procedures are not used or possible if the First-Factor Authentication property is set to External.
