IdentityGuard Server 13.0 Administration Guide

Find an administrator account

Before you can modify or delete administrators, you need to locate them. Follow this procedure to find administrators by name or by one of their attributes.

The Administration interface shows only those administrators that the administrator doing the searching is entitled to see; that is, any administrator for which the administrator doing the viewing has a role that includes all the roles of the administrator being viewed. For more information, see Understanding roles.

To see a list of administrators

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      Click User Accounts on the home page.

3.      Click the Find Accounts tab.

4.      Select the Administrator option.

5.      (Optional) To find all administrators with details in common, select additional options. (For details on other options, see Searching for user information.

6.      Click Find Accounts.

7.      A list of existing administrators meeting your search criteria appears. Click any name to see details about that administrator.

Note: When the list of administrators returned by the search includes administrators with multiple roles, you may not be able to manage some aspects of those administrators if your roles lists do not match. For example, even though options to unlock or delete an administrator appear, they may not function for every administrator you select.

To find a specific administrator

1.      Log in to the Administration interface.

2.      Click User Accounts on the home page.

3.      Click the Go To Account tab.

4.      Enter an administrator name or alias in the User Name or Alias field.

5.      Select a group from the list if the user name is not unique.

6.      Click Go To Account. Details about that administrator appear.
