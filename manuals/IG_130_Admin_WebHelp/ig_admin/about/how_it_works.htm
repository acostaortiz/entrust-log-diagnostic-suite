How mobile enrollment for digital IDs works

At a high level, mobile enrollment works as follows:

1.      A user goes to your organization's self-service website (configured using the Entrust IdentityGuard Self-Service Module) and clicks the I’d like to request a digital ID link.

2.      The Self-Service we page passes the request to Entrust IdentityGuard.

3.      Entrust IdentityGuard passes the request to the CA.

4.      The CA creates certificates (and possibly keys) and sends the data back to Entrust IdentityGuard. Whether the CA creates keys depends on the digital ID format you choose. See Digital ID types and formats for details.

5.      Entrust IdentityGuard passes the digital ID to the Self-Service Module.

6.      The Self-Service Module passes the digital ID over-the-air to the mobile device.

7.      The user is asked to download the digital ID (and CA certificate) on the mobile device.
