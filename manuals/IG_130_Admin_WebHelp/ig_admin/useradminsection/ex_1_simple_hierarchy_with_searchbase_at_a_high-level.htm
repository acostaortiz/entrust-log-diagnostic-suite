IdentityGuard Server 13.0 Administration Guide

Example 1: Simple hierarchy with searchbase at a high-level

In the following example, all users are in a single LDAP container. That container can be configured as the searchbase,

Properties Editor / LDAP Sync Directory instances — Only one configuration instance is required in the LDAP Directory Server Settings.

Database — Enrollment data can be added to a single Entrust IdentityGuard database (which could be the default Entrust IdentityGuard database).

Notifications — When all data is in one LDAP container  notifications about changes to user data in the LDAP directory are sent to Entrust IdentityGuard by default.

Filtering — If the searchbase contains some users that should not be enrolled in Entrust IdentityGuard (for example, non-human administrator accounts), a filter expression can be written to exclude them.
