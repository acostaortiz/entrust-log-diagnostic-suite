IdentityGuard Server 13.0 Administration Guide

Find users by token

To find users by token

1.      Log in to the Administration interface  

2.      In the main menu, click User Accounts.

The User Accounts page appears.

3.      Click the Find Accounts tab.

4.      Specify as many of the search options as necessary to reduce the search results to the exact records you need.

5.      To find users with tokens, select Has a token with the characteristics below.

The Token characteristics pane appears.

6.      To find users by their token serial number, enter the serial number in the Serial Number field. Wild cards are allowed, so you can enter 11*, for example, to search for all users with token serial numbers beginning with “11”.

7.      To find users with tokens from a particular vendor, select the vendor from the Token Vendor list.

8.      To find users by their token states, select the token states from the States Include and States Don’t Include lists. You can select more than one state from the list.

9.      To find users by their the date their token was added to Entrust IdentityGuard, select a time frame from the Token Added drop-down list.

If you select Custom date range, choose a date range from the From and To drop-down lists (day, month, year), or click the calendar icons to select dates.

Note: The Token Added date is the date the token was loaded into Entrust IdentityGuard, not the date it was assigned to a user.

10.  To find users by the date they last used their token, select a time frame from the Last Used drop-down list.

If you select Custom date range, choose a date range from the From and To drop-down lists (day, month, year), or click the calendar icons to select dates.

11.  To find users by whether or not they have a soft token license, next to Uses License, select Yes if the user has a soft token and uses a Soft Token license, or No if it they do not.

12.  To find users by whether or not they have a soft token that is licensed to use the transaction verification feature, next to Uses Transaction Verification License, select Yes if the user uses the transaction verification feature or No if they do not.

13.  To find users by whether they have a mobile soft token that is licensed to use the face recognition feature, next to Uses Facial Recognition License, select Yes or No.

14.  To specify how many search results are displayed per page, select a number from the Showing results per page drop-down list.

15.  Click Find Accounts.

The Search Results page displays all users that match your search criteria.

Note: You can change the sort order of records in the Search Results page. Click any column header to sort records by the values in that column.
Only the entries on the current page are sorted; if there are multiple pages of search results, only the one you are viewing is sorted.
