IdentityGuard Server 13.0 Administration Guide

Creating user accounts

You must create user accounts for users who will authenticate to Entrust IdentityGuard when accessing a protected resource or when completing an action (such as a money transfer) that requires second-factor authentication.

You can create users in multiple repositories and multiple partitions. You can create users from any site or replica repository as long as your replica sites and your master site create the users in different partitions. For more information about partitions, see Using partitions.

You can create users directly in Entrust IdentityGuard using the following procedures:

●       Create users individually

●       Create users through a bulk operation

If users already exist in an LDAP repository, you can configure Entrust IdentityGuard to create Entrust IdentityGuard accounts for those users automatically using one of the following features:

●       To create Entrust IdentityGuard user accounts in a database that is synchronized with an Active Directory LDAP repository, follow Create users through LDAP synchronization with a database.

●       To create Entrust IdentityGuard user accounts by adding Entrust IdentityGuard information to user accounts your LDAP directory, follow Create users by adding IdentityGuard data to your LDAP repository.

When you use multiple repositories to store user information and assign multiple repositories to a group, it is important to qualify all user names with a group name. If you do not specify the group name, Entrust IdentityGuard APIs search every repository for every API call that is made, which degrades Entrust IdentityGuard performance.

When you create a user:

●       Specify the Entrust IdentityGuard group to which the user belongs. Policies that govern the user are applied at the group level.

●       Ensure that each user name is unique within the group to which the user is assigned. Or, if you do not want users to have to specify their group name each time they enter their user name, ensure that user names that are unique across all groups.

Attention: If you are using an LDAP repository, the Entrust IdentityGuard user you create must already exist as an entry in the LDAP repository and the user ID must be unique within the LDAP searchbase as well as within the Entrust IdentityGuard group.

●       Specify the repository where the user's data is stored. Entrust IdentityGuard does not have to store data for all group members in the same repository.
