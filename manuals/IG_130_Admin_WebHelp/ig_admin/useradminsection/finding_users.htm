IdentityGuard Server 13.0 Administration Guide

Finding users

When searching for users, include as many search options as possible to reduce the search results to the exact records you need.

In large enterprise or consumer deployments, a generalized search can easily return thousands of users—far more than the Administration interface can display on one page or than are usable in the Master user shell.

You can search for a particular user or for a list of users in your system. Entrust IdentityGuard allows you to:

●       Search by user name matches. This function allows you to search by user name or alias and includes wildcard searches.

●       Search by group. This function allows you to search for users based on their assigned group.

●       Search by user account. This function allows you to search for users with specific account criteria, such as whether or not the user:

–  has a temporary PIN

–  is locked out of their account

–  has specific card characteristics (including serial number, state of card, usage threshold indicator, creation date, and expiry date)

–  has specific token characteristics (including serial number, state of token, addition date, and last used date)

●       Search by last authentication. This function allows you to search for users and administrators based on their last successful or unsuccessful authentication and the authentication type used.

●       Search by whether or not they have a grid card, token, or certificate.

You can set the number of records to display per page using the Showing results per page option. The maximum is 100.

Note: You cannot view corrupted user records in the Administration interface; however, you can delete the account on the Delete Account tab by entering the user account name.
