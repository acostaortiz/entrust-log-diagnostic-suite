IdentityGuard Server 13.0 Administration Guide

Manage orphaned user accounts

Entrust IdentityGuard accounts might be orphaned after a synchronization with an LDAP directory. This might occur for one of the following reasons:

●       a user was deleted from the LDAP directory

●       a user was moved to an LDAP directory container that is not synchronized with an Entrust IdentityGuard database

You can generate an Entrust IdentityGuard report to get information about orphaned accounts. Use this report to review the orphaned accounts and determine whether the accounts should be deleted.

Entrust IdentityGuard does not delete user accounts automatically because to do so would delete all authenticators for the user and that information cannot be recovered if it turns out that the LDAP directory user was only moved or perhaps deleted by mistake.

Orphaned users are treated similarly to suspended users in Entrust IdentityGuard, which means that (by default) orphaned users cannot authenticate to resources protected by Entrust IdentityGuard. The default behavior can be changed by enabling the Repository Data policy setting Allow Authentication if User Orphaned in Repository.

Red Hat Directory Server requirement: Removing a user in LDAP causes the associated Entrust IdentityGuard user to be orphaned. To enable users removed from the Red Hat Directory Server to be orphaned automatically in Entrust IdentityGuard, configure the Entry USN (Update Sequence Numbers) plugin. Instructions for doing this can be found at this URL:
https://access.redhat.com/documentation/en-US/Red_Hat_Directory_Server/8.2/html/Administration_Guide/Tracking_Modifications_to_Directory_Entries.html#tracking-modifications-through-usns

With USN enabled, when a user is deleted, a copy of their LDAP entry is moved to a so-called tombstone entry. Entrust IdentityGuard uses this tombstone entry to find the LDAP Sync Unique User ID attribute value associated with the deleted user so the user can be orphaned. Entrust IdentityGuard requires this tombstone entry immediately after a user is removed from the LDAP directory, after which tombstone entries can be removed from the LDAP directory. If USN is not enabled in Red Hat, Entrust IdentityGuard cannot process the real-time events about LDAP user removals.

To create a report of Entrust IdentityGuard orphaned accounts

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      In the main menu, click Reports.

The Select a report page appears.

3.      Click User CSV Report, and then click Next.

4.      In the Report Description field, briefly describe what the report will contain, for example Orphaned user accounts.

5.      In the User account search criteria pane, select Has the additional account characteristics below.

The Additional account characteristics pane appears.

6.      Select Sync orphaned.

7.      If desired, select other report options, as described in Configuring reports.

8.      Click Generate Report.

The Report List shows the report title and its status as it is being generated.

9.      When report generation is complete, click the report icon in the Download column.

The report opens in a program that reads CSV files (for example, Microsoft Excel).

10.  Use the information in the report to take appropriate action for the orphaned accounts. For example, if the users are deleted in the LDAP directory, delete the accounts in Entrust IdentityGuard individually or through a bulk operation..

Note: The Sync orphaned and Not sync orphaned user account characteristics apply only to users in an Entrust IdentityGuard database. Users in an Entrust IdentityGuard LDAP repository are not selected if their characteristics are selected as part of the search criteria. Additionally, any user in an Entrust IdentityGuard database repository that is not configured for LDAP directory synchronization is not returned for searches using these characteristics.
