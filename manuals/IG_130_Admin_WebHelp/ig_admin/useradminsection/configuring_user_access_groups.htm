IdentityGuard Server 13.0 Administration Guide

Configuring user access groups

Entrust IdentityGuard can be configured to authorize users to use specific protected resources, for example, web pages, web portals, or applications.

One way to grant different authorizations to different users is to create Entrust IdentityGuard groups, and group users with the same access needs together. Each IdentityGuard user can be a member of only one Entrust IdentityGuard group.

This section describes another way to grant different authorizations to users in an organization, by configuring user access groups.

User access groups might be a good solution for your organization if

●       if Entrust IdentityGuard groups are not used, or the fact that a user can be a member of only one Entrust IdentityGuard is constraining

●       If you use a database as the user data repository for your Entrust IdentityGuard installation, or if you use an LDAP repository such as Microsoft Active Directory but you are not able to configure user access through that software

A user access group is an attribute of a user account and can be seen in a user's account details or in user reports. A user account can have a list of access groups that are determined by the policy, or it can have a custom list that overrides the policy.

An example of how to use user access groups

Charles is a human resources staff member in a company. To do his job he uses a number of specialized applications hosted on the company's HR Web portal. He often travels to company recruiting events and he needs to access the company network and the HR Web portal remotely through VPN. Unlike his colleagues in the HR department, he also needs occasional use of software used by the Finance department.

All of the staff in the company's HR department have user accounts in the Entrust IdentityGuard group "HR" and the group uses the Entrust IdentityGuard policy "HR Policy". The Entrust IdentityGuard administrator created user access groups for this policy so the users in the group to which the policy applies are authorized to access the HR portal and to work remotely through VPN.

To give Charles the additional authorization to access the Finance department software, the Entrust IdentityGuard administrator updated Charles' account information to override the access groups set by the policy for the department and add the custom list of access groups so Charles can access the software applications and web pages he needs to do his work.

 

These user access groups are returned with the user ID during a successful authentication. The user access groups can then be used by an application for authorization purposes (for example, return the list of access groups to a VPN server for further authorization processing). In the preceding example, the access groups related to access the Finance department software would be included in Charles' Radius response to the VPN.
