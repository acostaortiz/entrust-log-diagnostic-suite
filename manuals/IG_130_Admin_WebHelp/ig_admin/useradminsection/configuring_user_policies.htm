Configuring user policies

User policies define the rules for user interaction with Entrust IdentityGuard. A policy is assigned to a group and the policy applies to all users in that group. For more information about policies, see Configuring policies.

There are occasions where an administrator needs to change the user policies related to a group of users. For example, an administrator may want to add tokens as a second-factor authentication method.

Before you can configure user policies, your role must include the correct permissions (see Permissions quick reference).
