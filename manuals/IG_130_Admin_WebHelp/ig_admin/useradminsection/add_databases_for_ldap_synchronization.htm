IdentityGuard Server 13.0 Administration Guide

Add databases for LDAP synchronization

Note: If you are using the Entrust IdentityGuard Virtual Appliance Server, only one database is available in the implementation. As the ratio of searchbases to databases is 1:1, you can synchronize users from only one LDAP searchbase.

When you have planned how many searchbases you require to implement LDAP synchronization, you should know how many databases you require to support the feature.

If there is only one searchbase, configure the default database, if it doesn't already exist. If you are working with a new installation, the default database should have been configured as part of the installation process.

For each additional LDAP searchbase, you need to set up another database. (Data for non-synced users can be stored in these databases, too.)

For information about supported databases and initial configuration, see the Entrust IdentityGuard Database Configuration Guide.

To add and configure databases required for LDAP synchronization

1.      If based on your planning you need to use multiple databases, add as many as required using the procedure Add a new database repository.

2.      When the databases exist and have a base configuration, additional configuration for synchronization is done as part of Configure synchronization with an LDAP directory.
