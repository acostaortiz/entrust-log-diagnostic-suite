IdentityGuard Server 13.0 Administration Guide

Configure the LDAP repository for Entrust IdentityGuard user enrollment

If you are configuring your LDAP repository in Entrust IdentityGuard for the first time, see To add a new LDAP repository.

If your LDAP repository is already configured in Entrust IdentityGuard, and you just need to enable user enrollment, as described in the following procedure.

To configure the LDAP repository for Entrust IdentityGuard user enrollment

1.      Log in to the Entrust IdentityGuard Properties Editor.

Windows

a.      Select the Windows button, and then select Entrust IdentityGuard > Properties Editor.

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

Linux

a.      Enter the URL of your Properties Editor web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardPropertiesEditor

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

2.      If you are configuring this feature for a new LDAP repository, complete the procedure Add a new LDAP repository, then return to this procedure.

3.      If you are configuring this feature for an LDAP repository that you have already added to Entrust IdentityGuard, on the Table of Contents, click LDAP Directory Server Settings.

4.      Set User Enrollment to True.

5.      (Optional) Add a filter expression in the User Enrollment Search Filter. See To create the filter for finding potential new users in the LDAP repository.

6.      If you are using a Microsoft Active Directory or Red Hat Directory Server, or another directory server that supports paging, set Paging Supported to True. If your LDAP directory server does not support paging or you are not sure, leave the default setting of False.

7.      Click Validate & Save.

8.      Restart the Entrust IdentityGuard Server service to have the changes take effect.
