IdentityGuard Server 13.0 Administration Guide

Prerequisites for LDAP directory synchronization

Your LDAP directory and Entrust IdentityGuard implementations must meet the following prerequisites to use this feature:

●       If you want to use LDAP directory synchronization as the first method of creating users for a new Entrust IdentityGuard installation, when the installation wizards asks you to choose whether user data should be stored in an LDAP repository or a database, choose database. After the system has been initialized, you can configure the LDAP server that will be used as the source of the users to be synchronized in your Entrust IdentityGuard database. Afterwards,.you can configure additional sources of users and they can be either LDAP repositories or databases..

●       The LDAP directory user repository to be synchronized with Entrust IdentityGuard must be one that is supported. This feature is supported for the following LDAP repositories:

–  Red Hat Directory Server (8.2 or newer). If using this directory server, the Entry USN (Update Sequence Numbers) plug-in must be configured. For more information, see Manage orphaned user accounts.

–  Microsoft Active Directory. This feature is not supported for Microsoft Active Directory Lightweight Directory Services (AD LDS) at this time.

–  While not officially supported, this feature should work with the other LDAP directory servers listed in the LDAP Directory Server Settings > LDAP Vendor property (in the Entrust IdentityGuard Properties Editor). Any LDAP directory server used with this feature must support paging so that an enrollment search can return more than a fixed number of results.

●       Entrust IdentityGuard user account information is stored in a supported database. For supported databases, see the Entrust IdentityGuard Server Release Notes.

●       The administrator who creates and administers the directory specified as the LDAP Sync Directory (LDAP Directory Server Settings in the Entrust IdentityGuard Properties Editor) has permissions to read the users in the configured searchbase.

●       The administrator who plans to enroll users in Entrust IdentityGuard has the userEnrollList permission.

●       All users in an LDAP searchbase configured for synchronization will be synchronized. Only users who are filtered out of the searchbase will not be enrolled or synchronized.

●       An LDAP directory user can be synchronized with only one Entrust IdentityGuard user account.
