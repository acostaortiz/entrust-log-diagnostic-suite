IdentityGuard Server 13.0 Administration Guide

Create users through LDAP synchronization with an Entrust IdentityGuard database

This feature was introduced for Microsoft Active Directory in Entrust IdentityGuard Server release 11.0 and extended to support Red Hat Directory Server (officially) and other LDAP directories in Entrust IdentityGuard Server release 12.0 Patch 67982.

You can create new Entrust IdentityGuard user accounts in an Entrust IdentityGuard database that is synchronized with your LDAP directory server. Because these new user accounts are synchronized, changes to the user full name and contact information data in the LDAP directory server are made to records in the Entrust IdentityGuard database almost immediately.

No schema changes or other modifications are required in your LDAP directory environment.

●       If LDAP external authentication is used, if users correctly enter their existing passwords but the passwords have expired, Entrust IdentityGuard can offer the option to force the users to change their passwords before proceeding. In this case, the new password value is stored in LDAP directory.

●       Password reset is an Self-Service feature that allows users who have forgotten their LDAP passwords to reset their passwords after successfully answering one or two forms of second-factor authentication. The new password value is stored in the LDAP directory.

Note: For LDAP directories supported with various releases of Entrust IdentityGuard, see Prerequisites for LDAP directory synchronization.

When LDAP synchronization is configured, you can use it to perform the following tasks related to Entrust IdentityGuard user accounts:

●       Create new user accounts in a database synchronized with an LDAP repository - (Automatic synchronization begins when the accounts are created.)

●       Manually synchronize Entrust IdentityGuard user accounts with an LDAP directory (On-demand synchronization)

●       Unsynchronize Entrust IdentityGuard user accounts

●       Manage orphaned user accounts
