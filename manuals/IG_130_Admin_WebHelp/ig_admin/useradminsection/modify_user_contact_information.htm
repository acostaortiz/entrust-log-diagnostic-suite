IdentityGuard Server 13.0 Administration Guide

Modify a user’s contact information

Modify a user’s contact information when that information changes. For example, the user may change email addresses or phone numbers.

To modify a user’s contact information

1.      Log in to the Administration interface (Log in and out of the Administration interface).

2.      In the main menu, click User Accounts.

The User Accounts page appears.

3.      Find a specific user in one of two ways:

●       use the Go To Account tab (see Search for information about a specific user)

●       use the Find Accounts tab (see Searching for user information)

The View Account page appears.

4.      Click Edit Account. The Edit Account page appears.

5.      Click Contact Information to expand the Contact Information pane.

Note: If your system is configured for contact information mapping from an LDAP user repository, you may see existing contact information. See Mapping contact info from an LDAP directory.

6.      In the Contact Information pane:

a.      To change the label of an entry, select a new label from the drop-down list

If you select Custom Label, the drop-down list changes to a text field. Enter a new label in this text field and press Enter. To cancel this action, press the ESC (Escape) key.

b.      To change the value of the entry (for example, to change the email address or phone number), select the old value and then enter the new value.

c.      To change the out-of-band delivery configuration, select a new delivery configuration from the Delivery Method drop-down list.

All out-of-band delivery configurations in the Delivery Method drop-down list are defined in the identityguard.properties file. See Configuring delivery mechanisms for one-time passwords . If there are no configurations in the identityguard.properties file, or you do not want to associate this entry with an out-of-band delivery configuration, select None.

d.      To make the entry the default entry, click the Default Delivery Method button.

7.      Click Save Changes to update the user account and return to the View Account page.
