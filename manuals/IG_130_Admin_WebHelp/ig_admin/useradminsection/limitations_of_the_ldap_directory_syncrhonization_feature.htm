Limitations of the LDAP directory synchronization feature

This feature has the following limitations in the current release:

●       LDAP directory groups are not mapped to Entrust IdentityGuard groups.

●       Only one LDAP directory searchbase is supported for each Entrust IdentityGuard database. If an additional searchbase is required, it must be configured and associated with a different Entrust IdentityGuard database.

●       If the LDAP directory  change notification mechanism is not running or if Entrust IdentityGuard is not running, changes to synchronized LDAP attributes are not made in the Entrust IdentityGuard database.

●       If an error occurs during a synchronization operation and the synchronization does not occur, Entrust IdentityGuard does not repeat the operation. In this case, user accounts are not synchronized until the next background synchronization operation when the user entry is updated (for example, the next time the user logs in). If an immediate synchronization is required, it can be done manually through the Administration interface or the Master user shell. For instructions, see  Manually synchronize Entrust IdentityGuard user accounts with an LDAP directory. Alternatively, you can perform an Entrust IdentityGuard bulk operation using the user set command for a specified file of users that require re-synchronization. (This could be done each night, for example.) Bulk operations can be done through the Administration interface or through the Master user shell. They can also be initiated using the Entrust IdentityGuard Administration API.
