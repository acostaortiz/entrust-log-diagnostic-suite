IdentityGuard Server 13.0 Administration Guide

Overview of LDAP synchronization configuration

This topic outlines the steps to plan synchronization of an LDAP directory with an Entrust IdentityGuard database user repository, configure the synchronization, and then enroll and synchronize user accounts. The remaining topics in this section describe how to complete the configuration and enrollment processes and to perform other actions related to account synchronization.

1.      Plan LDAP users to enroll and how you will configure Entrust IdentityGuard to find them.

The decisions you make about who in your organization will use Entrust IdentityGuard and where their information resides in your LDAP directory will affect your LDAP synchronization configuration in Entrust IdentityGuard. The procedures that follow in this section attempt to provide guidance for the various decisions you make in the planning phase.

See Plan LDAP users to enroll and methods to find them.

2.      Configure Entrust IdentityGuard settings. Several groups of settings need to be configured in the Entrust IdentityGuard Properties Editor:

●       General LDAP directory settings that apply to any LDAP directories used with Entrust IdentityGuard, whether for synchronization purposes or not

●       Synchronization-related properties

●       Contact information mapping properties to map the LDAP attributes for users' contact information to their counterparts in Entrust IdentityGuard.

●       Synchronization container mappings (if containers are used in your plan from step 1) to enable notifications of changes in the LDAP directory to be passed to Entrust IdentityGuard.

See Configure synchronization with an LDAP directory.

3.      Add and configure databases, if required. If your plan includes multiple searchbases, each searchbase requires a database. See Add and configure databases for LDAP synchronization.

4.      Enroll users. See Create new user accounts in a database synchronized with an LDAP repository.

5.      Perform ongoing tasks, as required. After users are enrolled and synchronization is running, administrators might need to perform any of the following tasks:

●       Manually synchronize Entrust IdentityGuard user accounts with an LDAP directory

●       Unsynchronize Entrust IdentityGuard user accounts

●       Manage orphaned user accounts
