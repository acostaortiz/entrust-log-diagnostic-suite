IdentityGuard Server 13.0 Administration Guide

Collect diagnostic data

If you need to consult Entrust Datacard Customer Support, you might be asked to send diagnostic data to help troubleshoot problems.

With release 12.0 Patch 200020 and newer, your Entrust IdentityGuard installation includes a command-line utility, igsupportutil (in .bat format for Windows and .sh format for Linux), that makes it easy to collect diagnostic data when requested by customer support.

The data that is collected includes files with extensions such as log, txt, info, properties, sample, xml, as well as the complete contents of the templates folder. (Private keys are not collected).

The utility offers two options: recent or all. If no option is specified, the default, all, is used. The all option collects all files. The recent option collects the same data except that for Entrust IdentityGuard log files, it includes only the two most recent ones (*.log and *.log1). The data is saved in a ZIP file (ig_support_data_<HOSTNAME>_<date and time>.zip) in the new directory IG_HOME/identityguard_support.

To collect diagnostic data requested by Customer Support

1.      In a command window, navigate into the location of the utility.

Windows:

<IG_HOME>\bin

Linux:

<IG_HOME>/bin

2.      Run the following command:

Windows:

igsupportutil.bat all|recent

Linux:

igsupportutil.sh all|recent

Where:

all – specifies collection of all data described above, including all Entrust IdentityGuard log files. This is the default option and it is used if no option is specified.

recent – specifies collection all data described above, but only the two most recent Entrust IdentityGuard log files (*.log and *.log1).

Messages display the progress of the operation. The utility creates a ZIP file with a name in the following format: ig_support_data_<HOSTNAME>_<date and time>.zip.

3.      Locate the ZIP file in the IG_HOME/identityguard_support directory and send it to Entrust Datacard Customer Support.
