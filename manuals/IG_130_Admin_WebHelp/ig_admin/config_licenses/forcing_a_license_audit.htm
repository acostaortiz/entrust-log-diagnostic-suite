Force a license audit

As you add users to your Entrust IdentityGuard database, you must keep track of the number of licenses of each type that you have used so that you can purchase more licenses before you run out. Although the licenses are audited at a specified interval, you may want to manually perform audits at a time that is convenient to you.

Use the following Master user shell command to find out if your installation is coming close to its license limit or license expiry date.

system license check <type> [-count <number>] [-time <time>]

Where:

<type> is the type of license for which you want to run the audit. It can be any of the following license types:

●       USER

●       SOFTTOKEN

●       SOFTTOKENTRANSACTIONVERIFICATION

●       SMARTCREDENTIAL

●       MOBILESMARTCREDENTIAL

●       SMARTCREDENTIALIDENTITYASSURED

●       BIOMETRIC

-<count> is either a number or a percentage. If specified, this number of licenses, when added to the current count of used licenses, exceeds the user license limit, a warning audit is written.

-<time> If the license is within <time> days of expiry, a warning audit is written

Examples:

system license check USER -count 200

This command counts the current number of users in the system, and adds 200. If the resulting number exceeds the current user licenses available, a warning audit is written.

system license check USER -count 10%

This command counts the current number of users in the system, and adds 10% of the total licenses. For instance, if your license allows for 1000 users, and your current user count is 950, the command would result in a warning audit being written.

950 (user count) + 100 (10% of 1000) = 1050

system license checkUSER-time 60

This command means you are warned if you are within 60 days of license expiry. Specifically, this command adds 60 days to the current date, and checks the sum against the license expiry date. If this sum is equal to or greater than the expiry date, a warning audit is written.

For more information about the system license check command and a complete list of its attributes, see the Entrust IdentityGuard Master User Shell Command Reference.
