IdentityGuard Server 13.0 Administration Guide

Mobile Smart Credentials licenses

Entrust IdentityGuard keeps track of the number of users licensed to use software (mobile) smart credentials. Each user with this kind of license can have more than one mobile smart credential. The tracking is performed as follows:

●       When a mobile smart credential is encoded on a mobile device, the Mobile Smart Credentials license count increases by one.

●       If a user is assigned another mobile smart credential, there is no change to the license count. With a single Mobile Smart Credentials license, a user can have as many mobile smart credentials as permitted by policy.

●       When all of a user's mobile smart credentials are deleted from Entrust IdentityGuard, the license count decreases by one.

●       When a user who had mobile smart credentials is deleted from Entrust IdentityGuard, the license count is decreased one.

●       Canceling all mobile smart credentials for a user does not decrease the license count. To decrease the count, all of the user's mobile smart credentials must be deleted, all of the user's mobile smart credentials must be unassigned, or the user who is licensed to use mobile smart credentials must be deleted from the system.

●       Unassigning a mobile smart credential does decrease the Mobile Smart Credentials license count if no other user smart credential associated with the user is a mobile smart credential..
