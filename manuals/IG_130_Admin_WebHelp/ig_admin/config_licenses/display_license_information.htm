IdentityGuard Server 13.0 Administration Guide

Display license information

An administrator must have the licenseGet and licenseSet permissions to view  license information.

Use the Administration interface to view license information and set the installation key and the activation key. Use the Properties Editor to set license auditing properties.

Use the following procedure to check whether your license is valid.

To display license information

1.      Start the Administration interface. (See Log in and out of the Administration interface.)

2.      In the Administration interface, select System.

3.      Click the License Information tab.

The current license information appears.

Note: An incorrect user count might be displayed if you remove users through your repository’s user interface instead of through the Entrust IdentityGuard user interface. This error is temporary and corrects itself after Entrust IdentityGuard performs its daily synchronization, which updates the license counts on the Entrust IdentityGuard server to mirror the actual license counts in the repository.
