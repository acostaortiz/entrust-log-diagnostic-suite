IdentityGuard Server 13.0 Administration Guide

Change the PIN on a Pocket Token

You can change your PIN after the Pocket Token displays a dynamic password.

To change the PIN

1.      When the Pocket Token is displaying the dynamic password, press the MENU button.

2.      If necessary, press the MENU button repeatedly until the CHANGE PIN menu option is displayed.

3.      Press the ON button to select the menu option.

The NEW PIN prompt is displayed.

4.      Enter a new PIN. (The Pocket Token displays an X for each number you enter. If you enter a wrong number, use the MENU button to delete it.)

You can cancel the PIN change operation by repeatedly pressing the MENU button until the Pocket Token displays the menu.

5.      After you have entered the new PIN, press the ON button.

Note: The ON button is not functional until the new PIN has the minimum number of required digits (configured during initialization). If the Pocket Token is configured for weak PIN control and you enter a weak PIN, the token displays ERROR, and prompts you to enter a new PIN.

When the PIN is acceptable, the Pocket Token displays a CONFIRM message.

6.      Enter the new PIN again, and then press the ON button. (The Pocket Token displays an X for each number you enter. If you enter a wrong number, use the MENU key to delete it.)

You can cancel the PIN change operation by repeatedly pressing the MENU button until the Pocket Token displays the menu.

If the entries for the new PIN and confirmation of the new PIN do not match, the Pocket Token displays an ERROR message, and shuts off.

If the PIN change is successful, the Pocket Token displays the COMPLETE message, and then automatically shuts off.
