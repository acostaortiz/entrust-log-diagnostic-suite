IdentityGuard Server 13.0 Administration Guide

Assign tokens to users

If you use Entrust IdentityGuard Self-Service Module, users can perform this action themselves.

Assign an unassigned token to an existing user in your system when the user needs to begin authenticating with a token. When a token is assigned, it is automatically removed from the unassigned token list.

Attention: The unassigned token should be in the same group as the user. If it is not, you can still assign the token if you have set the Move Tokens To User's Group During Assignment policy to True. The default policy setting is False.
When assigning tokens to users in a different group, the administrator must have permissions to modify both the user group and the token group.

This section describes the various ways in which an administrator can assign hardware tokens to users.

To complete the procedures in this section, administrators must have the correct role permissions. See Token permissions.
