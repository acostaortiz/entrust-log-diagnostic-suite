IdentityGuard Server 13.0 Administration Guide

Delete a token

You can delete an assigned token after it is canceled. When you delete a token, it is removed from the Entrust IdentityGuard server.

When you delete a token, the device can no longer be used to authenticate to Entrust IdentityGuard.

If you accidentally delete a token, you can load the token back into Entrust IdentityGuard by loading the token data file again. See Load the token data file.

You can either find a user and delete a token, or find a token and delete it.

Topics include:

●       To delete a user’s token

●       To delete assigned user tokens in bulk

To delete a user’s token

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      Locate the token to delete in one of two ways:

●       Find a user’s token (see To find a user’s token information )

●       Find an assigned token (see To search for assigned token information )

3.      Click Delete Token.

4.      When prompted, click OK to confirm.

To delete assigned user tokens in bulk

5.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      Click Bulk Operations from the menu bar.

3.      From the Bulk Operation page, click Browse to add the data file. For more information about data files for bulk operations, see Perform bulk operations in the Administration interface.

4.      From the Operation to Perform drop-down list, select Delete user tokens located under Tokens.

5.      From the Halt Processing drop-down list, select the number of errors to allow before processing stops due to too many errors: (See To delete unassigned tokens in bulk for an explanation of Halt Processing options.)

For more information about bulk file options, see Perform bulk operations in the Administration interface.

6.      Click Perform Bulk Operation.

The Bulk Operation in Progress page appears. The size of your bulk operation directly affects the time the operation takes to process. This page indicates the initial status of the operation.

7.      Click Update Results to view the status of your bulk operation. (The Results page is also updated automatically every 10 seconds.)

8.      Click Done to return to the Bulk Operation page.
