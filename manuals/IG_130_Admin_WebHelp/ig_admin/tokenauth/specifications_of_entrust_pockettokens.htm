Specifications of Entrust PocketTokens

 

Weight (including batteries)

28g

Dimensions (mm)

Length = 68

Width = 48

Depth = 8

LCD

One row of up to 10 characters (5x7 Dot Matrix)

Battery

Type CR2430 or CR2032 3V (up to 6 years)

Operating environment

·      Storage temperature range: -20°C to +80°C

·      Operating temperature range: +5°C to +50°C

·      Maximum relative humidity: +80% (non-condensing)

Security features

·      Secure PIN management

·      Keyboard scrambling

Algorithm

Triple DES

Uses the DES (Data Encryption Standard) algorithm three times. Like DES, it operates on 64 bit data blocks. Some forms of triple DES use two 56 bit keys and some use three. The DES “modes of operation” may also be used with triple DES. Entrust uses EDE mode with two 56 bit keys.

Standards compliance

The Entrust Pocket Token complies with the following standards:

●       ANSI X3.92 DES (Data Encryption Standard) algorithm standard

●       ANSI X9.9 standard challenge displayed in ASCII, MAC format response

●       ANSI X9.17 standard for key management

●       ANSI X9.24 standard DES key derivation

●       ANSI X9.26 standard for sign-on

●       ISO 7064 – mod 11, 10 for the check digit process
