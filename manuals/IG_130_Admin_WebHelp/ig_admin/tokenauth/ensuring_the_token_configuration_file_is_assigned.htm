IdentityGuard Server 13.0 Administration Guide

Ensure the token configuration file is assigned

Before configuring any drift-related settings, you must ensure that the token configuration file is assigned to the token vendor.

To ensure that the token configuration file is assigned

1.      Start the Entrust IdentityGuard Properties Editor. (See Log in or out of the Properties Editor.)

2.      From the Table of Contents, select Token Vendor Configuration.

The token vendor properties appear.

3.      Under the Configuration Instances drop-down list, select the applicable token vendor, such as entrust.

4.      Under Token Vendor Configuration File, enter the path and name of the token configuration file, if it is not yet entered.

5.      Click Validate & Save.

6.      Restart the Entrust IdentityGuard Server service.
