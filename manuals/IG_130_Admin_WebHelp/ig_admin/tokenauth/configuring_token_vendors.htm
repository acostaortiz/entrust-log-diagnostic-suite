IdentityGuard Server 13.0 Administration Guide

Configure a token vendor

During installation of Entrust IdentityGuard, you are asked what token vendor you plan to use for authentication. Based on your choice, the installer sets several properties. For a complete list of token properties, see Token Vendor Configuration.

To change those properties or to add additional token vendors, use the Properties Editor.

To modify token vendor properties

1.      Log in to the Entrust IdentityGuard Properties Editor.

Windows

a.      Select the Windows button, and then select Entrust IdentityGuard > Properties Editor.

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

Linux

a.      Enter the URL of your Properties Editor web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardPropertiesEditor

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

2.      On the Table of Contents, click Token Vendor Configuration. The token vendor properties appear with default settings based on choices you made during installation.

3.      Under the Configuration Instances drop-down list, select an existing configuration, such as entrust, to change its properties.

The only properties you should change or set for an existing configuration are:

●       Change Token Vendor Display name to change the name that appears in the Administration interface.

●       Set Default Token Vendor to False if you no longer want this token vendor to be the assumed default token.

●       Optional. Enter the path and name of a token configuration file, if needed. (See Configure the drift window and fix token drift.)

4.      Click Validate & Save.

To configure a new token vendor

5.      Log in to the Entrust IdentityGuard Properties Editor.

Windows

a.      Select the Windows button, and then select Entrust IdentityGuard > Properties Editor.

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

Linux

a.      Enter the URL of your Properties Editor web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardPropertiesEditor

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

2.      On the Table of Contents, click Token Vendor Configuration. The token vendor properties appear with default settings based on choices you made during installation.

3.      Enter a token configuration name in the empty field and click Add to configure a new token vendor.

4.      Under Token Vendor Implementation Class, pick one of the predefined classes (Entrust Token, Entrust Soft Token, Entrust DisplayCard, WatchdataQRO, OATH token ), or select Custom.

If you select Custom, an empty field appears. Enter the name of the Java class that defines your custom token.

5.      In Token Vendor Display Name, enter a name for the token for display in the Administration interface.

6.      Set Default Token Vendor to True if you want this token vendor to be the assumed default token.

7.      Enter the path and name of a token configuration file, if needed. (See Ensure the token configuration file is assigned.)

8.      Click Validate & Save.

9.      Log out of the Properties Editor and restart the Entrust IdentityGuard Server service after you make all property changes.
