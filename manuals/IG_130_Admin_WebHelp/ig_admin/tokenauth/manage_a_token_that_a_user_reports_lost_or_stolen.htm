IdentityGuard Server 13.0 Administration Guide

Manage a hardware token that a user reports lost or stolen

It is not uncommon for users to lose or misplace their hardware tokens, and your organizational policies should encourage them to report a loss as soon as they notice it. If your organization uses Entrust IdentityGuard Self-Service Module, users can go to your self-service website to perform these actions. If you do not use the Self-Service model, an Entrust IdentityGuard administrator can deactivate a lost or stolen token and assign a new one.

To find user of the lost or stolen token

1.      Log in to the Administration interface.

2.      On the main menu, click User Accounts.

3.      Enter the User Name or Alias, and select the user’s Group, if the user name or Alias is not unique.

4.      Click Go to Account.

The View Account page for the user appears.

5.      Continue with one of the following procedures to hold or cancel the token.

To put the lost token on hold

If the user believes he will be able to locate the token by tomorrow (the user forgot it at home, for instance), complete this procedure.

1.      In the View Account page for the user, under Authentication Types, select Tokens.

2.      Click Edit Token.

3.      Select the token in the Current state (if the user has not yet used it, it is in the Pending state) and click Edit Token.

4.      In the Edit a user’s token screen, select Hold from the State drop-down list.

5.      Click Save Changes.

If the user finds the token within, for example, 24 hours, then repeat this procedure and change the state of the token back to Current.

If the user has not found the token within the time frame set by your organization, follow the next procedure.

To cancel the lost or stolen token

If the user believes the token is lost or stolen and cannot be recovered in a short period of time, complete this procedure.

1.      Under Authentication Types on the View Account page, click Tokens.

2.      Select the serial number of the token you want to cancel.

3.      Click Edit Token.

The Edit Token page appears.

4.      In the State drop-down list, select Canceled.

5.      Click Save Changes. 

6.      When prompted, click OK to confirm the cancellation.

The token is now canceled. It is still accessible through the user’s account page as well as through a token search until it is deleted.

7.      Take note of the user’s Group before proceeding to the next step.

8.      Continue with the next procedure to assign a new token.

To assign a new token

1.      See Assign a token to a user account.

2.      (Optional) During the procedure, check the box labeled Use the following comments instead of those assigned to the token. Type a note about the circumstances of the replacement token in the Comments box.

3.      Continue with the next procedure to send the token to the user.

To send a new token to the user

1.      Get the token with the serial number you just assigned out of inventory.

2.      Package and send the token using security precautions necessary based on

●       the location of the user: If the user is sitting on the same floor in the same building, you could call the user to pick it up. If the user is overseas, you must to package the token for shipment.

●       your method of getting the token to the user. If you are sending the token within your building or within your city, you may choose to put it in an interoffice mailer. If you are sending the token overseas, you may need to package it for shipment with a courier.
