Features of Entrust Pocket Tokens

Entrust Pocket Tokens have the following features:

Display — The Entrust Pocket Token has an LCD display that displays ten alphanumeric characters.

Keypad — The keypad has ten numeric keys, a MENU button that functions as a menu and backspace key, and an ON button that turns the Entrust Pocket Token on and validates entries.

Interface — The Entrust Pocket Token has a serial communication interface for bi-directional data exchange.

Power — The Entrust Pocket Token is a disposable device. Replace the token when the battery runs out. Low battery power is indicated by a fading display.
