IdentityGuard Server 13.0 Administration Guide

Store unassigned token information

Entrust IdentityGuard requires that you load the token information into a repository before you assign hardware tokens to users (as described in Load the token data file). Before you load the token data files, make sure the token repository is set up correctly for your system. Entrust IdentityGuard provides a default configuration during installation.

Directory repository

●       If you select an LDAP directory as your default user repository, the installer automatically configures a file-based repository for your unassigned tokens.

In many cases, the file-based repository is all you need, but if your organization plans to deploy 100,000 tokens or more, it is recommended that you configure a database for storing the unassigned token information.

Note: Do not use a file-based repository on a replica system. There can be only one copy of a file-based repository.

●       After you select a directory for your user repository, and if you want to use a database repository for your token information, you must manually configure the database after installation. For instructions, see Configuring token and grid card repositories.

Database repository

●       If you select a database for your user repository, the installer automatically uses the database for unassigned tokens. For instructions on changing database settings, see Configuring a database.

●       Through post-installation configuration, you can set up multiple directories and databases for your user repository, but that does not affect the default token repository created during installation.
