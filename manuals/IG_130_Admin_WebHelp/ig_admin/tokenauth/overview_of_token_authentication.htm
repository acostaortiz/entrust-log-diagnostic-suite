IdentityGuard Server 13.0 Administration Guide

Overview of token authentication

Hardware tokens provide another method to authenticate to Entrust IdentityGuard. After Entrust IdentityGuard and users are set up to accept tokens, users can enter a dynamic password (a number generated by a token device) in response to an Entrust IdentityGuard challenge.

The numbers generated by the tokens are uniquely determined by the token seed information loaded into each token.

Your application is not limited to one type of token or one token supplier.
