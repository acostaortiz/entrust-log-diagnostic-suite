IdentityGuard Server 13.0 Administration Guide

Functionality of Entrust Pocket Tokens

The Entrust Pocket Token is a single slot token that can perform user authentication, data certification, and server authentication. The following configurable parameters apply to these three services. After one of these parameters is set, it is applicable for all three services.

●       Encryption algorithm (triple DES) — The triple DES algorithm is the secret key symmetric algorithm - triple DES in EDE mode (cf. ANSI X9.17 standards). It requires the use of 128 byte keys (also called double length keys). In this document, any reference to a DES operation means triple DES, depending on how the Pocket Token is configured.

●       Hexadecimal or decimal password and certificate display (the user always enters values in decimal)

The following configurable synchronous mode parameters apply only to the user authentication service and the data certification service.

●       Key derivation — This parameter determines whether or not a new secret 3DES key is derived after each authentication.

●       Counter increment — This parameter determines whether or not the authentication event counter is incremented after each authentication.

For user authentication, you can configure an Entrust Pocket Token to use the asynchronous (challenge/response), synchronous (internal challenge), or dual authentication mode (allows the user to choose either asynchronous or synchronous based on system administrator recommendations).

After an Entrust Pocket Token has generated a dynamic password, the user can access the menu options. The available options allow the user to:

●       change the PIN

●       view the Pocket Token internal clock value

●       view the synchronous authentication event counter

●       view the token serial number

●       manually re-initialize the authentication 3DES and optionally, its PIN policy and authentication mode policy

For more information, see Menu options of Entrust Pocket Tokens.

The functionality of the Entrust Pocket Token is protected by a PIN (optional) and offers a choice of protection mechanisms in the case of wrong PIN entries (to protect the Entrust Pocket Token if it is stolen). See Using PINs with Entrust Pocket Tokens and PIN protection mechanisms.

To conserve its battery, the Entrust Pocket Token automatically shuts off after a certain length of time of inactivity (no buttons are pressed). The user can manually shut an Entrust Pocket Token off by pressing the ON button after generating a dynamic password.
