IdentityGuard Server 13.0 Administration Guide

Enforce unique user names across groups

By default, Entrust IdentityGuard allows you to create users with the same user name, as long as they are in different groups. For example, Entrust IdentityGuard lets you create asmith in groupA even though an asmith might already exist in groupb. By contrast, Entrust IdentityGuard does not let you create two asmith’s in the same group due to potential lookup conflicts.

This behavior—where two asmith’s can co-exist in the same system under different groups—might not be desirable, because it forces users to specify their group when they log in. Having to specify a group may be confusing to users because they might not know what their group is. To fix this problem, Entrust IdentityGuard provides a setting that lets you enforce unique user names across all groups, thus preventing users from having to specify a group during login.

When unique user names are enforced, Entrust IdentityGuard will display a message indicating that the user name is already taken and that you must choose a different user name.

Other reasons to enforce unique user names (this list is not exhaustive):

●       If you are using the Self-Service Module, and have enabled the feature that gives end-users the ability to create their own user entries in Entrust IdentityGuard, then enforcing unique user names prevents them from having to decide which group they want to be a part of when creating their user ID.

●       If you are using the Federation Module, and have enabled OpenID claimed identifiers, then enforcing unique user names prevents them from having to include their group in the claimed identifier. For example, Alice Smith can use https://www.example.com/user/asmith as opposed to the longer https://www.example.com/user/group1/asmith.

Note: If you only have one Entrust IdentityGuard group, there is no need to enforce unique user names because user names are always unique within the same group.

To enforce unique user names across groups

1.      Open the Master user shell. For details, see the Entrust IdentityGuard Master User Shell Command Reference.

2.      Enter the following command:

system set –userNamesGloballyUnique true

This command only affects user names created after this command is run.
