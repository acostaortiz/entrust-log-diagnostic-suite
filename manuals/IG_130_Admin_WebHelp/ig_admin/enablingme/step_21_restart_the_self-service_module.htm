IdentityGuard Server 13.0 Administration Guide

Step 21: Restart the Self-Service Module

Restart the Self-Service Module to have your changes take effect.

To restart the Self-Service Module on Windows

1.      On the Self-Service Module computer, click Start > Administrative Tools > Services.

2.      From the list of services, select Entrust IdentityGuard Self-Service Module.

3.      Click Restart.

To restart the Self-Service Module on Linux

1.      In a command shell enter:

igselfservice.sh restart
