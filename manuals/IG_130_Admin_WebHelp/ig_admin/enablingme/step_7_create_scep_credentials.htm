IdentityGuard Server 13.0 Administration Guide

Step 7: Create SCEP credentials

You must generate SCEP credentials. The credentials consist of a private key and certificate. Entrust IdentityGuard uses these credentials to log in to your CA to process enrollment requests. The credentials are not used by human administrators.

On a Security Manager CA, the credentials must be in an EPF file.

On a Microsoft CA, the credentials must be in a P12 file.

Complete the procedure applicable to your type of CA:

●       Creating a SCEP EPF file (Security Manager CA)

●       Creating a SCEP P12 file (Microsoft CA)
