Hardware Security Module (HSM) audit messages

If the Entrust IdentityGuard master keys are stored on a hardware security module (HSM), these messages provide information about the HSM.

 

Audit name

Log level

Default SNMP trap?

Event description

HSM Connection Error

(AUD132)

ERROR

Yes

Entrust IdentityGuard could not connect to the hardware security module.

HSM Password Updated

(AUD133)

INFO

Yes

The password used to log in to to the hardware security module was updated.
