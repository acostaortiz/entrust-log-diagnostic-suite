IdentityGuard Server 13.0 Administration Guide

Load the Entrust IdentityGuard MIB into your SNMP manager

The Entrust IdentityGuard MIB is called ENTRUST-IG-MIB, and is installed with Entrust IdentityGuard. It is available in the <$IG_HOME>\etc\snmp directory. Also included in that directory is the main Entrust MIB, called ENTRUST-MIB. Both are required for the SNMP trap functionality to work.
