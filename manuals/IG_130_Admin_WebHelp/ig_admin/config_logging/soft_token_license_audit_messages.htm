IdentityGuard Server 13.0 Administration Guide

Soft token license audit messages

These messages provide information about the Entrust IdentityGuard soft token license.

 

Audit name

Log level

Default SNMP trap?

Event description

Token License Updated

(AUD5044)

INFO

Yes

Token license updated: {0}

Where {0} is the expiry date and number of soft tokens allowed.

Token License Reset

(AUD5045)

INFO

Yes

Number of licensed tokens reset from {0} to {1}.

Where:

·      {0} is the number of tokens in the Entrust IdentityGuard license count.

·      {1} is the number of licensed tokens found in the repository.

Token License Near Limit

(AUD5046)

WARN

Yes

Number of licensed tokens {0} is nearing license limit {1}.

Where:

·      {0} is the current number of licensed tokens.

·      {1} is the license limit.

Token License At Limit

(AUD5047)

WARN

Yes

Number of licensed tokens has reached the license limit {0}.

Where {0} is the current number of licensed tokens.

Token License Over Limit

(AUD5048)

ERROR

Yes

Number of licensed tokens {0} is over license limit {1}.

Where:

·      {0} is the current number of licensed tokens.

·      {1} is the license limit.

Token License Near Expiry

(AUD5049)

WARN

Yes

Token license is near expiry date {0}.

Where {0} is the token license expiry date.

Token License Over Expiry

(AUD5057)

ERROR

Yes

Token license is past expiry date {0}.

Where {0} is the token license expiry date.

Token License Deleted

(AUD5058)

INFO

 

Token license was deleted.

Partition Token Count Reset

(AUD5059)

INFO

Yes

Number of licensed tokens in partition {0} reset from {1} to {2}.

Where:

·      {0} is the name of the partition.

·      {1} is the number of licensed tokens in the partition.

·      {2} is the number of licensed tokens assigned to the partition that were found in the repository.

Partition Token Count MisMatch

(AUD5060)

WARN

Yes

Number of licensed tokens in partition {0} ({1}) does not match the count from the repository ({2}).

Where:

·      {0} is the name of the partition.

·      {1} is the number of licensed tokens in the partition.

·      {2} is the number of licensed tokens assigned to the partition that were found in the repository.
