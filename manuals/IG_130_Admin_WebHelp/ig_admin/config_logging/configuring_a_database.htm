Configuring a database

If you choose a database as your user repository during Entrust IdentityGuard installation, it is set as your default database repository. You can modify the default configuration in the Properties Editor or configure additional databases. For example, if you specified an LDAP directory repository during Entrust IdentityGuard installation and want to add a database, too, you can create a new configuration in the Properties Editor.

In the Properties Editor, there are two sections of properties that apply when configuring databases, JDBC Database Settings and Repository Settings. The first database you configure in the JDBC Database Settings pane becomes the default database. Only the default database applies to the database server specified on the Repository Settings pane.
