IdentityGuard Server 13.0 Administration Guide

Set general logging properties

Use the Properties Editor to modify the default Entrust IdentityGuard logging properties. For example, if you chose to log to Syslog when you installed Entrust IdentityGuard, you can reconfigure to log to a file, or, if you chose to log to a file, you can reconfigure to log to Syslog instead. You can change the location logs are sent to, the log file size, and the number of old log files to keep.

You can change the defaults that Entrust IdentityGuard uses to define loggers (the type and level of messages to be logged), to set the appenders (where the logs are to be written), and to configure the layouts (the format used for writing the logs).

The message level of each of the three loggers can be set to one of ALL, DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. The message level sets the lowest level of message to log; for example, WARN provides messages of WARN, ERROR and FATAL status. Select OFF to stop all messages from the applicable logger.

For descriptions of log file properties, see:

●       General Logging Configuration

●       Audit Logging Appenders

●       System Logging Appenders

Note: Changes to log settings take effect in the time period set on the Logging Configuration Refresh Interval property. You do not need to restart Entrust IdentityGuard when you change logging properties.

To change general logging properties

1.      Start the Entrust IdentityGuard Properties Editor. (See Log in or out of the Properties Editor.)

2.      On the Table of Contents, click General Logging Configuration.

3.      Edit the property settings as required. Click + to see the property descriptions.

Logging Configuration Refresh Interval

identityguard.refreshinterval

Defines how often in seconds the configuration is checked for changes to the log settings.

Default: 10

Logging Stack Trace Size

identityguard.log.maxstacksize

Defines the number of stack frames that are logged for errors. A setting of 0means that no stack trace is logged.

Default: 0

Base Logger Configuration

log4j.logger.IG

Defines the logging level of the Base Logger, and the location of the messages logged by the Base Logger.

The message level can be one of ALL, DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. This sets the lowest level of message to show; for example, WARN provides messages of WARN, ERROR and FATAL status.

Select OFF to stop all messages.

The destination can be SYSTEM_SYSLOG, or SYSTEM_FILELOG, or both if you edit the properties file manually.

Default: WARN, SYSTEM_FILELOG

Note: If this property is set to DEBUG, log4j.logger.additivity.IG must be set to False.

Base Logger Messages also go to Root Logger

log4j.logger.additivity.IG

If this property is True, base logger messages (those that are not included in the audit logs and system logs) are also written to the root logger.

When the base logger is set to DEBUG, leave this property at False, the default.

Default: False

Audit Logger Configuration

log4j.logger.IG.AUDIT

Defines the logging level of the audit logger, and the destination of any messages logged by the audit logger.

This property takes two values as listed in the paired drop-down lists: one for the message level and one for destination of logging messages.

The message level can be one of ALL,DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. This sets the lowest level of message to show; for example, WARN provides messages of WARN, ERROR and FATAL status.

Select OFF to stop all messages.

The destination is either AUDIT_SYSLOG or AUDIT_FILELOG.

Default: ALL, AUDIT_FILELOG

Note: Changing this configuration may disable audits. The logging message level should never need to be changed from its default of ALL, and the destination is either AUDIT_SYSLOG or AUDIT_FILELOG.

Audit logger messages also go to Base logger

log4j.additivity.IG.AUDIT

Defines whether or not Entrust IdentityGuard audits should also be added to the base logger.

Leave this value set to the default, False.

Default: False

System Logger Configuration

lo4j.logger.IG.SYSTEM

Defines the logging level of the system logger, and the destination of any messages logged by the system logger.

This property takes two values as listed in the paired drop-down lists: one for the message level and one for destination of logging messages.

The message level can be one of ALL,DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. This sets the lowest level of message to show; for example, WARN provides messages of WARN, ERROR and FATAL status.

Select OFF to stop all messages.

The destination is either AUDIT_SYSLOG or AUDIT_FILELOG. This default is set during configuration. (The destination can be SYSTEM_SYSLOG and SYSTEM_FILELOG if you edit the properties file manually.)

Default: WARN

System logger messages also go to Base logger

log4j.additivity.IG.SYSTEM

Defines whether or not Entrust IdentityGuard system logs should also be added to the base logger.

This value should remain set to the default, False.

Default: False

4.      Click Validate & Save.
