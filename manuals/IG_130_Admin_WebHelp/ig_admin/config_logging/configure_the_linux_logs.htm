IdentityGuard Server 13.0 Administration Guide

Configure the Linux logs

Configure Syslog to enable remote logging of Entrust IdentityGuard messages on Linux. You can adjust the related Entrust IdentityGuard log settings using the Properties Editor.

To log Entrust IdentityGuard messages remotely on Linux

1.      As root, edit the file /etc/sysconfig/syslog. Change the entry SYSLOGD_OPTIONS to SYSLOGD_OPTIONS="-m 0 -r".

2.      As root, restart Syslog by running

service syslog restart

To configure Syslog on Linux

1.      As root, edit /etc/syslog.conf and make changes similar to the following:

old line:

Attention: The whitespace before /var/adm/messages must be a tab and not a space.

# *.info;mail.none;authpriv.none;cron.none /var/log/messages

new line:

*.info;local1.*;local2.*;local3.*;mail.none;authpriv.none;cron.none /var/log/messages

2.      As root, restart Syslog by running:

service syslog restart
