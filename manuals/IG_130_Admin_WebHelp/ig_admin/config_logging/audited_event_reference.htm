IdentityGuard Server 13.0 Administration Guide

Audited event reference

Audit records detail Entrust IdentityGuard operations and events. Audits are written to the applicable audit file (see Logging overview).

The following tables describe the events audited by Entrust IdentityGuard. Numbers inside braces, for example, {0} and {1}, are placeholders for your system values; that is, names of users or administrators, numbers of cards or tokens, and so forth.
