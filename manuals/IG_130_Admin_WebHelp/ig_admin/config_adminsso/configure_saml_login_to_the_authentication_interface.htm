IdentityGuard Server 13.0 Administration Guide

Configure SAML login to the Administration interface

This section describes how to configure SAML-based SSO authentication to the Administration interface.

After you complete the procedures in this section, administrators will be able to access the Administration interface without needing to resubmit their Entrust IdentityGuard credentials, if they have already provided them to another SP.

Follow these steps to configure SAML authentication to the Administration interface:

●       Prerequisites

●       Generate a SAML certificate to be used by Entrust IdentityGuard Server

●       Import the Federation Module Web certificate

●       Import all CA certificates

●       Enable the SAML policy through the Administration interface

●       Create a delegation administrator

●       Configure properties for SAML login to the Administration interface

●       Restart the Server and verify that the SAML link appears

●       Configure authentication on the Federation Module

●       Copy the Administration interface metadata file to Federation Module

●       Import the metadata and keys into the Federation Module

●       Enable auto-reloading of metadata

●       Test SAML authentication to the Administration interface
