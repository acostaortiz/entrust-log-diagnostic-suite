IdentityGuard Server 13.0 Administration Guide

Configuring smart credential authentication to the Administration interface

This section describes how to configure and use smart credential authentication so administrative users can bypass second-factor authentication to the Entrust IdentityGuard Administration interface.

Smart credential authentication can be configured to work with Entrust IdentityGuard smart credentials or smart credentials from other vendors.

Note: This feature is supported on Microsoft Internet Explorer and Google Chrome browsers only.

This section contains the following topics:

●       How smart credential authentication works with the Administration interface

●       How smart credential logout (and re-login) works

●       Configure smart credential login to the Administration interface
