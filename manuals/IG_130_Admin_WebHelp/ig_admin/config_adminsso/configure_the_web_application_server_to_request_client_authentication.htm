IdentityGuard Server 13.0 Administration Guide

Configure the Web application server to request client authentication

To configure the Web application server to request client authentication

1.      Locate the server.xml file and open it for editing. By default, this file is located in the following directory:

<IG_HOME>\apache-tomcat-<version>\conf

2.      In the "Service name ="adminservice" section, copy the section that begins with <Connector port="8444".

<Connector port="8444"

disableUploadTimeout="true"

URIEncoding="UTF-8"

acceptCount="100"

enableLookups="false"

minSpareThreads="25"

maxThreads="150"

ciphers="TLS_DHE_RSA_WITH_AES_128_CBC_SHA256,TLS_DHE_RSA_WITH...

useServerCipherSuitesOrder="true"

keyAlias="tomcat"

keystorePass="entrust"

keystoreFile="${identityguard.home}/etc/keystore"

SSLEnabled="true"

sslEnabledProtocols="TLSv1.2+SSLv2Hello"

sslProtocol="TLS"

clientAuth="false"

secure="true"

scheme="https"

3.      Paste the copied section below the original section in the file, and then change the port number to 8450, and change clientAuth="false" to clientAuth="true", as shown in bold in the following example.

<Connector port="8450"

disableUploadTimeout="true"

URIEncoding="UTF-8"

acceptCount="100"

enableLookups="false"

minSpareThreads="25"

maxThreads="150"

ciphers="TLS_DHE_RSA_WITH_AES_128_CBC_SHA256,TLS_DHE_RSA_WITH...

useServerCipherSuitesOrder="true"

keyAlias="tomcat"

keystorePass="entrust"

keystoreFile="${identityguard.home}/etc/keystore"

SSLEnabled="true"

sslEnabledProtocols="TLSv1.2+SSLv2Hello"

sslProtocol="TLS"

clientAuth="true"

secure="true"

scheme="https"

4.      Save the file.

5.      Restart the Entrust IdentityGuard Server services for the changes to take effect.
