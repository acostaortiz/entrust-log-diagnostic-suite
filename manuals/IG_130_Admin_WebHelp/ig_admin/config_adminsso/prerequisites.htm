IdentityGuard Server 13.0 Administration Guide

Prerequisites for configuring SAML login to Administration

Before you can configure SAML authentication to the Entrust IdentityGuard Administration interface, your implementation must meet the following prerequisites:

1.      On the Entrust IdentityGuard Server, you have configured the authentication methods you want to use for SAML. All Entrust IdentityGuard authentication methods are supported with SAML.

2.      You have a working installation of the Entrust IdentityGuard Federation Module. with patch 176180 or later applied. Patches are available from:

https://trustedcare.entrustdatacard.com

You need a user name and password to access the site.

3.      The Federation Module is configured as a SAML Identity Provider (IDP) as described in the Entrust IdentityGuard Federation Module Installation and Configuration Guide.

4.      You have copied all the IDP’s files to the SP (which is the Entrust IdentityGuard Server), in a folder called c:\IDPdata or a similarly-named folder. The files you must copy are:

●       The IDP’s metadata file (idp.metadata.xml).

●       The root CA certificate that signed the IDP’s SAML signing and encryption key pairs (idpca.crt). If you have a certificate chain leading up to the root CA certificate, copy those intermediate CA certificates too. Each certificate must be in a separate CER or CRT file. (They cannot exist together in a P7 file. If they do, export them from the P7 file, one-by-one, to individual CER or CRT files.)

●       One of the following certificates:

–  The root CA certificate that signed the Federation Module’s Web certificate. This CA might be the same as the one that signed the IDP’s SAML keys. Again, if you have a CA certificate chain, export all the CA certificates to individual CER or CRT files.

OR

–  If you are using the self-signed certificate provided with the Federation Module, copy this certificate (igfederation.cer).

●       (Optional.) the MD5, SHA1, and SHA-256 hash values on the Federation Module’s CA certificate.
