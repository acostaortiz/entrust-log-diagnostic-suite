IdentityGuard Server 13.0 Administration Guide

Configure properties for smart credential login

To enable properties for smart credential login

1.      Log in to the Entrust IdentityGuard Properties Editor.

Windows

a.      Select the Windows button, and then select Entrust IdentityGuard > Properties Editor.

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

Linux

a.      Enter the URL of your Properties Editor web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardPropertiesEditor

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

2.      From the table of contents, select Web Application Settings and configure the following settings:

●       Administration Interface Smart Credential Login URL — Enter the URL of the Administration interface but with port number 8450.

https://hostname.com:8450/IdentityGuardAdmin

●       Enable Certificate Log In to Administration interface — Set to True.

●       (Optional) Password Login Prompt — The default behavior (True.) is to have the password login prompt (user name and password text boxes) visible as a backup authentication method when a user cannot complete smart credential authentication. If you want to remove the password login prompt and have smart credential login as the only authentication method allowed, set this property to False.

3.      Also in the Web Applications Settings section, configure the following properties related to the Delegation Administrator you created in Create a delegation administrator for smart credential login.

●       Delegation Administrator User ID —  Specify iginternalSCdelegate or whatever name you chose for the delegation administrator.

●       Delegation Administrator Password — Specify the password for the iginternalSCdelegate account. Select Encrypt to encrypt the password.

●       Delegation Administrator Password Length — Specify the maximum length of the password. This length is respected when the password is auto-updated. If you do not specify anything, the maximum length is the length specified in the Entrust IdentityGuard password policy.

●       Delegation Administrator Password Auto Update — Select True if you want the delegation administrator password to be auto-updated with a system-generated one when it expires. If you set the password to Password Never Expires (when setting up the delegation administrator account), set the Delegation Administrator Password Auto Update setting to False.

●       Delegation Administrator Password Auto Update Interval — Specify the frequency, in seconds, with which the password is checked to see if it is close its expiry. The password will be updated prior to expiry. The default is 3600 seconds (or 1 hour).

4.      Click Validate & Save.
