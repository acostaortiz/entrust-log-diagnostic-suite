IdentityGuard Server 13.0 Administration Guide

Configuring token and grid card repositories

When you select a database for your user repository, Entrust IdentityGuard automatically stores unassigned tokens and preproduced grid cards in the default database. No additional settings are needed.

When you select an LDAP repository for your default user repository, the installer automatically configures a file-based repository for your unassigned tokens and preproduced cards. Using the Properties Editor, you can change the file-based repository properties or switch to a database instead.

Policy data, users, preproduced grid cards, and unassigned tokens may all be stored in different repositories. See Entrust IdentityGuard groups overview.

If you need to switch from a file-based repository to a database repository to store unassigned tokens, preproduced grid cards, or both, use the following procedure.

To configure database repository settings for preproduced grid cards and unassigned tokens

Attention: Do not use this procedure if the repository is already in use. If you do, the repository will no longer be accessible from Entrust IdentityGuard.

1.      If a database is not already set up for Entrust IdentityGuard, load the Entrust IdentityGuard schema into your supported database and install the driver files. For instructions, see the Entrust IdentityGuard Database Configuration Guide.

2.      For Entrust IdentityGuard with embedded Tomcat only, complete the following:

●       On Linux, install the driver of the database JAR files in $IG_HOME/lib/db and $CATALINA_HOME/lib.

●       On Microsoft Windows, install the driver of the database JAR files in <$IG_HOME>\lib\ and <$IG_HOME>\apache-tomcat-6.0.26\lib

3.      Start the Entrust IdentityGuard Properties Editor. (See Log in or out of the Properties Editor.)

4.      On the Table of Contents, click Repository Settings.

5.      To store preproduced cards in a database, select Database (JDBC) from the Preproduced Card Repository Implementation Class drop-down list.

6.      To store unassigned tokens in a database, select Database (JDBC) from the Token Repository Implementation Class drop-down list.

These two properties are the only mandatory settings needed to use your default database configuration for unassigned tokens and preproduced grid cards. Set other properties if required for your installation. (For a complete list of properties on this pane, see Repository Settings.)

7.      Return to the Table of Contents and click JDBC Database Settings.

8.      In the Configuration Instances drop-down list of the JDBC Database Settings pane, click Default. If this database is not already fully configured, do that now. Follow the instructions in Add a new database repository.
