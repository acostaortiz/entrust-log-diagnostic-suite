IdentityGuard Server 13.0 Administration Guide

Prepare the new data repository

Before moving users from one repository to another repository, you must prepare the new repository for Entrust IdentityGuard data.

To prepare the new data repository

1.      If the repository you are moving the data to is not yet defined in Entrust IdentityGuard, add it using the appropriate procedure:

●       To add and configure a new LDAP repository, see Configuring an LDAP directory .

●       To add and configure a new database, see Configuring a database.

2.      If you are moving data between different types of repository, between a directory and a database, for example, make sure the repository settings allow access to both types of repository.

In the Properties Editor, select Repository Settings, and ensure that the implementation classes allow access to both types of repository.

For example, if user data is currently stored in a directory but it will be moved to a database, set the Card/User Repository Implementation Class to Directory Server (default) and Database.

3.      Repeat Step 2 for the other types of data being moved. This may include updating the following settings: 

●       Card/User Repository Implementation Classes 

●       Policy Repository Implementation Class 

●       Preproduced Card Repository Implementation Class 

●       Token Repository Implementation Class 

4.      Click Validate & Save.

5.      Log out of the Properties Editor.

6.      Restart the Entrust IdentityGuard service.
