Suspend disabled or expired LDAP users

Entrust IdentityGuard can be set to automatically detect when users are disabled or expired in the LDAP user repository. You can choose to suspend disabled users or expired users, or both.

Note: Entrust IdentityGuard users whose accounts are disabled or expired in the directory still count toward the Entrust IdentityGuard Users license count.

When these features are configured (by setting the Disabled Account Attribute and Expired Account Attribute properties in Add a new LDAP repository), Entrust IdentityGuard automatically sets the user’s state to “disabled in repository” or “expired in repository,” as appropriate.

There are four policies you can configure to govern the behavior of Entrust IdentityGuard with respect to disabled and suspended users. See Configure repository data policies for information and the procedure for their use.

When a user has been suspended using one of the Entrust IdentityGuard user interfaces, you can use Entrust IdentityGuard to reactivate the user. If the user has been suspended because it is either “disabled in repository” or “expired in repository,” the only way to reactivate them is to re-enable them in the repository. For more information about suspended users, see Suspend or activate users.

The operation of these features varies by repository. The expired and disabled user features are described in the following table.

Note: In the following table, “not supported” means that the particular function is not supported in the standard Entrust IdentityGuard implementation, often because there is not a standard way to mark the records as expired or disabled in the given directory. In many cases, you can create your own properties to add this support based on the directory attributes you use to mark an account as disabled or expired.

Active Directory

AD LDS

Account disabled: userAccountControl attribute

Account expired: accountExpires attribute

userAccountControl: This attribute is a bit mask. A user account is disabled if and only if ((userAccountControl & 0x0002) != 0). See http://support.microsoft.com/kb/305144 for more information.

accountExpires: This attribute uses syntax 2.5.5.16. A value of 0 or MAX_LONG (0X7FFFFFFFFFFFFFFF) means the account never expires.

Red Hat

Account disabled: nsaccountlock attribute

Account expired: not supported

nsaccountlock: Sun ONE uses the terms active and inactive rather than enabled/disabled.

Making a Sun ONE or Red Hat user inactive adds the following attributes to their entry:

·      nsaccountlock is true

IBM Tivoli

Account disabled: ibm-pwdAccountLocked attribute

Account expired: not supported

ibm-pwdAccountLocked: There are many attributes that could be used to mean the user’s account is disabled, but this one is being used by Entrust IdentityGuard to mark a user as active or suspended.

When ibm-pwdAccountLocked is set to TRUE, in the LDAP repository, the user is prevented from authenticating.

Novell eDirectory

Account disabled: loginDisabled attribute

Account expired: loginExpirationTime attribute

loginDisabled: Users are disabled when this attribute is TRUE. Users are enabled when this attribute is FALSE or missing.

loginExpirationTime: This attribute is the date after which users cannot log in

OpenLDAP

Account disabled: not supported

Account expired: not supported

  

Oracle Internet Directory

Account disabled: orclIsEnabled attribute

Account expired: orclActiveStartDate and orclActiveEndDate attributes

orclIsEnabled: When the user is enabled, this attribute is missing or contains the string ENABLED.
When the user is disabled, this attribute contains the string DISABLED.

orclActiveStartDate and orclActiveEndDate: These attributes are the start and end time of the accounts active state.
Syntax: GeneralizedTime syntax

Note: If your LDAP directory implementation uses different directory attributes than those listed in the table above, you can change the properties. See LDAP Directory Server Settings and Add a new LDAP repository for the property information and instructions.
