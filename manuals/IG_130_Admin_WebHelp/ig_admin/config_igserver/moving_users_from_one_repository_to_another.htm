IdentityGuard Server 13.0 Administration Guide

Move users from one repository to another

Moving users between repositories moves the user and all information associated with the user (grid cards, tokens, questions and answers, location history, and so on) There are two ways to move users between repositories; follow one of the procedures listed below.

Note: When you move users between repositories, their “disabled in repository”, “expired in repository”, and mapped contact info settings do not move with them.

Both methods work equally well, but if you prefer to keep your group names as they are, you should choose the method that changes the group definition.

●       To move users from one repository to another by changing group membership

●       To move users from one repository to another by updating the group definition

To move users from one repository to another by changing group membership

Note: If you are moving user data to an LDAP repository, the users must already exist in the repository. 

1.      Log in to the Master user shell. See Using the Master user shell.

2.      Change the group membership of the users to a group that uses the destination repository.

To move one user to another repository:

a.      Associate the destination group with the destination repository by entering:

group create <dest_group> -repository <dest_repository> 

For example:

group create newgroup -repository newrepository

b.      Change the group the user belongs to. Enter:

user set <src_group>/<user_to_move> -group <dest_group> 

For example:

user set oldgroup/joesmith -group newgroup

Changing the user's group automatically moves the user information to the appropriate repository.

To move multiple users, use the export and import capabilities.

a.      Export the users from the source group to a file. Enter:

user list -group <src_group> [<other search criteria>] -export <user_file>

For example:

user list -group oldgroup -export marketingusers

b.      Import the users into the destination group by entering:

user set -import <user_file> -group <dest_group>

For example:

user set -import marketingusers -group newgroup

3.      Optional. After all users in the group have been moved, you can delete the source group.

group delete <src_group>

For example:

group delete oldgroup

4.      Optional. Follow the instructions in Remove old repository definitions.

To move users from one repository to another by updating the group definition

1.      Log in to the Master user shell. See Using the Master user shell.

2.      Update the group definition of the group containing the users by adding another repository to the group’s repository list.

group set <groupname> -repository -add <dest_repository>

Where:

<groupname> is the name of the group to which the repository is associated.

<dest_repository> is the name of the new repository.

For example, assume that the group is currently associated with the repository called oldrepository:

group set marketinggroup -repository -add newrepository

The group marketinggroup is now associated with both oldrepository and newrepository.

3.      To move the user or users to the new repository, choose one of the following:

●       To move one user to the new repository, enter:the following command:

user set <group_name>/<user_to_move> -repository <dest_repository>

For example:

user set marketinggroup/susanwu -repository newrepository

●       To move multiple users from <src_repository> to <dest_repository>,

a.      Export the users from <src_repository> to a file using the following command:

user list -group <groupname> [<other search criteria>] -export <user_file>

For example:

user list -group marketinggroup -export marketingusers

b.      Import the users to <dest_repository> from the file you just created using the following command:

user set -import <user_file> -repository <dest_repository> 

For example:

user set -import marketingusers -repository newrepository

4.      (Optional) After all users have been moved, you can update the group definition to reference only the destination repository. To do so, enter the following command:

group set <groupname> -repository -remove <src_repository>

For example:

group set marketinggroup -repository -remove oldrepository

5.      (Optional) Follow the instructions in Remove old repository definitions.
