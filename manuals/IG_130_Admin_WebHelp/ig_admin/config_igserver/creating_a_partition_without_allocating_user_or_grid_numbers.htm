Create a partition without allocating user or grid numbers

Use the following procedure only if you want to create a partition now, but do not yet know the user or grid number ranges you want to use. You must add the user number or grid ranges later.

To create a partition without user or grid number ranges

1.      Log in to the Master user shell. See Using the Master user shell.

2.      At the Master user shell prompt, enter:

partition create <name> [-comment <comment>]

Where

<name> is the name of the new partition

<comment> is an optional description of the partition
