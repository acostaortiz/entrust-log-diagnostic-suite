Information maintained by the partition

Each partition policy contains the following information:

●       the partition name

This is set by the partition create command, and can be changed using the partition set command in the Master user shell. (See the Entrust IdentityGuard Master User Shell Command Reference for detailed syntax of these commands.)

●       comments describing the partition

●       one or more ranges of user numbers

●       one or more ranges of grid numbers

●       the serial number to be assigned to the next grid created with this partition

●       the number to be assigned to the next user created within this partition

●       a count of the users in the partition

●       a count of the soft tokens in the partition, if you are using soft tokens

The partition name, the descriptive comments, and the grid and user ranges can be set using the partition commands in the Master user shell. See the Entrust IdentityGuard Master User Shell Command Reference for the full list of the commands and their syntax.

The next grid serial number, the next user number, the user count, and the soft token count cannot be set using Master user shell commands.
