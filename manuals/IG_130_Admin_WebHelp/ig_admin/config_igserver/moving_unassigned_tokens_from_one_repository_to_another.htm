Move unassigned tokens from one repository to another

If you are moving tokens that have not yet been assigned to users from one repository to another, use the following procedure.

To move unassigned tokens from one repository to another

1.      Log in to the Master user shell. See Using the Master user shell.

2.      Move all of the tokens in a group. Enter the following command:

token move <groupname> <dest_repository> -updategroup true

See the token move command in the Entrust IdentityGuard Master User Shell Command Reference for all the command options.

Note: The destination repository must be a database, not an LDAP directory. IdentityGuard cannot store unassigned tokens in an LDAP directory.

3.      (Optional) Follow the instructions in Remove old repository definitions.
