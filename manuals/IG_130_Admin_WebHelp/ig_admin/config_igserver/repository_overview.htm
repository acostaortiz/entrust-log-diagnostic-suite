IdentityGuard Server 13.0 Administration Guide

Repository overview

As part of the installation procedure, you can choose either a single database or single LDAP-compliant directory to use as your repository of user information. After installation and initialization of Entrust IdentityGuard, you can use the Properties Editor to configure additional repositories.

There are three primary reasons to configure additional repositories:

●       You can spread user information (including administrators) across different types of repositories (any supported LDAP directory or database).

●       You can spread preproduced cards and unassigned tokens across different supported databases. (This feature is not supported for LDAP repositories.)

●       You can configure additional repositories as part of a failover and high-availability strategy.

This allows you complete flexibility in how you organize your data.

You can also use the Properties Editor to configure additional repository capabilities. The LDAP repositories support several data transfer features from your LDAP-compliant directory:

●       Enrolling users:

–  Synchronize Active Directory users with an Entrust IdentityGuard database

–  Synchronize LDAP users with an Entrust IdentityGuard LDAP repository

●       Suspending expired or disabled users. See Suspend disabled and expired LDAP users.

●       Mapping contact information. See Map contact info from an LDAP directory.
