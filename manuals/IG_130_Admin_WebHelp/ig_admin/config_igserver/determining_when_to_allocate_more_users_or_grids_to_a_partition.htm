Determine when to allocate more users or grids to a partition

For each partition, a warning audit is written when the following occurs:

●       75% of the allocated user count has been used.

●       75% of the allocated grid card serial numbers have been used.

When this audit occurs, you need to allocate new user or grid card capacity to the partition. This does not apply if the partition has not reserved any user or grid card numbers. See the partition set command. For details on using this command, see the Entrust IdentityGuard Master User Shell Command Reference.
