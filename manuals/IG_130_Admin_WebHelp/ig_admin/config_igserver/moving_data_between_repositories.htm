IdentityGuard Server 13.0 Administration Guide

Moving data between repositories

It may be necessary to move data from one repository to another (sometimes referred to as data migration). In some cases, the new repository may be of a different type; that is, you may need to move data from a database to an LDAP repository, or the other way around.

The following procedures in this section describe how to move the various kinds of data stored in Entrust IdentityGuard from one repository to another:

●       Prepare the new data repository

●       Move users from one repository to another

●       Move preproduced grid cards from one repository to another

●       Move unassigned tokens from one repository to another

●       Move policy information from one repository to another

You may have created a new repository instance temporarily to migrate users to the new repository. For example, you created a new database instance to migrate users from one database to another database, or you created a new directory instance to migrate users from one directory to another directory. You can point the old repository instance to the new repository before removing the new repository instance: To do so, complete the following tasks:

1.      Modify the properties of the old directory or database repository instance to point to the new repository.

●       For a directory repository, see Configuring an LDAP directory .

●       For a database repository, see Configuring a database.

2.      Move the groups back to the old repository instance:

group set <groupname> -repository -add <old_repository>

group set <groupname> -repository -remove <new_repository>

Where:

<groupname> is the name of the group to which the repository is associated.

<old_repository> is the name of the old repository.

<new_repository> is the name of the new repository.

For example:

group set example_group -repository -add old_repository

group set example_group -repository -remove new_repository

3.      (Optional) To remove the repository instance that you are no longer using, see Remove old repository definitions.

Note: Use the repository list command in the Master user shell at any time to see the names of all defined repositories and what kind of information can be stored in them. For detailed use of this command, see the Entrust IdentityGuard Master User Shell Command Reference.
