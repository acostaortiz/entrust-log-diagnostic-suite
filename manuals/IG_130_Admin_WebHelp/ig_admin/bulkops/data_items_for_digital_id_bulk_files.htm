IdentityGuard Server 13.0 Administration Guide

Data items for digital ID bulk files

Each data item in a digital ID bulk file must use the correct data type.

 

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

digitalIdConfig

string

The digital ID configuration name to use for the user’s digital ID. See Step 10: Add a digital ID configuration.

digitalIdDn

string

The DN of the user’s digital ID. For more on DNs, see the Entrust Authority Security Manager Directory Configuration Guide.

digitalIdClientType

string

The client type to use for the user’s digital ID. For example, iPhone. See Digital ID policies for more on client types.

digitalIdRemoveClientTypes

string

A flag to causes client types to be removed from an existing digital ID, if they are present.

digitalIdProfileType

string

The format of the digital ID. Allowable values are epf and p12.

digitalIdProfilePassword

string

The password of the digital ID. The password protects the digital ID. This password must be supplied to gain access to the keys and certificates within the digital ID.

digitalIdOutputFile

string

The path and filename of the digital ID.

For example, c:/ASmithDigitalId.epf

digitalIdP10CertDefn

string

The certificate definition to use with the digital ID, for example, Verification_p10. Certificate definitions are defined in Security Manager. See the Security Manager Administration User Guide for details.

If you are using your digital IDs with mobile enrollment, see also Step 10: Add a digital ID configuration to see which certificate definitions Entrust IdentityGuard uses by default, when it creates digital IDs for users who are requesting digital IDs through Self-Service.

digitalIdP10

string

The base64-encoded PKCS#10 data.

comment

string

A comment.

createIfNotExists

Boolean

true  or  false

When true, a user account is created in Security Manager if one does not yet exist for the user.

recoverIfExists

Boolean

true  or  false

When true, the user can enroll for a digital ID even if they already have an account in Security Manager. When false, the user cannot obtain a digital ID after they have an account Security Manager.
