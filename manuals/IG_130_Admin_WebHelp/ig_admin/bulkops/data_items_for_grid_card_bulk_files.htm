IdentityGuard Server 13.0 Administration Guide

Data items for grid card bulk files

Each data item in a grid card bulk file must use the correct data type.

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique.

serialNumber

string

Contains one of three types of values:

·      all matches all grid cards

·      a state value (for example, current) matches any grid cards in that state (only one state can be specified)

·      any other value is treated as a serial number

Provides a grid card serial number.

Note: The all and state values are not valid for assign operations.

state

One of: pending, hold_pending, current, hold,  or  canceled

Provides the state of a grid card.

Note: You cannot create a grid card in the canceled state.

lifetime

duration

A nonnegative integer with optional units, where:

·      d = days

·      h = hours

·      m = minutes

·      s = seconds

Example: 10s  = 10 seconds

Sets the lifetime of a grid card. Lifetime always starts from the current time on the server. A value of 0 indicates no time limit.

expireDate

dateTime

An RFC3339-formatted time string. Example 1:

2007-04-12T23:20:50Z

represents 20 minutes and 50 seconds after the 23rd hour of April 12th, 2007 in UTC.

Example 2:

2007-12-19T16:39:57-08:00

represents 39 minutes and 57 seconds after the 16th hour of December 19th, 2007 with an offset of -08:00 hours from UTC.

Provides an alternative way to set a lifetime. The date must be in the future.

supersededDate

dateTime

An RFC3339-formatted time string. Example 1:

2007-04-12T23:20:50Z

represents 20 minutes and 50 seconds after the 23rd hour of April 12th, 2007 in UTC.

Example 2:

2007-12-19T16:39:57-08:00

represents 39 minutes and 57 seconds after the 16th hour of December 19th, 2007 with an offset of -08:00 hours from UTC.

Sets an exact superseded date for a grid card.

supersededLifetime

duration

A nonnegative integer with optional units, where:

·      d = days

·      h = hours

·      m = minutes

·      s = seconds

Example: 10s  = 10 seconds

Sets a grid card’s superseded lifetime.

comment

string

Assigns a comment to a grid card.
