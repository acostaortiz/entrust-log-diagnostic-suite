IdentityGuard Server 13.0 Administration Guide

Bulk file limitations

When you process a bulk file, keep the following limitations and restrictions in mind:

●       If a bulk file references a group that does not exist, Entrust IdentityGuard generates an error message.

●       If you include any data type (except alias) more than once, the bulk operation fails.

●       You cannot include authentication secrets or shared secrets in a bulk file. Instead, use the -import attribute and various authentication attributes of the user set command in the Master user shell.

●       If an operation contains both a duration and a dateTime data type for the same data item (for example, lifetime), Entrust IdentityGuard uses the duration data type.

●       Entrust IdentityGuard generates an error and skips any row in which a field does not have the correct syntax for the data type.

●       Processing the same bulk file a second time usually results in errors because Entrust IdentityGuard tries to rewrite existing data. You can perform the following bulk operations repeatedly without errors:

–  Create OTPs for users if overwrite is true

–  Modify OTPs for users if overwrite is true

–  Create PINs for users if overwrite is true

–  Modify user cards unless the grid card state is canceled

–  Modify user tokens unless the token state is canceled

–  Modify user PVNs if PVNs are automatically generated

–  Modify user passwords if passwords are automatically generated or clearHistory is true

–  Unlock users

–  Modify users

–  Modify PINs

–  Modify user contact information
