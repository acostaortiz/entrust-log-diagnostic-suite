IdentityGuard Server 13.0 Administration Guide

Administration interface limitations

The following behaviors are expected when performing bulk operations in the Adminstration interface:

  • If an administrator does not have the bulkOperations permission, the Administration interface does not display the bulk operation options when that administrator is logged in.

  • Each administrator logged in to the Administration interface can process only one bulk file at a time.

  • If an administrator attempts to log out of the Administration interface while a bulk operation is in progress, the Administration interface displays a warning. If the administrator ignores the warning and logs off, Entrust IdentityGuard cancels the bulk operation. Entrust IdentityGuard keeps all changes but provides no record of what was changed.

  • The Bulk Operations Results page of the Administration interface refreshes every 10 seconds to show you the progress of the current bulk operation. You can click Update Results to refresh the page manually. When you finish a bulk operation, the Administration interface requires that you view the results before you can perform a subsequent bulk operation.

  • Entrust IdentityGuard cannot enforce preset restrictions on administrators when they create bulk files. For example, administrators may reference a group in a bulk file for which they do not have access. However, when Entrust IdentityGuard processes the bulk file, it applies any restrictions associated with the administrator. Invalid entries result in an error.

  • You cannot perform all bulk operations in the Administration interface. You can only perform certain bulk operations in the Master user shell. For more information, see the Entrust IdentityGuard Master User Shell Reference.
