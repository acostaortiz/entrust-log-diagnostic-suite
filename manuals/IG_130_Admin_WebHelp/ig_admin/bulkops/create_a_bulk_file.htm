IdentityGuard Server 13.0 Administration Guide

Create a bulk file

You perform bulk operations using data from a bulk file. A bulk file is a CSV (comma-separated value) formatted file in which each line in the file is constructed the same way. The bulk operation performs the same action on each line in the bulk file.

You must create a bulk file before you perform a bulk operation. You can create the bulk file several ways:

●       Create a file in any text editor and manually enter data in the file.

●       Export data from a database or other repository directly to a bulk file.

●       Export data from a database or other repository to an intermediate tool, such as a spreadsheet, and then create the bulk file.

After creating the bulk file, you must edit it. The first non-blank row in the bulk file must define each column in the file. Each subsequent row must have exactly the same number of fields as on the first line and contain the correct data. For example, if the first row includes three data items separated by commas, the file will have three columns and each row must have three fields separated by commas. The bulk file cannot contain comments or content other than what is described previously.

For example, a bulk file used to modify user cards might look like this:

userId,serialNumber,userState

group1/jsmith,111,CURRENT

group2/johndoe,83,HOLD

group2/janedoe,112,HOLD

group3/sjones,84,PENDING

See Bulk file operations and data items for details about the required and optional property data that you can include in bulk files for various operations.

After creating and editing a bulk file, you can validate it in the Administration interface. See Validate a bulk file.
