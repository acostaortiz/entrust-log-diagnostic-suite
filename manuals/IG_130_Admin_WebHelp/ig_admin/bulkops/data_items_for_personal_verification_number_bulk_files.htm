IdentityGuard Server 13.0 Administration Guide

Data items for personal verification number bulk files

Each data item in a personal verification number bulk file must use the correct data type.

For more information about creating, editing and validating bulk files, see Perform bulk operations.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique.

pvn

string

The value must be either:

·      all numbers and must have the exact number of digits as defined by policy

See Configuring personal verification number policies.

·      autogenerate  to have Entrust IdentityGuard automatically generate a PVN for the user

Specifies a PVN for the user, or has Entrust IdentityGuard automatically generate a PVN for the user.

changeRequired

Boolean

true  or  false

Determines whether or not a user must change the PVN the next time they authenticate.

Note: If a PVN is provided along with this option, then policy determines whether or not changeRequired can be false; that is, an error is generated if policy says that the PVN must be changed after creation or modification, and changeRequired is set to false.

On the other hand, if changeRequired on modify is used without a PVN, then true forces a PVN update by the user and false cancels any forced update currently in effect.
