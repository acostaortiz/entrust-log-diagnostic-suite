IdentityGuard Server 13.0 Administration Guide

Biometric Vendor Configuration properties

These properties control the configuration of biometrics capture and enrollment devices. For more information, see Biometric authentication.

Configuration Instances

Provides a list of biometric configurations.

To create a new instance, enter a unique name (100 characters or less) in the empty field and click Add. The other properties appear.

To delete an instance, select it in the list and click Remove.

Default: none

Biometric Vendor Class name

identityguardi.biometrics.{0}.impl

Sets the java class name of the biometric vendor library. You can select Cogent Fingerprint or Custom.

If you select Custom, enter the custom Java class name in the field that appears. (Used only in highly advanced custom installations.)

Default: no default

Biometric Vendor Display Name

identityguard.biometrics.{0}.name

Provides a unique display name for the biometric vendor. The name appears in the Administration interface and can appear in your client application.

Default: the instance name
