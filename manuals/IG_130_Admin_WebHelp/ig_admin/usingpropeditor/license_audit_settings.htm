IdentityGuard Server 13.0 Administration Guide

License Audit Settings

These properties control the Entrust IdentityGuard periodic license audit mechanism. License auditing helps you determine when to renew your licenses or when you are about to run out of Users licenses or other feature-related licenses. For more information and to view a snapshot of the properties, see License auditing.

License Auditing Enabled

identityguard.audit.integrity.enabled

Enables or disables license auditing for all types of licenses.

If set to True, Entrust IdentityGuard counts the number of licenses used without a partition ID. What is counted depends on the type of license. For example, Users licenses are consumed when user accounts created, and Transaction Verification with Soft Tokens licenses are consumed when a user first verifies a transaction with a mobile soft token. For more information, see How license counting works. If this value does not match the number in the global policy, the global policy is updated and an audit generated. License auditing also counts the number of general users and feature-license users created in each partition, and compares that count against the system count.

Attention: This property must be enabled on only one Entrust IdentityGuard Server at any time. The Entrust IdentityGuard Server chosen must be able to see all data in the system.

Default: True

License Audit Interval

identityguard.audit.integrity.interval

Sets the number of hours between license integrity checks.

Default: 12

License Audit User Number Limit

identityguard.audit.integrity.count_limit

If set to a positive integer value, generates an audit when the user count gets to within the given value of the license limit. For example, if this property is set to 3, Entrust IdentityGuard generates the message when only three Users licenses remain.

This value can also be specified as a percentage. If you specify the user count limit to be 2%, for example, Entrust IdentityGuard will start generating audits when 2% of the licenses remain.

Default: 15%

License Audit Expiry Day Limit

identityguard.audit.integrity.time_limit

If set to a positive integer value, generates an audit when the current date gets to within the given number of days of the user license expiry. For example, if set to 3, Entrust IdentityGuard generates the message when only three days remain before the user license expires.

Default: 3
