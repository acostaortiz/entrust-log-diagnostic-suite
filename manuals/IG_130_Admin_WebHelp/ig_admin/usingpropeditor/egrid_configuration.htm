IdentityGuard Server 13.0 Administration Guide

EGrid Configuration

Use these properties to specify the type and content of eGrids, which are grid cards in the form of an electronic file.

Configuration Instances

Provides a list of EGrid configurations.

To create a new instance, enter a unique name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

EGrid Type

identityguard.egrid.{0}.type

Specifies the EGrid format. It can be one of the following:

•  PDF

•  Text

•  Image

EGrid Template

identityguard.egrid.{0}.template

Specifies the template that defines the contents of the EGrid. If not specified, the default format is used. For information about customizing the size, format and content of the EGrid, see "Customizing eGrids" in the Self-Service Module Customization Guide.

Default: $IG_home/etc/templates/grids/egrid.xsl

EGrid Title

identityguard.egrid.{0}.title

Specifies the title of the EGrid. This property is optional.

EGrid Author

identityguard.egrid.{0}.author

Specifies the author of the EGrid. This property is optional.

EGrid Creator

identityguard.egrid.{0}.creator

Specifies the user who created the EGrid. This property is optional.

PDF EGrid Password Protected

identityguard.egrid.{0}.passwordProtected

Specifies whether PDF EGrids are password protected. If you set this property to true, the Password policy CHAP/MS-CHAP Compatibility must be set to Yes.

Default: False

Allow Printing of PDF EGrids

identityguard.egrid.{0}.allowPrint

Specifies whether PDF EGrids can be printed.

Default: False

Allow Copying of PDF EGrids

identityguard.egrid.{0}.allowCopyContent

Specifies whether EGrid contents can be copied.

Default: False

Allow Editing of EGrids

identityguard.egrid.{0}.allowEditContent

Specifies whether EGrid contents can be edited.

Default: False

Allow Edit Annotations of EGrids

identityguard.egrid.{0}.allowEditAnnotations

Specifies whether EGrid annotations can be edited.

Default: False

Use AES-128 for PDF Encryption

identityguard.egrid.{0}.pdf.encryptionAES

Specifies whether to use AES-128 as the encryption algorithm for password-protected EGrids. The default value is True, which sets the password-protected EGrid encryption algorithm to RC4.

Default: True
