IdentityGuard Server 13.0 Administration Guide

Properties Editor overview

The Properties Editor is a Web application that allows administrators with the propertiesSet permission to configure Entrust IdentityGuard properties. You should limit the number of administrators who have property editing permission to a few people who understand your system well.

Properties validation using Properties Editor

When you install Entrust IdentityGuard, it creates the initial properties file using a template with either database (JDBC) properties or LDAP properties, depending on the repository you specified during installation.

The identityguard.properties file is located at:

●       on Linux, in $IG_HOME/etc/ 

●       on Microsoft Windows, in <$IG_HOME>\etc\   (Ensure that file extensions are visible in Windows Explorer. See Ensure that file extensions are visible in Windows Explorer.

Attention: When you make changes to properties through the Properties Editor, the values are validated both for correct syntax (property names in this file are case-sensitive) and for inter-property dependencies. While you can edit the identityguard.properties file directly, it is not recommended because changes to the file are not validated.

Default properties

During installation and initial configuration, defaults are set for all properties needed to run a basic Entrust IdentityGuard configuration. You can change property settings and add new settings to customize your application. Areas that typically need customizing are:

●       repositories (especially if you add multiple repositories)

●       Radius proxy challenge strings used with cards, tokens and PVNs

●       Radius proxy and VPN server settings

●       specialized settings for logging and licenses

●       authentication methods (such as external authentication, passwords, one-time passwords, and others)

●       out-of-band delivery of one-time passwords

Note: Where a URL is required, you can supply a fully qualified domain name (FQDN), a host name, or an IP address. Where applicable, you can add a port number. The use of a host name is limited to your system configuration and DNS setup.

With the exception of log settings, you must restart the Entrust IdentityGuard service to have property changes take effect.
