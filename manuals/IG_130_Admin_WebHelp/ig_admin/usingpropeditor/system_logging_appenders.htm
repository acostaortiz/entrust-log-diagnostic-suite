IdentityGuard Server 13.0 Administration Guide

System Logging Appenders

An appender defines where log messages are written and the format of those messages. For system messages, Entrust IdentityGuard supports an appender for the Syslog protocol (SYSTEM_SYSLOG) and a rolling file appender (SYSTEM_FILELOG). For more details and to view a snapshot of the properties, see Set system logging properties.

SYSTEM_SYSLOG Implementation Class Name

log4j.appender.SYSTEM_SYSLOG

Defines the log4j appender to use for system logs. This should not be changed.

Default: org.apache.log4j.net.SyslogAppender

SYSTEM_SYSLOG Host Name

log4j.appender.SYSTEM_SYSLOG.SyslogHost

Defines the Syslog host (a host name or IP address) to which logging information is sent. You can use a colon to append a non-default port number to the host.

SYSTEM_SYSLOG Facility

log4j.appender.SYSTEM_SYSLOG.Facility

Defines the Syslog facility that is used by Entrust IdentityGuard system logs. Select the option from the drop-down list that best describes what facility on the system originated the message.

Default: LOCAL2

SYSTEM_SYSLOG Layout Implementation Class Name

log4j.appender.SYSTEM_SYSLOG.layout

The log4j class that converts a logging event into a message string to be printed in the logs.

Default: org.apache.log4j.PatternLayout

SYSTEM_SYSLOG Layout Pattern

log4j.appender.SYSTEM_SYSLOG.layout.ConversionPattern

The format of the converted logging event. Please see the log4j documentation for further information.

Default: [%t] [%-5p] [%c] %m%n.

SYSTEM_FILELOG Implementation Class Name

log4j.appender.SYSTEM_FILELOG

Defines the appender that is used if audit events are logged to files.

This value should remain set to the default: org.apache.log4j.RollingFileAppender

SYSTEM_FILELOG File Name

log4j.appender.SYSTEM_FILELOG.File

Defines the location of the system log.

Default:

•  On Windows <$IG_HOME>\logs\system.log

•  On Linux $IG_HOME/logs/system.log

SYSTEM_FILELOG Maximum File Size

log4j.appender.SYSTEM_FILELOG.MaxFileSize

Defines the maximum size in KB of a log file before rolling over to a new empty file.

Default: 1000

SYSTEM_FILELOG Maximum Number of Backup Files

log4j.appender.SYSTEM_FILELOG.MaxBackupIndex

Defines the number of previous log files to keep as a history.

Default: 5

SYSTEM_FILELOG Layout Implementation Class Name

log4j.appender.SYSTEM_FILELOG.layout

The log4j class that converts a logging event into a message string to be printed in the logs.

Default: org.apache.log4j.PatternLayout

SYSTEM_FILELOG Layout Pattern

log4j.appender.SYSTEM_FILELOG.layout.ConversionPattern

The format of the converted logging event. Please see the log4j documentation for further information.

Default: [%d] [%t] [%-5p] [%c] %m%n

SYSTEM_FILELOG Character Encoding

log4j.appender.SYSTEM_FILELOG.encoding

Defines the encoding method for the System Filelog.

The choices include many of the popular encoding methods, UTF-8 and ASCII, for example. If this field is left blank, Entrust IdentityGuard uses the Java default character encoding.

Default: UTF-8
