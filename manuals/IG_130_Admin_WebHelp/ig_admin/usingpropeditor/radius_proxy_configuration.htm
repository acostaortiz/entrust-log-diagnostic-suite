IdentityGuard Server 13.0 Administration Guide

Radius Proxy Configuration

These properties reflect the setup of Entrust IdentityGuard Radius proxy made during installation and configuration.

Several groups of other properties control the associated Radius server, and its authentication methods, VPN connections, and challenge strings. For details about using and configuring the Radius proxy and to view a snapshot of the properties, see Configuring the Radius proxy configuration.

Radius Proxy URL

identityguard.igradius.url

Provides the URL of the Entrust IdentityGuard server where the Radius proxy is running.

If nothing is specified, Entrust IdentityGuard uses the value of the Authentication Service HTTPS URL property. See Service Settings (2).

Radius Proxy Host

identityguard.igradius.host

Specifies the host that Entrust IdentityGuard Radius proxy uses as its host when listening for incoming requests. Normally this value should only be set if the Entrust IdentityGuard host has multiple IP addresses and you want to use a non-default IP address as the host address of Entrust IdentityGuard Radius.

Radius Proxy Port

identityguard.igradius.port

Provides the port the Radius proxy listens on for requests from the VPN.

If you use a Radius server for first-factor authentication and your VPN server recognizes different groups of users, use this property to specify a series of ports (separated by spaces) and use other properties to direct those groups to different ports.

Each port value must be an integer between 124 and 65535.

No additional ports are needed for groups for other first-factor authentication methods.

Default: 1812

Radius Proxy Callback Host

identityguard.igradius.callbackhost

Specifies the host of the Entrust IdentityGuard Radius proxy that handles callbacks from Entrust IdentityGuard when it receives responses to online mobile soft token authentication challenges.

If a value is not specified, the local host name is used.

Radius Proxy Callback Port

identityguard.igradius.callbackport

Specifies the port of the Entrust IdentityGuard Radius proxy that handles callbacks from Entrust IdentityGuard when it receives responses to mobile soft token authentication challenges.

If a value is not specified, a random port is used. The port is only used by and should only be accessible from the Entrust IdentityGuard Server.

Callback Queue Check Interval

identityguard.igradius.callback.checkinterval

Specifies the interval, in seconds, between checks for expired entries in the Entrust IdentityGuard Radius proxy callback queue. The entries in this queue are waiting for responses from Entrust IdentityGuard for mobile app push authentication.

Authentication requests that have expired are removed from the queue and they either fall back to manual OTP entry (mobile soft token) or fail due to timeout. The timeout interval is set by the VPN Server Configuration property MST/MSC Callback Response Timeout.

Accepts values between 2 and 10 seconds.

Default: 10

Number of Callback Worker Threads

The number of threads used by the Entrust IdentityGuard Radius proxy to process callback requests from Entrust IdentityGuard.

Default: 5

Enable Radius Message Logging

identityguard.igradius.msglog.enabled

If set to True, Radius messages are logged to the file specified by the Radius Message Log File (identityguard.igradius.msglog.enabled) property.

Default: False

Radius Message Log File

identityguard.igradius.msglog.file

Provides the name of the file that logs Radius messages. If the property does not provide an absolute path name, the file is created in the following directory:

•  on Linux, $IG_HOME

•  on Windows, <$IG_HOME>

If Enable Radius Message Logging is set to True but this property is not set or the file name is not valid, Entrust IdentityGuard generates errors and sends them to the system log.

Radius Message Log Maximum Number of Entries

identityguard.igradius.msglog.maxentries

Specifies (approximately) the maximum number of log entries after which Entrust IdentityGuard creates a new log file for subsequent messages. Rollover to the new log file also occurs when Entrust IdentityGuard Radius Proxy service is started.

This setting is applied only if Enable Radius Message Logging is set to True and a valid log file name is specified.

Default: (no rollover)

Number of Worker Threads

identityguard.igradius.numthreads

Specifies how many worker threads the Radius proxy uses to process incoming requests. Each thread has its own connection to Entrust IdentityGuard.

Default: 5

Connection to Entrust IdentityGuard Timeout

identityguard.igradius.igtimeout

Specifies the number of milliseconds that a request should wait for a response from Entrust IdentityGuard before the connection times out. If , connections never timeout.

Default: (no timeout)

Maximum Message Queue Time

identityguard.igradius.maxmessagequeuetime

Specifies the maximum number of milliseconds that a request to the Radius proxy can be queued. If the request is queued longer than the specified time, the Radius proxy ignores the request.

It is recommended that you set the value lower than the connection timeout used by the VPN server that calls the Entrust IdentityGuard Radius proxy.

Default: 1

Maximum Message Queue Size

identityguard.igradius.maxmessagequeuesize

Specifies the maximum number of requests to the Radius proxy that can be queued. When the queue becomes full, the Radius proxy removes the oldest queued requests when new requests are processed.

Default: 1
