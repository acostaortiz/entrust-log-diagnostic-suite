IdentityGuard Server 13.0 Administration Guide

Smart Credential Expiry Notification settings

These properties allow smart credential users to receive email notifications when their smart credentials are approaching their expiry dates. This prompts the users to re-encode their smart credentials before the smart credentials expire. If smart credentials expire, users cannot use them for authentication or other operations.

In addition to configuring these settings, ensure that the following are true:

●       the associated smart credential definition allows for the Smart Credential Expiry Delivery Method specified here.

●       the policy associated with the groups with smart credential users have Expiry Notification Enabled set to True.

For more information, see "Configure smart credential expiry notification" in the Entrust IdentityGuard Smart Credentials Guide.

Expiry Notification Enabled

identityguard.expiry.notify.smartcredential.enable

Enables or disables notifications that advise users when certificates in their smart credentials are nearing their expiry date and the smart credentials must be re-encoded. When set to True, smart credential expiry notification is enabled.

Default: False

Start Time

identityguard.expiry.notify.smartcredential.start

Specifies the time at which the search for expiring certificates begins. This property uses a 24-hour clock.

Default: 00:00:00

Stop Time

identityguard.expiry.notify.smartcredential.stop

Specifies the time at which the search for expiring certificates ends. This property uses a 24-hour clock.

Default: 6:00:00

Wait Time

identityguard.expiry.notify.smartcredential.days

Specifies the number of days to wait before restarting the next repository search for certificates nearing expiry. Set this property to 1 to run the search daily. This property must be set as a positive integer.

Default: 1

Priority

identityguard.expiry.notify.smartcredential.priority

Specifies the priority at which the search thread should run: Minimum Priority,.Normal Priority, or Maximum Priority.

Entrust IdentityGuard attempts to meet this thread priority, but it is dependent on the operating system.

Default: Minimum Priority

Maximum Search Rate

identityguard.expiry.notify.smartcredential.maxratesearch

Specifies the maximum rate, in users per second, at which to search the repository for users whose smart credentials are nearing expiry. This property must be set as a positive integer.

Default: 10 users per second

Maximum Message Rate

identityguard.expiry.notify.smartcredential.maxratesend

Specifies the maximum rate, in messages per second, at which Entrust IdentityGuard sends notification messages to the mail server. This property must be set as a positive integer.

Default: 100 messages per second

Queue Limit

identityguard.expiry.notify.smartcredential.maxqueue

Specifies the maximum number of messages to queue in memory. This property must be set as a positive integer.

Default: 10,000

IdentityGuard Self Service URL

identityguard.expiry.notify.smartcredential.selfserviceurl

Specifies the URL of the Self-Service Module instance that Entrust IdentityGuard should embed as a link in the notification messages. This directs users to Self-Service Module to re-encode their smart credentials.

Example: https://ssmhost.entrust.com:8445/IdentityGuardSelfService.

Delivery Configuration Instance Name

identityguard.expiry.notify.smartcredential.email.deliveryconfiginstance

Specifies the name of the User Email Delivery Configuration Instance that will deliver expiry notifications by email or text message. Set it to the name of a delivery configuration instance.

If using email to deliver the expiry notifications, select an instance you created and configured under User Email Delivery Configuration. The Email Delivery Configuration Type referenced here must be set to Smart Credential.

If using text messages to deliver expiry notifications, select an instance you created and configured under User SMS Delivery Configuration. The SMS Delivery Configuration Type referenced here must be set to Smart Credential.
