IdentityGuard Server 13.0 Administration Guide

SAML SP Keys Settings

The Entrust IdentityGuard reporting feature relies on JasperReports, and preset templates. Use these properties to set the locations for the templates, the report output, and the temporary reporting files.

Configuration Instances

Provides a list of SAML IDP configurations.

To create a new instance. enter a unique name for a set of keys in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

Key Alias

Use this property to enter the same alias as specified under Default Signing Key Alias. Example: igsaml

Key Password

Use this property to enter the password for the certificate specified under Key Alias. This password can be one of two things:

•  If you decided to re-use certificate and keys that already exist in the Entrust IdentityGuard keystore as your SAML keys, then use the password entrust.

•  If you decided to generate and import a new SAML certificate and keys to be used by the Entrust IdentityGuard Server, use the password that you specified when you imported the SAML certificate to the keystore. If you did not specify a password for the certificate when you imported it, then enter the associated keystore password. If you are using the Entrust IdentityGuard Server’s default keystore, the password is entrust.

Select Encrypt to encrypt the password.
