Content Security Policy Directives

Content-Security-Policy (CSP) is the name of an HTTP response header that modern browsers use to enhance the security of a web page. Content Security Policy (CSP) is an added layer of security that helps to detect and mitigate certain types of attacks, including Cross -site Scripting (XSS) and data injection attacks. These attacks are used for everything from data theft to site defacement to distribution of malware. For more information, see https://www.w3.org/TR/CSP/.

When enabled, the CSP directives are applied to the Entrust IdentityGuard Properties Editor and the Entrust IdentityGuard Administration interface.

Enable Content Security Policy Directive

identityguard.csp.enabled

This property specifies whether the Entrust IdentityGuard Server should set the Content-Security-Policy HTTP header when sending content back to a browser.

Content-Security-Policy Directives

identityguard.csp.token

The Content-Security-Policy directives makes it possible for server administrators to reduce or eliminate the vectors by which cross-site scripting (XSS) can occur by specifying the domains that the browser should consider to be valid sources. A CSP-compatible browser then only loads the source files that are configured in this property received from the domain, ignoring all other source files. If no input is provided for this property, default CSP directives are used.

Defaults: connect-src 'self'; default-src 'self'; frame-ancestors 'none'; img-src 'self' data:; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline';

CSP report Enable

identityguard.csp.report.enabled

Enable this property to instruct the user agent to report attempts to violate the Content Security Policy. These violation reports consist of JSON documents sent by an HTTP POST request to the Entrust IdentityGuard CSP Endpoint.

CSP Report Endpoint

identityguard.csp.report.endpoint

This property specifies the common CSP Report Endpoint URI of the Entrust IdentityGuard Properties Editor and the Entrust IdentityGuard Administration interface. If not specified, the default is used.

Default URL: /IdentityGuardAdmin/CSPEndpoint

Violation Report Files

identityguard.csp.report.filename

This property specifies the file path where the IdentityGuard CSP Report Endpoint writes violation report sent by browser. The default file location is <IG_HOME>/logs/cspreport.log.
