IdentityGuard Server 13.0 Administration Guide

Report Definitions

The Entrust IdentityGuard reporting feature includes the basic set of reports to generate. You can use the existing reports and you can create your own.

Configuration Instances

Sets the report name. Choose one of the existing reports or create your own.

To create a new report, enter a unique name in the empty field and click Add. The other properties appear. The report name replaces the {0} placeholder.

Note: Creating your own templates requires knowledge of JasperReports, and they have to be compiled before you can use them.

To delete a report, select it in the list and click Remove.

Note: You cannot remove built-in reports.

Report Data Source

identityguard.report.{}.datasource

When you use one of the predefined reports, the data source is automatically selected for you.

If you define a new report, enter the data source here. The choices are:

•  Audits

•  Cards

•  Certificates

•  Digital Ids

•  Smart Credentials

•  Tokens

•  Unassigned Cards

•  Unassigned Smart Credentials

•  Unassigned Tokens

•  Users

Default: none

Note: This is a mandatory setting; you must select a value.

Report Display Name

identityguard.report.{}.displayname

Sets the name to be displayed for your report in the Administration interface, in the Master user shell report get response, and optionally, in your client application. The maximum Report Display Name length is 255 characters.

By default, the display name is the Configuration Instance.

Note: The Report Display Name must be unique across all Entrust IdentityGuard instances.

Report Information

identityguard.report.{}.helpmessage

Use this property to define information to be displayed in the Administration interface.

A message you define here can also be displayed in your client application, if desired. Including a message is recommended because it communicates report information to other administrators who may choose to run it.

Maximum length: 248 characters

Report Template Name

identityguard.report.{}.templatename

When you use one of the built-in reports, this template file name is selected for you.

If you define a new report, enter the report template name here. The report template name cannot include the path; the path is always the path defined in the Report Template Directory property.

The maximum length of the template filename is 64 characters.  If an extension is not specified, the .jasper extension is automatically appended.

Allowable Report Formats

identityguard.report.{}.formats

This is the output format for the report. The choices are:

●        Portable Document Format (PDF)

●        Comma Separated Values (CSV)

When you use one of the predefined reports, the output format is automatically selected for you.

Default: All report formats

Maximum Number of Generated Reports

identityguard.report.{}.maxinstances

Use this property to define how many copies of the report to keep in the output directory. When the limit is reached, the oldest copy is deleted. This includes all existing formats of the report (both PDF and CSV may be present), and the metadata file.

A value of (zero) means there is no limit.

Default: 25

Maximum Number of Records

identityguard.report.{}.maxrecords

Use this property to define how many records to process in creating this report. When the limit is reached, processing stops, and the report output is truncated.

If the report is truncated, a message is added to the report, and an audit message is logged.

A value of (zero) means there is no limit. Maximum Number of Records must be an integer.

Default:

Maximum Generation Time

identityguard.report.{}.maxtime

Use this property to define how much time, in minutes, to allow for processing this report. When the limit is reached, Entrust IdentityGuard attempts to stop the report generation.

An audit message is added to the audit log if Maximum Generation Time is reached.

A value of (zero) means there is no limit. Maximum Generation Time must be an integer.

Default:60 minutes

Note: The stopping time for report generation will be approximately equal to the maximum time you set here. Report generation will not stop at exactly the time specified.
