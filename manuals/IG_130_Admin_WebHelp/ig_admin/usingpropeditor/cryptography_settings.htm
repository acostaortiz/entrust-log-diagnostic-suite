IdentityGuard Server 13.0 Administration Guide

Cryptography Settings

These properties change the location of master key files. Do not change these settings unless absolutely necessary. For more information about master keys, see Master key protection overview.

Master Key File

identityguard.MasterKeyFile

Sets the location of the master key file, masterkeys.enc.

Default location of master key file:

•  On Linux: $IG_HOME/etc

•  On Windows: <$IG_HOME>\etc

Key Protection File

identityguard.KeyProtectionFile

Sets the location of the master key protection file, masterkeys.kpf, used to obfuscate the master key file.

Default location of master key protection file:

•  On Linux: $IG_HOME/etc

•  On Windows: <$IG_HOME>\etc

Hardware Security Module Driver Library

identityguard.p11.library

Sets the full path to the PKCS #11 library used by Entrust IdentityGuard to connect to a Hardware Security Module (HSM).

This setting is read-only in the Properties Editor. To configure it, you must initialize Entrust IdentityGuard for use with an HSM. See the Entrust IdentityGuard Installation Guide for details.

Hardware Security Module Slot ID

identityguard.p11.slot

Sets the hardware slot number on the HSM where the master keys are stored.

This setting is read-only in the Properties Editor. To configure it, you must initialize Entrust IdentityGuard for use with an HSM. See the Entrust IdentityGuard Installation Guide for details.
