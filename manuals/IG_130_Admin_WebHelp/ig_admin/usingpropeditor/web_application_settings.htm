IdentityGuard Server 13.0 Administration Guide

Web Application Settings

The Web application settings reflect the URLs for the Administration interface and the Properties Editor, and they control Administration interface features, such as bulk operations and the policy cache. These settings are also used to configure single sign-on to the Administration interface using SAML or smart credentials and to configure a Delegation Administrator for the Administration interface.

Properties Editor URL

identityguard.preditor.url

Contains the URL of the Properties Editor. It is set during installation configuration and cannot be edited.

Administration Interface URL

identityguard.webadmin.url

Contains the URL of the Administration interface. It is set during installation configuration and cannot be edited.

Administration Interface Smart Credential URL

identityguard.webadmin.certificateLogin.url

Specifies the URL used to access the Administration interface when logging in with a smart credential. Set this property if you set the property Enable Certificate Log In to the Administration Interface to True.

This URL should be the same as the Administration interface URL, except for the port number.

The servlet container must be configured to require SSL client authentication at that port. For example, the server.xml file in Tomcat Servlet Container could have a connector at port 8450 configured with clientAuth=true, and this URL could be set to https://hostname.com:8450/IdentityGuardAdmin

Bulk File In Memory Threshold

identityguard.webadmin.bulk.inMemoryThreshold

Sets the maximum amount of memory used for bulk operations in the Administration interface. Entrust IdentityGuard writes large bulk files to disk and caches them when they exceed the set size. Enter a value in bytes. The default is 148576 bytes (1 MB).

Bulk File Maximum Size

identityguard.webadmin.bulk.maxFileSize

Sets the maximum size in bytes of files imported for bulk operations in the Administration interface. Enter a value in bytes.

If you attempt to load a bulk file that exceeds the set limit, the Administration interface cancels the operation and displays an error message.

Default: 52428800 (50 MB)

Certificate File Maximum Size

identityguard.webadmin.maxCertFileSize

Specifies the maximum size (in bytes) for a certificate file that can be uploaded using the Administration interface.

The certificate file must be kept in memory on the server until the upload process is complete, so it is recommended that you do not make this value very high.

Default: 20 kbytes

Cache Policy Settings

identityguard.webadmin.cachePolicies

Determines if policies are saved in memory until the Administrator logs out or re-authenticates. Setting this to False can slow performance.

Default: True

Direct Connection to Administration API

identityguard.webadmin.directConnection

Determines if the Administration interface and Properties Editor services establish a direct connection to the Administration API (True) or connects via SOAP (False).

Note: If you are configuring a replica, and you select Primary (to use the primary server’s administration service), then this parameter is set to False.

Default: True

Enable Certificate Log In to Administration interface

identityguard.webadmin.certificateLogin.enabled

Set to True to enable administrators to log into the Administration interface using smart credentials. For more information, see Configuring smart credential authentication to the Administration interface.

Default: False

Password Login Prompt

identityguard.webadmin.offerpasswordlogin

Determines whether the password login prompt (user name and password text boxes) are shown to a user who is configured to use smart credential or SAML login to the Entrust IdentityGuard Administration interface.

Set to True to have the user name and password prompts visible as a backup authentication method when a user cannot complete smart credential or SAML login.

Set to False to not show the password login prompt.

Default: True

Enable Token Activation using QR Codes

identityguard.webadmin.tokenActivateQRCode

Determines whether the Entrust IdentityGuard Web Administration interface displays user token activation QR Codes for tokens that support QR Code activation. If True, the Web Administration interface displays QR Codes. If False, the Web Administration interface does not display QR Codes.

For more information, see “Administrative creation and activation of mobile soft tokens - automatic entry of activation information” in the Entrust IdentityGuard Smart Credentials Guide.

Default: True

IdentityGuard Self-Service Activation Address

identityguard.webadmin.ssmActivationAddress

(Optional) Specifies the IdentityGuard Self-Service Address used for soft token and mobile smart credential activation.

This property is required for online activation of a soft token through the Administration interface.

This property is optional for QR code activation of a mobile soft token through the Administration interface. If specified, this value is included in the soft token activation QR code. For more information, see “Administrative creation and activation of mobile soft tokens - automatic entry of activation information” in the Entrust IdentityGuard Smart Credentials Guide.

Example value: ssm.example.com:8445/igst

This address should be short both for ease of entry when users need to enter it manually and because the QR code data can contain a maximum of 250 characters (for activation, code, serial number, and this URL).

Default: none

SAML Single Sign-On Enabled

identityguard.SAML.enabled

Set to True to enable administrators to have single sign-on between Federation Manager and the Administration interface. For more information, see SAML login to the Administration interface.

Default: False

SAML Single Sign-On Login Auto-Redirect

identityguard.SAML.autoRedirect

Set to True if you want users to be redirected to the Federation Module’s SAML login page when they attempt to access the Administration interface.

Set to False to have a SAML Single Sign-On link appear at the bottom of the Administration interface’s login page. This link takes users to the Federation Module’s SAML login page. See How SAML login works with the Administration interface for details.

Default: False

SAML Log Level

log4j.logger.org.springframework.security

Defines the logging level for SAML logs.

The message level can be one of ALL,DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. This sets the lowest level of message to show; for example, WARN provides messages of WARN, ERROR and FATAL status.

Select OFF to stop all messages.

Default: OFF

Delegation Administrator User ID

identityguard.delegation.userid

Specifies the user ID for the delegation administrator account that is used to log in to the Administration interface using SAML or smart credentials.

Delegation Administrator Password

identityguard.delegation.password

The password for the delegation administrator account specified under Delegation Administrator User ID.

Select Encrypt to encrypt the password.

Delegation Administrator Password Length

identityguard.delegation.password.length

Specifies the maximum length of the password. This length is respected when the password is auto-updated. If you do not specify anything, the maximum length is the length specified in the Entrust IdentityGuard password policy.

Delegation Administrator Password Auto Update

identityguard.delegation.password.update

Set to True if you want the delegation administrator password to be auto-updated with a system-generated one when it expires. If you set the password to Password Never Expires (when setting up the delegation administrator account), set the Delegation Administrator Password Auto Update setting to False.

Default: True

Delegation Administrator Password Auto Update Interval

identityguard.delegation.password.update.interval

Specifies the interval, in seconds, after which the password is checked to see if it is close to its expiry. The password is updated prior to expiry.

Default: 3600 seconds (1 hour)
