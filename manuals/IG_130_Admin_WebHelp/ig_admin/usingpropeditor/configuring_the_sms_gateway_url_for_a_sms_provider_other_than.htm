Configuring the SMS Gateway URL for a SMS provider other than Clickatell or TeleSign

If you are using an SMS provider other than Clickatell (or TeleSign, which does not use SMS Server Configuration properties), enter your SMS service provider’s Gateway URL (as defined by your SMS service provider), and insert Entrust IdentityGuard variables where appropriate. After the required Entrust IdentityGuard variables are inserted, the SMS provider’s URL might look like the following example:

https://sms.example.com/delivery?account=URL_USER_TAG&password=URL_PASSWORD_TAG&app_id=URL_APPID_TAG&to=TO_PHONE&msg=MSG_TEXT&from=FROM_ID

where Entrust IdentityGuard replaces the following Entrust IdentityGuard variables with values that you specify in the Properties Editor:

●       URL_USER_TAG maps to the User Name field

●       URL_PASSWORD_TAG maps to the Password field

●       URL_APPID_TAG maps to the API ID field

●       FROM_ID maps to the From Label In The SMS Message field

The remaining Entrust IdentityGuard variables are set by Entrust IdentityGuard with user-specific values:

●       TO_PHONE is the user's phone number stored in Entrust IdentityGuard

●       MSG_TEXT is the SMS message text generated from a template file (specified in the SMS Delivery Template File field)

You can exclude variables that are not relevant to your SMS service provider. For example, an acceptable URL might look like this:

https://sms.example2.com/delivery?account=URL_USER_TAG&password=URL_PASSWORD_TAG&to=TO_PHONE&msg=MSG_TEXT

Notice that the URL_APP_ID and FROM_ID variables are not present.

If your service provider requires additional values for which there is no equivalent Entrust IdentityGuard variable, those values must be hard-coded into the URL.
