IdentityGuard Server 13.0 Administration Guide

Anonymous Security Challenge Check

These properties control scheduling of the Anonymous Security Challenge Check, which checks the age of all anonymous security challenges that Entrust IdentityGuard has created. It removes them if they are older than the configured maximum age, or older than the lifetime they were given by policy when Entrust IdentityGuard created them. Before an anonymous security challenge is removed, a user can authenticate the anonymous challenge by signing it with an assigned certificate or a smart credential. Only when a user does this does Entrust IdentityGuard determine which user has authenticated the anonymous challenge.

For more information, see "Anonymous smart credential authentication" in the Entrust IdentityGuard Smart Credentials Guide.

Anonymous Challenge Check Enabled

identityguard.anonymouschallenge.check.enable

This property enables or disables the Anonymous Challenge Check. If True, Anonymous Challenge Check is enabled. The default is False.

Maximum Age

identityguard.anonymouschallenge.check.age

This property specifies the maximum age (in seconds) the Anonymous Challenge Check allows. When Anonymous Challenge Check is enabled, challenges older than this value are removed from the database. Entrust IdentityGuard also removes challenges if they are older than the lifetime specified by the Certificate Challenge Lifetime policy (in the Certificate Authentication policy category)  when it was created. The default value is one month (in seconds). It cannot be less than one second.

Start Time

identityguard.anonymouschallenge.check.start

This property specifies the local time of day at which the Anonymous Challenge Check begins, using a 24 hour clock (hh:mm:ss). By default the check begins at midnight.

Stop Time

identityguard.anonymouschallenge.check.stop

This property specifies the local time of day at which the Anonymous Challenge Check ends, using a 24 hour clock (hh:mm:ss). By default, the check ends at 06:00:00 (hh:mm:ss).

Wait TIme

identityguard.anonymouschallenge.check.days

This property specifies the number of days the Anonymous Challenge Check waits before it repeats the check for expired challenges. The default is 1 day. If set to zero, the Anonymous Challenge Check runs continuously between the configured start and stop times.

Priority

identityguard.anonymouschallenge.check.priority

This property specifies the priority at which the Anonymous Challenge Check will run. The default is Minimum Priority.

Maximum Rate

identityguard.anonymouschallenge.check.maxrate

This property specifies the maximum rate at which Entrust IdentityGuard reads anonymous challenges in the database to check for expired anonymous challenges. The rate can be set to a value that corresponds to the capabilities of the database. The default value processes challenges at a rate no greater than 10 per second on average.
