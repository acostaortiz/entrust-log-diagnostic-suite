IdentityGuard Server 13.0 Administration Guide

SAML IDP Configuration

Use these properties to configure the settings for the allowed SAML Identity Providers (IP).

Configuration Instances

Provides a list of SAML IDP configurations.

To create a new instance. enter a unique configuration name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

IDP Metadata File Location

identityguard.idp.IDP Configuration.metadata

Specifies the location of the file that contains the metadata of the SAML IDP that will perform the authentication. The default directory is $identityguard.home/etc.
