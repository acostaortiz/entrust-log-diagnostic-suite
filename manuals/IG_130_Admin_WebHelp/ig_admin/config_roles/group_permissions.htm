IdentityGuard Server 13.0 Administration Guide

Group permissions

These permissions control the creation and management of groups. For information about managing groups, see Entrust IdentityGuard groups overview.

 

Permission

Dependencies

Description

groupCreate

repositoryList, groupGet

Create a new group.

Note: The administrator must also have a role with the special “all” option as the group list, and at least one policy in the policy list.

groupDelete

groupGet

Delete an existing group. The group being deleted cannot include users, preproduced cards, or unassigned tokens.

groupGet

 

Retrieve information about a group.

Note: This permission is not needed if the group is the administrator's group.

groupList

groupGet

List information about groups.

groupSet

groupGet, repositoryList

Change an existing group.

repositoryList

 

Get a list of all directory and database repositories.
