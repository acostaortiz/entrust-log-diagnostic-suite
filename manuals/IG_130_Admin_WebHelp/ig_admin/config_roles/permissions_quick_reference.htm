IdentityGuard Server 13.0 Administration Guide

Permissions quick reference

This section lists all permissions that apply to administrators. Permissions are arranged in related categories.

Administrators can assign these permissions to a role. Many permissions have dependencies, so you must assign both these permissions, and the permissions they are dependent on, to the role. If the dependency column of a table does not contain any permissions, the permission has no dependency.

All permissions listed apply to both administrators using the Administration interface and administrators associated with the Administration API, unless otherwise noted.
