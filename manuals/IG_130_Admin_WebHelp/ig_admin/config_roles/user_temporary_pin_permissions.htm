IdentityGuard Server 13.0 Administration Guide

User temporary PIN permissions

These permissions control the creation and management of temporary PINs. For information about using temporary PINs, see Temporary PIN authentication overview.

 

Permission

Dependencies

Description

userPinCreate

userPinGet

Create a user’s temporary PIN.

userPinDelete

userPinGet

Delete a user’s temporary PIN.

userPinDeliver

userPinGet

Deliver a user’s temporary PIN.

userPinGet

 

Retrieve information about a user’s temporary PIN.

userPinOverridePolicy

 

Override the lifetime and maximum uses values set in the PIN policy when modifying or creating a user’s PIN.

userPinSet

userPinGet

Set information about a user’s temporary PIN.

userPinView

userPinGet

View the value of the user’s temporary PIN.
