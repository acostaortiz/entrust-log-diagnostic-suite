IdentityGuard Server 13.0 Administration Guide

Biometric permissions

These permissions control the management of biometric information. For more information about biometric authentication, see Configuring and using biometric authentication.

 

Permission

Dependencies

Description

biometricVendorGet

 

Display or export the name of biometric vendors. If this permission is missing, userBiometricGet and userBiometricList do not display the user’s biometrics.

biometricVendorList

biometricVendorGet

Display a list of biometric vendors.

userBiometricCreate

userBiometricGet

Create biometric metadata.

userBiometricDelete

userBiometricGet

Delete a biometric.

userBiometricEnroll

userBiometricGet

Allows a user to enroll biometric data against a biometric. It is the administrative account with the transactionadmin role that has this permission and submits the biometric data collected from the biometric enrollment client to Entrust IdentityGuard.

userBiometricGet

 

Retrieve information about a users biometric.

userBiometricList

userBiometricGet

Display a list of biometrics for a user.

userBiometricSet

userBiometricGet

Modify a biometric state or comment.
