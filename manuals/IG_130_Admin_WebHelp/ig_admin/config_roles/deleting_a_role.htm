IdentityGuard Server 13.0 Administration Guide

Delete a role

The built-in roles provided with Entrust IdentityGuard only permit an administrator with the superuser role to delete a role. Any administrator with a role that includes the roleDelete permission can accomplish this, too.

Delete a role if it is no longer useful to your organization.

The built-in roles are system roles and cannot be deleted. You cannot delete a role that is associated with one or more administrators, including your own role.

You can delete a role in one of two ways:

●       from the View Role page

●       from the Delete Role tab

Note: The delete operation cannot be undone.

To delete a role from the View Role page

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      Find the role to delete (see Find a role).

3.      Select the role from the list to view its role information.

4.      On the View Role page, click Delete Role. (You do not see the Delete Role option when you view your own role or a built-in role.)

5.      Click OK to confirm the deletion.

Note: If you do not see the Delete Role function on the View Role page, there may still be users assigned to the role. Check that your own userid is not associated with the role you are trying to delete. You cannot delete a role that has users associated with it.

To delete a role from the Delete Role tab

6.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      Click Roles on the home page.

3.      Click the Delete Role tab.

4.      Select the role you want to delete from the list.

5.      Click Delete Role.

6.      Click OK.

Note: If you do not see the Delete Role function, there may still be users assigned to the role. Check that your own userid is not associated with the role you are trying to delete.
You cannot delete a role that has users associated with it.
