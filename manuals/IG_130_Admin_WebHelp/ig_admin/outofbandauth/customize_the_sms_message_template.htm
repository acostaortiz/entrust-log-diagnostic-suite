Customize the SMS message template

All SMS messages use the template named in the SMS Delivery Template File property. Entrust IdentityGuard includes an SMS template file that you can use. If you are installing Entrust IdentityGuard for the first time, the email template file is called igsample_sms_template.txt 

You can find the template file:

●       on Windows: <$IG_HOME>\etc\templates\oob\

●       on Linux: $IG_HOME/etc/templates/oob/

Note: Telesign has a few limitations that require rewording of the message. See an example template for Telesign at the bottom of this topic.

Copy the template file and give it a new name before changing it for your application. The template uses Velocity syntax, so you must make sure all your changes also conform to Velocity syntax. The default template looks like this:

#if ($transactionDetails)

Your transaction details:

#foreach ($key in $transactionDetails.keySet())

 $key: $transactionDetails.get($key)

#end

#end

#if ($otp)

One Time Passwords: $o

#foreach ($o in $otp)

$o

#end

#if ($expiryDate)

Expiration Date: $expiryDate

#else

Never Expires.

#end

#end

#end

#if($dynamiclink)

The one-time password is dynamically linked to this transaction.

#end

Note: If you are using accented characters (é, à) in your template, you must save the template in UTF-8 format before using it, or the message will not be delivered.

The template, which uses Apache Velocity for its formatting, allows you to define placeholders that Entrust IdentityGuard replaces with the appropriate information when the message is sent:

●       $transactionDetails — the transaction details for the transaction in progress

●       $otp — the one-time password generated

●       $expirydate — the expiry date of the one-time password

Note: Many devices that receive SMS messages limit the message length. For Clickatell, the maximum message length is 160 characters. If your template is long and you send many OTPs, the SMS messages may be fragmented and sent as two or more messages. For TeleSign, the maximum message length is 140 characters. TeleSign does not support message fragmentation, so if the message exceeds 140 characters, the message is not sent.

The $transactiondetails, $date and $otp placeholders are part of the default template:

$transaction details

One-time password: $otp

Expiration Date: $date

As an example, an OTP SMS with transaction details would look something like this:

Transfer $10,000 from checking (***3733) to savings (***4145)

One-time password: 1A3D456H

Expiration Date: March 10, 2015

Note: Some receiving devices format the message with the specified carriage returns, and some devices display the whole message as one line.

For information about Apache Velocity syntax, see http://velocity.apache.org/engine/2.2/user-guide.html.

Sample template for Telesign messages

Your Entrust IdentityGuard installation includes a sample SMS template which is suitable for sending multiple OTPs in each SMS message. However, TeleSign can send only one numeric OTP in each message, so this sample template has better wording. 

 

#if ($otp)

One-time password is $otp[0]

#end

#if ($expiryDate)

Expires: $expiryDate

#else

Never Expires

#end
