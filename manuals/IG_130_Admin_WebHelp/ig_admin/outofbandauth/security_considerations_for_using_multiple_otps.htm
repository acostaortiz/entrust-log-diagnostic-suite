Security considerations for using multiple OTPs

In the default operation of one-time password delivery, an OTP is delivered only when needed for authentication, and the OTP has a lifetime of only three minutes.

When each user has multiple valid OTPs at the same time, you need to take extra care to minimize the risks of the OTPs being stolen.

To make use of the benefits of having multiple OTPs, set the OTP lifetime policy to a much longer time—an OTP may be valid for days or weeks. In addition, because all valid OTPs owned by a particular user have the same expiry date, if the number of OTPs is large enough, and the OTP lifetime long enough, it is possible that a specific OTP can be valid indefinitely.

When you configure out-of-band OTP authentication, consider the following security risks and employ a strategy to minimize them.

Security risk

Ways to minimize the risk

More valid OTPs means it may be easier for an attacker to guess the OTP.

Make the OTPs longer. A 6-digit OTP is more difficult to guess than a 4-digit OTP.

Increase the OTP alphabet to increase the number of possible combinations of characters.

Longer OTP lifetimes may give an attacker time to cycle through many OTPs and come up with a valid OTP.

Balance the number of OTPs each person has against the lifetime of the OTPs so that users are likely to cycle through all their OTPs within the OTP lifetime.

Users will have emails on their computers and text messages on their SMS devices that contain valid OTPs.

Users must keep their computers secure, and ensure that their mobile phones are not left where they might be compromised.
