Configure OTP delivery in voice messages

Entrust IdentityGuard provides a built-in, out-of-band delivery mechanism that allows you to deliver one-time-passwords (OTP) through telephone voice messages. The delivery mechanism assumes you are using the service offered by Authentify, Inc., but it also supports the service provided by TeleSign Corporation with only minor configuration changes. You might choose to use a different third-party service provider. Instructions are provided for all three scenarios. You must set up an account with the third-party provider before you configure Entrust IdentityGuard to use this service.

To use this delivery method, Entrust IdentityGuard must have telephone numbers for Entrust IdentityGuard users. See Create contact information for a user.

For additional information, see Authentify international telephone number rules or Telesign international telephone number rules.
