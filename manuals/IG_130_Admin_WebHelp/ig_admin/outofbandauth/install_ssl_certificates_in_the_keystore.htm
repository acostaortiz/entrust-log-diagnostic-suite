IdentityGuard Server 13.0 Administration Guide

Install an SSL certificate in the key store using keytool

Note: You can use the Key Store Management interface to do this. See Import a trusted certificate.

To use Clickatell. TeleSign, Authentify or another third-party service provider to supply out-of-band one-time passwords to your users, you must install the service provider's SSL certificate in the Entrust IdentityGuard key store. This procedure also applies when you are configuring an SMTPS server.

This procedure follows Download and install certificates for a third-party SSL connection.

To install an SSL certificate using they keytool utility

1.      Open a command window or terminal window on the Entrust IdentityGuard server.

2.      Change to the keytool.exe directory. The keytool utility is located in <$IG_HOME>\jdk<version>\bin (Windows) and $IG_HOME/jdk<version>/bin (Linux).

3.      Enter:

keytool -importcert -alias <alias_name> -keystore <$IG_HOME>/etc/keystore -storepass entrust -file <path_to_cert>

Where:

●       <alias_name> is an arbitrary name you assign to the certificate.

●       <$IG_HOME> is the directory in which Entrust IdentityGuard is installed.

●       <path_to_cert> is the location and filename of the certificate you are importing.

4.      Press Enter.

A confirmation message appears.

5.      Enter yes, and press Enter.

6.      To import multiple certificates, repeat Step 3 to Step 5 for each certificate.

7.      After you import all of the certificates, restart the Entrust IdentityGuard and application servers to register the imported certificates in the keystore.
