IdentityGuard Server 13.0 Administration Guide

TLS version downgrade

By default, Entrust IdentityGuard server 13.0 and Self-Service Module 13.0 specify TLS1.2 as the protocol to use when connecting to external services that require TLS such as TeleSign and ClickaTell (Entrust IdentityGuard server), or notify.entrust.com (Self-Service Module).

In the unlikely case that your installation must connect with an external service that does not support TLS1.2, you can add support for the older versions, TLS1.0 and TLS1.1 as described in this procedure. You should be aware, however, that TLS 1.0 is vulnerable to man-in-the-middle attacks, and both TLS 1.0 and TLS 1.1 do not offer modern cipher modes that are key to providing robust encryption.

Downgrade to TLS 1.0 or 1.1 on Linux

1.      In <$IG_HOME>, locate the env_settings.sh file.

2.      Create a backup copy of the file.

3.      Open the original file for editing.

4.      Locate the environment variable IG_CIPHER_OPTS. That variable has a default value that ends with -Djdk.tls.client.protocols=TLSv1.2.

5.      To add support for both TLS 1.0 and TLS 1.1, change the value to -Djdk.tls.client.protocols=TLSv1,TLSv1.1,TLSv1.2.To add support for TLS 1.1 only,change the value to -Djdk.tls.client.protocols=TLSv1.1,TLSv1.2.

6.      Save the file.

7.      From the <$IG_HOME>/bin directory, restart Entrust IdentityGuard using the following command:  

../igservice.sh identityguard restart

The new TLS protocol settings are used for all external services that require TLS connections.

Downgrade to TLS 1.0 or 1.1 on Windows

1.      Go to the bin folder of the Tomcat server associated with your Entrust IdentityGuard installation. The default location is "C:\Program Files\Entrust\IdentityGuard\apache-tomcat-<version>\bin".

2.      Create a backup copy of the service.bat file.

3.      Open the original service.bat file for editing.

4.      Locate the following line: set "IG_CIPHER_OPTS=-Djdk.tls.ephemeralDHKeySize=2048;-Djdk.tls.client.protocols=TLSv1.2"

To add support for both TLS 1.0 and TLS 1.1, change the value to -Djdk.tls.client.protocols=TLSv1,TLSv1.1,TLSv1.2.To add support for TLS 1.1 only,change the value to -Djdk.tls.client.protocols=TLSv1.1,TLSv1.2.

5.      Save the file.

6.      Stop the Entrust IdentityGuard server using the Windows Services panel.

7.      In a Windows command shell, run the following commands to remove the old file and install the updated file:

service.bat remove

service.bat install [IGHOME] [JDKHOME]

where

IGHOME is the full path to the Entrust IdentityGuard installation directory

JDKHOME is the full path to the current JDK folder. The default location is "C:\Program Files\Entrust\IdentityGuard\jdk-<version>"

8.      Start the Entrust IdentityGuard server using the Windows Services panel.

The new TLS protocol settings are used for all external services that require TLS connections.
