IdentityGuard Server 13.0 Administration Guide

Download and install certificates for a third-party SSL connection

Use the following procedure to import and install certificates required for connecting Entrust IdentityGuard to the third-party service provider that you are using for your voice or text messaging service.

Note: This procedure uses the Google Chrome browser. Steps may vary with other browsers.

To import third-party SSL certificates using Google Chrome

1.      Open a Google Chrome browser window and go to the site for your SMS service provider.

●       For Authentify, navigate to https://imp.authentify.com/s2s/default.asp.

●       For Clickatell, navigate to https://api.clickatell.com/rest/message.

●       For TeleSign, navigate to https://rest.telesign.com/.

Note: Your SMS service provider URL may be different. Use the URL assigned when you subscribed to the application.

2.      Click the lock icon in the browser address bar.

3.      On the drop-down text box that appears, select Certificate (Valid).

4.      On the Certificate dialog box, select the Certification Path tab. This shows you the entire chain of certificates.

The one at the bottom is the SSL certificate. In this example, it is *.telesign.com. You will not need this certificate.

5.      Select the certificate immediately above it, Thawte RSA CA 2018 and click View Certificate.

6.      Select the Details tab, and then click Copy to File.

The Certificate Export Wizard opens.

7.      Click Next.

8.      On the Export File Format page of the wizard, ensure that the first option, DER encoded binary X.509 (.CER), is selected, and then click Next.

9.      On the File to Export page, click Browse. On the page that opens, enter a descriptive file name for the cert (for example, ThawteRSACA2018.cer) and select a convenient location to save it, then click Save.

10.  On the File to Export page, click Next. The wizard confirms that the certificate file is exported and saved in the location you specified.

11.  Return to the Certificate dialog box and select the Certification Path tab. This shows you the remaining chain of certificates. The one at the bottom is the Thawte certificate that you have already downloaded.

12.  Select the certificate immediately above it, DigiCert, and click View Certificate.

13.  Select the Details tab, and then click Copy to File.

The Certificate Export Wizard opens.

14.  Click Next.

15.  On the Export File Format page of the wizard, ensure that the first option, DER encoded binary X.509 (.CER), is selected, and then click Next.

16.  On the File to Export page, click Browse. On the page that opens, enter a descriptive file name for the cert (for example, DigiCertGlobalRoot.cer) and select a convenient location to save it, then click Save.

17.  On the File to Export page, click Next. The wizard confirms that the certificate file is exported and saved in the location you specified.

18.  Click Finish, and then close all open dialogs and browser pages. You should now have the entire chain of certificates as separate files (except for the SSL certificate itself).

19.  Copy the certificates to each Entrust IdentityGuard server that needs to use the third-party application.

20.  Use the Key Store Management interface to install the certificates into the key store on each Entrust IdentityGuard server that needs to use the third-party application. Install the certificates in the following order:

a.      Root certificate, for example DigiCertGlobalRoot.cer.

b.      Intermediate certificate, for example ThawteRSACA2018.cer.

For instructions, see Import a trusted certificate.
