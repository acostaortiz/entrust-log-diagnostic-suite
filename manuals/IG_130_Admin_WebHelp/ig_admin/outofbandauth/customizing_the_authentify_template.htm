Customize the Authentify template

Authentify requests require an XML template file. Entrust IdentityGuard includes an Authentify template file that you can use: authentify_template.xml. By default, the file is found in the following location:

●       on Windows: <$IG_HOME>\etc\templates\oob\

●       on Linux: $IG_HOME/etc/templates/oob/

Entrust IdentityGuard uses the values set in the related properties, such as the account name and password, to populate fields in the XML request. It then adds the user’s telephone number, PVN, and automatically generated one-time password. You can edit the template file to change how the fields are arranged.

Note: Before editing the template, save a copy of the original.

Note: If you are required to work with configuration files directly in Microsoft Windows, ensure that file extensions are visible. See Ensure that file extensions are visible in Windows Explorer.

Authentify uses an XML template file, with variables filled in with the user name and OTP, for example. After Authentify receives this XML request, the automated phone message is sent quickly, often in seconds (though the pause can be as long as a minute). The user receiving the call follows the voice prompts and supplies a PVN, either through the keypad or by speaking it, and writes down the OTP given. The user then enters the OTP and the PVN to complete the step-up authentication.

Note: Authentify messages require the person answering the call to provide a confirmation number. Entrust IdentityGuard expects the personal verification number (PVN) as confirmation, so Authentify is not available to users who are not assigned a PVN. For more information about the PVN, see Personal verification number overview.
