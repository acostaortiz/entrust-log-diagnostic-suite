IdentityGuard Server 13.0 Administration Guide

Use a proxy server with the TeleSign SMS service provider

This is an optional procedure.

If your organization uses a proxy server to send messages to the TeleSign SMS service provider, add the proxy configuration to the Java startup options for your Entrust IdentityGuard installation. Complete the steps appropriate for your installation's operating system.

 To add a TeleSIgn SMS proxy configuration to the Java startup options on Windows

1.      Stop the Entrust IdentityGuard Server service.

2.      Modify the Java system properties for Entrust IdentityGuard in the Window registry. They are found in the Tomcat settings for Entrust IdentityGuard. You can find the registry entry by searching the Windows registry for Dcatalina.base.

3.      Append the following lines to the end of the registry entry:

a.      To include the proxy server, enter the following setting:

-Dhttps.proxyHost=<host> -Dhttps.proxyPort=<port>

where

<host> is the name of the computer that hosts the proxy server.

<port> is the port used for proxy server communication.

b.      To exclude localhost, machine name, and repositories, enter the following setting:

-Dhttps.nonProxyHosts=localHost

 

Example with TeleSign proxy server settings added (bold text):

-Dcatalina.base=C:\Program Files\Entrust\IdentityGuard\apache-tomcat<version>

-Djava.library.path=C:\Program Files\Entrust\IdentityGuard\identityguard<version>\lib\win64

-Dcatalina.home=C:\Program Files\Entrust\IdentityGuard\apache-tomcat<version>

-Djava.endorsed.dirs=C:\Program Files\Entrust\IdentityGuard\apache-tomcat<version>\common\endorsed

-Didentityguard.home=C:\Program Files\Entrust\IdentityGuard\identityguard<version>

-Djavax.net.ssl.trustStore=C:\Program Files\Entrust\IdentityGuard\identityguard<version>\etc\keystore

-Dcatalina.base=C:\Program Files\Entrust\IdentityGuard\apache-tomcat<version>

-Djava.library.path=C:\Program Files\Entrust\IdentityGuard\identityguard<version>\lib\win64

-Dcatalina.home=C:\Program Files\Entrust\IdentityGuard\apache-tomcat<version>

-Djava.endorsed.dirs=C:\Program Files\Entrust\IdentityGuard\apache-tomcat<version>2\common\endorsed

-Didentityguard.home=C:\Program Files\Entrust\IdentityGuard\identityguard<version>

-Djavax.net.ssl.trustStore=C:\Program Files\Entrust\IdentityGuard\identityguard<version>\etc\keystore

-Djava.io.tmpdir=C:\Program Files\Entrust\IdentityGuard\apache-tomcat<version>\temp

-XX:MaxPermSize=192M

-Dhttps.proxyHost=proxy.mycorp.com -Dhttps.proxyPort=443 -Dhttps.nonProxyHosts=localHost

4.      Restart the Entrust IdentityGuard Server service.

 

 To add a TeleSign SMS proxy configuration to the Java startup options on Linux

1.      Stop the Entrust IdentityGuard Server service.

2.      Modify /opt/entrust/identityguard<release>/env_settings.sh.

a.      Look for the line "IG_CUSTOM="

b.      Change it to:  IG_CUSTOM=-Dhttps.proxyHost=<host> -Dhttps.proxyPort=<port>

where

<host> is the name of the computer that hosts the proxy server.

<port> is the port used for proxy server communication.

3.      To exclude localhost, machine name, and repositories, enter the following setting:

-Dhttps.nonProxyHosts=localHost
