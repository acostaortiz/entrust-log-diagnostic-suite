IdentityGuard Server 13.0 Administration Guide

Configure Self-Service Module for use with SMS messaging

If you are using Self-Service Module release 12.0 Patch 68031 (or newer) with Entrust IdentityGuard, you can configure user Self-Registration to prompt users to provide a mobile phone number to be used for sending OTPs.by SMS. For details, see "Configure self-registration of personal information" in the Entrust IdentityGuard Self-Service Module Installation and Configuration Guide.

If you are using a version of Self-Service Module prior to release 12.0 Patch 68031 with Entrust IdentityGuard, use the instructions in the following technote:

https://trustedcare.entrustdatacard.com/TrustedCare/articles/en_US/Technote/How-do-I-configure-IdentityGuard-Self-Service-Server-to-map-user-contact-information-to-Entrust-IdentityGuard-SMS-delivery-methods
