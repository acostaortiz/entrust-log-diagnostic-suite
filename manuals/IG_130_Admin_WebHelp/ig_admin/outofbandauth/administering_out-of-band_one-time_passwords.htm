Administering out-of-band one-time passwords

This section describes how to find, create and delete a one-time password for a user:

●       Search for users with an out-of-band one-time password

●       Create out-of-band one-time passwords for a user

●       Modify a user account for out-of-band OTP use

●       Deliver a one-time password to a user

●       Change the out-of-band OTP expiry date

●       Delete out-of-band one-time passwords

Administrators must have the correct role permissions to complete these procedures. See User one-time password permissions for a list of all role permissions relating to one-time passwords.
