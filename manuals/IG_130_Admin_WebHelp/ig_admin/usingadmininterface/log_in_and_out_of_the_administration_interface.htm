IdentityGuard Server 13.0 Administration Guide

Log in and out of the Administration interface

To use the Administration interface, all administrators must log in using one of the following methods:

●       Password login to the Administration interface

●       Smart credential login to the Administration interface

●       SAML login to the Administration interface

●       External authentication to the Administration interface

The administrator’s session times out after the idle timeout value is reached, as specified in the Idle Timeout administration policy. The default is 15 minutes. The Idle Timeout policy affects all applications that use the Administration API. When the session times out, you must reauthenticate.

The Web application that hosts the Administration interface has another timeout associated with it. By default, it times out after 30 minutes of inactivity even if the Administration interface idle timeout value is set to be greater than 30 minutes. The login timeout values associated with the Web applications are set on an application by application basis.

Note: If you cannot reach either of the Entrust IdentityGuard services (Administration or Authentication), verify that firewall rules are not blocking their HTTPS ports (default 8443 and 8444, respectively).
