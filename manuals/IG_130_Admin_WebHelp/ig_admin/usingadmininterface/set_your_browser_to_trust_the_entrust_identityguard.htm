IdentityGuard Server 13.0 Administration Guide

Set your browser to trust the Entrust IdentityGuard certificate

The first time you access the Administration interface or Properties Editor, your browser might not recognize the self-signed certificate provided by Entrust IdentityGuard. Consequently, the browser might display a Web page warning that there is a problem with the Web site’s certificate. Ignore this warning and continue to the website.

This warning occurs because the website is using a self-signed certificate. If you replace the certificate with a CA-signed one, no such is displayed. For information about obtaining a CA-signed certificate, see the Entrust IdentityGuard Installation Guide.

Your browser may have an option to save the security exception. Select that option to avoid seeing the warning in subsequent sessions until you replace it with a CA-signed certificate.
