IdentityGuard Server 13.0 Administration Guide

Smart credential login to the Administration interface

This method of login requires pre-configuration of smart credential authentication in your Entrust IdentityGuard implementation. For full details, see the Entrust IdentityGuard Smart Credentials Guide.

When your system supports smart credential authentication, complete the procedures in Configuring smart credential authentication to the Administration interface.

When all configuration is complete, administrators follow these steps to log in.

To log in to the Administration interface with a smart credential

1.      Start the Entrust IdentityGuard Administration interface.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locating your Administration interface URL.

2.      On the Administrator Log In page, click Smart Credential Log In.

The Entrust IdentityGuard Administration home page appears.
