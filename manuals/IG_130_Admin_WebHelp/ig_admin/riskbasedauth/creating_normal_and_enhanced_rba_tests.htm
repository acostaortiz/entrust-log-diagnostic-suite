Create normal and enhanced RBA tests

This section explains how to create RBA test expressions in the Master user shell.

There are four policy rba set command attributes to set authentication behavior under normal and enhanced security. The four policies are:

●       normalReject

●       normalAuthenticated

●       enhancedReject

●       enhancedAuthentication

The default test expressions for normal and enhanced security are described in the following table. These expressions are equivalent to the defaults shown in the RBA policy screen in the Administration interface. To set these policies in the Administration interface, see Set normal and enhanced RBA policies.

Policy

Default RBA expression

Description

normalReject

FAIL(IP_IPBLACKLIST)

FAIL(IP_COUNTRYBLACKLIST

FAIL(CERTAUTH_CERTVALID)

A normal request will be rejected if the IP blacklist or country blacklist checks fail or if the certificate is not valid.

normalAuthenticated

PASS(MACHINEAUTH) + NOTFAIL(IP) + NOTFAIL(CERTAUTH) + NOTFAIL(EXTERNAL_RISK)

PASS(CERTAUTH) + NOTFAIL(IP) + NOTFAIL(MACHINEAUTH) + NOTFAIL(EXTERNAL_RISK)

A normal request will be authenticated if machine authentication passes and none of the other tests fail, or if certificate authentication passes and none of the other tests fail.

enhancedReject

FAIL(IP_VELOCITY)

An enhanced request will be rejected if the IP blacklist, country blacklist, or velocity checks fail, or if a specified certificate is not valid.

(The normal reject policy is enhanced with the addition of the Velocity test.)

enhancedAuthenticated

<empty list>

In the default case, an enhanced request will never be authenticated.

For the enhanced mode, the test results are rejected if they match the enhanced reject policy or the normal reject policy. That is, any test condition that causes a failed authentication using the normal policy also causes authentication failure using the enhanced policy. The normal and enhanced authentication definitions can be equal in strength.

For the normal mode, the test results are authenticated if they match the normal authenticated policy or the enhanced authenticated policy. That is, if a test condition authenticates you for the enhanced policy, it will also authenticate you for the normal policy.
