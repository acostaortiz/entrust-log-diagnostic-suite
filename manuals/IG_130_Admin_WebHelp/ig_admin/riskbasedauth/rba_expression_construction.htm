RBA expression construction

RBA expressions are expressions built from a PASS or NOTPASS; FAIL or NOTFAIL, followed by the test performed. The PASS/FAIL parameters are interpreted as follows:

●       PASS

Authentication is successful if the test passes.

Example: PASS(MACHINEAUTH)

●       NOTPASS

Authentication fails if the test is not performed or the test fails. Use this construct when you want to fail the test only if the specified test fails, not if it is not run.

Example: NOTPASS(CERTAUTH)

●       FAIL

Authentication fails if the test fails.

Example: FAIL(IP_BLACKLIST)

●       NOTFAIL

Authentication passes if the test is not performed or the test passes. Use this construct when you want to pass the test as long as the specified test passes, not if it is not run.

Example: NOTFAIL(CERTAUTH)
