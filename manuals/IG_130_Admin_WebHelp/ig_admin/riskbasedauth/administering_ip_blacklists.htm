Administering IP blacklists

When a user logs in to your site and risk-based authentication is enabled, the user’s IP address is compared to all addresses in the IP blacklist. If there is a match, the IP blacklist test fails.

No comparison with the IP blacklist or country blacklist occurs if the current address is on the expected IP location list.

Through the Administration interface, you can review and update the IP blacklist. For information about managing the country blacklist, see Configuring risk-based authentication policies.
