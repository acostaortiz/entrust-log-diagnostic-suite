IdentityGuard Server 13.0 Administration Guide

Configure IP/Geolocation policies

Use the IP/Geolocation policy settings to control policy for the location history list, IP velocity, the expected location list, and the country blacklist.

To view or edit IP/Geolocation policy

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      Select Policies on the menu bar.

A list of all policies appears on the List Policies tab.

3.      Click any policy name to view its policy information.

The View Policy page appears and lists all policy settings.

4.      Under Policy Category, select IP/Geolocation from the list.

The IP/Geolocation policies appear.

5.      To edit the policy, on the View Policy page, click Edit Policy.

An editable version of the settings appear. 

6.      Edit the policies as required. Select a policy in the list to see its description.

Normal Security Level — Reject User

When an authentication test fails at the normal security level, this policy sets which failures result in a rejection of the user.

For a description of the choices, see Using risk-based authentication tests.

Normal Security Level — Authenticate User

When an authentication test passes at the normal security level, this policy sets what combination of successes result in automatic authentication.

For a description of the choices, see Using risk-based authentication tests.

Enhanced Security Level — Reject User

When an authentication test fails at the enhanced security level, this policy sets which failures result in a rejection of the user.

Enhanced Security Level — Authenticate User

When an authentication test passes at the normal security level, this policy sets which combination of successes result in automatic authentication.

7.      Click Save Changes.
