IdentityGuard Server 13.0 Administration Guide

Setting up IP/Geolocation authentication

Use these steps to configure IP/Geolocation:

1.      Entrust IdentityGuard is configured to use MaxMind as the source for IP/Geolocation data. For information about MaxMind data, see https://dev.maxmind.com/faq/category/geoip-general/.

2.      Ensure that your application can supply valid IP addresses to Entrust IdentityGuard. See the Entrust IdentityGuard Programming Guide.

3.      Ensure that administrators have the required permissions to set policy and do the rest of the tasks in this list. See User location permissions.

4.      Using the System pages of the Administration interface, create or import an IP blacklist. See Managing the IP blacklist.

5.      Using the Properties Editor:

a.      Set the properties related to IP/Geolocation, if applicable. See Configuring IP/Geolocation policies.

b.      Set the IP/Geolocation properties related to the Radius proxy, if applicable. See Configuring the Radius proxy for risk-based authentication.

6.      Using the Policies pages of the Administration interface, do the following (also see Configuring risk-based authentication policies):

c.      Set the normal security level policies related to rejecting, challenging, or automatically authenticating a user.

d.      Set the enhanced security level policies related to rejecting, challenging, or automatically authenticating a user.

7.      Set policy related to the location history list, expected location list, and velocity test.

8.      Modify the expected location list, and create personal user expected location lists as needed. See Using the expected IP location list.

9.      Optional: Modify the country blacklist. See Configuring risk-based authentication policies.
