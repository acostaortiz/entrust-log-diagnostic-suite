IdentityGuard Server 13.0 Administration Guide

Search for users by location history

The Administration interface lets you search for users based on a wide range of criteria. You can search for users based on their location history entries.

To find users by IP/Geolocation history

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start and expand Entrust  IdentityGuard in the list of applications. Select Administration Interface. For other login scenarios, see Log in and out of the Administration interface.

On Linux or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

For other login scenarios, see Log in and out of the Administration interface.

2.      Click User Accounts on the main menu.

3.      From the User Accounts page, click the Find Accounts tab.

The Search Options page appears.

4.      Click Has the additional account characteristics below.

The Additional Account Characteristics pane appears. There is one user search option that applies to location history.

5.      To find users with location history entries, select Has between [ ] and [ ] location history entries, then do one of the following:

●       To find users with a minimum number of location history entries or more, enter the minimum number in the first text field.

●       To find users with a maximum number of location history entries or fewer, enter the maximum number in the second text field.

●       To find users with any number of location history entries in a range, enter the minimum number in the first text field, and enter the maximum number in the second text field.

6.      Select other search options as applicable (see Searching for user information for details).

7.      Click Find Accounts.

The Search Results page appears.

8.      Click a user name.

The Account Information pane appears.

9.      Scroll down to Authentication Types, click Location and review the user’s location settings.

For information about changing information about the settings, see Set IP/Geolocation options for individual users.
