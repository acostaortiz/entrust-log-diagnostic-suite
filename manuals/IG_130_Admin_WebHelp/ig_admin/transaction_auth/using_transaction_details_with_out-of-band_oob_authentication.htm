Using transaction details with out-of-band (OOB) authentication

Transaction details can be verified by the user when using out-of-band authentication. The out-of-band message allows the customer to determine if the transaction details submitted with the challenge request were modified. The transaction authentication ensures that the transaction details submitted with the authentication match those from the challenge.

For information about configuring out-of-band authentication, see Out-of-band one-time password authentication.
