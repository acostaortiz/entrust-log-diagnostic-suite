IdentityGuard Server 13.0 Administration Guide

Generate and manage reports

You can generate reports from the Administration interface and from the Master user shell, and you can view reports from the Administration interface. You cannot view reports from the Master user shell.

You can view reports only from the same Entrust IdentityGuard server that created the report, unless the Entrust IdentityGuard servers share a file system. 

When you launch a new report, the report job is added to the report queue. The report queue has a configurable capacity, with a default maximum queue size of 100 reports, and reports are run, one at a time, on a first-come, first-served basis. If you launch a report, and the report generation queue is already at capacity—there are already 100 reports in the queue, for example—then your report launch fails. You can try again in a few minutes, as reports are completed and leave the queue.

Note: After reports have started the data gathering stage, you cannot delete or update the report.

Each time a report is generated, a message is recorded in the log file. If there are no records found when the report is generated, you still get a report, but it does not show any data and there is a message in the log file.

Attention: If the Entrust IdentityGuard service is stopped for any reason, all reports in the report generation queue are lost.
