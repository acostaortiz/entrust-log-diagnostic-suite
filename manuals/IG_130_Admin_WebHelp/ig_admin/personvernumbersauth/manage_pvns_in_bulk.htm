IdentityGuard Server 13.0 Administration Guide

Manage PVNs in bulk

Bulk files imported through the Bulk Operations tab of the Administration interface can create, change or delete PVNs.

One field in the input file, pvn, can contain the numeric PVN. Alternatively, any pvn field can include the autogenerate command. When Entrust IdentityGuard encounters this command, it generates a random PVN using a random-number generator for each digit in the PVN.

For more information about bulk operations, see Personal verification number bulk operations.

To manage personal verification numbers for users in bulk

1.      Log in to the Administration interface (see Log in and out of the Administration interface).

2.      Click Bulk Operations from the main menu.

3.      From the Bulk Operation page, click Browse to add the data file. For more information about data files for bulk operations, see Perform bulk operations in the Administration interface .

4.      From the Operation to Perform drop-down list, select the applicable PVN option:

●       Create PVNs for users

●       Modify user PVNs

●       Delete user PVNs

5.      From the Halt Processing drop-down list, select the number of errors to allow before processing stops due to too many errors. (See Validate a bulk file.)

6.      Click Perform Bulk Operation.

The Bulk Operation in Progress page appears. The size of your bulk operation directly affects the time the operation takes to process. This page indicates the initial status of the operation.

7.      Click Update Results to view the status of your bulk operation.

8.      Click Done to return to the Bulk Operation page.
