IdentityGuard Server 13.0 Administration Guide

Modify personal verification numbers

Administrators with applicable permissions can change PVNs for users.

To modify a PVN for a user

1.      Find one or more users with a PVN. (See Search for users by personal verification number.)

On the Find Accounts page, be sure to select the Has a PVN option as part of your search criteria.

2.      Select a user on the Search Results page.

The Account Information pane appears for the user.

3.      Under Authentication Types, click Personal Verification Number.

4.      Click Change PVN.

The Change PVN page appears.

5.      Change the PVN value in one of two ways:

●       Enter a value next to Personal Verification Number. The value must match the length set by policy.

●       Select Autogenerate PVN to have Entrust IdentityGuard create a random number.

6.      Select Change Is Required On Next Usage to force the user assigned the PVN to provide an update the next time the PVN is used. Use this option if administrators modify or distribute PVNs to users to ensure that users operate with a PVN known only to them. This is not necessary if users create their own PVNs through your application. Depending on policy, you may not be able to deselect this option (see Force PVN updates.)

Note: The Radius proxy does not support the updating of PVNs except through the PAP protocol.

7.      Click Change PVN.

The Account Information pane reappears for the user showing the new PVN information.
