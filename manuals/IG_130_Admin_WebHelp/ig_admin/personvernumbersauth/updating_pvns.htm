IdentityGuard Server 13.0 Administration Guide

Updating PVNs

When creating or changing a PVN, the Change Is Required On First Usage or Change Is Required On Next Usage check box is enabled automatically. It is good practice to have each user update their own PVN so that only they know what its value is. If the Change Required On Administrator Reset policy is enabled, there is no way to deselect the check box and users must always update a PVN created or modified for them. (Also see Forcing PVN updates.)
