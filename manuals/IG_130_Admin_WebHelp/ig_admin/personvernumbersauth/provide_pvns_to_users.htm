IdentityGuard Server 13.0 Administration Guide

Provide PVNs to users

After you create PVNs for users in bulk or through the Administration interface, you need to distribute the correct PVN to each user. In a typical user registration process, your application should ask for a postal address, an email address, and a cell phone number. With this information, you can contact each user and provide their new PVN by phone, mail or email.

Since PVNs created by administrators are not confidential, you can have your application force a PVN update the first time a user authenticates with the new PVN (see Force PVN updates.)
