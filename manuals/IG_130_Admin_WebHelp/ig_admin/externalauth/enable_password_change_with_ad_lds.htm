IdentityGuard Server 13.0 Administration Guide

Enable password change with AD LDS

If you are using external authentication with Microsoft Active Directory Lightweight Directory Service (AD LDS) as your repository, and you want password change to work, you must complete one of the following tasks:

●       Enable SSL between AD LDS and Entrust IdentityGuard. See Secure the LDAP connection with SSL.

OR

●       Configure AD LDS to allow password change operations to be performed over a non-SSL connection. See http://technet.microsoft.com/en-us/library/cc732352%28WS.1%29.aspx for details.

The following is an example of the series of command for allowing AD LDS password change over a non-SSL connection.

Commands for allowing AD LDS password change over a non-SSL connection

C:\WINDOWS\ADLDS>dsmgmt

dsmgmt: ds behavior

ds behavior: connections

server connections: connect to server

localhost:389

Binding to localhost:389 ...

Connected to localhost:389 using credentials of locally logged on user.

server connections: quit

ds behavior: list current ds-behavior

Password operations on unsecured connection: Denied.

ds behavior: allow passwd op on unsecured connection

Successfully modified DS Behavior to reset password over unsecured network.

ds behavior: list current ds-behavior

Password operations on unsecured connection: Allowed.

ds behavior: quit

dsmgmt: quit
