IdentityGuard Server 13.0 Administration Guide

Overview of the Key Store Management tab

If your Entrust IdentityGuard installation uses the embedded Tomcat application server, the Administration interface includes a Key Store Management interface .

Use the Key Store Management tab to perform certificate-related functions such as replacing the self-signed tomcat certificate and tracking and updating certificates that are about to expire.

To see the Key Store Management interface, select System from the top menu, and then select the Key Store Management tab.

Note:  To use this feature, you must log in to the Administration interface with an account that includes the keystoreManage permission (in the Application-Specific permissions category). The superuser role is the only built-in role that has this permission enabled by default.

The Key Store Contents table contains two sections: Private Keys and Trusted Certificates.

●       Each row in the Private Keys list represents a key pair. Each key pair contains a private key that is kept on the Entrust IdentityGuard server, and a public key, which is stored in a certificate and often signed by a Certificate Authority (CA). The public key is given out freely. Together these two keys enable secure communication between a server and its clients using server-authenticated SSL. The tomcat entry contains the Entrust IdentityGuard server's private key and its associated public certificate.

●       Each row in the Trusted Certificates list contains certificates that have been imported into Entrust IdentityGuard. Those can include an Entrust Root Certificate, the root certificates of other CAs, some intermediate certificates that complete the validation chain between your CA-signed tomcat server certificate and the Entrust Root Certificate, and the SSL server certificates of external services that the Entrust IdentityGuard server needs to interact with. When you add an external certificate, your Entrust IdentityGuard server requires that you trust it. When the certificate is trusted, Entrust IdentityGuard is able to communicate with other servers whose public certificates match those in your key store.

Certificate details

The list shows summary information for each entry in the table. To see detailed information about a selected certificate, click the down arrow in the Actions column. The detailed information includes:

●       Expiry Date as found in the summary row but expanded to include the time in addition to the date.

●       Subject (Owner) The distinguished name (DN) as found in the summary row.

●       Issue Date The date and time that the certificate was issued.

●       Issuer The distinguished name of the issuer.

●       Signature Algorithm. The hashing algorithm (for example, SHA1), along with the public key encryption algorithm (for example, RSA).

●       Serial Number of the certificate.

●       Fingerprint The certificate fingerprints using MD5, SHA-1, and SHA-256.
