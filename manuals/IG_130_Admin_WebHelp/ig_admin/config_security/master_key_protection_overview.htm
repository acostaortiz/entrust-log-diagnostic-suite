IdentityGuard Server 13.0 Administration Guide

Master key protection overview

Master keys protect any encrypted information stored in the repository. This includes card grids, temporary PINs, question and answer values, authentication secrets, and more.

Entrust IdentityGuard uses master keys for encryption and creating message authentication codes (MAC), which protect data integrity.

For all information stored in the Entrust IdentityGuard repository, MACs are created using HMAC-SHA256 to prevent unauthorized modification of the data. Sensitive information stored in the Entrust IdentityGuard repository is also encrypted using AES-256. The protection keys are stored securely on the Entrust IdentityGuard system and bound to the host. Optionally, your organization can use a Hardware Security Module (HSM) to store Entrust IdentityGuard’s master keys. For more information, see Updating the HSM password and the Entrust IdentityGuard Installation Guide.

The Master keys are stored in a master key (.enc) file. It contains the encrypted versions of the master users’ keys.

Keys in the master key file are protected as follows:

●       the master keys are wrapped by an encryption key

●       the encryption key is encrypted by keys derived from each of the three master user passwords

Another file, the key protection file, (.kpf) allows Entrust IdentityGuard services to access the master keys without administrator intervention. Also see Binding and unbinding the master keys.

Master users have the option of binding or unbinding the key protection (.kpf) file. When you bind the key protection file, Entrust IdentityGuard uses machine-specific information when creating the key protection file, so as to create a file that is valid only on that machine. This allows for additional security because an attacker cannot take the key files to another computer and use them there. However, this does affect your load-balancing, failover deployment, and your Entrust IdentityGuard computer if you change hardware parts. Changing hardware parts may require you to rebind the password file.
