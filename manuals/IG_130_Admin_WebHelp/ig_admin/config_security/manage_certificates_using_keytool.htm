IdentityGuard Server 13.0 Administration Guide

Manage certificates using keytool

Use the procedures in this section to manage certificates in the key store as alternative to the Key Store Management interface.

IMPORTANT:
You must not delete the tomcat entry because to do so would make it impossible for Entrust IdentityGuard to communicate using SSL.

You must always have at least one trusted certificate in the key store in order for Tomcat to start.

The Key Store Management interface prevents you from making these changes. There is no such safeguard if you manage your key store with keytool or another key store management tool.

If you accidentally remove all trusted certificates from the keystore, you must add at least one trusted certificate to the key store using keytool for Tomcat to start. Use the steps described in Import certificates using keytool.
