Binding the master keys

Perform system binding on the master keys to:

●       rebind master keys that were unbound

●       rebind master keys after a hardware change, as required

●       complete initializing of a replica or restoring from a backup

Note: When you perform initialization of a primary system through the Master user shell (using the init command), or perform initialization through the Windows Configuration Panel, this automatically binds the master keys.

By default, Entrust IdentityGuard binds the Master Keys to the local computer hardware in such a way that minor changes to the hardware still allows the Entrust IdentityGuard services to start. You can also bind the master keys in strict mode. In strict mode, minor hardware changes will cause the services to fail to start.

To bind the master keys

1.      Start the Master user shell in Linux or Windows on the machine where you want to bind the master keys (see Using the Master user shell).

2.      Enter the following command:

system bind [-strict]

Where -strict binds the binds the Master Keys to the local computer hardware in strict mode. In strict mode, minor hardware changes will cause the services to fail to start.

3.      When prompted, enter your master user name and password.
