IntelliTrust migration audit messages

These messages provide information about the process of migrating Entrust IdentityGuard data and authenticators to Entrust Datacard IntelliTrust. For more information, see Migration to Entrust Datacard IntelliTrust..

 

Audit name

Log level

Default SNMP trap?

Event description

IntelliTrust Migration Export Start

(AUD8500)

INFO

Yes

IntelliTrust Migration authenticator export started

IntelliTrust Migration Export Failed

(AUD8501)

ERROR

Yes

IntelliTrust Migration authenticator export failed

IntelliTrust Migration Export Finished

(AUD8502)

INFO

Yes

IntelliTrust Migration authenticator export completed with status {0}.

Where:

·      {0} is a string with information about the export.

Example:

authexport: Export file: C:\Program Files\Entrust\IdentityGuard\identityguard120\testexport9.dat, steps completed: 2 of 2, user number: 156 of maximum user number: 156, exported users: 79 of possible 156, exported unassigned tokens: 28, Done at: Fri Oct 20 07:38:33 GMT-04:00 2017
