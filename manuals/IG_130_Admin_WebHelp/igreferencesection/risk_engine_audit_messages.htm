IdentityGuard Server 13.0 Administration Guide

Risk engine audit messages

These messages provide information about operations that involve the iovation risk engine integration. For more information, see Using external risk engine data for RBA authentication.

 

Audit name

Log level

Default SNMP trap?

Event description

Device paired with account

(AUD8300)

INFO

 

Paired device id {0} with Entrust IdentityGuard user account {1}, using external user id {2}, for Risk Engine {3}. {4}

Where:

{0} - device id

{1} - userid

{2} - external user id (hashed)

{3} - external risk provider

{4} - details about the device

Example:

Paired device id 0123456789 with Entrust IdentityGuard user account default/jdoe, using external user id ADFA3241254FDF0, for Risk Engine iovation. OS: Windows, Browser: TRIDENT

One device unpaired from account

(AUD8301)

INFO

 

Unpaired device id {0} associated with Entrust IdentityGuard user account {1}, using external user id {2}, for Risk Engine {3}.

Where:

{0} - device id

{1} - userid

{2} - external user id (hashed)

{3} - external risk provider

Example:

Unpaired device id 0123456789 associated with Entrust IdentityGuard user account default/jdoe, using external user id ADFA3241254FDF0, for Risk Engine iovation.

All devices unpaired from account

(AUD8302)

INFO

 

Unpaired {0} device(s) associated with Entrust IdentityGuard user account {1}, using external user id {2}, for Risk Engine {3}.

Where

{0} - number of devices unpaired

{1} - userid

{2} - external user id (hashed)

{3} - external risk provider

Example:

Unpaired 3 device(s) associated with Entrust IdentityGuard user account default/jdoe, using external user id ADFA3241254FDF0, for Risk Engine iovation.

Authentication failure reported to risk engine

(AUD8303)

ERROR

 

Failed authentication using Risk Engine {0} for Entrust IdentityGuard user account {1}, using external user id {2}, for device id {3}.

Where:

{0} - external risk provider

{1} - userid

{2} - external user id (hashed)

{3} - device id

Example:

Failed authentication using Risk Engine iovation for Entrust IdentityGuard user account default/jdoe, using external user id ADFA3241254FDF0, for device id 0123456789.

External Risk Engine explicit deny reason

(AUD8304)

ERROR

 

Risk Engine {0} rejected device id {1} with reason: {2}.

Where:

{0} - external risk provider

{2} - device id

{3} - reason

Example:

Risk Engine iovation rejected device id 0123456789 with reason: invalid admin username or password.
