IdentityGuard Server 11.0 Administration Guide

Import third-party SSL certificates

Use the following procedure to import SSL certificates from third-party application provider.

To import third-party SSL certificates using Microsoft Internet Explorer

1.      Open Internet Explorer, and browse to the certificate location for the application you are using.

●       For Authentify, navigate to https://imp.authentify.com/s2s/default.asp.

●       For Clickatell, navigate to https://api.clickatell.com/.

●       For another provider, consult the documentation provided with your subscription.

Note: Your Authentify or Clickatell URL may be different. Use the URL assigned when you subscribed to the application.

2.      Click the lock icon. The lock icon is next to the navigation bar in Internet Explorer 7.0 and 8.0.

The Certificate dialog box appears.

3.      Click View Certificates.

4.      Click Install Certificate.

This opens the Certificate Import wizard.

5.      Click Next.

6.      Select Automatically select the certificate based on the type of certificate if you want to store it automatically. If you would like to choose the storage location for the certificates, select Place all certificates in the following store and browse to your chosen location.

7.      A dialog box appears, listing the location of the imported certificate.

8.      Click Finish.

9.      After you have imported the certificate, you must export it to a file.

a.      Click Tools > Internet Options.

b.      Select the Content tab.

c.      Click Certificates.

d.      Click Other People.

e.      Select the certificate and click Export.

f.        Follow the instructions in the Certificate Export Wizard to save the certificate to a file on your machine.

10.  Copy the certificate to each Entrust IdentityGuard server that needs to use the third-party application.

11.  Use the JDK keytool to import them one by one to the keystore. See Installing SSL certificates into the keystore.
