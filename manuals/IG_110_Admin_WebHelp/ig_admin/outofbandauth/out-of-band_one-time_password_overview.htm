Out-of-band one-time password overview

A one-time password (OTP) is a temporary password that is used once, and then discarded immediately. An out-of-band OTP is sent to a user through email, a phone message, a text message (SMS), or by another delivery mechanism. It is called "out-of-band" because the password is delivered by a means other than the one that was used to request the OTP, usually a Web-based application or custom interface (for example, a bank machine).

A one-time password is useful in the following types of scenarios:

●       You want an already-authenticated user to re-authenticate. For example, a use may have already authenticated to log in to a banking Web site, but the bank might request an OTP when the user attempts to transfer a large amount of money. The OOB OTP means the bank and the user use 2 channels to communicate. If malicious code had been inserted in the user’s computer browser, the attacker might gain access to the data flowing between the browser and the server, but also would have to gain access to the out-of-band message, be it an email, SMS, or phone message. A successful attack in such a scenario is much less likely.

●       You need to provide users with one-time access to your system. For example, when users lose their tokens or grids, they can request an OOB OTP. This OTP can then be used once to log in to your system to report the loss of the authenticator and initiate getting a temporary or permanent replacement,
