Configure OTP delivery in voice messages

Entrust IdentityGuard provides a built-in, out-of-band delivery mechanism that allows you to deliver one-time-passwords (OTP) through telephone voice messages. The delivery mechanism assumes you are using the service offered by Authentify, Inc., but it also supports the service provide by TeleSign Cororation with only minor configuration changes. You might choose to use a different third-party service provider. Instructions are provided for all three scenarios. You must set up an account with the third-party provider before you configure Entrust IdentityGuard to use this service.

To use this delivery method, Entrust IdentityGuard must have telephone numbers for Entrust IdentityGuard users. See Create contact information for a user.

For Authentify telephone number rules, see Authentify international telephone number rules.

Authentify uses an XML template file, with variables filled in with the user name and OTP, for example. After Authentify receives this XML request, the automated phone message is sent quickly, often in seconds (though the pause can be as long as a minute). The user receiving the call follows the voice prompts and supplies a PVN, either through the keypad or by speaking it, and writes down the OTP given. The user then enters the OTP and the PVN to complete the step-up authentication.

Note: Authentify messages require the person answering the call to provide a confirmation number. Entrust IdentityGuard expects the personal verification number (PVN) as confirmation, so Authentify is not available to users who are not assigned a PVN. For more information about the PVN, see Personal verification number overview.

Note: This is a sample scenario based on a standard Authentify template. You may be using a different template, so the sequence events of described here should be used as an example only.
