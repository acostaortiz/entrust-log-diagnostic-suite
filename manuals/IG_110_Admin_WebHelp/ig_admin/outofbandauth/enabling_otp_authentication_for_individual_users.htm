IdentityGuard Server 11.0 Administration Guide

Enable OTP authentication for individual users

Even if OTP is set as an authentication method in the Authentication Types policy, OTP authentication must also be enabled for each individual user.

When each new user is created, OTP Authentication Allowed is set to Yes by default.

To set OTP Authentication Allowed for a user

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Select User Accounts on the menu bar.

3.      Enter in the name of the user.

The View Account page appears.

4.      Under Authentication Types, select One-Time Password from the list.

The setting for OTP Authentication Allowed should be Yes.

5.      If you want ot change the setting, click Change Personal OTP settings.

The Change personal OTP settings page appears.

6.      Under OTP Authentication Allowed, click Yes. to enable OTP authentication for the user, or No to disable OTP authentication for the user.

7.      Click Save Changes to return to the account view.
