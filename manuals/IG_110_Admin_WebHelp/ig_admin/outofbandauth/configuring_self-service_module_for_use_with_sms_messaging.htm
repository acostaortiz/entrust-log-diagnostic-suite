Configure Self-Service Module for use with SMS messaging

For detailed instructions, see the Entrust IdentityGuard Self-Service Module Customization Guide.

If you are using Self-Service Module with Entrust IdentityGuard, make the following changes to the oob-delivery.xml file in the etc directory under the Self-Service installation.

●       Remove the following line (the provider may be different in your implementation):

<suffix>@pcs.rogers.com</suffix>

This will allow users to successfully enter contact information in Self-Service Module.

●       Find this line in the file, and ensure that the text in the label line includes the name configured for the Out-of-Band SMS Delivery Configuration instance in the Entrust IdentityGuard properties file.

<label>“Configuration Instances”</label>

For more information about the Out-of-Band SMS Delivery Configuration properties, see Out-of-Band OTP SMS Delivery Configuration.
