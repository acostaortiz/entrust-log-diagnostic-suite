IdentityGuard Server 11.0 Administration Guide

Modify a user account for out-of-band OTP use

An administrator with the userOTPOverridePolicy permission can set out-of-band OTP options for a user that are different than those set by policy for the user’s group.

To modify a user’s one-time password settings

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click User Accounts on the main menu.

3.      Find a specific user (see Searching for users with an out-of-band one-time password ).

4.      On the View Account pane, under Authentication Types, choose One-Time Password.

The One-Time Password pane appears. Click Change Personal OTP Settings.

5.      Under OTP Authentication Allowed, you can change whether or not the user is allowed to authenticate with a one-time password. You need the userOtpOverridePolicy permission and the userSet permission to make this change.

●       To allow the user to authenticate with a one-time password, click Yes.

●       To prevent the user from authenticating with a one-time password, click No.

6.      Under OTP Delivery Enabled, you can change whether or not the user is allowed to receive a one-time password by an out-of-band (OOB) delivery mechanism. You need the userOtpOverridePolicy permission and to the userSet permission to make this change.

●       To allow the user to receive a one-time password by an OOB delivery mechanism, click Yes.

●       To prevent the user from receiving a one-time password by an OOB delivery mechanism, click No.

●       To let the user’s group policy determine if the user can receive a one-time password by an out-of-band delivery mechanism, click Use Policy.

The Use Policy option label shows the current policy setting in parentheses.
