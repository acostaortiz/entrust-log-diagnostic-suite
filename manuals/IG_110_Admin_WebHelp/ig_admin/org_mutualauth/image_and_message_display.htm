Image and message display

Another display method supported by Entrust IdentityGuard is image and message display.

Image display selection

In this case, as part of the registration process, a user selects an image from a selection presented by your application. For example, in the following figure the user clicks the Change button until a suitable image appears and then enters their own caption, such as “my scissors.” This image and caption are stored as an authentication secret. You can also allow users to upload their own images.

Image display at login

During subsequent logins, the user is shown the selected image and caption.

For example, in the following figure the user is shown the image and caption after machine authentication (which is automatic) to assure the user that the site is legitimate. Your site can also prompt for additional authentication, such as a password.

Complete the following tasks to configure message or image display authentication for your users:

●       Allow for message or image display authentication by editing the mutual authentication policy attributes (see Configuring mutual authentication policies).

●       Create a list of images or messages to display to your users, and store the images in a file. You can also use the stock images that ship with Entrust IdentityGuard.

●       After you configure Entrust IdentityGuard policies and properties, configure your client application to:

–  set the message or image authentication secrets (using the Entrust IdentityGuard Administration API) when the user registers

–  authenticate the user

–  display the message or image (using the Entrust IdentityGuard Authentication API) before or after the user authenticates

For more information, see the Entrust IdentityGuard Programming Guide.
