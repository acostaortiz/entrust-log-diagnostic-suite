IdentityGuard Server 11.0 Administration Guide

Step 11: Add a SCEP trusted signer certificate

If you are deploying SCEP digital IDs (see Digital ID types and formats for details), read this section. Otherwise, skip it.

You can optionally load a trusted signer certificate into Entrust IdentityGuard. Once loaded, signed SCEP requests are verified using this certificate.

To add a trusted signer certificate

1.      Obtain a trusted signer certificate.

2.      Determine the name of your digital ID configuration. To find this name:

a.      Log in to the Entrust IdentityGuard Administration interface.

b.      From the top menu, click Certificates.

c.      Click List Managed CAs.

d.      Select your CA.

e.      Look under Digital ID Configurations to see the name of the digital ID configuration. 

f.        Record this name.

3.      In Entrust IdentityGuard, log in to the Master user shell. See Using the Master user shell.

Attention: Use / in paths, not \. Even using double-quotes around paths containing \ will not work.

4.      Enter a command using this syntax:

digitalid config entrust set <name> -p10TrustedSignerCert <certfile>+

where:

<name> is the name of the digital ID configuration. 

●       <certfile> is the path and filename of the trusted signer certificate. You can add multiple CA certificates. Separate each with a space.

Example:

digitalid config entrust set –“Network Access Config” –p10TrustedSignerCert c:/mytrustedsignercert.cer

You have now loaded the trusted signer certificate.
