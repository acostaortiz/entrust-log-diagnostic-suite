General Logging Configuration

Entrust IdentityGuard uses the log4j logging service to generate both audit logs and general system logs. Log4J lets you define loggers (the type and level of messages to be logged), appenders (where the logs are to be written), and layouts (the format used for writing the logs). Below are the general log properties. For more details and to view a snapshot of the properties, see Setting general logging properties.

Logging Configuration Refresh Interval

identityguard.refreshinterval

Defines how often in seconds the configuration is checked for changes to the log settings.

Default: 1

Logging Stack Trace Size

identityguard.log.maxstacksize

Defines the number of stack frames that are logged for errors. A setting of means that no stack trace is logged.

Default:

Base Logger Configuration

log4j.logger.IG

Defines the logging level of the Base Logger, and the location of the messages logged by the Base Logger.

The message level can be one of ALL, DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. This sets the lowest level of message to show; for example, WARN provides messages of WARN, ERROR and FATAL status.

Select OFF to stop all messages.

The destination can be SYSTEM_SYSLOG, or SYSTEM_FILELOG, or both if you edit the properties file manually.

Default: WARN, SYSTEM_FILELOG

Note: If this property is set to DEBUG, log4j.logger.additivity.IG must be set to False.

Base Logger Messages also go to Root Logger

log4j.logger.additivity.IG

If this property is True, base logger messages are also written to the root logger.

When the base logger is set to DEBUG, leave this property at False, the default.

Default: False

Audit Logger Configuration

log4j.logger.IG.AUDIT

Defines the logging level of the audit logger, and the destination of any messages logged by the audit logger.

This property takes two values as listed in the paired drop-down lists: one for the message level and one for destination of logging messages.

The message level can be one of ALL,DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. This sets the lowest level of message to show; for example, WARN provides messages of WARN, ERROR and FATAL status.

Select OFF to stop all messages.

The destination is either AUDIT_SYSLOG or AUDIT_FILELOG.

Default: ALL, AUDIT_FILELOG

Note: Changing this configuration may disable audits.

Audit logger messages also go to Base logger

log4j.additivity.IG.AUDIT

Defines whether or not Entrust IdentityGuard audits should also be added to the base logger.

Leave this value set to the default, False.

Default: False

System Logger Configuration

lo4j.logger.IG.SYSTEM

Defines the logging level of the system logger, and the destination of any messages logged by the system logger.

This property takes two values as listed in the paired drop-down lists: one for the message level and one for destination of logging messages.

The message level can be one of ALL,DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. This sets the lowest level of message to show; for example, WARN provides messages of WARN, ERROR and FATAL status.

Select OFF to stop all messages.

The destination is either SYSTEM_SYSLOG or SYSTEM_FILELOG. This default is set during configuration.

Default: WARN

System logger messages also go to Base logger

log4j.additivity.IG.SYSTEM

Defines whether or not Entrust IdentityGuard system logs should also be added to the base logger.

This value should remain set to the default, False.

Default: False
