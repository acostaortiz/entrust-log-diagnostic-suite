IdentityGuard Server 11.0 Administration Guide

Performance Statistics Logging Settings

The Performance Statistics Logging properties control the logging of performance statistics and connection pool usage statistics that are gathered as the server is running. Changes to these properties are monitored based on the Logging Configuration Refresh Interval property (identityguard.refreshinterval). You do not have to restart the Entrust IdentityGuard server for changes to these properties to take effect.

Enable Performance Logging

identityguard.estat.enabled

Set this property to True to enable logging of Entrust IdentityGuard service performance statistics.

When performance statistics logging is enabled, data is logged to:

<$IG_HOME>/Log/identityguard_estat.log

Default: False

Services Enabled for Performance Logging

identityguard.estat.enabledservices

If Enable Performance Logging is set to true, use this property to specify the list of services against which to log performance data.

Specify the services to monitor in a space or comma-separated list. The list can contain one or more of the following:

–  ADMININTERFACE - the Web Administration interface

–  ADMINSERVICE - the Administration service

–  AUTHSERVICE - the Authentication service

–  IGRADIUS - the Entrust IdentityGuard Radius Proxy

–  PROPERTIESEDITOR - the Properties Editor

–  SUPERSH - the Master user shell

Unrecognized strings are ignored. If no services are specified, the default list is used.

Default: ADMININTERFACE ADMINSERVICE AUTHSERVICE

Performance Logging Schedule

identityguard.estat.schedule

If Enable Performance Logging is set to true, use this property to specify the number of seconds to wait between logging performance statistics. In the default case, performance statistics are logged once every 6 seconds (1 minutes).

Default: 6

Clear Performance Data

identityguard.estat.clear

Set this property to True to clear and reset performance statistics periodically.

Clearing and resetting performance statistics periodically allows you to check system performance during specific time intervals.

Default: False

Clear Performance Data Schedule

identityguard.estat.clearschedule

If Clear Performance Data is enabled, use this property to set the minimum time after logging to wait before clearing the data. A value of 0 (zero) means the performance statistics are cleared after every time they are logged.

Default: 0

Enable radius VPN Request Table Logging

identityguard.estat.igradiusvpnrequestenabled

Set to True to log periodically the performance statistics for the internal VPN Request table usage within the Entrust IdentityGuard Radius proxy.

If you change this setting, you must restart the Entrust IdentityGuard Radius Server service.

Enable radius VPN State Information Table Logging

identityguard.estat.igradiusstateinfoenabled

Set to True to log periodically the performance statistics for the internal VPN and Radius State Information table usage within the Entrust IdentityGuard Radius proxy.

If you change this setting, you must restart the Entrust IdentityGuard Radius Server service.

Connection Pool Logging Schedule

identityguard.estat.pool.schedule

If Enable Connection Pool Logging is set to True, use this property to specify the number of seconds to wait between logging connection pool usage statistics. In the default case, connection pool usage statistics are logged once every 6 seconds (1 minutes).

Default: 6
