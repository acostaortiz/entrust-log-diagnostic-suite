IdentityGuard Server 11.0 Administration Guide

Audit Logging Appenders

An appender defines where log messages are written and the format of those messages. For audit messages, Entrust IdentityGuard supports an appender for the Syslog protocol (AUDIT_SYSLOG) and a rolling file appender (AUDIT_FILELOG). For more details and to view a snapshot of the properties, see Setting audit logging properties.

AUDIT_SYSLOG Implementation Class Name

log4j.appender.AUDIT_SYSLOG

Defines the log4j appender to use for audit logs. This should not be changed.

This value should remain set to the default: org.apache.log4j.net.SyslogAppender.

AUDIT_SYSLOG Host Name

log4j.appender.AUDIT_SYSLOG.SyslogHost

Defines the Syslog host to which logging information is sent. You can use a colon to append a non-default port number to the host.

AUDIT_SYSLOG Facility

log4j.appender.AUDIT_SYSLOG.Facility

Defines the Syslog facility used to audit logs. Select the option from the drop-down list that best describes what facility on the system originated the message.

Default:LOCAL1

AUDIT_FILELOG Layout Implementation Class Name

log4j.appender.AUDIT_FILELOG.layout

The log4j class that converts a logging event into a message string to be printed in the logs.

Default: org.apache.log4j.PatternLayout

AUDIT_SYSLOG Layout Pattern

log4j.appender.AUDIT_SYSLOG.layout.ConversionPattern

Defines the format of the converted logging event. Please see the log4j documentation for further information.

Default: [%t] [%-5p] [%c] %m%n

AUDIT_FILELOG Implementation Class Name

log4j.appender.AUDIT_FILELOG

Defines the appender used if audit events are logged to files.

This value should remain set to the default: org.apache.log4j.RollingFileAppender

AUDIT_FILELOG File Name

log4j.appender.AUDIT_FILELOG.File

Defines the location of the audit log.

Default:

–  On Windows <$IG_HOME>\logs\audit.log

–  On UNIX $IG_HOME/logs/audit.log

AUDIT_FILELOG Maximum File Size

log4j.appender.AUDIT_FILELOG.MaxFileSize

Defines the maximum size in KB of a log file before rolling over to a new empty file.

Default: 1000

AUDIT_FILELOG Maximum Number of Backup Files

log4j.appender.AUDIT_FILELOG.MaxBackupIndex

Defines the number of previous log files to keep as a history.

Default: 10

AUDIT_FILELOG Layout Implementation Class Name

log4j.appender.AUDIT_FILELOG.layout

The log4j class that converts a logging event into a message string to be printed in the logs.

Default: org.apache.log4j.PatternLayout

AUDIT_FILELOG Layout Pattern

log4j.appender.AUDIT_FILELOG.layout.ConversionPattern

Defines the format of the converted logging event. Please see the log4j documentation for further information.

Default: [%d] [%t] [%-5p] [%c] %m%n

AUDIT_FILELOG Character Encoding

log4j.appender.AUDIT_FILELOG.encoding

Defines the encoding method for the Audit Filelog.

The choices include many of the popular encoding methods, UTF-8 and ASCII, for example. If this field is left blank, Entrust IdentityGuard uses the Java default character encoding.

Default: UTF-8
