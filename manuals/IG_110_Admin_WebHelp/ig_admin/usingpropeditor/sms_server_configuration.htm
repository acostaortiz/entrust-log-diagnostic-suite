IdentityGuard Server 11.0 Administration Guide

SMS Server Configuration

Your application can automate the delivery of information using a text (SMS) message to a mobile phone. Using the following properties, you can set up an SMS server. Support for Clickatell and TeleSign SMS service providers is built into Entrust IdentityGuard, however, you can configure these settings for other third-party service providers. Properties in this section are required for Clickatell support. They are not required for TeleSign support. For more information, see Configuring the SMS Gateway URL for a SMS provider other than Clickatell or TeleSign.

Configuration Instances

Provides a list of SMS Server configurations.

To create a new instance, enter a unique name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

SMS Gateway URL

identityguard.sms.{0}.url

The URL used as an API to deliver SMS messages through the use of an SMS gateway. While you can use any SMS service provider, Clickatell and TeleSign are built in to Entrust IdentityGuard.

Clickatell:

https://api.clickatell.com/http/sendmsg?user=USERNAME&password=PASSWORD&api_id=API_ID&to=TO_PHONE&text=MSG_TEXT&from=FROM_ID

TeleSign does not use this property.

Note: The uppercase characters are replaced by values gathered from the rest of this configuration.

Note: If you are sending a one-time-password through a proxy that requires basic authentication, specify the user name and password in the gateway URL. For example:
https://myuser:mypass@example.com/http/sendmsg?user=USERNAME&password=PASSWORD&api_id=API_ID&to=TO_PHONE&text=MSG_TEXT&from=FROM_ID

To configure the SMS Gateway URL for a different SMS service provider, see Configuring the SMS Gateway URL for a SMS provider other than Clickatell or TeleSign.

User Name

identityguard.sms.{0}.userid

Specifies the SMS service provider user name to use when logging in to the service. The user name and password are provided when you register for the SMS service provider.

The value replaces USERNAME in the SMS Gateway URL setting.

Default: none

Password

identityguard.sms.{0}.password

Specifies the SMS service provider password to use when logging in to the service. The user name and password are provided when you register for the SMS service provider.

The value replaces PASSWORD in the SMS Gateway URL setting.

Select Encrypt to encrypt the password.

Default: none

API ID

identityguard.sms.{0}.apiid

Specifies the API Identification obtained from the SMS service provider. (For Clickatell, it is listed under the API Connections on Clickatell Central.)

The value replaces API_ID in the SMS Gateway URL setting

Default: none

From Label In The SMS Message

identityguard.sms.{0}.from

Sets the From label in the SMS message sent by Entrust IdentityGuard.

For Clickatell, the From label is the Sender ID registered with Clickatell. The value replaces FROM_ID in the SMS Gateway URL setting

Note: If the contents of the From field is invalid, the message is still delivered. No error message is generated, but your Clickatell account manager may receive an email notice, as an anti-spam precaution, indicating that messages are coming from an invalid sender.

TeleSign does not use this property.

Default: none

Prepend Digits for SMS Recipients

identityguard.sms.{0}.prependdigit

SMS service providers require that all SMS recipients follow a universal numbering standard (E.164).

This property defines a digit (country code) to add to the beginning of all contact numbers using this configured out-of-band delivery mechanism. Use this property if the user contact information does not include the country code.

Default: none

SMS Unicode Encoding

identityguard.sms.{0}.unicode

If the SMS message contains any characters outside of the Basic Latin character set (Unicode Latin-1 Supplement characters, for example), set this property to True.

This imposes a shorter limit on SMS messages: messages containing more than 7 characters might be divided and sent as several messages.

Attention: If a Unicode message is sent to a network that does not support Unicode messages, the message is not delivered. There is no error message when this occurs. You must verify with your SMS service provider that Unicode is supported for the end user before enabling this feature.

TeleSign does not use this property.

Default: False

SMS Message Maximum Fragments

identityguard.sms.{0}.maxfragments

Sets the maximum number of messages that will be sent when a long SMS message is split.

This property is used only when SMS Message Fragmentationis set to True.

TeleSign does not use this property.

Default: 5

SMS Message Fragmentation Split Characters

identityguard.sms.SMS Server.splitchars

Sets which characters are used to decide where a message is split. To specify more than one split character, separate each with a space. The following special characters are supported:

\s (space)

\t (tab)

\n (new line)

The default is to split at whitespace characters (spaces, tabs, and new lines). If the message does not contain a split character, the message is split at the maximum message size.

This property is used only when SMS Message Maximum Fragmentation is set to True.
