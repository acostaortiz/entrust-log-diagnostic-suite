IdentityGuard Server 11.0 Administration Guide

Token Vendor Configuration

These properties control the configuration of token vendors and the repositories for unassigned tokens. For information about managing tokens, see Token authentication overview. For additional token-related properties, see Customizing VPN challenge strings. Also see Configuring token vendors for more details and to view a snapshot of the properties.

During installation of Entrust IdentityGuard, you are asked what token vendor you plan to use for authentication. Based on your choice, the installer sets these properties.

Configuration Instances

Provides a list of token configurations.

To create a new instance, enter a unique name (100 characters or less) in the empty field and click Add. The other properties appear.

To delete an instance, select it in the list and click Remove.

Default: Entrust

Token Vendor Implementation Class

identityguard.token.<vendor>.impl

Sets the Java class name of the token library. You can select EntrustToken, Entrust Soft Token, Entrust DisplayCard, Watchdata QRO, OATH Token or Custom.

If you select Custom, enter the custom Java class name in the field that appears. (Used only in highly advanced custom installations.)

Default: Entrust

Token Vendor Display Name

identityguard.token.<vendor>.name

Provides a unique display name for the token type or vendor. The name appears in the Administration interface and can appear in your client application.

Default: the instance name

Default Token Vendor

identityguard.token.<vendor>.default

Determines if the token vendor named in the configuration instance is used as the default when no vendor is specified. Set this to True for the token vendor to use as the default.

Default: False

Token Vendor Configuration File

identityguard.token.<vendor>.configfile

Provides the name and location of the token configuration file, if it is required by the token vendor. This file is used only for special vendor-specific settings.

For Entrust tokens and Entrust soft tokens, this property is set by default. The file, entrusttoken.conf, is located:

●        On UNIX $IG_HOME/etc

●        On Windows <$IG_HOME>\etc

For other tokens, set this property only if you need to use a configuration file.

Note: You can use a file similar to the Entrust configuration file for Entrust DisplayCard tokens as well (use the Entrust DisplayCard setting), except that the resetClockWindow parameter is not supported.
