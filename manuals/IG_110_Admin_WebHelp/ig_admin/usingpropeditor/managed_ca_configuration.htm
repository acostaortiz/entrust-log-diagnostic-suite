IdentityGuard Server 11.0 Administration Guide

Managed CA Configuration

When you deploy smart credentials, you might need to configure a managed Certification Authority (CA). See "Setting up a managed CA" in the Entrust IdentityGuard Smart Credentials Guide.

These properties control how Entrust IdentityGuard works with a managed CA when issuing X.509-based digital identities for smart credentials, mobile devices, and other resources.

Managed CA Manager Enabled

identityguard.managedca.manager.enabled

Determines if the managed CA manager is enabled. If True, the manager starts at system startup and automatically manages the administrative identities configured for managed CAs.

Management of identities ensures that the keys or certificates they contain are always current. Always enable this property on the primary Entrust IdentityGuard server. It can be disabled on a replica server.

Default: True.

Managed CA Manager Interval

identityguard.managedca.manager.interval

Sets the interval in hours at which the managed CA manager confirms the identities configured for managed CAs. This check also occurs at system startup.

The default interval is 24 hours.

Initial XAP Connection Pool Size

identityguard.managedca.xap.connections.initial

Sets the initial size of the XAP connection pool.

Entrust IdentityGuard maintains a connection pool for each configured managed Entrust CA. It allocates more connections as needed up to the maximum set by Maximum XAP Connection Pool Size. More connections allow more concurrent processing of XAP operations, but they require more resources.

The default initial size is 4.

Maximum XAP Connection Pool Size

identityguard.managedca.xap.connections.maximum

Controls the maximum size of the XAP connection pool. Entrust IdentityGuard dynamically allocates XAP connections as needed up to the maximum set by this property.

The default maximum is 20.

XAP Connection Idle Timeout

identityguard.managedca.xap.connections.idletimeout

Sets the idle timeout in minutes for XAP connections. If a connection to a managed CA is idle for longer than the value of this property, the connection closes.

When set to 0, idle connections are never dropped.

The idle timeout value is only checked when Entrust IdentityGuard sends a XAP message to the managed CA; therefore, XAP connections with the CA may be open for longer than the idle timeout period, but will be closed and refreshed when a subsequent XAP operation is performed with the CA.

When using an Entrust CA located behind a firewall, it is recommended that the idle timeout be set to a value less than the idle timeout of the firewall.

The default idle timeout is 30 minutes.

XAP Connection Socket Timeout

identityguard.managedca.xap.connections.sockettimeout

Sets the socket timeout in seconds for XAP connections. When set, read attempts on an XAP connection only block for the specified number of seconds.

The default socket timeout is 60 seconds.
