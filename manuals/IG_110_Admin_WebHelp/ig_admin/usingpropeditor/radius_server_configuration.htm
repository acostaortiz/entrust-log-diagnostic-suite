IdentityGuard Server 11.0 Administration Guide

Radius Server Configuration

These properties configure one or more Radius servers to use with your VPN for first-factor authentication. You can have more than one address for a given server configuration (for failover purposes), but all addresses must share the same secret. For more details and to view a snapshot of the properties, see Configuring the Radius proxy for VPN servers.

Where it appears in properties in the following table, the {0} placeholder is replaced by the Radius server configuration instance name.

Typically, you create your Radius server setups using the Configuration Panel or a UNIX script, as described in the Entrust IdentityGuard Installation Guide. You can add new servers or change existing settings using these properties.

Configuration Instances

You can create multiple Radius server configurations.

To create a new Radius server instance, enter a unique server label in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To use multiple Radius servers that are mapped to Entrust IdentityGuard groups, give each Radius server the name of a group when you create it. This means that you could have Configuration instances named marketing, development, and humanresources, for example.

Note: To use the group mapping feature, user IDs must include the group name at login. For more information, see Creating, modifying, and removing Radius servers.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

Radius Server Address

identityguard.igradius.radius.{0}.address

Provides the host name or IP address (with an optional port setting) of one or more Radius servers. To specify more than one Radius server (for failover purposes) add a space between each entry.

There is no default address.

Radius Server Secret

identityguard.igradius.radius.{0}.secret

Provides the Radius server shared secret used to protect communication between the Radius server and the Entrust IdentityGuard Radius proxy.

Select the Encrypt option to have the secret encrypted when saved.

Radius Timeout

identityguard.igradius.{0}.radiustimeout

Specifies the number of seconds that the Radius proxy waits for a response from the Radius server.

Default: 1

Radius Number of Retries

identityguard.igradius.radius.test.radiusnumretries

Specifies the number of times the Entrust IdentityGuard Radius proxy will resend a message to a Radius server if it does not receive a response. The value must be a non-negative integer.

Default:

Radius Proxy Requires Message-Authenticator

identityguard.igradius.{0}.radiusrequiremsgauth

If this property is set to True, incoming messages from the Radius server must include the Message-Authenticator attribute. If the attribute is not found, the message is ignored.

Default: False

Radius Proxy Includes Message-Authenticator

identityguard.igradius.{0}.radiusincludesmsgauth

Specifies whether outgoing messages to the Radius server must include the Message-Authenticator attribute. Set this to False if the Radius server does not understand the attribute and rejects messages as a result.

Default: True
