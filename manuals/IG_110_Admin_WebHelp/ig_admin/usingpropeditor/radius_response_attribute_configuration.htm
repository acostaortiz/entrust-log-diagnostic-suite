IdentityGuard Server 11.0 Administration Guide

Radius Response Attribute Configuration

The properties described in the following table configure one or more Radius attributes for use with the VPN for successful authentication. For more informtion, see Configuring the Radius response attributes.

Radius Attribute ID

identityguard.igradius.radiusattribute.{0}.id

Specifies the type of Radius attribute used in this configuration instance. Choose an attribute type from the drop-down list.

There is no default value.

Radius Attribute Value Type

identityguard.igradius.radiusattribute.{0}.valuetype

Specifies the Radius attribute value type. Set this property based on the Radius Attribute ID you set.

The value types to choose from are:

–  STRING (character sequence, must be no more than 253 bytes; not necessarily null terminated)

–  IP (V4) ADDRESS (a 4-byte IP address in network-byte order; for example, 10.4.16.61)

–  INTEGER (a 4-byte value in big-endian order)

–  DATE (a 4-byte value in big-endian order; the number of seconds since :: GMT - January 1st, 1970)

–  BINARY (a byte sequence of length less than 253 bytes — used for VSAs that do not conform to RFC2138)

Default: STRING

Radius Attribute Format

identityguard.igradius.radiusattribute.{0}.format

This property specifies the format in which the attribute values should be returned.

The value of this property is interpreted using the Java MessageFormat class where {0} represents the value to format (the data object Entrust IdentityGuard is searching for). This can be the Entrust IdentityGuard Group Name or any predefined LDAP attribute name. Static (hard coded) values may be included by removing any reference to {0}. The default value is 0{}.

The following rules apply to static and non-static values:

–  If the value type is a string, the format encoder expects a string value.

non-static = ‘CN={0}’

static = ‘This is a string’

–  If the value type is an IP address, the format encoder expects a dot notation string value representing an IP address.

non-static = '{0}'

static = '10.4.123.23'

–  If the value type is an integer, the format encoder expects a string value representing the integer.

non-static = '{0}'

static = '3423'

–  If the value type is a date, the format encoder expects a string value representing the date expressed as an integer.

non-static = '{0}'

static = '132456323'

–  If the value type is binary, the format encoder will expect a hexadecimal string value representing the actual binary data.

non-static = '{0}'

static = 'A2ED341E5D'

Default: {0}

Radius Attribute Return as Multiple Attributes Flag

identityguard.igradius.radiusattribute.{0}.returnasmultipleattributes

Specifies a flag that determines whether attributes with multiple values are returned in the same Radius attribute or there is a separate Radius attribute for each value.

If set to True, attributes are returned in separate Radius attributes rather than being concatenated and sent in one Radius attribute.

Default: False

Radius Attribute Multi-Value Delimiter

identityguard.igradius.radiusattribute.{0}.multivaluedelimiter

Specifies the delimiter to use when returning multi-valued attributes in one Radius attribute.

If the Radius Attribute Return as Multiple Attributes Flag property is True, this property is ignored.

Default: space

Radius Vendor-Specific Attribute Vendor Code

identityguard.igradius.radiusattribute.{0}.vendorcode

This property is required if the Radius Attribute ID property is set to VENDOR-SPECIFIC.

Provides the vendor code as specified in IETF RFC 1007. See www.iana.org for the up-to-date list of SMI Network Management Private Enterprise Codes. Enter the code that corresponds to the equipment vendor you are using.

Radius Vendor-Specific Attribute Conforms to RFC2138 Flag

identityguard.igradius.radiusattribute.{0}.conformstorfc2865

This property is required if the Radius Attribute ID property is set to VENDOR-SPECIFIC.

Specifies whether the Vendor-Specific Attribute conforms to the format recommended in RFC 2138. RFC 2138 format contains a specific vendor attribute number, its length, and the value.

If this property is set to False, the Radius Attribute Value Type property must be set to BINARY, and the Radius Attribute Format property then represents the value specified for the Vendor-Specific Attribute. This must be a hexadecimal value of the type 12AB up to a maximum of 249 bytes.

Default: True

Radius Vendor-Specific Attribute Number

identityguard.igradius.radiusattribute.{0}.vendorattributenumber

This property is required if the Radius Attribute ID property is set to VENDOR-SPECIFIC, and Radius Vendor-Specific Attribute Conforms to RFC2865 Flag is set to True.

This property represents the vendor attribute number (a value between 0 and 255). This value is set by the vendor. Check the equipment documentation for this attribute number.
