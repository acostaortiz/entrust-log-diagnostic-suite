LDAP Contact Info Mapping Settings

These properties control mapping of user contact information from the LDAP user repository to Entrust IdentityGuard, including an Active Directory repository used with the Active Directory synchronization feature..

Configuration Instances

Provides a name for the configuration instance you are mapping.

You can create contact information mapping configurations where each configuration includes a different directory attribute to map.

To create a new instance, enter a unique contact info mapping instance name in the empty field and click Add. The other properties appear. The name replaces the {0} placeholder.

To delete an instance, select it in the list and click Remove.

There is no default configuration.

Note: Use configuration instance names when specifying contact information mappings. See “Apply Contact Info Mappings" in LDAP Directory Server Settings. For more information, see Map contact info from an LDAP directory.

Directory Attribute

identityguard.ldap.contactInfoMapping.{}.attribute

Specifies the directory attribute that contains the contact information.

This must be the exact name of the attribute as it is stored in the directory; for example, telephoneNumber.

Label

identityguard.ldap.contactInfoMapping.{}.label

Specifies a text label to display with the contact information. This is the label the user sees in the application.

For multi-valued attributes, the label may include the text {0} to insert a numeric counter. If, for example, the label is set to Email {}, then a multi-valued attribute would generate contact information entries labeled Email 1, Email 2, and so on.

Contact information entries must have a unique label. If a multi-valued attribute is mapped, but does not include a {0} in the label, only the first value of the attribute is mapped.

Delivery Configuration

identityguard.ldap.contactInfoMapping.{}.deliveryConfig

Contains the out-of-band delivery mechanisms. Select the mechanism to use to deliver OTP challenge information using the contact information defined in this mapping.

If no out-of-band delivery mechanisms are defined, this property contains only one option: NONE.

Default: NONE

Default Contact Information

identityguard.ldap.contactInfoMapping.{}.default

Set this property to True to mark this contact info mapping as the default mapping.

A user’s default contact information is used when out-of-band delivery is requested, but no specific contact information is specified.

If a multi-valued attribute is mapped to a user’s default contact information, only the first value will be used.

Default: False
