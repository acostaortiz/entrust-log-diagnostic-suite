IdentityGuard Server 11.0 Administration Guide

External Q&A Provider Configuration

These properties control the integration of Entrust IdentityGuard with question and answer data created and maintained in an external system and used for Entrust IdentityGuard knowledge-based authentication. For more information, see Using external Q&A data for Entrust IdentityGuard authentication.

Configuration Instances

Provides a list of external Q&A provider configurations.

To create a new instance, enter a unique name (1 characters or less) in the empty field and click Add. The other properties appear.

To delete an instance, select it in the list and click Remove.

Default: none

External Q&A Provider Class name

identityguard.externalQA.{}.impl

Sets the java class name of the external Q&A provider library.

Default: no default

External Q&A Provider Display Name

identityguard.externalQA.{}.displayname

Optional

Provides a unique display name for the external Q&A provider. The name appears in the Administration interface and can appear in your client application. If specified, this name must be unique across all external Q&A instances.

Default: the instance name

External Q&A Provider Configuration File

identityguard.externalQA.{}.configfile

Optional

Defines a file that contains property data specific to the external Q&A provider.
