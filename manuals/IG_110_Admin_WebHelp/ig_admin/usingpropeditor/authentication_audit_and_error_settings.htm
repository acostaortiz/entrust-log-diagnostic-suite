IdentityGuard Server 11.0 Administration Guide

Authentication Audit and Error Settings

These properties control Entrust IdentityGuard messages related to authentication operations, primarily those dealing with risk-based authentication. See Configuring authentication audits for more details and to view a snapshot of the properties.

Audit Successful Authentications

identityguard.authentication.audit.success

Determines whether audit messages (AUD6000) are written when a user successfully authenticates using any authentication method.

Default: False

Audit Challenge Requests That Return Challenge

identityguard.authentication.audit.challenge

Determines whether audit messages (AUD6012) are written when your risk-based authentication policies issue a second-factor authentication challenge.

Default: False

Audit Challenge Requests That Return Authenticated

identityguard.authentication.audit.authenticated

Determines whether audit messages (AUD6013) are written when your risk-based authentication policies authenticate a user without a second-factor authentication challenge.

Default: False

Audit Authentications Where The User Does Not Exist

identityguard.authentication.audit.usernotexist

Determines whether audit messages are written when authentication fails because the user does not exist. This can track failed login attempts due to, for example, misspelled user names.

Default: False

Audit Knowledge-Based Questions That Are Answered Incorrectly

identityguard.authentication.audit.incorrectlyansweredquestions

Determines whether audit messages (AUD6014) are written when a user incorrectly answers a knowledge-based question. The incorrectly-answered question is included in the audit message.

Default: False

Include Location Information In Authentication Audits

identityguard.authentication.audit.includelocation

Determines whether audit messages for risk-based authentication should include IP location information when available.

Default: False

Include Lockout Information In Authentication Errors

identityguard.authentication.audit.includelockout

Determines whether error messages for risk-based authentication should include lockout information when available.

Default: False
