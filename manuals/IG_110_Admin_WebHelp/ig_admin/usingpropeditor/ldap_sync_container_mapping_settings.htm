LDAP Sync Container Mapping Settings

These properties define the configuration for one or more LDAP repositories that are used to synchronize Entrust IdentityGuard account information with user accounts in Active Directory.

When Entrust IdentityGuard is configured to synchronize users in its database with an LDAP directory, notifications from the LDAP directory to Entrust IdentityGuard can be used to automatically propagate changes.

Notifications are supported for specific-containers (for example, ou=Marketing,ou=WestCoastUsers). These container settings are RDNs (relative distinguished names) that are relative to the context prefix in the LDAP URL property of the LDAP directory instance that uses this container mapping. For example, assuming ou=WestCoastUsers resides at the root (context prefix) of the LDAP directory, then the container name defined here should be ou=Marketing. If the LDAP directory instance container is defined at the root (that is, ou=WestCoastUsers is not part of the context prefix), then the container name defined here should be ou=Marketing,ou=WestCoastUsers. These settings define the possible mappings.

Note: Which sync container mapping settings actually apply to a particular LDAP directory sync configuration instance is specified with the LDAP Sync Apply Container Mappings property in the LDAP instance (see LDAP Directory Server Settings (5)). The instance value should not contain spaces or commas and should not be set to the value ROOT.

Configuration Instances

Lists all current configurations for LDAP synch containers.

To create a new instance, enter a unique name in the empty field and click Add.

To delete an instance, select it in the list and click Remove.

Name

identityguard.ldap.sync.containerMapping.Level1.name

Specifies the container name relative to the LDAP directory instance container that will use this mapping. This must be the exact name of the container as it is defined in the directory, for example: ou=Marketing,ou=WestCoastUsers.
