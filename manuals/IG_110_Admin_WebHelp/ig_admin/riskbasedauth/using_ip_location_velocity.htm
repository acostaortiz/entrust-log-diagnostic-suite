IdentityGuard Server 11.0 Administration Guide

Using IP location velocity

When a user logs in, Entrust IdentityGuard converts a public IP address to location data. For a velocity test, Entrust IdentityGuard compares the current user location data to the most recent location data in the user’s location history list by following these steps:

●       Compare the latitude and longitude coordinates of the current location and most recent location, and calculate the distance between them.

●       Compare the current time with the timestamp of the most recent location, and calculate the difference.

●       Use the distance and time to calculate the velocity required to travel this distance in the given time.

●       If the velocity is greater than that allowed by the Maximum Possible Velocity policy attribute, the velocity test fails.

An administrator can disable the velocity test on a per user basis.

No velocity test occurs when the IP address is a private address.

Note: Velocity tests depend on the location history list. If the Maximum Location History Size policy attribute is 0, the velocity test always passes.

The default setting for the Maximum Possible Velocity policy attribute is 500 kilometers per hour (approximately 311 miles per hour), which implies travel by air.

When a user logs in for the first time, that user has no location history list; therefore, the velocity test passes.

To set policy related to location velocity, see Configuring RBA policies.
