RBA policy syntax

There is an almost limitless number of possibilities for defining these RBA policies. What follows is a breakdown of the policy commands.

To set normal and enhanced security rules for authentication, the standard syntax of the policy commands are:

policy rba set <policyname> -normalReject [-add|-remove] <RBA expression> 

policy rba set <policyname> -normalAuthenticated [-add|-remove] <RBA expression> 

policy rba set <policyname> -enhancedReject [-add|-remove] <RBA expression>

policy rba set <policyname> -enhancedAuthenticated [-add|-remove] <RBA expression>
