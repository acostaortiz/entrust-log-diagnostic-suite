IdentityGuard Server 11.0 Administration Guide

IP/Geolocation authentication

In Entrust IdentityGuard, you can set up the following IP/Geolocation tests:

●       IP Blacklist — If a user logs in from an IP address that is on the IP blacklist, this test fails. For more information, see Managing the IP blacklist.

●       Country Blacklist — If a user logs in from a country that is on the country blacklist, this test fails. For more information, see Configuring RBA policies.

●       Location History — If the user logs in from an IP address that is not in the user’s location history list (IP addresses the user authenticated from recently), this test fails. For more information, see Using the location history list.

●       Velocity — If a user logs in from two widely separated geographic locations in a suspiciously short period of time, this test fails. For more information, see Using IP location velocity.

Note: Some of these tests may not be run depending on the results of preliminary IP address checks. For details, see Preliminary checks and how they affect subsequent tests.
