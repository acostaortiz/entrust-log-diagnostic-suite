Documentation conventions

The following typographical conventions are used in this guide:

Convention

Purpose

Example

Bold text (other than headings)

Indicates a label, button, tab name or other element in the graphical user interface

Click Next.

Italicized text

Used for titles of referenced books or documents

Entrust IdentityGuard Administration Guide

Bold, underlined text

Used for hyperlinks to other topics in this guide or links to Web pages

For more information. see Documentation feedback.

Courier type

Indicates installation paths, file names, commands, and text you must enter

init [-sernum <num>] [-overwrite] [-force]

Angle brackets  in a command

< >

Indicates variables (text you must replace with your organization’s correct values)

user delete <userid> [-import <file>] [-force] [-continue [true | false]] [-errorfile <file>]

Square brackets in a command

[courier type]

Indicates optional parameters

init [-sernum <num>] [-overwrite] [-force]

A plus sign in a command

+

When appended to an parameter, it means multiple values for the parameter are permitted.

user list -group <groupname>+

An asterisk in a command

*

When appended to a parameter, it means that zero or more values are permitted.

policy cardspec set <policyname> -cellReplacements ([-add] (<src> <dest>)*) | (-remove <char>+)

Hide additional help text

Indicates that there is additional content to read. Select the + symbol or the line of text beside it to show the additional content if it is relevant to what you are doing. Select the - symbol to hide the expanded content.

Show All/ Hide All

Click this toggle button in the help toolbar to show or hide all expanded content on the page you are viewing.

 

 

Note, Attention, and Tip text

Throughout this guide, there are paragraphs preceded by Note, Attention, or Tip. These paragraphs provide key information with two levels of importance, as shown below.

Note: Contains information to help you maximize your understanding of your Entrust product.

Attention: Contains issues that, if ignored, may seriously affect performance, security, or the operation of your Entrust product.

Tip: Provides an alternate or easy way to perform a common task.
