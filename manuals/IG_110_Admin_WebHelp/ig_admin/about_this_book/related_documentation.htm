IdentityGuard Server 11.0 Administration Guide

Related documentation

Entrust product documentation, white papers, technical notes, and a comprehensive Knowledge Base are available through Entrust TrustedCare Online. If you are registered for our support programs, you can use our Web-based Entrust TrustedCare Online support services at:

https://www.entrust.com/trustedcare

Entrust IdentityGuard is supported by a complete documentation suite:

●       Entrust IdentityGuard Installation Guide — Provides instructions for installing and configuring the Entrust IdentityGuard Server.

●       Entrust IdentityGuard Directory Configuration Guide — Provides information about configuring Entrust IdentityGuard to work with a supported LDAP repository

●       Entrust IdentityGuard Database Configuration Guide — Provides information about configuring Entrust IdentityGuard to work with a supported JDBC database.

●       Entrust IdentityGuard Server Administration Guide — Provides instructions about configuring and maintaining your Entrust IdentityGuard implementation and various and authentication methods, as well as administering IdentityGuard users and groups.

●       Entrust IdentityGuard Smart Credentials Guide — For instructions about configuring, administering, and using Entrust IdentityGuard smart credentials. This guide assumes a working knowledge of Entrust IdentityGuard system configuration, as documented in the Entrust IdentityGuard Server Administration Guide.

●       Entrust IdentityGuard Master User Shell Reference — Describes the commands used to run Entrust IdentityGuard from a command line using the Master user shell.

●       Entrust IdentityGuard Error Messages — This document is reference for Entrust IdentityGuard error messages.

●       Entrust IdentityGuard Server Release Notes — Provides information about new features, system requirements, limitations and known issues in the latest release.

●       For information about the Entrust IdentityGuard Self-Service Module, see:

–  Entrust IdentityGuard Self-Service Module Installation and Configuration Guide

–  Entrust IdentityGuard Self-Service Module Customization Guide

–  Entrust IdentityGuard Self-Service Module User Guide

●       Entrust IdentityGuard Programming Guide — Provides information about integrating the authentication and administration processes of your applications with Entrust IdentityGuard. Separate versions of the guide are available for Java and .NET development platforms.

Note: If you are using a programming environment other than .NET or Java, you can still connect applications to Entrust IdentityGuard. Entrust IdentityGuard exposes a standard Web-services interface for authentication and administration. The server installation includes the WSDL for these services in the $identityGuard.home/client/doc directory. You can translate example code in the .NET and Java guides into other languages.

●       For information about the Entrust IdentityGuard Device Fingerprint Software Development Kit, see:

–  Entrust IdentityGuard Device Fingerprint SDK Programmer's Guide

–  Entrust IdentityGuard Device Fingerprint SDK Readme files for Android, iOS, and Java

For other Entrust IdentityGuard product information, go to http://www.entrust.com/products/
