Generating reports in the Master user shell

You can generate reports in the Master user shell using the various list commands shown below. For full details of command syntax, see the Entrust IdentityGuard Master User Shell Command Reference, and the specific reporting commands:

●       report definition list

●       report definition list

Note: You cannot create or use personal queries in the Master user shell.

user list -report <report_name> [-reportDesc <desc>] [-reportFormat PDF | CSV] [-reportSummaryOnly] [-reportTimeZone <timezone>] [-reportLocale <locale>]

Where <report name is one of: UserAuthenticatorDetail, UserSearchCSV, or UserStatusDetail

user card list -report <report_name> [-reportDesc <desc>] [-reportFormat PDF | CSV] [-reportSummaryOnly] [-reportTimeZone <timezone>] [-reportLocale <locale>]

Where <report name is one of: CardStatusDetail or CardSearchCSV

user token list -report <report_name> [-reportDesc <desc>] [-reportFormat PDF | CSV] [-reportSummaryOnly] [-reportTimeZone <timezone>] [-reportLocale <locale>]

Where <report name is one of: TokenStatusDetail or TokenSearchCSV

user cert list -report <report_name> [-reportDesc <desc>] [-reportFormat PDF | CSV] [-reportSummaryOnly] [-reportTimeZone <timezone>] [-reportLocale <locale>]

Where <report name is one of: CertificateStatusDetail or CertificateSearchCSV

card list -report <report_name> [-reportDesc <desc>] [-reportFormat PDF | CSV] [-reportSummaryOnly] [-reportTimeZone <timezone>] [-reportLocale <locale>]

Where <report name is: UnassignedCardStatusSummary

token list -report <report_name> [-reportDesc <desc>] [-reportFormat PDF | CSV] [-reportSummaryOnly] [-reportTimeZone <timezone>] [-reportLocale <locale>]

Where <report name is: UnassignedTokenStatusSummary

audit list -report <report_name> [-reportDesc <desc>] [-reportFormat PDF | CSV] [-reportSummaryOnly] [-reportTimeZone <timezone>] [-reportLocale <locale>]

Where <report name is one of: AuditActionByTime, AuditAdminActionDetail, or AuditSearchCSV
