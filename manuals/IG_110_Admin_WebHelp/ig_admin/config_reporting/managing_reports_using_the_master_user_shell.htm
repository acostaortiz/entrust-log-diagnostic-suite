IdentityGuard Server 11.0 Administration Guide

Manage reports using the Master user shell

Some of the report management functions you can perform in the Master user shell include:

●       list report definition names

report definition list

●       display details of a specific report definition

report definition get <report_name>

Example:

report definition get TokenStatusDetail

●       list existing reports (including report name and ID)

report list

●       delete existing reports

report delete <report_id>

Example:

report delete 20090525152458468

For detailed command syntax, see the Entrust IdentityGuard Master User Shell Command Reference.
