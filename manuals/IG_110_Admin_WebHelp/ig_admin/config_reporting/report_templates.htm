IdentityGuard Server 11.0 Administration Guide

Report templates

Reports are generated in PDF or CSV format, depending on the report template you choose. Entrust IdentityGuard includes the following report templates:

●       Audit Action By Time Detail Report

●       Audit Admin Action Detail Report

●       Audit Search CSV Report

●       Biometric Search CSV Report

●       Card Search CSV Report

●       Card Status Detail Report

●       Certificate Search CSV Report

●       Certificate Status Detail Report

●       Digital ID Search CSV Report

●       Smart Credential Search CSV Report

●       Token Search CSV Report

●       Token Status Detail Report

●       Unassigned Card Status Summary Report

●       Unassigned Token Status Summary Report

●       User Authenticator Detail Report

●       User Search CSV Report

●       User Status Detail Report

You set up the report search criteria in the Administration interface or Master user shell and generate one of these reports.
