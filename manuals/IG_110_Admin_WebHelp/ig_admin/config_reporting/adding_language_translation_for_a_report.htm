IdentityGuard Server 11.0 Administration Guide

Add language translation for a report

If additional language translation files are present in the report template directory, you can run a report with static text in another language. The language of the report output is selected based on your browser locale settings (in the case of the Administration interface), or is set explicitly (in the case of the Master user shell).

If a language file that matches the request does not exist, the default language is used (English).

To add a language translation for a report

1.      Navigate to the Entrust IdentityGuard report template directory.

●       For Windows installations, the default location is:

C:\Program Files \Entrust\identityguard\identityguard93\etc\templates\reports

●       For UNIX installations, the default location is:

/opt/entrust/identityguard93/etc/templates/reports

2.      Find the report you want to modify, for example, AuditAdminActionDetail.

3.      Copy the report properties file to a language-specific file name in the same directory. The language-specific report file name follows one of these conventions:

●       <reportname>_<lang>.properties

●       <reportname>_<lang>_<country>.properties

Where:

●       <lang> is a two letter ISO language code. For a list of language codes, see https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes.

●       <country> is a two letter ISO country name. For a list of country codes, see https://en.wikipedia.org/wiki/ISO_3166-2.

Some examples:

AuditAdminActionDetail_es.properties for Spanish strings

AuditAdminActionDetail_fr_CA.properties for Canadian French strings

4.      In any text editor, open the .properties file for the report you want to update.

5.      Translate the contents of the report properties file into the language specified by the file name convention.

6.      Run the report specifying the appropriate Locale to see the translated text.
