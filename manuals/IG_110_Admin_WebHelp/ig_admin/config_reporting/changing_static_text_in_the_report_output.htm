IdentityGuard Server 11.0 Administration Guide

Change the static text in the report output

You can edit a report properties file to change the text used in the display of the report. Static text includes labels like the Report Start Date, Records Processed, for example.

To change static text in the report output

1.      Navigate to the Entrust IdentityGuard report template directory.

●       For Windows installations, the default location is:

C:\Program Files \Entrust\identityguard\identityguard93\etc\templates\reports

●       For UNIX installations, the default location is:

/opt/entrust/identityguard93/etc/templates/reports

2.      Find the report you want to modify, for example, AuditAdminActionDetail.

3.      Copy the properties file for the report you want to modify to a new name in the same directory, for example, AuditAdminActionDetail.properties.OLD.

4.      In any text editor, open the .properties file for the report you want to update.

5.      Modify the text as desired, and save the file. The file contains comments to indicate where the text labels appear.

6.      Run the report to view the results. No restart of the Entrust IdentityGuard Server service is required.
