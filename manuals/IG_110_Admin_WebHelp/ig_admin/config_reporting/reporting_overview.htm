IdentityGuard Server 11.0 Administration Guide

Reporting overview

Reporting is a powerful tool that you can use to get information about your Entrust IdentityGuard deployment. It is designed to zoom in on current information about specific groups of users, audits, or authentication types, based on search criteria and the personal queries feature. Reporting makes use of the same data repositories used by your production IdentityGuard system.

Entrust IdentityGuard allows you to create reports to help you get a snapshot of your current repository details. Use the built-in report templates to create reports for all the Entrust IdentityGuard data types. No database is required (except for creating audit reports). You can generate reports to display detailed information about users, authentication methods, and audits.

Reports and their associated report information files are stored in the file system used by the Entrust IdentityGuard server. This means that the reports are not included in Entrust IdentityGuard backups, so you must set up your own procedures for backing up the report storage directories.

You can generate reports from the Administration interface and from the Master user shell. From the Master user shell, you generate reports using options in the list command. See the Entrust IdentityGuard Master User Shell Command Reference for detailed information about Master user shell command syntax.

You can view reports from the Administration interface or directly from the file system.

The reports you can generate and the data that is included in them depends on your permissions. Entrust IdentityGuard also restricts who can view the reports based on their permissions. For more information about the required reporting permissions, see Report permissions.
