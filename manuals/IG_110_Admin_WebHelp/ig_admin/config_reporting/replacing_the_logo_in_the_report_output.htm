IdentityGuard Server 11.0 Administration Guide

Replace the logo in the report output

You can replace the logo used in the report templates if you want to customize the report output for your organization or department. The logo must be changed in each report individually, but the procedure is the same for all reports. The existing Entrust logo is a JPG image 2359 x 243 pixels in size. It is called EntrustLogo.jpg.

To ensure that the report layout is not affected by the addition of the new logo, it is recommended your replacement logo be roughly the same size as the Entrust logo.

To update the logo in a report

1.      Create your own JPG image approximately 2359 x 243 pixels in size. Save the file and make a note of the file name.

2.      Make a copy of the <$IG_HOME>/lib/IdentityGuardReportResources.jar file and give it a new name; MyReportResources.jar, for example.

3.      Open the new JAR file with a ZIP utility such as WinZIP®.

4.      Remove the existing EntrustLogo.jpg image from the JAR file, and add your own file.

Attention: Do not use EntrustLogo.jpg as the file-name.

5.      Save the JAR file.

6.      Copy the updated JAR file from <$IG_HOME>/lib to both of the following locations::

<$IG_HOME>/services/admin/IdentityGuardAdmin/WEB-INF/lib

<$IG_HOME>/services/admin/IdentityGuardAdminService/WEB-INF/lib

7.      Restart the Entrust IdentityGuard Server service so that it can find the new logo.

8.      Open the .properties file with the same name as the report you are updating.

9.      Locate the text that refers to EntrustLogo.jpg.

10.  Replace EntrustLogo.jpg with the new logo file name in the .properties file.

11.  Save the file.

12.  Run the report.

The report output now displays your new logo.
