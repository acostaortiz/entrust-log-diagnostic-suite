IdentityGuard Server 11.0 Administration Guide

Manually synchronize Entrust IdentityGuard user accounts with Active Directory

Use this procedure to synchronize Entrust IdentityGuard user accounts with Active Directory when required.

You might use this procedure to synchronize an account immediately instead of waiting for the next automatic synchronization or to resynchronize an account that was orphaned in the Entrust IdentityGuard database after the condition that caused it to be orphaned is resolved.

Note: If the Active Directory change notification mechanism is not running or Entrust IdentityGuard is not running, any changes during those outages are missed and the synchronization does not occur. Entrust IdentityGuard does not repeat the synchronization operation. In this case, user accounts will not be synchronized again until the next time user data is updated. Active Directory notifications are sent for any user update in Active Directory, including the last login timestamp attribute that is updated each time a user logs in to Active Directory.

To manually synchronize an Entrust IdentityGuard user account with Active Directory

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      In the main menu, click User Accounts.

The User Accounts page appears.

3.      Find a specific user in one of two ways:

●       use the Go To Account tab (see To search for information about one user)

●       use the Find Accounts tab (see To search for information about one or more users)

The View Account page appears with account and authentication information for the specific user.

4.      Click Sync Account.

5.      Click OK on the confirmation message.

The Last Sync Time on the user account information is updated if the synchronization is successful.
