Prerequisites for Active Directory synchronization

Your Active Directory and Entrust IdentityGuard implementations must meet the following prerequisites to use this feature:

●       The user repository to be synchronized with Entrust IdentityGuard is a Microsoft Active Directory repository. This feature is not supported for Microsoft Active Directory Lightweight Directory Services (AD LDS) or Microsoft Active Directory Application Mode (ADAM) at this time.

●       Entrust IdentityGuard user account information is stored in a supported database.

●       The administrator who creates and administers the AD Sync directory has permissions to read the users in the configured searchbase.

●       The administrator who configures this feature for enrollment in Entrust IdentityGuard has the userEnrollList permission.

●       User account names in Active Directory must be

–  an exact match with those in Entrust IdentityGuard

–  unique in the searchbase

–  case insensitive

●       All users in an Entrust IdentityGuard database configured for this feature will be enabled for the feature. Synchronization cannot be applied to some users in the database and not others.

●       An Active Directory user can be synchronized with only one Entrust IdentityGuard user account.
