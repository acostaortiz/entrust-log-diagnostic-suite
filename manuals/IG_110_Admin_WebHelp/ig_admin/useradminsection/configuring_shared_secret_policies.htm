IdentityGuard Server 11.0 Administration Guide

Configure shared secret policies

Shared secrets are small bits of information that a client application can release to a user after that user has successfully authenticated. Through the Administration interface, you can set how many shared secrets a user can have, and the total size of all the shared secrets.

For more information about shared secrets, see Administering shared secrets .

To configure shared secret policies

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      In the main menu, click Policies.

A list of all policies appears on the List Policies tab.

3.      Click any policy name to view its policy information.

The View Policy page appears and lists all policy settings.

4.      From the Policy Category drop-down list, select Shared Secret.

5.      Click Edit Policy.

An editable version of the settings appears.

6.      In the Shared Secret Policy Category pane, configure the following settings:

 Click a policy to see its description.

Total Maximum Size in Kilobytes

Sets the maximum storage space (in KB) that all shared secrets for the user combined can use. Select a value that ensures capacity issues are not encountered.

Entering 0 (zero) for either of the shared secret policies disables the use of shared secrets.

Default: 4

Maximum Number of Shared Secrets

Sets a maximum number of shared secrets each user can have. Select a value that ensures capacity issues are not encountered.

Entering 0 (zero) for either of the shared secret policies disables the use of shared secrets.

Default: 10

Note: Entering 0 (zero) for either of the shared secret policies disables the use of shared secrets.

7.      Click Save Changes.
