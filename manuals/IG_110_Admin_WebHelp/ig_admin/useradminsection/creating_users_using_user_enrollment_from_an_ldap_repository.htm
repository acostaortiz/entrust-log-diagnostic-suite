Synchronize LDAP users with an Entrust IdentityGuard LDAP repository

With the user enrollment feature, you can search your LDAP repository for potential new users, and create them in an Entrust IdentityGuard LDAP repository using the Administration interface.

Note: If your LDAP repository is Microsoft Active Directory, you can choose to store Entrust IdentityGuard user information for your Active Directory users in a synchronized database. See Synchronize users with Active Directory.

As users are added to your LDAP repository, you can set up a procedure in your organization to add these users to an Entrust IdentityGuard LDAP repository at appropriate intervals. You may want to run the user enrollment procedure every few days, or every week—whatever interval works for your organization.

The topics in this section describe how to configure and use this feature.
