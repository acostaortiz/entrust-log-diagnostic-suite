IdentityGuard Server 11.0 Administration Guide

Synchronize Active Directory users with an Entrust IdentityGuard database

With Entrust IdentityGuard Server release 11.0 and later, you can store Entrust IdentityGuard user information in a database that is synchronized with your Microsoft® Active Directory user repository. This allows automatic enrollment of users in Entrust IdentityGuard and ongoing synchronization of user full name and contact information, as well as the status of expired and disabled accounts.

This feature allows you to maintain Entrust IdentityGuard user accounts simultaneously as you manage users in Active Directory. No schema changes or other modifications are required in your Active Directory environment.

Note: This feature is not supported for Microsoft Active Directory Lightweight Directory Services (AD LDS) or Microsoft Active Directory Application Mode (ADAM) at this time.

When this feature is configured, you can use it to perform the following tasks related to Entrust IdentityGuard user accounts:

Create new Entrust IdentityGuard user accounts from Active Directory

Manually synchronize Entrust IdentityGuard user accounts with Active Directory

Manage orphaned user accounts
