IdentityGuard Server 11.0 Administration Guide

Administering users

After you create a user in Entrust IdentityGuard, administrators have access to the user’s account, and can perform a variety of tasks described in this section. The administrators’ roles must include the applicable permissions for performing these tasks.

Users can include customers, clients, partners, and your organization’s own employees. Some of these users can be given roles and acquire administrative privileges. For more information, see Administrator overview.
