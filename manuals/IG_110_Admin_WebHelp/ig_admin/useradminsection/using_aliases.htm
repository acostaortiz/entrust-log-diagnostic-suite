Using aliases

Users can have one or more aliases. These are additional names for the user that an administrator defines when creating a user entry. Aliases allow different applications to share Entrust IdentityGuard authentication. For example, one alias may be a Windows domain user name while another may be the user's Distinguished Name or email address. Or, you may have an integrated banking and investment site where each user has one user name in the banking portion and another in the investment portion. Entrust IdentityGuard aliases allow a user to have a single authentication method, such as a grid card, for authentication to all these applications.

Like a user’s name, an alias is not allowed as part of a password.
