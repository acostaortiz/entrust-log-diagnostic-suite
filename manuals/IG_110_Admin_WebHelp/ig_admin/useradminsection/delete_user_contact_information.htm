IdentityGuard Server 11.0 Administration Guide

Delete a user’s contact information

Delete a user’s contact information if the information is outdated. For example, the user may no longer use a particular phone number or email address.

To delete a user’s contact information

1.      Log in to the Administration interface (Logging in and out of the Administration interface).

2.      In the main menu, click User Accounts.

The User Accounts page appears.

3.      Find a specific user in one of two ways:

●       use the Go To Account tab (see To search for information about one user)

●       use the Find Accounts tab (see To search for information about one or more users)

The View Account page appears.

4.      Click Edit Account. The Edit Account page appears.

5.      Click Contact Information to expand the Contact Information pane.

6.      In the Contact Information pane, select the check box beside each entry you want to remove.

7.      Click Delete to delete the entry.

8.      Click Save Changes to update the user account and return to the View Account page.

If you decide not to save the changes you have made, click Restore to remove new entries and restore any you have deleted.
