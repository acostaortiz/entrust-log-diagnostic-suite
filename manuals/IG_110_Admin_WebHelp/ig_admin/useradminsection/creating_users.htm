IdentityGuard Server 11.0 Administration Guide

Creating user accounts

You must create user accounts for users who will authenticate to Entrust IdentityGuard when accessing a protected resource or when completing an action (such as a money transfer) that requires second-factor authentication.

You can create users in multiple repositories and multiple partitions. You can create users from any site or replica repository as long as your replica sites and your master site create the users in different partitions. For more information about partitions, see Using partitions.

You can create users directly in Entrust IdentityGuard using the following procedures:

●       Create a user

●       Create users through a bulk operation

If users already exist in an LDAP repository, you can configure Entrust IdentityGuard to create Entrust IdentityGuard accounts for those users automatically using one of the following features:

●       To create Entrust IdentityGuard user accounts in a database that mirrors an Active Directory LDAP repository, follow Synchronize Active Directory users with an Entrust IdentityGuard database.

●       To create Entrust IdentityGuard user accounts in an LDAP directory that mirrors and external LDAP repository, follow Synchronize LDAP users with an Entrust IdentityGuard LDAP repository.

When you use multiple repositories to store user information and assign multiple repositories to a group, it is important to qualify all user names with a group name. If yu do not specify the group name, Entrust IdentityGuard APIs search every repository for every API call that is made, which degrades Entrust IdentityGuard performance.

When you create a user:

●       Provide a user name that is unique within the group to which the user is assigned. If you do not want to have to specify the group name, then create a user name that is unique across all groups.

●       Specify the group the user belongs to. This sets the policies that govern the user.

●       Specify a repository where the user information is stored. (This is only required if the Entrust IdentityGuard installation is associated with more than one repository.)

Attention: If you are using an LDAP repository, the Entrust IdentityGuard user you create must already exist as an entry in the repository and the user ID must be unique within the search base as well as within the group.
