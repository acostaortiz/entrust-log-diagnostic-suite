IdentityGuard Server 11.0 Administration Guide

Create a temporary PIN for a user

Create temporary PINs for users when they need to authenticate to your system and they do not have a valid card or token.

The default temporary PIN lifetime, expiry date, and maximum number of uses are set by the temporary PIN policies (see Configuring temporary PIN policies). When creating a temporary PIN for a user, administrators can override these defaults if their role includes the userPinOverridePolicy permission.

After creating the temporary PIN, provide the temporary PIN to your users in a secure manner (such as a phone call or secure email).

Note: You cannot create a temporary PIN for a user who already has a temporary PIN. To create a new temporary PIN for a user, you must first delete the user’s current temporary PIN (see Deleting a user’s temporary PIN).

To create a temporary PIN for a user

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click User Accounts on the main menu.

3.      Find a specific user in one of two ways:

●       use the Go To Account tab (see To search for information about one user)

●       use the Find Accounts tab (see To search for information about one or more users)

The View Account page for the user appears.

4.      Under Authentication Types, select Temporary PIN, and then click Create PIN.

The Create PIN page appears.

5.      Under PIN Lifetime, select when the temporary PIN expires. The choices are:

●       Default — The temporary PIN policies determine when the temporary PIN expires.

●       Set PIN Lifetime — Additional options appear. Specify a length of time by entering a number in the text field and then selecting a time value from the drop-down list (hours, days, months).

●       Set PIN Expiry Date — Additional options appear. Specify a date and time by selecting a date from the PIN expires on drop-down lists (day, month, year), and then selecting a time from the Time drop-down lists (hour, minute). Alternatively, click the calendar icon to select a date.

●       PIN Never Expires — The temporary PIN never expires.

6.      Under Maximum Uses, set how many times a user can authenticate with the temporary PIN.

●       Default The temporary PIN policies determine the number of authentications.

●       PIN can be used a maximum number of times — Enter a number in the text field to specify the number of times a user can authenticate with the temporary PIN.

●       PIN can be used an unlimited number of times — The user can authenticate with the temporary PIN until it expires or is deleted.

7.      (Optional) In the Comments, enter comments.

8.      Click Create PIN.

The View Account page reappears.
