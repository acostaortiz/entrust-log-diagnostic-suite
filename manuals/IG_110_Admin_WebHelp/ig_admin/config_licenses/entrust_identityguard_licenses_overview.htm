IdentityGuard Server 11.0 Administration Guide

Entrust IdentityGuard licenses overview

The user capacity and enabled features of your Entrust IdentityGuard installation depend on the number of licenses your business has purchased. You can administer these licenses, and arrange to be notified when your license count is running low.

Before Entrust IdentityGuard Server release 10.2 Feature Pack 1, the following types of licenses were available:

●       Users

●       Soft Tokens

●       Smart Credentials

In Entrust IdentityGuard Server 10.2 Feature Pack 1, the licensing scheme was revised to make it easier to enable optional features and manage licenses. In 10.2 Feature Pack 1 and later releases, the Licensing Information window in the Administration interface lists the following licenses:

●       Users — enables IdentityGuard administrators to use the core product features and allows licensed users to use the all second-factor authenticators except soft tokens, smart credentials, and biometrics, which are licensed separately.

●       Soft Tokens — controls the ability to create soft tokens to be used for authentication.

●       Transaction Verification with Soft Tokens — with the Soft Tokens license, this license allows a soft token to be used for out-of-band transaction verification, as well as for authentication.

●       TEE Storage for Soft Tokens — with the Soft Tokens license, this license allows soft token seed to be stored in a supported Trusted Execution Environment (TEE) of an enabled mobile device. Currently, Entrust IdentityGuard supports the Samsung KNOX TEE on some Samsung mobile devices. For more information and configuration details, see Enable storage of soft tokens in TEE.

●       Smart Credentials — controls the ability to create and manage smart credentials and encode smart credentials on plastic smart cards or USB tokens.

●       Mobile Smart Credentials — with the Smart Credentials license, this license controls the ability to encode smart credentials in mobile device apps.

●       Identity Assured with Smart Credentials — with the Smart Credentials license and the Mobile Smart Credentials license, this license allows smart credentials to be used from a mobile device with a cellular provider data network or Wi-Fi connection for operations such as authentication, transaction verification and digital signing.

●       Biometrics — allows users to enroll biometric information (fingerprints) and use them to log in to computers running the Entrust IdentityGuard Desktop client for Windows.

All features are activated through a composite license and all feature licenses have the same expiry date.

For information about how licensing is handled when partitions are in use, see Using partitions. (Partitions are an advanced feature that may be required if you have multiple Entrust IdentityGuard servers with replicated repositories.)
