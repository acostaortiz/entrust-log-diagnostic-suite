IdentityGuard Server 11.0 Administration Guide

Users licenses

When the authentication and administration services start, the Entrust IdentityGuard server performs the following checks:

●       Is the Users license current? If the Users license has expired, the services do not start.

●       Is the user license count within set limits of the Users license? If the number of users exceeds the license count, the services do not start. This would occur if you restored entries in a directory from backup. Some of those entries may have been deleted from IdentityGuard thus releasing the license for other user creations, but restoring the entries brings the IdentityGuard user data back and uses more licenses.

Each time you create or delete an Entrust IdentityGuard user, the Users license is checked and the user license count is updated. If the number of users meets or exceeds the Users license count, you cannot create new users.

Users that are suspended still count as used licenses. That includes users who are suspended in Entrust IdentityGuard after their LDAP account is disabled when LDAP status mapping is enabled. See Suspending disabled and expired LDAP users for information about enabling this mapping.

Attention: If the Entrust IdentityGuard services do not start because the number of users exceeds the Users license count, you can log in to the Master user shell and either delete users until your user count is within the limit, or update the Users license to increase the user limit.
