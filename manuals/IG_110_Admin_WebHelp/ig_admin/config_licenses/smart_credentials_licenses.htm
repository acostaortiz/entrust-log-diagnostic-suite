IdentityGuard Server 11.0 Administration Guide

Smart Credentials licenses

Entrust IdentityGuard keeps track of the number of users licensed to use smart credentials. Each user with this kind of license can have more than one smart credential.

The tracking is performed as follows:

●       When a user enrolls for a smart credential, the Smart Credentials license count increases by one.

●       If a user is assigned another smart credential, there is no change to the license count. With a single Smart Credentials license, a user can have as many smart credentials as permitted by policy.

●       When all of a user's smart credentials are deleted from Entrust IdentityGuard, the license count decreases by one.

●       When a user who had smart credentials is deleted from Entrust IdentityGuard, the license count is decreased by one.

●       Canceling all smart credentials for a user does not decrease the license count. To decrease the count, all of the user's smart credentials must be deleted, or the user who is licensed to use smart credentials must be deleted from the system.

●       Unassigning a smart credential does not free the Smart Credential license.
