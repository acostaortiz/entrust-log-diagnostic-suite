IdentityGuard Server 11.0 Administration Guide

TEE Storage for Soft Tokens

Entrust IdentityGuard keeps track of the number of soft tokens that can be stored in the Trusted Execution Environment (TEE) on some models of Samsung mobile devices. Unlike other feature licenses with which one license can enable multiple authenticators (for example, multiple smart credentials), each soft token that is created in a TEE consumes one license.

The tracking is performed as follows:

●       When Entrust IdentityGuard policy dictates that a soft token be created in the Trusted Execution Environment of an eligible Samsung device and a user creates a first soft token, the Soft Tokens license count and the TEE Storage for Soft Tokens license count both increase by one.

●       When a second or subsequent soft token is created in the TEE, the Soft Tokens license count remains the same, but the TEE Storage for Soft Tokens license count increases again.

●       If a user has more than one soft token, when a user's soft token (stored in the TEE) is deleted from Entrust IdentityGuard, the count of the TEE Storage for Soft Tokens license decreases by one, but the Soft Tokens license count remains the same (1).

●       When a user who has this kind is license is deleted from Entrust IdentityGuard, the count of the Soft Token licenses decreases by one and the TEE Storage for Soft Tokens license count decreases by the number of soft tokens the user had stored in the TEE.

●       Canceling all soft tokens for a user does not decrease the count of the Soft Tokens licenses or the TEE Storage for Soft Tokens licenses. To decrease the license counts, all of the user's soft tokens must be deleted, or the user who is licensed to use the soft tokens must be deleted from the system.
