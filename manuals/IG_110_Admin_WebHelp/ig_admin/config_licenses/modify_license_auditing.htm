IdentityGuard Server 11.0 Administration Guide

Modify license auditing

 

To modify license auditing

1.      Start the Entrust IdentityGuard Properties Editor on the primary or replica server where you want to modify the auditing features. (See Log in or out of the Properties Editor.)

2.      On the Table of Contents, click License Audit Settings.

3.      Under License Auditing Enabled, ensure that True is selected.

4.      (Optional) Enter a number in the License Audit Interval field. This sets how often in hours Entrust IdentityGuard performs the license audit check. The default is 12.

The audit check runs only after the interval has passed, not at system startup. This means that if the service is always restarted within the specified interval, the audit integrity is never checked.

5.      (Optional) Enter a number in the License Audit User Number Limit field. When the user count remaining reaches that number, Entrust IdentityGuard generates an audit message. The default is 15%.

6.      (Optional) Enter a number in the License Audit Expiry Day Limit field. When the number of days left before license expiry reaches that number, Entrust IdentityGuard generates an audit message. The default is 30.

7.      The remaining fields in the License Audit Settings let you specify the Number Limit and Expiry Day Limit for each of the features you are licensed to use. Complete the fields relevant to your system, based on this example for soft tokens. Check the help in the License Audit Settings page for defaults. For more information on these properties, see License Audit Settings.

a.      Under Token License Audit Token Number Limit, enter a number or percentage value such as 10%.

–  If set to a number, an audit is generated when the soft token count gets to within this number of the license limit. For example, if you set this value to 10, and the license limit is 50, then an audit is logged when the soft token count reaches 40.

–  If set to a percentage, an audit is written when the soft token count is within this percentage of the maximum. For example, if you set this value to 10% and the license limit is 50, then an audit is logged when the soft token count reaches 45.

–  If not set, the default is 15%.

b.      Under Token License Audit Expiry Day Limit, enter a number in days. An audit is generated when the current date gets to within the given number of days of the soft token license expiry. For example, if you set the value to 30 and the soft token license expires on December 30th, an audit is logged on December 1st.

8.      If not set, the default is 90. 

9.      Repeat the previous step for all relevant license types, then click Validate & Save.

The audit is enabled on all replicas of the Entrust IdentityGuard Server. To prevent duplicate audits from being generated on replica Entrust IdentityGuard servers, use the Properties Editor to disable the audit integrity check on all but one of the replicas.
