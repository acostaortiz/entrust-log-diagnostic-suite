IdentityGuard Server 11.0 Administration Guide

Delete unassigned tokens

Remove the unassigned token information if it is no longer required. You can delete tokens one at a time or in bulk.

If you accidentally delete a token, you can reload the token in Entrust IdentityGuard by loading the token data file again. See Load the token data file.

When you delete a token in Entrust IdentityGuard, the token device can no longer be used to authenticate.

To delete an unassigned token

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click Tokens from the menu bar.

3.      From the Tokens page, click the List Unassigned Tokens tab.

4.      Retrieve a list of unassigned tokens. See To find unassigned token information for details.

5.      When the Search Results page appears, click the serial number of the token to delete.

The Token Details page appears.

6.      Click Delete Token to delete the specified token.

7.      When prompted, select OK to confirm deletion.

A success message appears noting the serial number of the deleted token.

To delete unassigned tokens in bulk

8.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click Bulk Operations on the menu bar.

3.      From the Bulk Operation page, click Browse to add the data file. For more information about data files for token bulk operations, see Token bulk operations.

4.      From the Operation to Perform drop-down list, select Delete unassigned tokens located under Tokens.

5.      From the Halt Processing drop-down list, select the number of errors to allow before processing stops due to too many errors.

For more information about bulk file options, see Perform bulk operations.

6.      Click Perform Bulk Operation.

The Bulk Operation in Progress page appears. The size of your bulk operation directly affects the time the operation takes to process. This page indicates the initial status of the operation.

7.      Click Update Results to view the status of your bulk operation. (The Results page is also updated automatically every 10 seconds.)

8.      Click Done to return to the Bulk Operation page.
