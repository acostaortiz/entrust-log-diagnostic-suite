Unlock a WatchdataQRO token using Self-Service

If you enter the wrong token PIN too many times, the token becomes locked. You can unlock the token using the token provider's Self-Service Web site, or by contacting the token provider's help desk.

To unlock a WatchdataQRO token through Self-Service

1.      Log in to the token provider's Self-Service Web site.

2.      On the Self-Administration Actions page, select I'd like to unlock my hardware token.

The Self-Service page displays your token serial number and asks you to confirm that you want to unlock it.

3.      Click Yes.

4.      If the token is not already on, long press the On button to start the token.

5.      On the Token Unlock screen, enter the Unlock Code shown on your token, and then click OK.

Self-Service displays a QR code.

6.      Point the camera on the back of the token at the QR code displayed on the Token Unlock page, and then press OK.

The token scans the QR code, and then the Token Unlock screen prompts you to enter a new PIN.

7.      Enter the new PIN and enter it again to confirm it.

The token screen confirms that the PIN is reset and you can continue to use the token.

8.      Click Done on the Self-Service Web page.
