IdentityGuard Server 11.0 Administration Guide

Create groups for uninitialized and initialized tokens

You might receive WatchdataQRO tokens that are initialized or uninitialized.

Before a token can be given to a user, it must be initialized and then assigned to a specific user in Entrust IdentityGuard. (Token assignment can be manual through the Administration interface or automatically through Self-Service).

It is important to separate initialized and uninitialized tokens in different Entrust IdentityGuard groups because there is no capability to search for initialized tokens. (Token Details for specific tokens do have an indicator of whether the tokens are initialized.)  

For this purpose, create different Entrust IdentityGuard groups to keep track of which tokens are initialized and which are not. After tokens are initialized, associate them with the group that can request initialized WatchdataQRO tokens..

To create groups in which to track initialized and uninitialized Watchdata QRO tokens

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click Groups on the home page.

3.      Click the Create Group tab.

4.      Type a name in the Group field, for example, W_uninitialized.

5.      (Optional) Add comments describing the purpose of the group. In this case, the group exists to track the serial number of WatchdataQRO tokens that have not yet been initialized.

6.      Click Create Group.

The Group Information  page appears for the new group.

7.      Click Done.

8.      Repeat steps 3 to 7 to create a second group for initialized tokens. You might call it W_initialized.

9.      Click Save Changes.

10.  On the Token Details page, click Done.
