Correct token drift (synchronizing a token)

Occasionally, a token device can become unusable due to “event drift” or “clock drift”.

Event drift occurs when a user repeatedly presses the button on an event-based token, such as the Entrust Mini token, without the response being used to authenticate. When this occurs, the event counter maintained by the token becomes out-of-sync with the event counter maintained by the Entrust IdentityGuard server. When this drift becomes too large, the user can no longer authenticate.

Clock drift occurs when the clock on a time-based token, such as the Entrust OT token, becomes out-of-sync with the clock on the Entrust IdentityGuard server. When this drift becomes too large, the user can no longer authenticate.
