IdentityGuard Server 11.0 Administration Guide

Authenticate in response-only mode with a Pocket Token

Response-only mode is also known as synchronous mode.

In this mode, when a user attempts to connect to a secure resource, the user generates a dynamic password with the Pocket Token. The user then enters the password into the secure resource.

To authenticate in asynchronous mode

1.      Press the ON button.

If the Pocket token is protected by a PIN, it displays the ENTER PIN message.

2.      If required, enter your PIN. (The Pocket Token displays an X for each number you enter. If you enter a wrong number, use the MENU button to delete it.)

The Pocket Token displays the dynamic password.
