IdentityGuard Server 11.0 Administration Guide

Administer assigned tokens

After tokens are assigned to users, each user's Account Information page in the Administration interface displays the user’s tokens and allows you to modify the information. You can modify a token’s state, change the token lifetime, delete the token, and so on.

To complete these procedures, administrators must have the required role permissions. See Token permissions.

The following administrative tasks can be performed on assigned tokens:

●       Find assigned token information

●       Authenticate a user with a token

●       Edit token information

●       Cancel a token

●       Unassign an assigned token  (not applicable to soft tokens)

●       Unlock a PIN-protected token

●       Delete a token

●       Add tokens again after an accidental deletion

●       Create or rename a token set

●       Correct token drift (synchronizing a token) (not applicable to WatchdataQRO tokens)

Any changes made to the token take effect the next time it is used for authentication.

Note: Most tasks listed here can also be performed on soft tokens. The exceptions are marked.
