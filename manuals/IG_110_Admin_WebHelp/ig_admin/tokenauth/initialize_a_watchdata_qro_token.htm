IdentityGuard Server 11.0 Administration Guide

Initialize WatchdataQRO tokens

This procedure applies only to uninitialized WatchdataQRO tokens.

If you received uninitialized WatchdataQRO tokens, they must be initialized before they can be used. After the tokens are initialized, move them to an Entrust IdentityGuard group for initialized tokens from which they can be assigned to users.

To initialize a WatchdataQRO token

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click Tokens.

3.      Click the List Unassigned Tokens tab.

4.      Click the serial number of the token you want to initialize. Ensure it is a token from the uninitialized token group you created in Create a group for uninitialized tokens.

The Token Details page appears.

5.      Click Initialize Token.

The Initialize an unassigned token page displays a QR code.

6.      Turn on the token. (Long press the On button .)

The token display prompts you to press OK to activate the token.

7.      Point the camera on the back of the token at the QR code displayed in the Administration interface, and then press OK.

The token scans the QR code and activates the token, and then prompts you to enter a PIN for the token.

8.      Use the token keypad to enter a PIN and then confirm the PIN when prompted.

Note: You can set the same PIN for all tokens or you can specify a unique PIN for each user. Either way, you must communicate the PIN to the user. Currently Entrust IdentityGuard does not provide a way to set or record the PIN automatically. As a best practice, direct users to change the PIN when they use the token for the first time.

9.      In the Administration interface, click Complete.

10.  Move the initialized token to the Entrust IdentityGuard group for initialized tokens. To do so, complete the following steps:

a.      On the Token Details page for an initialized token, click Edit Token.

b.      On the Edit an assigned token page, from the Group drop-down list, select the name of the group that contains initialized tokens.

c.      Click Save Changes.

The initialized token is ready to assign to a user.
