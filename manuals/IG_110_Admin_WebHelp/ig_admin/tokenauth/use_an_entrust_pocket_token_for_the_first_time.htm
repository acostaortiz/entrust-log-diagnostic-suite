IdentityGuard Server 11.0 Administration Guide

Use a Pocket Token for the first time

When you receive your Entrust Pocket Token, it has an initial PIN configured. The first time users use the Pocket Token, they have to change this initial PIN. Users must be careful to keep this new PIN secret in order to keep the Pocket Token secure.

Note: You can configure the Pocket Token to not use a PIN (that is, to not use PIN protection). In this case, when the user turns on the token, it immediately enters the password generation process.

To use the Entrust Pocket Token for the first time

1.      Press the ON button.

The Pocket Token displays the ENTER PIN message.

2.      Enter the initial PIN.

(The Pocket Token displays an X for each number you enter. If you enter a wrong number, use the MENU key to delete it.)

If the PIN is correct, the Pocket Token displays the NEW PIN message.

Otherwise, it displays an ERROR message.

3.      Enter a new PIN known only to you, and press the ON button.

Note: Pocket Token devices can be configured to check for weak PINs and reject them (see “Weak PIN checking” on page 21). If you entered a weak PIN, the Pocket Token displays the ERROR message, and then displays the NEW PIN message again so that you can try a different new PIN.

The Pocket Token displays the CONFIRM message, prompting you to confirm the new PIN.

4.      Enter the new PIN again, and press the ON button.

The Pocket Token displays the COMPLETE message.

●       If the Pocket Token is configured for synchronous (response-only) authentication, it displays the dynamic password.

●       If the Pocket Token is configured for asynchronous (challenge/response) authentication, it displays a flashing cursor, prompting you to enter the challenge number from your secure resource.
