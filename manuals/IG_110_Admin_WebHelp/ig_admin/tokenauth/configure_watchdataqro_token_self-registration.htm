IdentityGuard Server 11.0 Administration Guide

Configure self-registration for WatchdataQRO tokens

Complete this procedure if you are using Entrust IdentityGuard Self-Service Module and if you want to issue WatchdataQRO hardware tokens to users when they register.

The procedure is the same as for self-registration for other types of hardware tokens, with the following exceptions:

●       WatchdataQRO tokens must be auto-assigned to users (that is, a specific token must be assigned to a specific user by an administrator before it is given to the user)

●       If you created groups for uninitialized and initialized tokens (as recommended in Create groups for uninitialized and initialized tokens), specify the tokens should be assigned from an alternate group, which is the group of initialized tokens.

To configure self-registration of WatchdataQRO tokens

1.      Log in to Self-Service Module Configuration interface.

2.      Click Registration.

3.      From the Table of Contents, select Hardware Token Self-Registration.

The Hardware Token Self-Registration section appears.

4.      To configure Self-Service self-registration for WatchdataQRO tokens, answer the following questions in the Hardware Token Self-Registration section. For details about the other configuration options in this section, see "Configure hardware token self-registration" in the Entrust IdentityGuard Self-Service Module Installation and Configuration Guide.

●       Do you want users to be issued a hardware token at registration time if they do not already have a token?

Select Yes.

–  1. Select which Entrust IdentityGuard groups should be issued a hardware token.

Select the user group or groups that can request WatchdataQRO tokens.

–  2. Would you like to auto-assign hardware tokens?

Select Yes. When a user requests a token in Self-Service, Self-Service Module selects the next available token of the type specified as the preferred hardware token vendor. Self-Service Module sends an email to the administrator requesting a token for the user, and specifies the serial number of the token that should be delivered. That specific token must be initialized and delivered to the user.

–  3. Select a preferred hardware token vendor:

Select watchdata.

–  4. Would you like to force users to activate their hardware tokens using self-administration? If No, users can start using their hardware tokens as soon as they receive them.

Select Yes if you want users to perform an authentication in Self-Service to activate the token. This setting assigns the tokens in the hold-pending state, and requires that users select the Self-Administration action I'd like to activate my hardware token so I can start using it to change the token to the current state, after which it can be used for authentication.

If you select No, tokens are assigned in the pending state and users can start using their tokens when they receive them.

–  5. If an unassigned token associated with the user's group is not available, select an alternate group from which the token can be obtained.

From the drop-down list, select the group you created to store initialized tokens. In this example, the group is W_initialized.

5.      Click Validate & Save.

6.      Restart the Self-Service Module service to have the changes take effect.
