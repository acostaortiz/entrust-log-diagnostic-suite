IdentityGuard Server 11.0 Administration Guide

Find and delete corrupt tokens

If token data becomes corrupt you cannot delete the tokens in the Administration interface. The Administration interface does not display corrupt tokens.

To find and delete a corrupt token, you must use the Master user shell.

If you accidentally delete a token, you can load the token back into Entrust IdentityGuard by loading the token data file again. See Load the token data file.

To find corrupt tokens

1.      Open the Master user shell and log in. (See Using the Master user shell.)

2.      Do one of the following:

●       To find users with corrupt tokens (and grids), enter

user list

●       To find corrupt unassigned tokens, enter

token list

Any line of data that includes corrupt data is prefixed with an asterisk.

If your system uses tokens from multiple vendors, you need to specify the vendor ID of the token to delete it. If you do not specify the vendor ID, the default vendor ID is assumed.

To delete small numbers of corrupt tokens

1.      Do one of the following:

●       For unassigned tokens, enter

token delete [<vendorid>] <sernum>

●       For tokens assigned to users, enter

user token delete <userid> [<vendorid>] <sernum>

Where:

–  userid identifies the user

–  vendorid identifies the token vendor

–  sernum is the serial number that identifies token.

2.      Enter y (yes) when prompted to confirm the action.

To delete large numbers of corrupt tokens

1.      In the Master user shell, enter:

token list -invalidToken -export <export_file>

This command finds all invalid tokens and lists them in the export file you specified.

2.      Enter:

token delete -import <export_file> -force

This command deletes the tokens listed in the export file.
