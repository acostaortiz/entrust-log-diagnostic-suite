Messages of Entrust Pocket Tokens

The Entrust Pocket Token can display the following messages.

Message

Description

COMPLETE

Indicates that the operation just performed (PIN change, for example) was successfully completed.

CONFIRM

Prompts you to enter the new PIN again when changing the PIN.

INIT

Prompts you to enter the initialization code when initializing the token manually.

ENTER PIN

Prompts you to enter the PIN after turning on the Entrust Pocket Token.

ERROR

Indicates an error occurred in the current operation (for example, a wrong PIN entry).

LAST TRY

Indicates that this is your last attempt to enter the correct PIN before the Entrust Pocket Token locks, or that this is your last attempt to enter the correct unlock code before the Entrust Pocket Token resets.

LOCKED

Indicates that the Entrust Pocket Token is locked after too many consecutive wrong PIN entries.

NEW PIN

Prompts you to change the PIN after:

·      accessing the change PIN function

·      unlocking a locked Entrust Pocket Token

·      resetting an Entrust Pocket Token

WAIT

Indicates that the Entrust Pocket Token is temporarily locked due to a wrong PIN entry (delay mechanism is enabled)
