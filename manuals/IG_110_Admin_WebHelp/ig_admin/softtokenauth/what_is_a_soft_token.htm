What is a soft token?

A soft token, like a hardware token, generates a number (also known as an OTP or security code) that can be entered on your Web site to authenticate. Unlike a hardware token, a soft token is software only, and must be installed on a mobile device or computer. Entrust delivers two applications that contain soft tokens: the Entrust IdentityGuard Mobile ST app (for mobile devices), and Entrust IdentityGuard Desktop Soft Token (for Windows or Mac).
