IdentityGuard Server 11.0 Administration Guide

Administering soft tokens

You can perform the following administration tasks on soft tokens:

●       Creating and activating a mobile soft token using the Administration interface

●       Finding assigned token information

●       Authenticating a user’s token

●       Editing token information

●       Unlocking a PIN-protected token

●       Deleting a token

●       Creating or renaming a token set

●       Correcting token drift (synchronizing a token)

In addition, may administrative tasks for soft tokens are the same as for hardware tokens. For more administrative procedures, see Token authentication.

In order to complete these procedures, administrators must have the correct role permissions. See Token permissions for a list of all role permissions relating to tokens.
