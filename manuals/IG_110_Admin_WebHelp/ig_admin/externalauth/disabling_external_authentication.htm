IdentityGuard Server 11.0 Administration Guide

Disable external authentication

If you need to disable external authentication temporarily, leave the related Entrust IdentityGuard properties as they are, and just remove the External option from the Included list of the authentication restriction policy of each applicable group. That way you can easily enable external authentication again through a policy setting. If your intention is to disable external authentication permanently, use the Properties Editor to remove any values associated with the external authentication. See External First-Factor Authentication.
