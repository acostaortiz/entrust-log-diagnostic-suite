IdentityGuard Server 11.0 Administration Guide

Import the Federation Module’s Web certificate (if you copied it)

Complete this procedure f you copied the Federation Module’s Web certificate (igfederation.cer) (see Prerequisites for configuring SAML login to Administration for details). The Web certificate is used to enable SSL communication between the Entrust IdentityGuard Server and the Federation Module. It is not used for SAML communication.

If you instead copied the CA certificate that signed the Federation Module’s Web certificate, skip this procedure.

To import the Federation Module’s Web certificate (if you copied it)

1.      Change to the keytool directory. The utility is located in:

●       UNIX or Linux: $IG_HOME/jre<version>/bin 

●       Windows: <$IG_HOME>\jre<version>\bin 

2.      Enter the following command:

keytool –import –alias <alias> -file <filename> -keystore <keystore> -storepass <storepass>

where:

●       <alias> is an alias you want to give to the certificate. Example: igfm.

●       <filename> is the path and location of the certificate file. Example: c:\IDPdata\igfederation.cer.

●       <keystore> is the path and name of the keystore file where you want to store the keys associated with the certificate. You can re-use the Entrust IdentityGuard Server’s keystore, by default <$IG_HOME>\etc\keystore, or you can specify a new keystore path and name. If you specify a new keystore, it will be created when you execute the command. Supported keystore file extensions are: JKS, JCK (for a JCEKS type of store), and P12 (for a PKCS#12 type of store). If no file extension is provided, JKS is used.

●       <storepass> is password for the keystore. If you are using the Entrust IdentityGuard Server’s keystore, the password is entrust by default. If you are creating a new keystore as part of this command, select a password of your choice.

Example:

keytool –import –alias igfm -file "C:\IDPdata\igfederation.cer" -keystore "C:\Program Files\Entrust\IdentityGuard\identityguard102\etc\keystore" -storepass entrust
