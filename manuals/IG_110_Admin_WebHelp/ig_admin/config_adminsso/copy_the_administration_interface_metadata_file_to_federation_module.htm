IdentityGuard Server 11.0 Administration Guide

Copy the Administration interface metadata file to Federation Module

To copy the Administration interface’s metadata file to Federation Module

1.      In a browser, go to:

<admin_interface_URL>/saml/metadata.xml

For example:

https://yourcorp.com:8444/IdentityGuardAdmin/saml/metadata

2.      Download the XML file. Save it as ig.metadata.xml or a similar name that describes the metadata.

3.      On the Federation Module, create a folder  called c:\SPdata or a similarly-named folder.

4.      Into c:\SPdata, copy:

●       The Entrust IdentityGuard Server’s metadata file (ig.metadata.xml)

●       The CA certificate chain that signed the Entrust IdentityGuard Server’s SAML certificate and keys (igsamlRootCA.cer, igsamlIntermediateCA1.cer, igsamlIntermediateCA2.cer) OR the Entrust IdentityGuard Server’s SAML certificate itself (igsaml.cer), if it is self-signed.

Note: Do not copy the Entrust IdentityGuard Server’s Web certificate or the CA certificate that signed the Entrust IdentityGuard Server’s Web certificate. These files are not required.
