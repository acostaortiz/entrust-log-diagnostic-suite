IdentityGuard Server 11.0 Administration Guide

Configure SAML keystore settings in the Properties Editor 

To configure SAML keystore settings in the Properties Editor

1.      Scroll to the next section in the Properties Editor, entitled, SAML SP Keystore Settings.

2.      Under SAML Keystore File Location, specify the keystore file that contains the Entrust IdentityGuard Server’s SAML certificate and keys. See Generate a SAML certificate to be used by Entrust IdentityGuard Server for details. The default is <$IG_HOME>\etc\keystore. If you instead created a keystore dedicated to SAML keys, specify that keystore here.

3.      Under SAML Keystore Password, specify the password of the SAML keystore. If you are using Entrust IdentityGuard Server’s default keystore, <$IG_HOME>\etc\keystore, the password is entrust. If you created a new keystore dedicated to SAML keys, enter its password.

4.      Select Encrypt to encrypt the password.

5.      Under SAML Keystore Type, specify the format of the keystore used for the SAML keys. Supported types are: JCEKS, JKS, and PKCS12. The default is JKS, which is the type used for Entrust IdentityGuard Server’s keystore, <$IG_HOME>\etc\keystore.

6.      Under Default Signing Key Alias, specify the alias of the Entrust IdentityGuard Server’s SAML certificate and keys. This alias can be one of two things:

●       If you decided to re-use keys that already exist in the Entrust IdentityGuard keystore as your SAML keys, then use the alias tomcat.

●       If you decided to generate and import new SAML keys to be used by the Entrust IdentityGuard Server, use the alias that you used when you imported the keys. For example: igsaml. For details, see Generate a SAML certificate to be used by Entrust IdentityGuard Server.
