IdentityGuard Server 11.0 Administration Guide

Specify the delegation administrator in the Properties Editor

To specify the delegation administrator in the Properties Editor

1.      Log in to the Properties Editor. See Log in or out of the Properties Editor.

2.      From the table of contents, select Web Application Settings.

3.      Under Delegation Administrator User ID, specify iginternalSAMLdelegate or whatever name you chose for the delegation administrator.

4.      Under Delegation Administrator Password, specify the password for the iginternalSAMLdelegate account.

5.      Select Encrypt to encrypt the password.

6.      Under Delegation Administrator Password Length, specify the maximum length of the password. This length is respected when the password is auto-updated. If you do not specify anything, the maximum length is the length specified in the Entrust IdentityGuard password policy.

7.      Under Delegation Administrator Password Auto Update, select True if you want the delegation administrator password to be auto-updated with a system-generated one when it expires. If you set the password to Password Never Expires (when setting up the delegation administrator account), set the Delegation Administrator Password Auto Update setting to False.

8.      Under Delegation Administrator Password Auto Update Interval, specify the frequency, in seconds, with which the password is checked to see if it is close to its expiry. The password will be updated prior to expiry. The default is 3600 seconds (or 1 hour).

9.      Click Validate & Save.
