IdentityGuard Server 11.0 Administration Guide

Import all CA certificates

If you copied any CA certificates (idpca.crt and any others) as instructed in Prerequisites, you must import all these files to a keystore on the Entrust IdentityGuard Server.

To import all CA certificates

1.      In the Java keytool utility, enter the following command:

keytool –import -trustcacerts –alias <alias> -file <filename> -keystore <keystore> -storepass <storepass>

where:

●       <alias> is an alias of the CA certificate. For example: idpca 

●       <filename> is the path and filename of the CA certificate. For example, C:\IDPdata\idpca.crt.

●       <keystore> is the path and name of the keystore file where you want to store the keys associated with the CA certificate. Example:

<$IG_HOME>\etc\keystore 

●       <storepass> is password for the keystore. If you are using the Entrust IdentityGuard Server’s keystore, the password is entrust by default. If you are using a different keystore, enter its password.

Example:

keytool –import -trustcacerts –alias idpca -file "C:\IDPdata\idpca.crt" -keystore "C:\Program Files\Entrust\IdentityGuard\identityguard102\etc\
keystore" -storepass entrust
