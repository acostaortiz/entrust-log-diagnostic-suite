IdentityGuard Server 11.0 Administration Guide

Overview

Secure Assertions Markup Language (SAML) is a open standard. Its purpose is to make it easy to enable single sign-on (SSO) between Web applications.

There are several SAML-ready applications that have been tested with Entrust IdentityGuard. They are called SAML service providers, or SPs. They are:

●       Google

●       Salesforce

●       Office 365

●       Entrust IdentityGuard Self-Service Module

●       Entrust IdentityGuard Administration interface

To these applications, you can add Entrust IdentityGuard authentication methods (like grid, for example) without any code changes. For configuration instructions, see:

●       For Google Apps, see the Entrust IdentityGuard Federation Module and Google Technical Integration Guide.

●       For Salesforce, see the Entrust IdentityGuard Federation Module and Salesforce Technical Integration Guide.

●       For Office 365, see the Entrust IdentityGuard Federation Module and Microsoft Office 365 Technical Integration Guide.

●       For the Self-Service Module, see the Entrust IdentityGuard Self-Service Module Installation and Configuration Guide.

This section describes how to enable SAML SSO to the Entrust IdentityGuard Server’s Administration interface.
