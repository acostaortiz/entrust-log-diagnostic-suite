IdentityGuard Server 11.0 Administration Guide

Configuring knowledge-based authentication policies

Each group defined in Entrust IdentityGuard has an associated set of user policies. Every user belongs in a group, and the group’s policies affect all users in that group.

Administrators with applicable permissions in their roles can change policy. (See User registration password permissions.)
