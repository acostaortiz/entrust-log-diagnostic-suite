IdentityGuard Server 11.0 Administration Guide

View a user’s questions and answers

If a user has question-and-answer pairs, you can view the questions in the user’s Account Information. If you have the superuser role, or any role with the userQAView permission, you can also see the user’s answers.

To view a user’s questions

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click User Accounts on the main menu.

3.      To find a specific user, use the Go To Account tab (see To search for information about one user)

4.      On the Account Information pane for the user, scroll down to Authentication Types, click Knowledge-Based Q&A and review the questions.

If you have the superuser role, or another role with userQaView permission, you see the questions and the answers. If you have any other set of permissions, you can view the questions only, not the answers.

With

Questions and answers display (requires userQaView permission). Users without this permission see only the questions.
