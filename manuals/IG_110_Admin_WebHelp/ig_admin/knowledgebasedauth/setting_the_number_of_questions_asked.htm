Set the number of questions asked

There may be cases where you want a different number of questions presented based on the type of access or transaction the user requires. For example, access to a company information portal could require two questions while access to a online investment site could require four questions.

You set the minimum and maximum number of required questions in Entrust IdentityGuard policy, and then set the exact number of questions for each authentication scenario in your application. When no minimum or maximum is set, the value of the Default Q&A Challenge Size policy is used.

The application must present a number of questions between the minimum and maximum, and take into account the number of wrong answers allowed, if applicable.

When more questions are stored for users than the number required by the policy settings or the application, Entrust IdentityGuard selects the questions to present at random. Since there are a limited number of questions stored, a question may appear more than once within the same user session if this authentication method is used more than once.
