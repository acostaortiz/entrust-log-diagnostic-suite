IdentityGuard Server 11.0 Administration Guide

Card permissions

These permissions control the creation and management of preproduced (unassigned) and assigned grid cards. For information about managing grids and cards, see Grid authentication overview.

 

Permission

Dependencies

Description

cardCreate

cardGet

Create a preproduced card. The role must also include at least one group in the group list.

cardDelete

cardGet

Delete a preproduced card. The role must also include at least one group in the group list, and the cardList permission.

cardExport

cardGet

Export a preproduced card.

cardGet

 

Retrieve information about a preproduced card.

cardList

cardGet

List information about preproduced cards.

cardOverridePolicy

 

Override specific values set in the card policy when modifying or creating a preproduced card.

cardSet

cardGet

Modify preproduced card information.

cardView

cardGet

View the grid for a given preproduced card.

userAuthenticate

userGet

Authenticate a user’s account by requiring the user to respond to a grid challenge.

userCardAssign

userCardGet, cardGet

Assign a preproduced card to a user.

userCardCreate

userCardGet

Create a new user card.

userCardDelete

userCardGet

Delete a user’s card.

userCardDeleteCanceled

userCardGet

Delete canceled cards only.

Note: If userCardDelete is specified with userCardDeleteCanceled, userCardDelete takes precedence and userCardDeleteCanceled is ignored.

userCardDeliver

 

Deliver a user’s card.

userCardExport

userCardGet

Export the information about a user’s card to a file.

userCardGet

 

Retrieve information about a card.

userCardList

userCardGet

List information about user cards.

userCardOverridePolicy

 

Override the supersede and expiry date values set in the card policy when modifying or creating a user’s card.

userCardSet

userCardGet

Set information for user cards.

userCardUnassign

userCardGet

Move the card back to the preproduced card repository. This is only possible if:

·      it was originally a preproduced card assigned to the user

·      it is in the Pending or Hold_Pending state (that is, the card has not been used for authentication yet)

userCardView

userCardGet

View the grid for a given user’s card.
