IdentityGuard Server 11.0 Administration Guide

Deleting the personal verification number

Administrators with applicable permissions can delete PVNs for users.

To delete a user’s PVN

1.      Find one or more users with a PVN. (See Searching for users based on personal verification numbers.)

On the Find Accounts page, select the Has a PVN option as part of your search criteria.

2.      Select a user on the Search Results page.

The Account Information pane appears for the user.

3.      Under Authentication Types, select Personal Verification Number.

4.      Click Delete PVN.

5.      Answer OK at the prompt.

The Account Information pane reappears.
