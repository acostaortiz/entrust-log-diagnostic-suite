IdentityGuard Server 11.0 Administration Guide

Configuring personal verification number policies

Each group defined in Entrust IdentityGuard has an associated set of policies. All users belong to a group, and the group’s policies affect all users in that group.

Administrators with applicable permissions in their roles can change policy. (See User registration password permissions and User personal verification number permissions.)

The Personal Verification Number policy sets defaults for PVN uses and length for all users of the applicable group.

To view PVN policy

1.      Log in to the Administration interface. (See Logging in and out of the Administration interface.)

2.      Select Policies on the menu bar.

A list of all policies appears on the List Policies tab.

3.      Click any policy name to view its policy information.

The View Policy page appears and lists all policy settings.

4.      Under Policy Category, select Personal Verification Number from the list.

The PVN policies appear.

To change PVN policy

1.      Find the policy to change (see To view PVN policy).

2.      On the View Policy page, click Edit Policy.

An editable version of the settings appear.

3.      Edit the policies described in Personal Verification Number policies.

4.      Click Save Changes.
