IdentityGuard Server 11.0 Administration Guide

Data items for contact information bulk files

Each data item in a contact information bulk file must use the correct data type.

 

Data item name

Data type

Description

userId

string

Provides a user’s full user ID, in group/username format. The group is optional if user names are unique.

contactinfoLabel

string

The label of the contact information entry. The label must be unique across the user's contact information list.

contactinfoValue

string

The value of the contact information entry. This field can be empty if the configuration label is “none”.

deliveryConfigLabel

string

A value of none means there is no out-of-band delivery configuration for this data item.

The label of the out-of-band delivery configuration assigned to this contact information entry. The configuration must be a valid configuration.

All valid delivery configurations are defined in the identityguard.properties file. See Configuring delivery mechanisms for one-time passwords .

Default

Boolean

true or false

Flag indicating whether or not this contact information entry is the default for the user.

For this data item to be set to true, the value for deliveryConfiglabel must be valid.
