IdentityGuard Server 11.0 Administration Guide

Optimize the Administration interface for bulk operations

When the Administration interface processes large bulk files, it can take a long time and use a lot of memory. Entrust IdentityGuard provides two properties to manage resources used for bulk operations and improve performance:

●       Bulk File in Memory Threshold This property limits the amount of memory used for bulk operations. Entrust IdentityGuard writes large bulk files to disk and caches them when they exceed the limit.

●       Bulk File Maximum Size This property limits the size of files imported for bulk operations. You cannot import a bulk file that exceeds this size.

Note: You must have the propertiesSet permission to configure properties.

To configure the Administration interface properties for bulk operations

1.      Log in to the Entrust IdentityGuard Properties Editor.

Windows

a.      Select Start > All Programs > Entrust > IdentityGuard > Properties Editor.

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

UNIX

a.      Enter the URL of your Properties Editor web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardPropertiesEditor

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

b.      On the Log In page, enter your administrator name in Userid.

c.      Enter your password in Password.

d.      Enter a group name in the Group field.

e.      Click Log In.

f.        Complete the second-factor challenge, if presented.

2.      On the Table of Contents, click Web Application Settings.

3.      In the Bulk File in Memory Threshold field, enter (in bytes) a new memory threshold.

4.      In the Bulk File Maximum Size field, enter (in bytes) a new maximum size.

5.      Click Validate & Save.
