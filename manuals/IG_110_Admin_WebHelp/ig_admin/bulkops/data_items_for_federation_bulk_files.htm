IdentityGuard Server 11.0 Administration Guide

Data items for federation bulk files

Each data item in a contact information bulk file must use the correct data type.

 

Data item name

Data type

Description

userId

string

The user’s full user ID, in group/username format. The group is optional if user names are unique.

partnerID

string

The partnerID is different for SAML and OpenID. For SAML, it is the PartnerEntityID of the partner site where the user is federated.

type

string

The federation type. Typical values are: persistent, transient, igid, ppid. Persistent or transient are used for SAML; igid or ppid are used with OpenID.

isOriginator

true or false

This data item is only used for SAML persistent identifiers. Set it to true if you want the Federation Module to be the originator of the federation.

originatorFederationName

string

The federation value from the originator’s perspective.

receiverFederationName

string

This data item is only used for SAML persistent identifiers. It is the federation value from the receiver’s perspective.

comment

string

A comment about a federation.
