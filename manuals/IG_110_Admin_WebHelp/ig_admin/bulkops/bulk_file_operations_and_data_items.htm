Bulk file operations and data items

You can perform a bulk operation to accomplish a single task for a set of the same type of authenticators or users all at once. Each bulk operation requires that you include certain data items in the bulk file. Some operations allow optional items. The tables in this section list the required and optional data items for each type of bulk file.
