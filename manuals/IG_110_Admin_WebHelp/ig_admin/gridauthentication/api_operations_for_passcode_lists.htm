API operations for passcode lists

As noted earlier, you can present the user with passcodes in a random order or in the order they are printed in the list. Your choice determines the API operations you need to use.

To prompt in a random order

Note: This scenario requires less application code than the set-order scenario because Entrust IdentityGuard creates the challenge set and keeps track of rows used.

1.      Set the grid card policies as listed under Random in the table in Grid card policies for passcode lists.

2.      Use the getGenericChallenge operation to get a passcode challenge to present to the user.

3.      Use the authenticateGenericChallenge operation to verify the response.

To prompt in a fixed order

Note: This scenario requires more application code than the random-order scenario.

1.      Set the grid card policies as listed under Fixed Order in Grid card policies for passcode lists.

2.      Add code to your application to generate the challenge to present to the user.

3.      Add code to your application to keep track of which rows in the list are used. This tells the application which row is next in the list, and when to log a warning that the list is nearing the end.

4.      Use the authenticateAnonymousChallenge operation to verify the response.
