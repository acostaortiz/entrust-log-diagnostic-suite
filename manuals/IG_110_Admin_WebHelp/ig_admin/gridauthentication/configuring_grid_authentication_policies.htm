IdentityGuard Server 11.0 Administration Guide

Configure grid authentication policies

The Authentication Types policy sets the authentication methods available to users and your application. To allow grid authentication, you must add the Grid option to the list of allowed authentication methods. (Grid is included by default.)

Through the Authentication API, your client application can use any method of second-factor authentication as long it is allowed by policy.

There are two authentication security levels you can set: normal and enhanced. Each security level has its own policy, so you can set different authentication methods for each security level.

To view the authentication types policy

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Select Policies on the menu bar.

A list of all policies appears on the List Policies tab.

3.      Click any policy name to view its policy information.

The View Policy page appears and lists all policy settings.

4.      Under Policy Category, select Authentication Types from the list.

The policies for normal and enhanced security appear along with other authentication-related policies.

To change the authentication types policy

1.      Find the authentication policy to change.

2.      On the View Policy page, click Edit Policy.

An editable version of the settings appear.

Authentication methods can be in one of two lists (Included and Not Included). Buttons placed between the two lists allow you to move some or all options from one list to the other.

3.      Do one of the following to select authentication methods for the Normal Security Authentication Types and Enhanced Security Authentication Types:

●       To add grid authentication if not already included, select the Grid option in the Not Included list and click the right-arrow to move the option to the Included list.

●       To disable grid authentication if it is in effect, select the Grid option in the Included list and click the left-arrow to move the option to the Not Included list.

See Move items between option lists for detailed instructions on moving options between the Included and Not Included lists.

4.      Set the precedence of grid authentication for normal security, enhanced security, or both:

●       Select the Grid option in the Included list.

●       Click the up-arrow to move the Grid option up the list or click the down-arrow to move it lower in the list. Click the button once for each position you want the option moved.

See Set option precedence for more information about precedence.

5.      Change other settings as applicable. For a description of each setting, see Policies quick reference.

For information about setting the authentication types that can view or modify user secrets, see Configure access to user secrets.

6.      After you make your policy changes, click Save Changes.
