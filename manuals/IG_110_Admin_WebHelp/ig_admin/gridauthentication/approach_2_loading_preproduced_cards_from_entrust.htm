IdentityGuard Server 11.0 Administration Guide

Approach 2: Load preproduced cards from Entrust

If you have received pre-printed grid cards from Entrust, you must load the accompanying CSV file into Entrust IdentityGuard. When you load the CSV file, the digital versions of the printed grid cards are added to Entrust IdentityGuard. You can then assign the grids to users.

To load the CSV file into Entrust IdentityGuard

1.      Copy the CSV file to the Entrust IdentityGuard server.

2.      Open the Master User Shell and log in. (See Using the Master user shell.)

3.      Enter:

card create -import <filename>

where <filename> is the full name and path to the CSV file.

Example:

card create -import “c:/my cards/mygridcards.csv”

Your grid cards are now loaded into Entrust IdentityGuard. You can now assign them to users in Entrust IdentityGuard, and distribute the physical grids by mail or in person.
