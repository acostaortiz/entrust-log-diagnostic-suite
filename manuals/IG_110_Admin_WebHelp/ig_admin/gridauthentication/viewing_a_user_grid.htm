IdentityGuard Server 11.0 Administration Guide

View a user's grid card

You can authenticate a user by viewing the grid belonging to their card and asking what for the contents of grid cells you choose.

To view a user’s card grid

1.      Log in to the Administration interface (Logging in and out of the Administration interface).

2.      On the main menu, click User Accounts.

3.      Find a specific user. See Finding users.

4.      Under Authentication Types, click Cards.

5.      Click View Card Grid.

The Card Grid page appears.

6.      Ask the user the contents of specific cells, such as C4 and H2. If a user provides the correct answers, this verifies their identity.
