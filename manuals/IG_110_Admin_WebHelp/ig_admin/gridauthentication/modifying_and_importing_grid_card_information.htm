IdentityGuard Server 11.0 Administration Guide

Modify and import grid card information

Complete one of the following procedures to modify the grid card information:

●       To modify assigned grid card information 

●       To modify assigned grid cards for multiple users using bulk operations

To modify assigned grid card information

1.      Log in to the Administration interface (see Logging in and out of the Administration interface).

2.      On the main menu, click User Accounts.

3.      Find a specific user in one of two ways:

●       Use the Go To Account tab (see To search for information about one user).

●       Use the Find Accounts tab (see To search for information about one or more users).

4.      Under Authentication Types, click Cards.

5.      Select the grid card you want to edit, then click Edit Card.

The Edit Card page appears.

6.      On the Edit Card page, you can change:

●       the grid card state by selecting a state from the State drop-down list (see Grid card state overview)

●       (if applicable) when the grid card becomes superseded, by selecting one of the following options in the Superseded Date drop-down list

–  Card will not be superseded

The grid card cannot be superseded.

–  Set supersede lifetime

Choose how long the grid card can be used until it becomes superseded. Type a number in the text field, then select a time value from the drop-down list (hours, days, or years) from the drop-down list.

–  Set Supersede Date

Choose a specific date and time when the grid card becomes superseded. Select a day from the drop-down lists (day, month, and year), then select a time from the Time drop-down lists (hours and minutes). Alternatively, you can click the calendar icon to select a date.

●       when the grid card expires, by selecting one of the following options in the Expiry Date drop-down list

–  Card Never Expires

No expiry date exists.

–  Set Card Lifetime

Choose how long the grid card can be used until it expires. Type a number in the text field, then select a time value from the drop-down list (hours, days, or years).

–  Set Card Expiry Date

Choose a date and time when the grid card expires. Select a day from the drop-down lists (day, month, and year), then select a time from the Time drop-down lists (hours and minutes). Alternatively, you can click the calendar icon to select a date.

●       the comments for the grid card by typing your comments in the Card Comments box

7.      Click Save Changes.

To modify assigned grid cards for multiple users using bulk operations

1.      Create a bulk file (see Creating and editing bulk files).

2.      Log in to the Administration interface (see Logging in and out of the Administration interface).

3.      On the main menu, click Bulk Operations.

The Bulk Operations page appears.

4.      Click the Bulk Operation tab.

5.      Click the Browse button to locate the bulk file.

6.      In the Operation to Perform drop-down list, select Modify user cards.

7.      From the Halt Processing drop-down list, select the number of errors to allow before processing stops due to too many errors.

For more information about bulk file options, see Performing bulk operations in the Administration interface.

8.      Click Perform Bulk Operation.

The Bulk Operation in Progress page appears. The size of your bulk operation directly affects the time the operation takes to process. This page indicates the initial status of the operation.

9.      Optional. While Entrust IdentityGuard processes the bulk file, you can do the following:

●       To view the current status of the bulk operation, click Update Results. (The Results page is also updated automatically every 10 seconds.)

●       To cancel the bulk operation, click Cancel Operation.

Note: If you cancel a bulk operation, Entrust IdentityGuard keeps all changes it made while it processed the bulk file. You cannot undo a bulk operation. See Limitations of bulk operations for more information.

When Entrust IdentityGuard completes the bulk operation, the Results page appears.

10.  Click Done.
