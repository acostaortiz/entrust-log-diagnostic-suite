IdentityGuard Server 11.0 Administration Guide

Supported wireless authentication protocols

Entrust IdentityGuard supports the following EAP protocols through the Radius proxy:

●       EAP-GTC

●       EAP-MSCHAPv2

Not all Entrust IdentityGuard authentication methods are available through the Radius proxy for these protocols. The following table lists the authentication methods and protocols that are supported through the Radius proxy for wireless authentication.

Note: Not all clients can display the challenge message sent by the Radius proxy. Do not configure grid, token (challenge-response mode), or knowledge-based authentication if your wireless access clients cannot display challenge messages.
