Using Entrust IdentityGuard groups with a VPN server

To associate one or more VPN servers with one or more specific groups, you need to define a VPN server instance on the VPN Server Configuration pane for each VPN group you want to pair with an Entrust IdentityGuard group. Then you need to set specific properties on that pane and the Radius Proxy Configuration pane.

The key properties related to groups are:

1.      In the Radius Proxy Configuration pane:

●       In the Radius Proxy Port field, enter a list of Radius ports. Enter one port number for each VPN server you want to associate with individual groups.

2.      On the VPN Server Configuration pane, create a separate instance for each VPN server and then set the following properties as applicable:

●       In the VPN Host field, enter the VPN server host. You can use the same VPN host for different groups. The instance name and the group name differentiate them.

●       In the Radius Proxy Port Used By VPN field, type the Entrust IdentityGuard Radius port to be used by that VPN server. This associates a port with the group.

●       In the Entrust IdentityGuard User Group field, enter the Entrust IdentityGuard group name you want associated with that VPN server.

Note: You do not have to specify a group name to configure a VPN server for the Radius proxy. By not specifying group names in the Entrust IdentityGuard User Group field of the VPN Server Configuration pane, your VPN server configuration applies to all groups not explicitly associated with a VPN server. (See also Matching a group to a user.)

●       If you are using a Radius server for first-factor authentication, set Radius Proxy Removes Group for 3rd-party Radius to True so that the group is stripped out of the user ID before the request is forwarded to the Radius server.

Note: If set to True, this property works as intended only if group names do not include a backslash (\) or at-sign (@) character.

●       If your domain groups and Entrust IdentityGuard groups do not match, set Radius Proxy Removes Group for IdentityGuard to True so that the Radius proxy strips the group out of the user ID before the request is forwarded to Entrust IdentityGuard server.

If set to True, the VPN server must use the PAP protocol, and user names in Entrust IdentityGuard must be unique across all Entrust IdentityGuard groups

Note: If set to True, this property works as intended only if group names do not include a backslash (\) or at-sign (@) character.

●       Under First-Factor Authentication Server, select the method of first-factor authentication to apply to users in this group.

●       If your first-factor authentication resource is a Radius server, select the name of the server from the Radius Server drop-down list.

3.      You can configure Entrust IdentityGuard to return the Active Directory or LDAP group (and other attributes) with the Radius response upon successful authentication. See Configuring the Radius response attributes.
