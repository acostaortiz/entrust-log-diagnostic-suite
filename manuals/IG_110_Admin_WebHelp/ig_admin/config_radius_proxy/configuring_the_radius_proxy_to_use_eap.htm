IdentityGuard Server 11.0 Administration Guide

Configuring the Radius proxy to use EAP

Complete the following procedure to configure the Entrust IdentityGuard Radius proxy to use the EAP protocol for wireless communication with the wireless access point.

To configure the Radius proxy for wireless support

1.      Install and configure your wireless access point, configuring the Radius proxy as a Radius server.

For detailed integration instructions specific to your platform, see the Technical Integration Guide that applies to your wireless access point.

2.      When adding a VPN Server to the Radius proxy (see Configuring the Radius proxy for VPN servers), configure the following properties:

a.      Set the Use EAP for Authentication property to True.

b.      Set the Type of EAP Protocol Supported property to either PEAPv0 with MS-CHAPv2 or PEAPv1 with EAP-GTC. For more information on these protocols, see Supported wireless authentication protocols.
