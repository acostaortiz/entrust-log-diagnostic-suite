IdentityGuard Server 11.0 Administration Guide

Token challenge string

The syntax and default content for the Default Token Challenge Message property is:

Enter

Enter{3, choice, 0#| 1# your PVN and}

{4, choice, 0# a response from your token| 1# your temporary PIN}

{5, choice, 0#|1# with serial number {0} or {1} or your temporary PIN|2# with serial number {0} or {1}|3# with serial number {0} or your temporary PIN|4# with serial number {0}|5# with a serial number from the list {8} or your temporary PIN|6# with a serial number from the list {8}}

{7, choice, 0#|1# using the token challenge {2}}

{6, choice, 0#.|1# and update your PVN twice in succession}{9,choice, 0#|1# (PVN size: {9})}.

Table 59: Parameters and values for token challenge strings

Parameter

Value

Description

{0}

serial number

The serial number of the user's current token.

{1}

serial number

The serial number of the user's pending token, if there is one.

{2}

token challenge

The challenge to be answered for challenge-response tokens.

{3}

0

A PVN is not required for authentication.

1

A PVN is required for authentication.

{4}

0

A token is available for authentication. There may also be a temporary PIN.

1

Only a temporary PIN is available for authentication.

{5}

0

Only a temporary PIN is available for authentication.

1

Authentication can take place with a current or pending token or a temporary PIN.

2

Authentication can take place with either a current or pending token.

3

Authentication can take place with only one token, either current or pending, or a temporary PIN.

4

Authentication can take place with only one token, either current or pending.

5

The user has more than two tokens and a temporary PIN

6

The user has more than two tokens and does not have a temporary PIN

{6}

0

If a PVN is required for authentication, it does not need updating.

1

If a PVN is required for authentication, it requires updating.

{7}

0

A challenge-response token is not being used for authentication.

1

A challenge-response token is being used for authentication.

{8}

Not applicable

A dynamically generated comma-separated list of token serial numbers assigned to the user. Only tokens in the current and pending states are displayed.

{9}

0

If a PVN does not require updating, nothing is shown.

 

1

If a PVN is required or it must be changed, show the required PVN size.
