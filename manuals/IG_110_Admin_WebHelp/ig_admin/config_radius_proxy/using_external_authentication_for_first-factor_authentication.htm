Using external authentication for first-factor authentication

In this example, assume you want to set up an LDAP directory to provide first-factor authentication for one VPN instance, SalesVPN. And you want to a domain controller to provide first-factor authentication for another VPN instance, MarketingVPN. These groups are again paired with two Entrust IdentityGuard user groups, IGSales and IGMarketing. In this scenario, the relevant settings would look like this:

●       Radius Proxy Configuration pane

–  Radius Proxy Port: 1812 1813

●       first VPN configuration instance on the VPN Server Configuration pane

–  Configuration Instance: salesVPN

–  Radius Proxy Port Used By VPN: 1812

–  VPN Host: 10.12.1.1

–  VPN Shared Secret: xyz76#r

–  Entrust IdentityGuard User Group: IGSales

–  First-Factor Authentication Server: External

●       External First-Factor Authentication pane set up for an LDAP directory

–  Configuration Instance: IGSales

–  External First-Factor Authentication Method: LDAP External Authentication

●       second VPN configuration instance on the VPN Server Configuration pane

–  Configuration Instance: marketingVPN

–  Radius Proxy Port Used By VPN: 1813

–  VPN Host: 10.12.1.1

–  VPN Shared Secret: xyz76#r

–  Entrust IdentityGuard User Group: IGMarketing

–  First-Factor Authentication Server: External

●       External First-Factor Authentication pane set up for a domain controller

–  Configuration Instance: IGMarketing

–  External First-Factor Authentication Method: Domain Controller External Authentication

–  Kerberos Realm for Domain Controller Authentication: ENTRUST.COM

Also, if you are using a domain controller, you must map each realm to its KDC in the igkrb5.conf file. For more information, see Configuring external authentication for a domain controller.

When you give an external authentication configuration instance a name, other than the default, Entrust IdentityGuard treats the instance name as a group name.

When you use the default configuration, the property creates a default entry for all users who are not directed to a specific group. For more details, see Using groups with external authentication.
