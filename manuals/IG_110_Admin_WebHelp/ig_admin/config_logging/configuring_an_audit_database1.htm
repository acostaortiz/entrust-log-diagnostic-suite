IdentityGuard Server 11.0 Administration Guide

Configuring an audit database

By default Entrust IdentityGuard audits are written to syslog or to files, but you can also write the audits to a database for reporting later, and you can administer the audits in the database using properties that you can set up and edit in the Properties Editor.

The audit data is available for reporting as well, either from the Administration interface, or from the Master user shell.

Note: If your Entrust IdentityGuard installation uses a JDBC repository, you can use your existing repository for storage of audits, or you can set up a new JDBC database specifically for your audit data.
If your Entrust IdentityGuard installation uses an LDAP repository, then you must install and configure a JDBC repository for your audit data.

An audit database entry includes the fields shown in the following table.

Field name

Description

seqNo

The audit sequence number. The sequence number is incremented for each audit added.

date

The date the audit was generated.

host

The host of the Entrust IdentityGuard administration service that generated the audit.

level

INFO, WARNING, or ERROR.

code

The numeric code of the audit. AUD5300 is entered in the database as 5300, for example.

adminGroup

The group of the administrator performing the operation.

adminName

The name of the administrator performing the operation.

targetType

The type of the target of the operation. Examples are USER and MASTER.

targetOp

The operation performed on the target. Examples are CREATE and DELETE.

targetGroup

The Entrust IdentityGuard group the target belongs to.

targetName

The name of the target of the operation.

targetSubname

The subname of the target of the operation. If targetName is the name of a user with a token, for example, then the targetSubname is the token serial number.

service

SUPERSH, ADMINSERVICE, AUTHSERVICE, ADMININTERFACE, IGRADIUS, PROPERTIESEDITOR

externalCode

The application code of the external application.

externalService

The service name of the external application.

text

The explanation text from the audit.
