IdentityGuard Server 11.0 Administration Guide

Setting general logging properties

You can change the defaults that Entrust IdentityGuard uses to define loggers (the type and level of messages to be logged), to set the appenders (where the logs are to be written), and to configure the layouts (the format used for writing the logs).

The message level of each of the three loggers can be set to one of ALL, DEBUG, INFO, WARN, ERROR, FATAL and OFF, where ALL produces the most messages and FATAL the least. The message level sets the lowest level of message to log; for example, WARN provides messages of WARN, ERROR and FATAL status. Select OFF to stop all messages from the applicable logger.

To change general logging properties

1.      Start the Entrust IdentityGuard Properties Editor. (See Logging in and out of the Properties Editor.)

2.      On the Table of Contents, click General Logging Configuration.

3.      To set how often Entrust IdentityGuard should check for new log settings, type the number of seconds in the Logging Configuration Refresh Interval field. The default is 10 seconds.

4.      To set the number of stack frames that are logged for errors, type a number in the Logging Stack Trace Size field. The default setting of 0 means that no stack trace is logged.

5.      Use the Base Logger Messages Also Go to Root Logger to route log messages not included in the audit logs and the system logs to go to the root as well as the base logger.

6.      Use the Audit Logger Configuration property to define the logging level of the audit logger, and to set the destination of any messages logged by the audit logger. This property takes two values as listed in the paired drop-down lists: one for the message level and one for destination of logging messages. The default is: ALL, AUDIT_FILELOG. The logging message level should never need to be changed from its default of ALL, and the destination is either AUDIT_SYSLOG or AUDIT_FILELOG.

7.      Use the System Logger Configuration property to define the logging level of the system logger, and to set the destination of any messages logged by the system logger. This property takes two values as listed in the paired drop-down lists: one for the message level and one for destination of logging messages. The default level is WARN. This default is set during configuration of Entrust IdentityGuard. (The destination can be SYSTEM_SYSLOG and SYSTEM_FILELOG if you edit the properties file manually.)

8.      Set the Audit Logger Messages Also Go to Base Logger property to True if Entrust IdentityGuard audits should also be added to the base logger. The default is False.

9.      Set the System Logger Messages Also Go to Base Logger property to True if Entrust IdentityGuard audits should also be added to the base logger. The default is False.

10.  Click Validate & Save.
