IdentityGuard Server 11.0 Administration Guide

Log file example

Entrust IdentityGuard logs describe events that occur while the system is running. You can configure logging behavior using the log file settings in the Properties Editor. For more information about logging properties, see General Logging Configuration, Audit Logging Appenders, and System Logging Appenders. You can view the log on your screen or print it as a text file.

The following illustrates a sample log in syslog format on UNIX:

Apr 21 11:56:04 localhost [main] [ERROR] [IG.AUDIT] [AUD110] Administration service startup failed.

Apr 21 11:53:22 localhost [main] [ERROR] [IG.SYSTEM.INITIALIZER.Administration] [RepositoryConfig:Loading property file from /opt/entrust/identityguard93/etc/identityguard.properties] FAILED

Apr 21 11:53:22 localhost [5202046] Cannot initialize cryptographic services because no password or key protection data is available. (Ref:31056583)
