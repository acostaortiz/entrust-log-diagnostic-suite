Repository Proxy to Authentication Service Connection Failure

(AUD150)

ERROR

Yes

Failed to connect to repository {0} with URL: {1}

Where:

·      {0} is the name of the repository.

·      {1} is the URL to the repository.

High Availability Repository Failover

(AUD151)

WARN

Yes

Repository {0} connection failed to URL {1} switching to URL {2}.

Where:

·      {0} is the name of the repository.

·      {1} is the URL to the repository that failed to connect.

·      {2} is the next URL that Entrust IdentityGuard will use to connect to the repository.

High Availability Primary Repository Restored

(AUD152)

INFO

Yes

The primary connection has been restored for repository {0} to URL {1}.

Where:

·      {0} is the name of the repository.

·      {1} is the URL to the repository.

High Availability Connection Failure

(AUD153)

ERROR

Yes

Failed to establish a connection to any supplied URLs for repository {0}.

Where {0} is the name of the repository.

Connection Pool Exhausted

(AUD154)

WARN

Yes

Failed to obtain a connection to repository {0} from the connection pool due to pool exhaustion.

Where {0} is the name of the repository.

Connection Pool 80 Percent Used

(AUD155)

WARN

Yes

Connection pool to repository {0} is 80 percent used.

Where {0} is the name of the repository.
