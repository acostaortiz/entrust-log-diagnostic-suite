Audits filter

You can specify a subset of audits to write to the database, if you do not want them all, using the Audit Database Filter property.

Enter a list of audit codes or code ranges to write to the database, separated by commas. All audits that match any one of the specified filter values are written to the database. If you do not specify a filter value, all audits are written to the database.

The following table shows sample acceptable entries for the Audit Database Filter property.

Audit filter entry

Means:

-100

all audit codes <= 100 are written to the database

200-300

all codes between 200 and 300 inclusive

1000-

all audit codes >= 1000

-100, 200-300,1000-
