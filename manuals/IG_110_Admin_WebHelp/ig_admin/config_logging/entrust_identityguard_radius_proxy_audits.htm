IdentityGuard Server 11.0 Administration Guide

Entrust IdentityGuard Radius proxy audits

These messages provide information related to the Entrust IdentityGuard Radius proxy.

 

Audit name

Log level

Default SNMP trap?

Event description

Invalid Radius Message Received

(AUD7500)

ERROR

Yes

The Entrust IdentityGuard Radius Proxy received an invalid Radius message from {0}.

Where {0} is the address of the client that sent the bad message.

Radius Server Address Has Changed

(AUD7501)

ERROR

Yes

The Entrust IdentityGuard Radius Proxy has switched the address for Radius server {0} to {1}.

Where:

·      {0} is the name of the Radius server.

·      {1} is the new address.

Too Many Outstanding Requests For Radius Proxy

(AUD7502)

ERROR

Yes

The Entrust IdentityGuard Radius Proxy has too many outstanding requests.

No Response From Radius Server

(AUD7503)

ERROR

Yes

The Entrust IdentityGuard Radius Proxy timed out waiting for a response from a Radius server {0} for an authentication request for user {1}.

Where:

·      {0} is the name of the Radius server.

·      {1} is the user performing authentication.

Radius Proxy Skipped Second Factor Authentication

(AUD7504)

INFO

 

User {0} skipped second-factor authentication in Entrust Radius Proxy because the user does not exist or does not have active credentials.

Where {1} is the user performing authentication.

Radius Server Rejected Authentication

(AUD7505)

INFO

 

The Radius server {0} rejected authentication for user {1}.

Where:

·      {0} is the name of the Radius server.

·      {1} is the user performing authentication.

Radius Server Accepted Authentication

(AUD7506)

INFO

 

The Radius server {0} accepted authentication for user {1}.

Where:

·      {0} is the name of the Radius server.

·      {1} is the user performing authentication.

Authentication Forwarded to Displaced Server

(AUD7507)

INFO

 

Authentication for user {1} has been forwarded to the displaced server {0}.

Where:

·      {0} is the name of the displaced Radius server.

·      {1} is the user performing authentication.

Invalid Radius Configuration

(AUD7510)

ERROR

 

Entrust IdentityGuard Radius has invalid configuration.

Authorization Failure

INFO

 

User {0} is not authorized to access vpn {1}.

Where:

·      {0} is the user performing authentication.

·      {1} is the name of the VPN server.
