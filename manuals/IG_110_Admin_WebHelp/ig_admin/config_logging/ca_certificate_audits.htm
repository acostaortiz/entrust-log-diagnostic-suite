CA certificate audits

These messages provide information about Certification Authority (CA) certificates.

 

Audit name

Log level

Default SNMP trap?

Event description

CA Certificate Loaded

(AUD8010)

INFO

 

CA Certificate {0} has been loaded. {1}

Where:

·      {0} is the name of the CA certificate.

·      {1} is the certificate details.

CA Certificate Deleted

(AUD8011)

INFO

 

CA Certificate {0} has been deleted.

Where {0} is the name of the CA certificate.

CA Certificate Updated

(AUD8012)

INFO

 

CA Certificate {0} has been updated. {1}

Where:

·      {0} is the name of the CA certificate.

·      {1} is the certificate details.
