IdentityGuard Server 11.0 Administration Guide

User card audit messages

These messages provide information about users’ grid cards.

 

Audit name

Log level

Default SNMP trap?

Event description

User Card Created

(AUD2000)

INFO

 

Card {1} has been created for user {0}. {2}

Where:

·      {0} is the user ID.

·      {1} is the card serial number.

·      {2} is the list of arguments set for the user card.

User Card Superseded

(AUD2001)

INFO

 

Card {1} for user {0} has been superseded by card {2}. {3}

Where:

·      {0} is the user ID.

·      {1} is the serial number of superseded card.

·      {2} is the serial number of new card.

·      {3} is the list of arguments for the supersede operation including the supersede date.

User Card Deleted

(AUD2002)

INFO

 

Card {1} for user {0} has been deleted.

Where:

·      {0} is the user ID.

·      {1} is the card serial number.

User Card Updated

(AUD2003)

INFO

 

Card {1} for user {0} has been updated. {2}

Where:

·      {0} is the user ID.

·      {1} is the serial number of the user card.

·      {2} is the list of arguments for the user card.

User Card Unassigned

(AUD2004)

INFO

 

Card with serial number {1} for user {0} has been unassigned. {2}

Where:

·      {0} is the user ID.

·      {1} is the serial number of user card.

·      {2} is the list of arguments for the user card.
