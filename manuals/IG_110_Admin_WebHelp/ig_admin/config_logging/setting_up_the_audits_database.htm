IdentityGuard Server 11.0 Administration Guide

Setting up the audits database

Entrust IdentityGuard allows you to set up a database specifically for storing audit data. Set up the database in the Properties Editor in the JDBC category. See JDBC Database Settings for more detail. Then set up and enable the audit database, also in the Properties Editor, in the Audits to Database Configuration category. See Biometric Vendor Configuration for details.

Note: You cannot log audits to an LDAP repository. If your Entrust IdentityGuard deployment uses an LDAP repository, you must configure a JDBC database to which to write the system audits.

Set up your audit database starting with the Audit Database Name. The Entrust IdentityGuard Properties Editor shows all of the currently configured databases (all those configured using the JDBC properties as mentioned above). Choose one from the drop-down list. If no name is selected, audits are not written to a database, and the rest of the audit properties listed below are disabled.

Then change the Write Audits to Database property to True. These two properties, the Audit Database Name property and the Write Audits to Database property are the minimum required for setting up an audit database.
