IdentityGuard Server 11.0 Administration Guide

User digital ID audits

These messages provide information about user digital IDs.

 

Audit name

Log level

Default SNMP trap?

Event description

User Digital ID Created

(AUD2450)

INFO

 

Digital Id {0} has been created for user {1}. {2}

Where:

·      {0} is the distinguished name of the digital ID.

·      {1} is the user ID.

·      {2} is a list of arguments set for the digital ID.

User Digital ID Recovered

(AUD2451)

INFO

 

Digital Id {0} has been recovered for user {1}. {2}

Where:

·      {0} is the distinguished name of the digital ID.

·      {1} is the user ID.

·      {2} is a list of arguments set for the digital ID.

User Digital ID Deleted

(AUD2452)

INFO

 

Digital Id {1} for user {0} has been deleted.

Where:

·      {0} is the user ID.

·      {1} is the distinguished name of the digital ID.

User Digital ID Updated

(AUD2453)

INFO

 

Digital Id {1} for user {0} has been updated. {2}

Where:

·      {0} is the user ID.

·      {1} is the distinguished name of the digital ID.

·      {2} is a list of arguments set for the digital ID.

User Digital ID Canceled

(AUD2454)

INFO

 

Digital Id {1} for user {0} has been canceled. {2} certificates revoked.

Where:

·      {0} is the user ID.

·      {1} is the distinguished name of the digital ID.

·      {2} is the number of certificates that were revoked.

User Digital ID Hold

(AUD2455)

INFO

 

Digital Id {1} for user {0} has been put on hold. {2} certificates put on hold.

Where:

·      {0} is the user ID.

·      {1} is the distinguished name of the digital ID.

·      {2} is the number of certificates that were put on hold.

User Digital ID Unhold

(AUD2456)

INFO

 

Digital Id {1} for user {0} has been removed from hold. {2} certificates removed from hold.

Where:

·      {0} is the user ID.

·      {1} is the distinguished name of the digital ID.

·      {2} is the number of certificates that were taken off hold.

User Digital ID Cancel Failed

(AUD2457)

ERROR

 

Error trying to cancel digital id {1} for user {0}.

Where:

·      {0} is the user ID.

·      {1} is the distinguished name of the digital ID.
