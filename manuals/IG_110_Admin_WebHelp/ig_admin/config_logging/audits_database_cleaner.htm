IdentityGuard Server 11.0 Administration Guide

Audits database cleaner

Your audit database will get large very quickly, especially if your filter is set to write all or most of the audits generated to your database.

To administer your database for best performance, you should plan on removing the oldest audit data records at regular intervals. You can set the system to automatically delete old audit records from your database by enabling the cleaner in the Properties Editor. You can also set the maximum age of audit records, and how often to check for and delete old audit records.

Entrust IdentityGuard properties for cleaning the audit database include those shown in the following table.

Cleaner property

What it does:

Audit Removal Enabled

Turns on the automatic audit record cleaner. Set this property to True if you want to automatically delete records older than the age specified.

If you do not turn on the cleaner by setting this property to True, then the rest of the properties in this table are unavailable in the Properties Editor.

Audit Removal Interval

This is the interval between automatic checks for old audit records.

The default interval if you do not set one is 24 hours.

Audit Removal Age

This is the age, in days, of the oldest records you want kept in the audit database.

If you do not specify, the default age is 180 days, or approximately 6 months.

Audit Removal Export Enabled

Turns on exporting to a file when audits are removed from the database.

Audit Removal Export Directory

When you delete the old audit records from your database, Entrust IdentityGuard archives them. You can delete them later, when you are sure you do not need them.

This property is the path name of the directory to which the deleted audit records are exported.

If you do not specify a path, Entrust IdentityGuard exports the deleted records to <$IG_HOME>/export/audits.
