IdentityGuard Server 11.0 Administration Guide

Configure biometric policies

You can set the biometrics policies in the Administration interface.

To configure biometrics policies

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

Log in as a user with a role that includes these permissions: policyGet, and one of policyCreate, or policySet. See Policy permissions for details.

2.      Select Policies on the menu bar.

A list of all policies appears on the List Policies tab.

3.      Click any policy name (default, for example) to view its policy information.

The View Policy page for the selected policy appears.

4.      Under Policy Category, select Biometric from the list.

The biometric policies appear.

5.      Click Edit Policy.

An editable version of the settings appears.

6.      Edit the policies as required. Select a policy in the list to see its description.

Allow All Biometric Vendors

Select this option to allow all biometric vendors to be available for all users whose group is associated with this policy.

Clear this option if you want to use only specific biometric vendors you select in the Allowed Biometric Vendors list.

Note: Currently, only one biometric vendor is supported for each Biometrics license.

Default: Yes

Allowed Biometric Vendors

Specifies all the biometric vendors that can be assigned to a user.

Note: Currently, the only supported biometric vendor is Cogent.

Default: no default

Maximum Biometric Data Size (bytes)

Specifies the maximum size in bytes allotted for a user’s biometric data.

Default: 40,000 bytes

Requires Admin Activation After Enroll

If you select this option, when an end user enrolls or updates biometric data, the biometric is put into the inactive state. This allows the administrator to complete any required process steps before the biometric is changed to the active state, after which it can be used for authentication.

Default. No

7.      Click Save Changes.

The View Policy page reappears.

Return to Worksheet for configuring biometric authentication for additional configuration steps in Entrust IdentityGuard Self-Service Module.
