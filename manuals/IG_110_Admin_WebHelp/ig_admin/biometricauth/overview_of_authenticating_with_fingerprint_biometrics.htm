IdentityGuard Server 11.0 Administration Guide

Overview of authenticating with fingerprint biometrics

When a user has the Entrust IdentityGuard Desktop client installed, biometric authentication works as follows:

1.      A user, Alice, logs in to her Windows computer using first factor authentication.

2.      At the login screen, Alice sees the following image, indicating that fingerprint authentication is required.

3.      Alice places one of the fingers she enrolled previously with the enrollment client on the fingerprint scanner attached to her computer.

4.      One of the following happens:

●       Entrust IdentityGuard checks that her fingerprint matches the enrolled fingerprint.

●       If for some reason Alice’s fingerprint does not match the enrolled fingerprint, Alice is presented a different second factor challenge (grid or token).

●       If Alice’s computer is offline (not connected to the network), Alice is presented with a question and answer challenge.

5.      Alice is granted access to the computer.
