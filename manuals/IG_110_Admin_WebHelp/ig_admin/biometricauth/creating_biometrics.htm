IdentityGuard Server 11.0 Administration Guide

Creating biometrics

Biometrics are created by users using a fingerprint scanner and the fingerprint enrollment software provided as part of the Entrust IdentityGuard Desktop for Microsoft Windows application. As part of the installation of the fingerprint enrollment clients, users are directed to your Self-Service website to launch the fingerprint enrollment client and enroll fingerprint biometric data with Entrust IdentityGuard.

For information about enabling biometric enrollment in Self-Service, see the Entrust IdentityGuard Self-Service Module Installation and Configuration Guide.

For information about how users enroll their fingerprints using the enrollment client, see the Entrust IdentityGuard Desktop for Microsoft Windows Administration Guide for Windows Login.

Administrators can create biometric metadata using the Create Biometric command in the Administration interface or the user biometric create command in the Master User Shell, but the actual fingerprint data must be created using the fingerprint enrollment client and a fingerprint scanner.
