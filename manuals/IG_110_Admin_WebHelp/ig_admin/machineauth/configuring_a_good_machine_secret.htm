Configuring a good machine secret

The policy choices you make regarding the machine nonce, sequence nonce, and application data have a direct impact on the security level the machine secret provides.

The following section explains three distinct ways that you can configure the various machine secret policies to suit your security needs and the realities of your client application. Each scenario supplies a different level of authentication security, and within these three scenarios, your settings for the amount of application data to use and the amount of bad application data to allow further defines the security level.

Attention: You must have a number greater than 0 in the Total Maximum Size in Kilobytes policy (Machine Secret). If this number is zero, you cannot store any authentication data and machine authentication will effectively be disabled.
