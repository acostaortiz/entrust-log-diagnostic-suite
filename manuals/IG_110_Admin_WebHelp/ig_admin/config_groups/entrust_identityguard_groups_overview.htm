IdentityGuard Server 11.0 Administration Guide

Entrust IdentityGuard groups overview

An Entrust IdentityGuard group is a collection of users to which an administrator can apply the same policy, features, authentication methods, and restrictions.

After installation, Entrust IdentityGuard has a single default group. If administrators do not specify a group when they create user accounts, tokens or cards, Entrust IdentityGuard assumes they belong to the default group.

If your implementation includes Entrust IdentityGuard Self-Service Module, a group called samplegroup is also present.

An Entrust IdentityGuard group contains the following information:

●       a unique name

●       a default flag, if this group is the default

●       an associated policy that applies to users, administrators, tokens, and grid cards in the group

●       a list of repositories that determines where the user information is stored

●       a repository where preproduced cards are stored

●       a repository where unassigned tokens are stored

●       the name of the partitions assigned to this group

You do not need to explicitly assign users to groups. They can all belong to the default group, but assigning users to different groups allows for different treatment of different users.
