IdentityGuard Server 11.0 Administration Guide

Matching a group to a user

You must have a way to uniquely identify each user in the IdentityGuard system, so each user must have a unique combination of group/user name. If you have two John Smiths, for example, they must be in different groups.

For user names that are unique to the whole system, you do not need to specify the group name when referring to the user.

When Entrust IdentityGuard needs to verify a user and that user is not specifically identified with a group, Entrust IdentityGuard tries to match the user with the correct group following these rules:

●       Search the repositories for all users with the given user name.

For an LDAP directory, look in all search bases.

●       If no matching user name is found, return an error.

●       If one unique user entry is found, use that entry.

●       If multiple entries are found with the same user name, return an error.

When Entrust IdentityGuard has group information for a user, Entrust IdentityGuard tries to match the user with the correct group following these rules:

●       Find the list of repositories assigned to the group.

●       If the repository is found, search the repository associated with the group.

●       If no entry is found, return an error.

●       If one unique entry is found, use that entry.

●       If the list is empty, search for the user in the default repository.

●       If no entry is found, return an error.

●       If one unique entry is found, use that entry.

●       If multiple entries are found with the same user name, return an error.
