Managing the Entrust IdentityGuard certificate

During the Entrust IdentityGuard installation, a self-signed certificate is created. This certificate is used to enable a secure SSL connection between the Entrust IdentityGuard server and its clients, such as users’ browsers and the Self-Service Module.

You may want to:

●       switch the certificate to a CA-signed certificate. A CA-signed certificate is more secure than a self-signed certificate, and browsers implicitly trust it.

●       update the certificate if it is approaching expiry.

●       update the certificate with a new DN. A new DN is required if you change the host name of the Entrust IdentityGuard server.

●       change the key size or lifetime of the certificate. The default key size is 1024.

●       export the certificate from the system. An export is only required if you have lost the original certificate file. Exporting the certificate places all relevant certificate information in a CER or CRT file for easy transfer to Entrust IdentityGuard clients who need it to enable SSL.

For instructions, see the Entrust IdentityGuard Installation Guide.
