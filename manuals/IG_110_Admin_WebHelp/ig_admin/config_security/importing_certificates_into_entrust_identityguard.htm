IdentityGuard Server 11.0 Administration Guide

Importing certificates into Entrust IdentityGuard

To enable SSL, you may be instructed to import a certificate into Entrust IdentityGuard.

Note: The following procedure uses the Java keytool utility. For details on the keytool commands and options, see http://docs.oracle.com/javase/7/docs/technotes/tools/windows/keytool.html (Windows) or http://docs.oracle.com/javase/7/docs/technotes/tools/solaris/keytool.html (UNIX).

To import a certificate

1.      Copy the CA-signed certificate (.cer file) to the Entrust IdentityGuard server.

2.      Change to the keytool directory. Depending on your Operating System, the utility is located in one of these directories:

●       Windows: <$IG_HOME>\jre<version>\bin 

●       UNIX: $IG_HOME/jre<version>/bin 

3.      Import the certificate as follows:

keytool -importcert -alias <alias> -file <cert_file> -keystore <path_to_keystore> -storepass entrust

Where:

●       <alias> is tomcat if the certificate you are importing is the Entrust IdentityGuard server certificate. For all other certificates, choose a descriptive alias. For example, if you are importing the Self-Service Module’s certificate, you can use igssm as your alias or if importing the Print Module certificate, you can use igpm.

●       <cert_file> is the full path and file name of your certificate.

●       <path_to_keystore> is <$IG_HOME>\etc\keystore (Windows) or $IG_HOME/etc/keystore (UNIX).

Example:

keytool -importcert -alias tomcat -file c:\igssm.cer -keystore "c:\Program Files\Entrust\IdentityGuard\identityguard110\etc\keystore" -storepass entrust

4.      If asked whether you want to trust the certificate, enter yes.

5.      Restart the IdentityGuard server:

You have now imported a certificate.
