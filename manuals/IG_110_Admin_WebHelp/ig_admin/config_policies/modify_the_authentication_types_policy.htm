IdentityGuard Server 11.0 Administration Guide

Modify the Authentication Types policy

 

To set the authentication types policies for certificate authentication

Note: Perform this procedure only if you are setting up explicit certificate authentication. You do not need to do  it if you are using certificate authentication as part of risk-based authentication.

1.      Log in to the Entrust IdentityGuard Administration interface as the administrator.

On the Windows computer where Entrust IdentityGuard is installed

●       Select Start > All Programs > Entrust > IdentityGuard > Administration Interface.

On UNIX or from a remote client

●       Enter the URL of your Administration interface web application in a Web browser. It has this form:

https://<hostname>:<port>/IdentityGuardAdmin

Where:

<hostname> is the host name you selected during configuration

<port> is the administration port you selected during configuration

If you cannot find the correct URL, see Locate your Administration interface URL.

2.      Click Policies.

3.      From the list of policies that appears on the List Results screen, select the policy to modify.

4.      On the View Policy screen, select Authentication Types from the Policy Category drop-down menu.

5.      Check that Certificate appears in the list of authentication types for Normal Security Authentication Types and Enhanced Security Authentication Types.

6.      If Certificate is not in the list, click Edit Policy.

7.      Select Certificate in the Not Included list.

8.      Click the right arrow between the Not Included and Included list boxes to move Certificate to the Included list box.

9.      Click Save Changes.
