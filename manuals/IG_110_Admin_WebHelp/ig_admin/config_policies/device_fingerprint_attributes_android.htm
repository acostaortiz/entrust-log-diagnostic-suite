Device fingerprint attributes Android

The table that follows lists the Android device attributes that can be used to create the device fingerprint for an Android mobile device. The table shows the default settings for the attribute characteristics. For descriptions of these characteristics, see Characteristics of device fingerprint attributes.

To collect and use these attributes for machine authentication or as part of risk-based authentication, you must create an application that gathers the attributes and passes them the Entrust IdentityGuard. For more information, see the Entrust IdentityGuard Device Fingerprint SDK Programming Guide.
