Setting passwords in bulk

Bulk files imported through the Bulk Operations pages of the Administration interface can create or change user passwords and password attributes. One field, userPassword, can contain the clear text password. Alternatively, any userPassword field can include the autogenerate command. When Entrust IdentityGuard encounters this command, it generates a random password. (See Autogenerated passwords.)

If the passwordName field is not included, the operation applies to the default password. When a user has multiple passwords, use the passwordName field to set or modify named passwords.

For example, consider the following bulk file snippet:

userid,passwordName,userPassword

user1,,Pa$$w0rD99

user1,ATM,1234

user1,Broker,Pa$$w0rD101

These bulk commands create three passwords for user1: a default password, a password named ATM, and a password named Broker.

For more information about bulk operations see Bulk operations in the Administration interface .
