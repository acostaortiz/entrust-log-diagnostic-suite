IdentityGuard Server 11.0 Administration Guide

Retrievable passwords

When you manually create or change any user’s password (including administrator’s passwords), you can choose to have the password retrievable.That means it is displayed on the Password pane for the administrator. Allowing display of the password makes it easy to communicate the new password to the target user.

An automatically generated password is always retrievable (displayed). In both cases, the retrievable version of the password only appears on the Password pane until the user or administrator authenticates using that password.
