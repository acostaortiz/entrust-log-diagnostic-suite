IdentityGuard Server 11.0 Administration Guide

Configuring repositories

Use this section to configure or reconfigure Entrust IdentityGuard repositories, and to take advantage of the common failover and high-availability feature.

This section contains the following topics:

●       Repository overview

●       Configuring an LDAP directory

●       Configuring a database

●       Enabling cached challenges

●       Specifying multiple repositories

●       Configuring repository failover

●       Using partitions

●       Running multiple load-balanced Entrust IdentityGuard servers

Attention: Ensure that you synchronize the backups of your LDAP directory or database repositories. Remember that any time you restore Entrust IdentityGuard from a backup, both the LDAP and database repositories must be restored as well. See the Entrust IdentityGuard Installation Guide for backup information.
