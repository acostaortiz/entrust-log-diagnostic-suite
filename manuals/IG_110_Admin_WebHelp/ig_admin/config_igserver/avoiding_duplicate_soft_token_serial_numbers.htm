IdentityGuard Server 11.0 Administration Guide

Avoid duplicate soft token serial numbers

To avoid duplicate soft token serial numbers in a multi-server system, there is no need to set up partitions. Instead, set up different token vendor configuration instances for each Entrust IdentityGuard system using the following procedure.

These instructions use Toronto and South America in the example.

To set up soft token vendors

1.      On the primary Entrust IdentityGuard server, create two soft token vendor configurations:

●       Call the first instance TorontoSoftToken.

●       Call the second instance SouthAmericaSoftToken.

For details on creating a soft token vendor configuration, see Configuring the soft token vendor.

2.      Configure the Entrust IdentityGuard Self-Service Module:

●       Configure the Toronto Self-Service Module to use the TorontoSoftToken configuration for the user group TorontoUsers.

●       Configure the South American Self-Service Module to use the SouthAmericaSoftToken configuration for the user group SouthAmericaUsers.

The result is that when users activate their soft tokens through the Self-Service site in either Toronto or South America, serial numbers are generated. The serial numbers from the TorontoSoftToken configuration will not overlap with the serial numbers from the SouthAmericaSoftToken configuration.

For details on configuring the Self-Service Module to use a particular soft token vendor with a particular group, see the Entrust IdentityGuard Self-Service Module Installation and Configuration Guide.
