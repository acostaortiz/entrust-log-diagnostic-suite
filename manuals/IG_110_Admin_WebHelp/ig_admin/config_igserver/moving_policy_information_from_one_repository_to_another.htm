IdentityGuard Server 11.0 Administration Guide

Move policy information from one repository to another

Policy information consists of any repository contents other than users, cards, and tokens, including:

●       global policy

●       policy definitions

●       group definitions

●       role definitions

●       partition definitions

●       IP blacklist

●       transaction certificates

The following procedure describes how to move policy information to another repository.

To move policy information from one repository to another

Attention: You MUST stop all Entrust IdentityGuard services before moving policy information to another repository. If you have multiple Entrust IdentityGuard systems running in a replica configuration, all services on all replicas must be stopped and all Master user shells on all replicas must be closed.

1.      Stop all Entrust IdentityGuard services.

2.      Log in to the Master user shell. See Using the Master user shell.

3.      Move policy information to a new repository. Enter: 

system set -policyRepository <dest_repository>

4.      Wait for this command to complete successfully.

5.      Restart the Entrust IdentityGuard services. 

6.      (Optional) Follow the instructions in Remove old repository definitions.
