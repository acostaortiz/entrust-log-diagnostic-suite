IdentityGuard Server 11.0 Administration Guide

Using the Master user shell

Most of your day-to-day administration tasks can be performed in the Administration interface as described in this guide. For some of the tasks you will perform less frequently, you must use the Master user shell. 

For more information about using the Master user shell commands and detailed descriptions of all the Master user shell commands, see the Entrust IdentityGuard Master User Shell Reference.

To start the Master user shell on UNIX

1.      Log in to the Entrust IdentityGuard server as the user who owns the Entrust IdentityGuard installation.

2.      Change to $IG_HOME (usually /opt/entrust/identityguard101).

3.      From $IG_HOME, source the environment settings file by typing:

. ./env_settings.sh

(Include a space between the two periods in the command.)

4.      To start the Master user shell, enter:

supersh

Copyright information and the Entrust IdentityGuard version number appear, followed by a command prompt.

To start the Master user shell on Windows

●       Click Start > All Programs > Entrust > IdentityGuard > Master User Shell.

Copyright information and the Entrust IdentityGuard version number appear, followed by a command prompt.

 

To log in to the Master user shell

1.      To log in to the Master user shell, enter:

login

2.      At the prompt, enter your user name (Master1, Master2, or Master3). User names are case-sensitive.

3.      At the prompt, enter your password. Passwords are case-sensitive.

Note: The Master user shell does not display your password as you type it.

Log out of the Master user shell whenever you have completed your session, or when leaving the Entrust IdentityGuard server unattended.

To log out of the Master user shell

1.      To log out of the Master user shell, enter:

logout

2.      To exit the Master user shell, enter:

exit

Note: You can also exit the Master user shell without typing the logout command.
