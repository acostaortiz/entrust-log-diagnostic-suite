Entrust IDaaS (Identity as a Service) - Guía de Troubleshooting Cloud & SSO

Referencia de Administración Cloud: Entrust Identity Cloud Tenant / SAML 2.0, OIDC & Push MFA

1. Troubleshooting SAML 2.0 & Aserción Expirada (SAML_RESPONSE_EXPIRED)

SAML_RESPONSE_EXPIRED Entrust IDaaS Cloud SSO

Significado del Log: La aserción de identidad SAML 2.0 emitida por el tenant de Entrust IDaaS fue rechazada por la aplicación del cliente porque la hora NotOnOrAfter caducó durante el tránsito de red.

Solución Inmediata:

  1. Sincronizar el reloj NTP del servidor con el estrato oficial.
  2. Aumentar la tolerancia de reloj (Clock Skew Tolerance) a 180 segundos en las opciones de SSO de la aplicación.

2. Autenticación Adaptativa Móvil & Push MFA (PUSH_NOTIFICATION_FAILED)

PUSH_NOTIFICATION_FAILED Identity Mobile Cloud MFA

Significado del Log: No fue posible entregar la notificación Push de segundo factor al dispositivo registrado del usuario.

Acción de Remediación: Re-enrolar el dispositivo o usar el OTP temporal generado por la aplicación móvil Entrust Identity.

3. Diagnóstico de RADIUS Cloud Gateway Proxy (RADIUS_PROXY_TIMEOUT)

RADIUS_PROXY_TIMEOUT OnPremise RADIUS Gateway

Significado del Log: El conector RADIUS local no obtuvo respuesta del servicio Cloud de Entrust IDaaS dentro del timeout especificado.

sudo systemctl status entrust-radius-gateway && journalctl -u entrust-radius-gateway -n 50
